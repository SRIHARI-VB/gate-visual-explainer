Topic and objective

TOPIC: Flip-flop conversion — building one type of flip-flop out of another by putting logic in front of the available device’s inputs. Given a host (the flip-flop you have) and a target (the behaviour you want), the answer is one Boolean equation for each input of the host, expressed in the target’s inputs and the present state Q.

LEARNING OBJECTIVE: State the characteristic table and the excitation table of SR, JK, D and T, and explain why the second is the first read backwards. Apply the four-step procedure to any ordered pair of types and produce the host input equations. Explain why a free entry in an excitation table is what makes a conversion cheap. Derive all twelve conversions and justify each gate count under a stated counting convention. Explain why only the D–T pair costs the same in both directions. Verify a conversion by simulating every row of the target’s domain, and say why a conversion into SR has six rows and not eight. Identify the wiring that looks like a conversion and is not.

GATE RELEVANCE: Class A — explicitly in the syllabus, under Section 2, “Design of combinational and sequential circuits”.

PREREQUISITES: the four characteristic tables and the SR forbidden state (Sequential Circuits); reading a truth table and minimising a two- or three-variable function (Boolean Algebra and Minimisation).

VISUALIZATION PLAN: twelve scenes. Four characteristic tables side by side, so the four types are visibly four ways of labelling the same four actions. The excitation tables derived by search, with the free entries highlighted, because the free entries are the currency of the whole topic. The four-step procedure as four cards. Then each conversion drawn as the equation it produces, with its gate count beside it, and finally the twelve-cell square with the cost of every direction. Every number on the canvas is read from the page’s own model.

I read this topic as one procedure and twelve answers. The procedure is: write the target’s table, read the host’s excitation table, minimise, then simulate. Prerequisites, precisely

Must already be comfortable with:

  • The four characteristic tables, and that SR at S = R = 1 has no defined next state. Sequential circuits.
  • Reading Q+ (the next state) as a function of the inputs and Q (the present state).
  • Minimising a two- or three-variable function from a truth table, by K-map or by algebra. Boolean algebra and minimisation.
  • That a complemented signal costs a gate unless something already supplies it.

Helpful, not required: the sequential-circuits lesson’s FSM design scene, which uses the same excitation-table step to design a machine rather than to convert a device.

Approximate learning time: 50–70 minutes with the animation, or 20 minutes for the Revision tab alone. The figure is an estimate, not a measurement.

The five ideas

  1. The host stays; only the input logic changes. Clock, setup time and hold time are inherited.
  2. The excitation table is the characteristic table read backwards. Four rows: 0→0, 0→1, 1→0, 1→1.
  3. Free entries are the currency. JK leaves an input free on every one of its four transitions, SR on two, and D and T on none.
  4. Minimise over the target’s inputs and Q. Never over the host’s inputs — those are what you are solving for.
  5. Simulate every row of the domain. Six rows into SR, eight into JK, four into D or T.

The legend: green marks a conversion that costs nothing or a value that holds; red marks a row where the circuit fails; amber marks a free entry or a trap.

Intuition: a shop that stocks one kind of lock

You need a door that opens when pushed, and the shop only sells a lock with two keys, “turn left” and “turn right”. You cannot buy a different lock. What you can do is build a small linkage in front of the two keyholes so that pushing the door turns the right key the right way at the right time.

The lock is the host. The door that opens when pushed is the target. The linkage is the input logic, and it is the whole of this topic. The lock itself never changes: it still has two keyholes, it still needs the same key, and it still takes the same time to turn.

Educational interpretation The analogy is exact about the important part — you are building something in front of the device, not replacing it — and loose about the rest: the “linkage” here is a Boolean equation, and the “time to turn” is the one extra gate delay the linkage adds.

Formal definition

A flip-flop type is a one-bit storage element together with a characteristic table: a function from its inputs and the present state Q to the next state Q+.

Q+ = f(inputs, Q)

The excitation table of a type is the inverse relation: for each transition Q → Q+, the set of input combinations that produce it. A row of an excitation table whose set has more than one element is written with a free entry X.

A conversion from host H to target T is a function g for each input h of H, such that for every input combination t of T on which T is defined and every Q:

H(g(t, Q), Q) = T(t, Q)

Mathematical derivation The definition is a statement about functions, and it is why the domain clause is not a technicality: the equation is only required to hold where T is defined, which for SR excludes S = R = 1.

Two-input types have four input rows; one-input types have two. Each row is shown for both values of Q.

Mathematical derivation Each cell is obtained by asking which input values produce that transition. For JK, 0→1 is reached by J = 1 with either value of K, because J = 1, K = 1 also gives 1 (by toggling from 0). Two inputs, one transition, so K is free.

Visual understanding: why a conversion is a table lookup, twice

Put the two tables end to end. The target’s characteristic table says: for this input, the next state must be this. The host’s excitation table says: to reach this next state from that present state, drive the host’s input like so.

Chain the two and the host’s input is a function of the target’s input and Q. That is the entire method. Nothing else is happening: no new state is introduced, no clock is changed, and no storage is added.

The picture on the Animation tab draws exactly this chain. Scene 3 shows the second lookup; scene 4 shows the chain as four steps; scenes 5 to 8 show the chain run for four different host and target pairs.

Educational interpretation “Table lookup twice” is a way of describing the procedure, not a claim about hardware. In hardware the second lookup is a gate network; the table is how you find out what network.

The gate-counting convention, stated once

A gate count is meaningless without the gate set, so here is the one used on every page of this lesson, applied identically to all twelve conversions.

  • Gates available: two-input AND, two-input OR, one-input NOT.
  • Q and Q′ are taken from the flip-flop’s own outputs, so neither is charged.
  • A complement of one of the target’s own inputs (such as K′) is charged one NOT, once, however often it is used.
  • A product of k literals costs k − 1 AND gates; p products cost p − 1 OR gates.
  • A single literal is a wire and costs nothing.

Educational interpretation Under this convention a D–T conversion costs 4 gates, and as a single XOR primitive it costs 1. Both numbers are correct; they are answers to different questions. A GATE question that says “2-input NAND gates” is asking a third question, with a third answer, and this lesson does not claim that number.

Boundaries: what a conversion does not change

The converted device is the host device plus gates. Therefore:

  • The clock is unchanged. A converted JK flip-flop is still edge-triggered on the same edge as the JK it was built from.
  • Setup time gets worse, never better. The target’s inputs must now settle before the host’s inputs are needed, which is one gate delay earlier.
  • Hold time is unchanged in the ideal model and may worsen in a real one, because the input path is longer.
  • The maximum clock frequency can only fall, by the delay of the added gates on the input path.
  • The state set is unchanged. Two states before, two states after; a conversion cannot give a flip-flop more memory.

Mathematical derivation The first four follow from the converted device being a composition: H ∘ g. A composition of functions cannot have a shorter input path than its second component, and the timing parameters are properties of that path.

Edge case before the examples: the domain clause

A conversion into SR is required to work on six of the eight rows of its inputs, because S = R = 1 is not a defined SR input. A conversion into JK, D or T is required to work on all of its rows: eight, four and four respectively.

This is not a loophole. It is the definition: the equation must reproduce the target wherever the target has a value. Two rows have no value, so nothing is required there, and the minimiser is free to choose them to make the rest cheaper.

Mathematical derivation Those two rows become don’t-cares in the map for S and for R. Spending them is exactly what turns the SR→JK conversion from four gates into two, as Example 2 shows.

Example 1 — JK to T, the free one

Build a T flip-flop from a JK flip-flop.

1. Target T, host JK. The map variables are T and Q.

2. Target rows: T = 0 gives Q+ = Q (hold); T = 1 gives Q+ = Q′ (toggle).

3. Read the JK excitation table. Hold (0→0 and 1→1) is J = 0, K = X and J = X, K = 0. Toggle (0→1 and 1→0) is J = 1, K = X and J = X, K = 1.

4. Both rows of the target agree on J = T and on K = T.

5. J = T, K = T. Zero gates: two wires.

No minimisation was needed because the target has only two rows and each one fixed both host inputs. That is what a free conversion looks like.

Example 2 — SR to JK, the two-gate one

Build a JK flip-flop from an SR flip-flop.

1. Target JK has eight rows. Host SR needs S and R, so two equations.

2. For 0→1 the SR excitation table demands S = 1, R = 0; for 1→0 it demands S = 0, R = 1; for a hold it demands the matching input at 0.

3. A toggle (J = K = 1) needs a set when Q = 0 and a reset when Q = 1. So the set input is enabled only while Q = 0, and the reset only while Q = 1.

4. S = J·Q′ and R = K·Q. Two AND gates, and Q, Q′ come from the flip-flop.

5. Check the forbidden input: S and R are both 1 only if Q is 0 and 1 at once. Never happens; verified on all eight rows.

The naive answer is S = J, R = K, which is the JK→SR result read backwards. It fails on both toggle rows, because it asks an SR flip-flop for S = R = 1.

Example 3 — D to JK, the characteristic equation

Build a JK flip-flop from a D flip-flop.

1. A D flip-flop has one input and its next state is that input. So the required D is simply the target’s next-state formula.

2. JK’s next state is JQ′ + K′Q.

3. So D = J·Q′ + K′·Q.

4. Cost: two AND (for JQ′ and K′Q), one OR, one NOT for K′. Four gates.

5. Simulate all eight rows: the derived D reproduces JK on every one.

This is the shortest correct derivation in the topic, and the one most often got wrong by students who try to invent logic instead of reading the target’s formula. When the host is D, the answer is always the target’s characteristic equation.

Example 4 — T to SR, where the domain pays

Build an SR flip-flop from a T flip-flop.

1. Target SR has six rows: S = R = 1 is excluded, and the two excluded rows become don’t-cares for T.

2. At Q = 0, the next state is S, so T = S. At Q = 1, the next state is S + R′, so T = 1 exactly when R = 1 and S = 0.

3. Under the constraint S·R = 0, that is T = S·Q′ + R·Q.

4. Cost: two AND, one OR. Three gates.

5. Simulate the six rows: it matches. On the two excluded rows it gives a defined value, which SR does not require.

The shape S·Q′ + R·Q is the same shape as the JK case, because JK and SR differ only on the row SR forbids.

Example 5 — D to SR, three gates

Build an SR flip-flop from a D flip-flop.

1. The required D is SR’s next-state formula, S + R′Q.

2. The term S stands alone because S = 1 forces the next state to 1 whatever R and Q are.

3. The term R′Q covers the hold: with S = 0 and R = 0 the next state is Q.

4. Cost: one NOT for R′, one AND, one OR. Three gates.

Note that D = S alone would be wrong: it sets on S = 1 and clears otherwise, so it would never hold.

Example 6 — reading a conversion off a question

“A T flip-flop is to be built using a D flip-flop and the minimum number of additional gates.” What is the equation?

1. Direction: host D, target T. One equation, and it is T’s next-state formula.

2. Q+ = T′Q + TQ′, which is T xor Q.

3. So D = T′Q + TQ′.

4. In AND/OR/NOT that is four gates; as one XOR it is one.

“Using a D flip-flop” fixes the host and “to build a T flip-flop” fixes the target. Reading those two phrases the wrong way round is the error this example exists to prevent.

Example 7 — the saturating counter, in full

A 2-bit counter counts 00, 01, 10, 11 and then stays at 11. It is built from T flip-flops. Find T1 and T0.

1. The T excitation table is one line: T equals the exclusive-or of the present bit and the next bit.

2. Bit 1: 0→0, 0→1, 1→1, 1→1 for the four rows. So T1 = 1 only on the row Q1Q0 = 01.

3. That single row is the minterm Q1′Q0, so T1 = Q1′Q0.

4. Bit 0: T0 = 1 on 00, 01 and 10, and 0 on 11. The zero is at a single minterm, so T0 = (Q1Q0)′ = Q1′ + Q0′.

This is GATE CSE 2017 Set 2’s question, worked from the table. The step people miss is that T0 is cheapest as the complement of one minterm, not as a sum of three.

Example 8 — two converted devices wired together

A D flip-flop’s output feeds both J and K of a JK flip-flop, and the JK output feeds the D input. Both start as D = 1, JK = 0. What sequence appears at the JK output?

1. This is JK→T with the D flip-flop as a one-bit delay: J = K = A means the JK toggles when A = 1 and holds when A = 0.

2. Track the pair (A, B): start (1, 0).

3. (1,0) → (0,1) → (1,1) → (1,0), and then it repeats.

4. The JK output is therefore 0, 1, 1, 0, 1, 1, 0, … — a cycle of length three.

This is GATE CSE 2015 Set 1’s question. The pair has four states but only three are reachable, which is why the period is 3 and not 4.

Counterexample: the conversion that looks right

The claim that fails: “to convert SR into JK, wire S = J and R = K, because that is what JK→SR does.”

The minimal case: with J = K = 1, the wiring asks the SR host for S = R = 1. The SR flip-flop has no next state for that input. The wiring is wrong on exactly two of the eight rows, and they are the two toggle rows — the rows that are the whole point of a JK flip-flop.

What the condition was: a conversion must be correct in the direction it is asked. JK→SR is legitimate because SR never requests the toggle; SR→JK is not, because JK does.

Mathematical derivation The failure is counted, not asserted: the page simulates all eight rows of the naive wiring and reports two mismatches, both at J = K = 1.

Counterexample: verifying on the wrong domain

The claim that fails: “a conversion is correct only if it agrees on all eight rows of a two-input target.”

The minimal case: take the correct S = J·Q′, R = K·Q and demand agreement at S = R = 1. The SR flip-flop has no value to agree with, so the correct answer is rejected.

What the condition was: the equation must reproduce the target wherever the target is defined. A conversion into SR has six rows; into JK eight; into D or T four.

Mathematical derivation The six rows are counted here: four input combinations times two values of Q, minus the two rows at S = R = 1.

Boundary: the converted flip-flop inherits the forbidden input

A JK flip-flop converted into an SR flip-flop has J = S and K = R. If someone drives S = R = 1, the host will toggle — it has a defined behaviour there — but the SR interface still declares that input illegal.

The conversion did not remove the restriction; it removed the undefined behaviour, which is a different thing. A circuit built this way will do something specific and wrong when it is fed the illegal input.

Educational interpretation This is why datasheets list forbidden inputs even for parts that “do something” there: defined is not the same as legal.

Boundary: the timing cost of the gates

A conversion adds gates in front of the host’s inputs. In the ideal model used for all the logic on this page, that changes nothing. In a real circuit it moves the setup time earlier by the delay of those gates and can only reduce the maximum clock frequency.

The D–T conversion is the sharpest case: as one XOR it is a single gate of delay; as four gates it is two levels. Same logic, different timing.

Educational interpretation The lesson counts gates and does not model delay. Any question about frequency after a conversion needs the gate delays, which this page does not supply.

Counterexample: “the cheapest host is the simplest host”

The claim that fails: “a D flip-flop is the simplest device, so it should be the easiest to convert from.”

The minimal case: the D host costs 11 gates across its three conversions; the JK host costs 1. The D flip-flop is simplest to use and most expensive to convert from.

What the condition was: the cost of a conversion is set by how much of the target’s behaviour the host already has as an input row. D has one input and no free entries, so nothing is already there.

Mathematical derivation Host totals are computed by summing the three conversions for each host: JK 1, SR 5, T 10, D 11, totalling 27.

Edge case: a one-row target

A conversion into D or T has only four rows to satisfy — two input values times two values of Q — because the target has a single input. That is why those conversions verify fastest and why a mistake in them is easy to miss: there is less to check.

The check still catches it, because four rows is enough to distinguish any two Boolean functions of two variables. A function of D and Q is determined by its four values.

Mathematical derivation Two functions of two variables that agree on all four rows are equal, since the four rows enumerate the domain.

Edge case: a conversion with no gates still has an equation

“Zero gates” means zero gates, not zero logic. J = T and K = T are equations; they are realised by wires. If the target’s input is not available as a signal — for instance if T is itself the output of a gate — then the wire is still a wire, and the cost is still zero.

Educational interpretation The distinction matters when counting: a question that asks for “the number of gates” expects 0 here, and a question that asks for “the number of inputs to the host” expects 2.

Edge case: two host types with the same equations

Look at the pair SR→JK and SR→T. Both give the same shape: S = X·Q′, R = X·Q, where X is the single target input. That is not a coincidence: T and JK agree on the hold and toggle rows, and disagree only on J = 1, K = 0 versus J = 0, K = 1, which SR reaches with a single input.

Mathematical derivation Substituting J = K = T into S = JQ′, R = KQ gives the SR→T answer exactly, which is why the two costs are both 2.

Misconception 1 — “conversion is symmetric”

The wrong belief: if JK→T is free, then T→JK is free.

Why it feels right: the two devices have the same behaviour, so the logic between them should be reversible.

What is actually true: JK→T costs 0 and T→JK costs 3. Of the six unordered pairs, only D and T cost the same in both directions; the other five differ, by 1, 2, 2, 3 and 3 gates.

The one-line fix: a conversion is not a bijection. The host’s free entries are consumed in one direction and do not exist in the other.

Misconception 2 — “use the target’s excitation table”

The wrong belief: to convert to a JK flip-flop, write the JK excitation table and read off the SR inputs.

Why it feels right: both tables are involved, and the phrase “excitation table” is used for both.

What is actually true: the target’s characteristic table says what the next state must be; the host’s excitation table says which host input produces it. Reading the target’s excitation table gives you the target’s inputs, which you already have.

The one-line fix: characteristic of the target, excitation of the host. One of each, never two of one.

Misconception 3 — “SR has no free entries”

The wrong belief: only JK has don’t-cares, because only JK has a toggle.

Why it feels right: the free entries in JK’s table are the memorable ones.

What is actually true: SR has two free entries as well — S = 0 is enough to hold from 0, whatever R is, and R = 0 is enough to hold from 1. Counted here: JK 4, SR 2, D 0, T 0.

The one-line fix: a free entry exists whenever one input alone forces the transition. JK has one on all four of its transitions; SR has one on the two hold transitions.

Misconception 4 — “the forbidden row must be avoided in the equations”

The wrong belief: when converting into SR, the equations must be written so that S = R = 1 is impossible, even at the cost of extra terms.

Why it feels right: the forbidden input is the defining feature of SR, so it seems it must be respected everywhere.

What is actually true: the forbidden input is illegal at the interface. Inside a conversion, whether the host is ever driven there is a separate check — and it is a check worth doing, because an equation correct on all transitions can still drive S = R = 1. The correct SR→JK equations pass it; the naive ones do not.

The one-line fix: two different questions. Is the equation right on the domain, and does it ever drive the host forbidden. Answer both.

Misconception 5 — “D→T is impossible without a T flip-flop”

The wrong belief: a toggle needs a toggle device, so a D flip-flop cannot be made to toggle.

Why it feels right: the D flip-flop has no toggle input, and its next state is just D.

What is actually true: feed it D = T xor Q and it toggles exactly when T = 1. One exclusive-or, four gates in AND/OR/NOT form. The storage element never needed a toggle input; the logic supplies it.

The one-line fix: every action a flip-flop can perform is a function of its next state, and the next state of a D flip-flop is its input.

Misconception 6 — “the conversion changes the flip-flop”

The wrong belief: a converted JK flip-flop is a T flip-flop, so it behaves like a T flip-flop in every respect.

Why it feels right: the whole point is that it behaves as the target.

What is actually true: it behaves as the target on the target’s inputs. Its clock, its edge, its setup time and its propagation delay are still the host’s, plus the gate delay of the added logic. A converted device is never faster than the device it was built from.

The one-line fix: conversion changes the input logic, and nothing else.

The closely confused pair: host and target

“Design a T flip-flop using a JK flip-flop” — host JK, target T. Cost 0.

“Design a JK flip-flop using a T flip-flop” — host T, target JK. Cost 3.

The two sentences differ by the order of two words and by three gates. The word that fixes the host is using; the words that fix the target are a … flip-flop before it.

Educational interpretation A reliable reading rule: the device named after “using” is the one you have. Everything else named is what you want.

Four question shapes, and one first move

Conversion is examined as a procedure applied to a named pair, almost never as a definition to recite. Every shape below is answered by naming host and target, writing the target’s characteristic table, reading the host’s excitation table, and minimising over the target’s inputs and Q.

Shape 1 — derive the input equations

Reasoning demanded: the four-step procedure, with the target’s domain respected. The answer is one equation per host input.

Common wrong approach: writing the map variables as the host’s own inputs, which produces a plausible equation for the wrong direction.

Verified previous-year example below.

Verified PYQ — GATE CSE 2017 Set 2

“The next state table of a 2-bit saturating up-counter is given below. The counter is built as a synchronous sequential circuit using T flip-flops. The expressions for T1 and T0 are…” with the transitions 00→01, 01→10, 10→11, 11→11.

Answer, computed here: T1 = Q1′Q0 and T0 = Q1′ + Q0′.

Each T input is the exclusive-or of the present and next bit, so it is read straight off the transition. T1 is 1 on the single row Q1Q0 = 01; T0 is 1 on three rows and 0 on one, so the complement of that one minterm is cheapest.

Question text and paper verified from two previous-year listings. The expressions are derived here from the transition table rather than copied from a key, and the page’s model re-checks all four rows.

Shape 2 — count the gates for a stated conversion

Reasoning demanded: derive the equations, then count against the gate set the question names. If it names 2-input NAND, count in 2-input NAND; the number will differ from the AND/OR/NOT count and both can be right.

Common wrong approach: counting the gates of a remembered answer without checking that the question’s host and target match it.

The convention used on this page is stated on the Build-up tab and applied to all twelve conversions.

Verified PYQ — GATE CSE 2026 Set 1

“Consider a 2-bit saturating up/down counter that performs the saturating up count when the input is 0, and the saturating down count when it is 1. The next state table of the counter is as shown. The counter is built as a synchronous sequential circuit using JK flip-flops. Which one of the following options corresponds to the expressions for the inputs of the JK flip-flops…”

This is the same procedure with a two-input host, so the answer is two equations, each minimised over the counter’s single input and the two state bits. The JK excitation table leaves one of J, K free on each of its four transitions, and those free entries are where the options differ.

Question text verified from a previous-year listing that names the paper and set. The specific option set is not reproduced here and no answer is claimed, because the next-state table is not reproduced in full on this page.

Shape 3 — trace the output of a converted or composed device

Reasoning demanded: identify the effective type of each device from its wiring, then step the pair through the clock. The step is the same every time: compute both next states from the present ones.

Common wrong approach: stepping one flip-flop and then the other, using the new value of the first in the second. In a synchronous circuit both flip-flops sample the same instant.

Verified previous-year example below.

Verified PYQ — GATE CSE 2015 Set 1

“A positive edge-triggered D flip-flop is connected to a positive edge-triggered JK flip-flop as follows. The Q output of the D flip-flop is connected to both the J and K inputs of the JK flip-flop, while the Q output of the JK flip-flop is connected to the input of the D flip-flop. Initially, the output of the D flip-flop is set to logic one and the output of the JK flip-flop is cleared. Which one of the following is the bit sequence (including the initial state) generated at the Q output of the JK flip-flop…”

Answer, computed here: 0, 1, 1, 0, 1, 1, 0, … — the initial 0 followed by a cycle of length three.

The wiring is exactly JK→T: tying J and K to the same signal makes the JK toggle when that signal is 1 and hold when it is 0. Stepping the pair (A, B) gives (1,0) → (0,1) → (1,1) → (1,0), and three of the four states are reachable.

Question text verified from two previous-year listings that name the paper and set. The sequence is derived here by simulation, not copied from a key, and the page’s model re-checks that its period is 3.

Shape 4 — find what is wrong with a given circuit

Reasoning demanded: take the wiring given, derive its actual next-state behaviour, and compare it with the type it is claimed to be. The failure is usually on one or two rows, and naming those rows is the answer.

Common wrong approach: checking only one row, usually the all-zeros row, on which almost every plausible wiring happens to be correct.

The canonical instance is the naive SR→JK wiring on the Edge cases tab: correct on six rows, wrong on the two toggle rows.

MCQ original

Q1 — the free direction

Which conversion needs no additional gates?

(a) T to JK   (b) D to T   (c) JK to T   (d) SR to T

(c). J = T and K = T are two wires. T = 0 gives J = K = 0, which is JK hold; T = 1 gives J = K = 1, which is JK toggle.

(a) is 3 gates. (b) is 4 in AND/OR/NOT form, or one exclusive-or. (d) is 2 gates: S = T·Q′, R = T·Q.

Only two conversions are free, and both have JK as the host. Anything with JK as the target costs something.

NAT original

Q2 — count the gates

Using two-input AND, two-input OR and NOT gates, with Q and Q′ available free, the number of gates needed to build a JK flip-flop from a D flip-flop is ______.

4. The required input is JK’s own next-state formula: D = J·Q′ + K′·Q.

Two products of two literals: 2 AND. One sum of two products: 1 OR. One complement of an input, K′: 1 NOT. Total 4.

The common wrong answers are 2 (forgetting K′) and 3 (forgetting that K′Q is a product and so needs an AND).

MCQ original

Q3 — the naive wiring

An SR flip-flop is wired with S = J and R = K in an attempt to obtain a JK flip-flop. On how many of the eight input-and-state rows does it fail?

(a) none   (b) two   (c) four   (d) six

(b), two. Both failures are at J = K = 1, one for each value of Q. There the wiring drives S = R = 1, and the SR flip-flop has no next state.

(a) is the belief that the wiring is the JK→SR answer reversed, which it is not. (c) would be true if the set and reset cases also failed; they do not. (d) would be true if only the two hold rows worked.

The corrected wiring is S = J·Q′, R = K·Q, which is correct on all eight rows and never drives S = R = 1.

MSQ original

Q4 — which statements hold

Select every statement that is true of flip-flop conversion.

(a) A conversion into SR is required to reproduce SR on six of the eight input-and-state rows.
(b) JK leaves an input free on each of its four transitions, and SR on two of the four.
(c) A converted flip-flop can have a shorter setup time than the device it was built from.
(d) The D–T pair costs the same number of gates in both directions.
(e) A conversion into D needs two equations, because D has two states.

(a), (b), (d).

(c) is false: the input path is longer by the added gates, so setup time can only worsen.

(e) is false: the number of equations equals the number of host inputs, not states. A D host has one input, so one equation, whichever type is the target.

(a) is the domain clause and (b) is the currency of the topic; both are recomputed on the Build-up tab.

NAT original

Q5 — the total

Summing over all twelve conversions, with the counting convention stated on the Build-up tab, the total number of gates is ______.

27. Per host: JK 1, SR 5, T 10, D 11.

Broken down: JK→SR 0, JK→D 1, JK→T 0; SR→JK 2, SR→D 1, SR→T 2; T→SR 3, T→JK 3, T→D 4; D→SR 3, D→JK 4, D→T 4.

A different gate set gives a different total, which is why the convention is stated. The total is a check on twelve separate derivations, not a fact to memorise.

MCQ original

Q6 — the host with no free entries

Which host type has no free entries in its excitation table, and therefore needs every term of the target computed for it?

(a) SR   (b) JK   (c) D and T   (d) all four have free entries

(c). D and T each have exactly one input value per transition, so every transition is single-valued and no cell of the map is a don’t-care.

(a) has two free entries and (b) has four, which is why SR and JK are cheaper hosts than D and T. (d) is false: the free entries come from having two inputs, where one input can force the transition alone.

This is the reason D is the most expensive host at 11 gates and JK the cheapest at 1.

MCQ original

Q7 — the toggle equation

A D flip-flop must behave as a T flip-flop. The input equation is

(a) D = T   (b) D = T′Q   (c) D = T′Q + TQ′   (d) D = T + Q

(c). That is T xor Q: the next state flips exactly when T = 1, and holds when T = 0.

(a) sets the output to T and never toggles. (b) clears whenever T = 0 instead of holding. (d) sets on T = 1 or Q = 1, so it never clears from a set state.

Check one row: T = 0, Q = 1 must hold at 1. (c) gives 0 + 1 = 1. (b) gives 0. (d) gives 1, but fails elsewhere.

MCQ original

Q8 — the direction

“Design a JK flip-flop using a T flip-flop.” Which pair is host and target, and what does it cost?

(a) host JK, target T, 0 gates   (b) host T, target JK, 3 gates   (c) host T, target JK, 0 gates   (d) host JK, target T, 3 gates

(b). The device named after “using” is the host, so the host is T. The equation is T = J·Q′ + K·Q: two AND and one OR, three gates, and no inverter because Q′ comes from the flip-flop.

(a) and (c) read the sentence backwards, which is exactly the confusion this question tests. (d) has the direction right and the cost wrong.

The reverse sentence, “design a T flip-flop using a JK flip-flop”, is 0 gates. Two words, three gates.

The procedure, in five lines

1. Name the host (the device you have) and the target (the behaviour you want). The word after using is the host.

2. Write the target’s characteristic table. Delete the rows the target forbids; they become don’t-cares.

3. Read the host’s excitation table for each remaining row.

4. Minimise each host input over the target’s inputs and Q.

5. Simulate every row of the domain: 6 into SR, 8 into JK, 4 into D or T. And check the host is never driven to its own forbidden input.

That is the whole topic. The twelve answers are consequences, not facts to memorise.

The facts worth carrying

  • Free entries: JK 4, SR 2, D 0, T 0. This one count explains the whole cost table.
  • Host totals: JK 1, SR 5, T 10, D 11. Richest host, cheapest conversion.
  • Only D and T cost the same both ways, because both directions are an exclusive-or.
  • 6 of 12 need one equation; 8 of 12 use Q on the input path.
  • The largest single conversion is 4 gates; the smallest is 0.
  • A D host needs the target’s characteristic equation as its input, always.

Every number here is printed on the Animation tab by the page’s own model, and every one is checked.

The four traps

  1. Reading the direction backwards. “T using JK” is free; “JK using T” is three gates.
  2. Using the target’s excitation table. Characteristic of the target, excitation of the host.
  3. Verifying on the wrong domain. Six rows into SR, not eight. Verifying on eight rejects correct answers.
  4. Trusting the symmetric-looking wiring. S = J, R = K works as JK→SR and fails as SR→JK.

Each of the four has a worked failure on the Edge cases or Misconceptions tab.

Where this connects

Sequential circuits uses the same excitation table to design a machine from a state diagram rather than to convert a device; the step is identical and only the target changes.

Boolean algebra and minimisation supplies the minimisation, including the don’t-care handling that the domain clause depends on.

Combinational circuits supplies the gate vocabulary, and the adder chain is the same two-level reasoning applied to arithmetic rather than to state.

In Computer Organisation, a converted flip-flop is what a register file built from one standard cell actually is; the gate delay on the input path is the reason the cell count and the clock frequency trade off.
