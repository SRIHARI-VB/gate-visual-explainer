All topics Transcript

Topic and objective

TOPIC: I/O interface, interrupts and DMA — the clause "I/O interface (interrupt and DMA)", which is the last uncovered item of GATE 2027 Section 3, Computer Organization and Architecture.

LEARNING OBJECTIVE: Given a device, say which of the three registers of its interface the CPU must touch and how often, and name the transfer method that follows. Place the five interrupt events in their one legal order, and distinguish the two independent jobs hidden in "interrupt handling" — naming the source and ranking the sources. Given a DMA controller, compute the number of bus acquisitions for a file from a count-register width, and the CPU time a transfer costs from a clock rate, a stolen-cycle fraction and a word width.

I read this topic as one question asked three times. An interface is three registers on the bus. Programmed I/O has the CPU drive the data register every time; interrupt-driven I/O has the CPU drive it only when called; DMA has a controller drive it while the CPU pays at the two ends. Every definition and every numerical question in this area is that sentence at a different scale. Nothing here repeats the memory or cache lessons: mapping, tags and average access time live there.

Prerequisites

  • The idea of a bus and a register. A set of wires one master drives at a time, and a small named storage location inside a chip.
  • What a decoder is. An n-input, 2n-output part asserting exactly one line. Built and counted in Design of Combinational Circuits.
  • Address space as a count. An k-bit address names 2k locations. That is the whole arithmetic of memory-mapped I/O.
  • Rates, intervals and their reciprocals. A device at r words per second delivers one word every 1/r seconds. Used throughout, and treated in Memory Hierarchy and Cache for the same reason.

Nothing from Memory Interfacing and Interleaving is assumed, but that lesson's bank schedule is the same overlap reasoning this one uses for cycle stealing, and the two are designed to be read in either order.

The five ideas to leave with

  1. An interface is three registers. Every I/O method is an answer to who drives the data register.
  2. Memory-mapped I/O spends address space; isolated I/O spends instructions and one control line. Neither spends nothing.
  3. Polling has no separate overhead, because the CPU never leaves the loop. Its cost per byte is the whole interval.
  4. Naming the source and ranking the sources are different jobs. Vectored answers the first; daisy chain the second.
  5. DMA moves the copying, not the cost: the CPU still pays the setup, the completion interrupt and every stolen bus cycle.

Intuition: the counter, the tray and the clipboard

A memory is a wall of numbered pigeonholes. You can ask for number 4100 at any moment, twice in a row, and get the same answer both times. A device is not that. It is a counter clerk: there is a tray holding whatever is being handed over right now, a small sign that says ready or wait, and a clipboard where you write what you want done next.

You cannot read the clerk's mind, and asking twice is not the same question twice — the second look may find the tray empty. So the machine puts a translator between you and the clerk: a small box with exactly those three things, a tray, a sign and a clipboard, wired to the system bus. That box is the interface. Every method in this lesson is a different arrangement of who walks up to the counter and how often.

Educational interpretation The analogy is a teaching device. It fixes the three registers and the fact that the data register is a moving part, which is exactly what the exam asks you to keep separate.

Formal vocabulary, every symbol glossed

Interface (controller). The hardware between a device and the bus. It presents three registers:

  • Data register — holds the item in transit. One word wide on the bus side.
  • Status register — bits saying whether the device is ready, busy, or has failed.
  • Control register — written by the CPU to start, stop or configure.

Port — the address, or port number, at which one of those registers answers. A port is a name; a register is the thing named.

Polling (programmed I/O) — the CPU reads the status register in a loop and moves each word itself. Interrupt-driven I/O — the interface asserts an interrupt request line when a word is ready, and the CPU moves it then. DMA — a separate controller drives the data register, using an address register, a count register and a control register of its own.

The address budget, worked once

A 16-bit address bus names 216 = 65536 locations. Memory-mapped I/O places device registers inside that count, so the registers are addresses memory can no longer use.

memory left = 2k − p

With k = 16 and p = 256 port addresses: 65536 − 256 = 65280 addresses of memory, and 256 addresses that now drive devices.

Isolated I/O spends none of that: its 256 ports are counted in a separate space, and memory keeps all 65536. The cost moves elsewhere — to the IN and OUT instructions, and to one control line that tells the bus which space is meant.

Three checks that catch most slips

Each is arithmetic on numbers you already have:

Check one. Count addresses, not bytes. 65536 addresses is 65536 bytes only when every address is one byte.

Check two. A device at r words per second has an interval of 1/r seconds. Every cost in this lesson is expressed against that interval.

Check three. A fraction of CPU time must lie below 1. Above 1, the model has failed: the CPU cannot keep up with the device and data is being lost.

The three transfer methods, side by side

Read the middle column as the only thing that changes. Everything else in the table follows from it.

Programmed I/O

Who copies: the CPU, once per word.
When: whenever the loop comes round, whether or not the device is ready.
CPU cost per byte: the whole interval, because the CPU never leaves the loop.

Needs: nothing beyond the registers. No interrupt line, no vector table, no context save. This is why it survives in firmware.

Interrupt-driven I/O

Who copies: the CPU, once per word.
When: only when the interface asserts the request line.
CPU cost per byte: the service time — save, move, restore — not the interval.

Needs: a request line, an enable bit, a vector or a shared entry point, and a stack to save onto.

DMA

Who copies: the controller, using its own address and count registers.
When: as fast as the bus can be granted.
CPU cost: setup, plus a completion interrupt, plus the bus cycles stolen.

Needs: a controller, a request/grant handshake, and a bus that can be handed over.

Ordering them by CPU utilisation is a trap

The three are often written as a ladder, programmed < interrupt < DMA. That is true for CPU utilisation on a bulk transfer, and it is exactly what GATE 2024 Set 1 tests by offering its negation as the false statement.

It is not true as a general ranking of throughput, of latency, or of suitability. A polled port has the lowest latency of the three, because there is no handshake and no context switch. Mathematical derivation Polling's latency is the loop's period; an interrupt's is the remaining part of the current instruction plus the save.

The five interrupt events, and why only one order works

Q finish the current instruction → P push the process status → T load the new program counter → R execute the service routine → S pop the process status.

Q is first because an interrupt is honoured only at an instruction boundary: a processor cannot abandon an instruction with its registers half-updated and expect to resume. P comes before T because the program counter is part of the process status, so writing the new value first destroys the return address.

Steps 1, 2, 4 and 5 are identical in every machine. Only step 3 varies, and that variation is the whole of the next page.

Naming against ranking, and then the DMA schedule

"Interrupt handling" hides two independent jobs. Keeping them apart removes most of the wrong answers in this topic.

Job one: naming the source

Vectored. The interrupting device places a vector — an identifier or a direct address — on the bus during the acknowledge cycle. The CPU loads the program counter from it and enters the right routine immediately.

Non-vectored. Every device branches to one fixed address. The handler there must discover which device asked, usually by reading status registers in turn. That discovery is software polling, and it is what makes a non-vectored interrupt slower to start.

Job two: ranking the sources

Daisy chain. Devices are wired in series on the acknowledge line. The CPU asserts it; each device either takes it, if it is the one requesting, or passes it on. Position is priority, and identification is implicit in where the pulse stopped. No instruction runs while this resolves.

Software polling. The handler reads status registers in a chosen order, so the order is the priority. This is a software ranking, and it is a different mechanism from the hardware chain even though both visit devices in sequence.

A third, independent axis

Maskable. Software can disable it by clearing a bit, so a critical section can run undisturbed.

Non-maskable (NMI). Cannot be disabled. Reserved for failures that must not wait: power failure, memory parity error, an overheating processor. A temperature sensor is the standard example; a mouse is the standard counterexample.

Maskability is not priority

An NMI is unmaskable, which says it cannot be switched off. That is a different claim from "it outranks everything in the priority order". A machine can have a maskable interrupt with higher priority than its NMI for a specific purpose; the two properties are set by different hardware. GATE has not asked this directly, but the confusion produces wrong answers to questions about ranking.

DMA: registers, handshake, and three schedules

The controller holds an address register (where in memory next), a count register (how many words remain) and a control register (direction and mode). Each transfer increments the address and decrements the count; that loop is the whole of the controller.

The handshake is two wires: the controller asserts a bus request (HOLD or BR), the CPU finishes the bus cycle it is in and asserts the grant (HLDA or BG), floating its own drivers so the two never drive the same lines. The request-to-grant delay is real and belongs in any timing calculation.

Three schedules. Burst — one grant, held to the end of the block: highest throughput, longest lock-out. Cycle stealing — one word per grant, then release: lower throughput, but the CPU loses only one bus cycle at a time. Transparent — a word moves only in a cycle the CPU left idle: the CPU is never delayed, and the block takes longest.

Worked examples, page 1 of 2

Every figure below is recomputed by this page's own model, and the Animation tab lists the checks. Nothing is copied from a key without being re-derived.

A keyboard, polled and interrupted

A keyboard is used at 1 keystroke per second. The system polls it every 10 ms, spending 100 µs per poll, plus 200 µs to process a keystroke. With interrupts it spends 1 ms per keystroke. Find T1/T2.

Step 1 — polls per second. One second is 1000 ms, and 1000 / 10 = 100 polls.

Step 2 — polling cost. 100 × 100 µs = 10000 µs = 10 ms.

Step 3 — processing. One keystroke × 200 µs = 0.2 ms.

Step 4 — totals. T1 = 10.2 ms, T2 = 1 ms, so T1/T2 = 10.2.

The poll count is set by the clock, not by the keystrokes: a silent keyboard still costs 100 polls. That is the whole economic argument for interrupts, in one line.

A device at 10 KB/s: interrupt against programmed

Data is transferred byte-wise, interrupt overhead is 4 µs, and the byte transfer time is negligible. Find the minimum performance gain of interrupt mode over program-controlled mode.

Programmed. The CPU waits for the whole byte: at 10 KB/s one byte takes 1/(10 × 1000) = 100 µs, so the CPU is busy 100 µs per byte.

Interrupt. The CPU spends 4 µs per byte.

Gain. 100 / 4 = 25.

Mathematical derivation If a kilobyte is read as 1024 bytes the interval is 97.66 µs and the gain is 24.41. Both readings select the option 25, which is why the question is safe and why the convention still deserves stating.

A disk under cycle stealing

16 surfaces, 512 tracks per surface, 512 sectors per track, 1 KB per sector, 3000 rpm. Cycle stealing, one 4-byte word per DMA cycle, memory cycle time 40 ns. Find the maximum percentage of time the CPU is blocked.

Step 1 — one track. 512 sectors × 1 KB = 512 KB.

Step 2 — rate. 3000 rpm = 50 revolutions per second, so 512 KB × 50 = 25600 KB/s = 26214400 B/s.

Step 3 — word interval. 4 / 26214400 s = 152.588 ns.

Step 4 — fraction. 40 / 152.588 = 26.2 per cent exactly; 25 per cent if the interval is counted as 4 whole memory cycles and one is stolen.

Only one head reads at a time, so the 16 surfaces do not multiply the rate. That is the most common error on this item.

Worked examples, page 2 of 2

Two numerical questions that look different and are the same shape: count something, then divide once.

A 16-bit count register against a 29154 KB file

The data count register is 16 bits, memory is byte addressable, and the file is 29154 KB. Find the minimum number of times the controller must take the bus.

Step 1 — the ceiling. 216 = 65536, so one transfer moves at most 65536 bytes, which is 64 KB.

Step 2 — the ratio. 29154 KB / 64 KB = 455.53125. In bytes: 29853696 / 65536 = 455.53125.

Step 3 — the ceiling again. 455 × 65536 = 29818880 bytes, leaving 34816. So 456 acquisitions.

Rounding down loses 34816 bytes. A file one byte larger than 64 KB needs two acquisitions while the nearest integer is one — which is why the operation is a ceiling and not a rounding.

A software loop against a DMA controller

A five-statement loop moves 500 bytes: load and store take two cycles each, the other three take one. Initialisation is two statements of one cycle. The DMA path costs 20 cycles of setup plus two cycles per byte. Find the speedup.

Step 1 — per iteration. 2 + 2 + 1 + 1 + 1 = 7 cycles.

Step 2 — the loop. 2 + 500 × 7 = 3502 cycles.

Step 3 — the DMA path. 20 + 500 × 2 = 1020 cycles.

Step 4 — the ratio. 3502 / 1020 = 3.43, so approximately 3.4.

Both small constants matter: dropping the two initialisation instructions gives 3500/1020 = 3.43 anyway, but dropping the 20 cycles of DMA setup gives 3502/1000 = 3.5, which is a different option.

Two throughputs from the same formula

GATE CSE 2021 Set 2. A 2 MHz processor; the controller moves one 8-bit character per stolen cycle; 0.5 per cent of cycles are stolen. Rate = 2 × 106 × 0.005 × 8 = 80000 bits per second.

GATE CSE 2024 Set 2. A 4 MHz processor; the controller moves 8 bytes per stolen cycle; 1 per cent of cycles are stolen. Rate = 4 × 106 × 0.01 × 64 = 2560000 bits per second, written 25,60,000 in Indian grouping.

Both are f × p × w: clock rate, times the fraction of cycles stolen, times the bits in one stolen cycle. The only decisions are whether the width given is bytes or bits, and whether the answer is asked in bits or bytes.

Where each rule stops holding

Every formula in this topic has a condition attached. These are the conditions, and what happens on the other side of each.

When the interrupt fraction exceeds one

The fraction is cost divided by interval, and it is a fraction only while the cost fits inside the interval. Let a device raise one interrupt every 100 µs and let servicing cost 200 µs. The formula returns 2.

That is not "the CPU spends twice as much time as it has". It means the CPU cannot keep up: requests arrive faster than they can be served, the backlog grows without bound, and data is lost. The correct reading of a value above 1 is always the model has failed.

When DMA is the wrong answer

DMA costs a fixed setup and a completion interrupt regardless of block size. For a single byte, those two can exceed what polling would have cost.

Mathematical derivation If setup plus completion costs s and each byte costs b under polling, DMA wins once the block length n satisfies s < n·b. Below that threshold the controller is pure overhead. This is why real machines route a single keystroke through an interrupt and a disk block through DMA, in the same box.

65536, not 65535

An n-bit register holds 2n distinct values, and a count register decremented once per unit therefore covers 2n units. Sixteen bits cover 65536 bytes.

The instinct to subtract one comes from thinking of the counter's last value rather than its number of values. The check that settles it: a 1-bit count register covers 2 bytes, not 1, and a 2-bit one covers 4.

Whole memory cycles against an exact fraction

A 4-byte word arriving every 152.588 ns against a 40 ns memory cycle gives 40/152.588 = 26.2 per cent. But a controller can only steal whole cycles, and the interval contains 3.81 of them, so the natural whole-cycle reading is one in four, which is 25 per cent.

The published key for the 2005 item is 25. This lesson reports both, because the disagreement is about which model the question intends, not about arithmetic.

A polled system with nothing to do

Polling every 10 ms costs 10 ms a second even if the device never becomes ready. A device that is idle 99 per cent of the time still costs 1 per cent of the CPU, forever.

Now make the poll interval 1 ms: the cost is 100 ms a second, ten times worse, and the device is no busier. Polling cost scales with the poll rate, not with the event rate — which is the exact inversion of how an interrupt's cost behaves.

Two masters, or one at a time?

During a DMA transfer the CPU and the controller are both active. They are never both bus masters.

The distinction is between activity and ownership. The CPU can execute an instruction that touches only registers throughout a burst transfer. The instant that instruction needs memory, it must wait for the grant to be released. GATE 2020 offers the conflation as a false statement, and GATE 2024 Set 1 makes the same point from the other side.

The interrupt latency nobody puts in the formula

Every cost figure in this lesson is a service cost. Real latency also includes the time to finish the current instruction, the request-to-grant delay if the bus must be taken, and any time spent with interrupts masked by an outer critical section.

A numerical question that gives only a service time is asking you to ignore the rest, and that is legitimate — but the omission should be visible. If a question mentions a long instruction or a masked region, it is telling you that the omitted terms are the point of the question.

Six beliefs that cost marks

Each is stated as a learner would state it, then broken with the smallest counterexample available.

1. "An interrupt transfers the data"

Why it is wrong. The interrupt announces that a word is available. The service routine still reads or writes the data register itself, one word at a time. The copying is unchanged from polling; only the timing of the copying changes.

What it costs. A question asking which method has the highest throughput for a bulk transfer. Interrupt-driven I/O is still one CPU move per word, so DMA wins — which is exactly GATE CSE 2022 Q17.

2. "A vectored interrupt still needs polling to find the source"

Why it is wrong. The vector is the identification. The device places it on the bus during the acknowledge cycle, so the CPU enters the right routine without asking anyone anything.

Where it is tested. GATE CSE 2020 Q3, statement II, which is false for this reason; and GATE CSE 2026 Set 2 Q18, whose S1 asserts the true comparison — non-vectored is slower to start precisely because of that discovery step.

3. "A daisy chain polls the devices"

Why it is wrong. Daisy chaining is a hardware grant chain. The acknowledge signal propagates through the devices and stops at the first one requesting. No instruction executes during that propagation, and no status register is read.

Where it is tested. GATE CSE 2026 Set 2 Q18, statement S2, which is false. Software polling is a separate mechanism in which the handler reads status registers in a chosen order.

4. "The new program counter is loaded before the status is saved"

Why it is wrong. The program counter is part of the process status. Loading the new value first overwrites the return address, and the interrupted program can never be resumed.

Where it is tested. GATE CSE 2018 Q9 offers Q T P R S alongside the correct Q P T R S. GATE CSE 2025 Set 1 Q11 asks the same three-step order and expects finish, save, load.

5. "Programmed I/O has better CPU utilisation, because it needs no interrupt hardware"

Why it is wrong. It needs less hardware and it uses more CPU. Polling occupies the CPU for the whole interval; an interrupt occupies it only for the service time. Utilisation is a statement about CPU time, not about parts count.

Where it is tested. GATE CSE 2024 Set 1, where this is the false statement among four. The other three — cycle stealing moves one word per stolen cycle, burst has higher throughput than cycle stealing, and a vectored interrupt starts its routine faster — are all true.

6. "The CPU and the DMA controller are both bus masters during a transfer"

Why it is wrong. Bus mastership is exclusive at any instant. The controller requests, the CPU grants and floats its drivers, and the two never drive the same lines together. They overlap in time, not on the wires.

Where it is tested. GATE CSE 2020 Q3, statement IV, which is false. The same distinction makes GATE CSE 2024 Set 2 Q15's claim that "the CPU does not need to get involved, so the current program continues" true rather than false.

Two confusions that are not quite misconceptions

Maskable against non-maskable, read as a priority. Maskability says whether software can disable the request. It does not say where the request sits in the ranking. The two are separate hardware properties, and treating "non-maskable" as "highest priority" gives wrong answers to ranking questions.

Memory-mapped, read as "the registers are memory". They are at memory addresses and reached by ordinary loads and stores. But a device register is a moving part: two reads of the same address can give two different answers, and a write can start a physical action. Any reasoning that treats a port as a variable is reasoning about the wrong object.

The test to apply before answering

Ask which of the two jobs the statement is about — naming the source or ranking the sources — and then ask who is doing the copying. Almost every wrong option in this topic confuses one of those two pairs. Both questions are answerable from the statement alone, before any arithmetic.

What this clause actually asks

Thirteen questions from 2011 to 2026 are attributable to this heading across the papers listed in the Sources tab: ten single-correct, none multiple-select, three numerical. The patterns below are a description of those questions, not a forecast.

Pattern 1 — the ordering question

Give five events after an interrupt and ask for the order, or give three and ask the same. The answer is always forced by two facts: an interrupt is honoured at an instruction boundary, and the status is saved before the program counter is loaded.

Seen in 2018 Q9 and 2025 Set 1 Q11. Procedure: write the two facts first, then place the events. Never place them by feel.

Pattern 2 — the false-statement cluster

Offer four statements spanning three or four subtopics and ask which is false. Each option is a one-line claim about a different mechanism.

Seen in 2020 Q3, 2024 Set 1, 2026 Set 2 Q18. Procedure: classify each option as naming or ranking, then check it. The false one is usually the one that mixes them.

Pattern 3 — throughput from a clock and a fraction

Give the clock rate, the percentage of cycles stolen, and the width moved per stolen cycle. Ask for a rate.

Seen in 2021 Set 2 Q20 and 2024 Set 2 Q11. Procedure: f × p × w, with w in bits. The two traps are bytes-against-bits and Indian digit grouping.

Pattern 4 — the register ceiling

Give a count-register width and a file size, and ask how many times the controller must take the bus.

Seen in 2016 Set 1 Q31. Procedure: 2n is the chunk, and the count of transfers is a ceiling. Verify by multiplying back and checking the remainder is nonzero.

Pattern 5 — CPU time against a device rate

Give a device rate, an overhead, and a mode; ask for a fraction, a gain, or a ratio. Sometimes two modes are compared in one question.

Seen in 2005 Q69, 2005 Q70, 2023 Q34. Procedure: convert the rate to an interval, express both modes as times per byte, divide.

Pattern 6 — the one-word conceptual

Ask which mechanism gives the highest throughput for a bulk transfer, or which interrupt cannot be masked.

Seen in 2011 Q11, 2022 Q17. Procedure: name the copier. Bulk plus highest throughput is always DMA; an unmaskable source is always a hardware failure sensor.

The three arithmetic habits that decide these questions

One. Convert every rate to an interval before comparing anything. Rates compare by ratio, intervals compare by ratio of the other way, and mixing the two is the commonest slip.

Two. Write the unit next to every number as you go: cycles, bytes, words, acquisitions, µs, ns. GATE offers options that differ only by a factor of ten or by bits against bytes.

Three. Decide the operation before computing: is this a division, a ceiling, or a count? A count of transfers is a ceiling; a count of bits is a product; a fraction is one division.

Practice set — page 1 of 2

NATEasyOriginal practice

A processor has a 20-bit address bus and uses memory-mapped I/O. Device registers occupy the top 512 addresses of the space. How many addresses remain for memory?

Answer: 1048064

220 = 1048576 addresses. 1048576 − 512 = 1048064.

The subtraction is on addresses, not on bytes. If the question had said the machine is word addressable with 4 bytes per word, the answer would still be a count of addresses, and the byte capacity would be four times as large.

MCQEasyPYQ — GATE CSE 2022, Q17

Which one of the following facilitates transfer of bulk data from hard disk to main memory with the highest throughput?

(A) DMA based I/O transfer   (B) Interrupt driven I/O transfer   (C) Polling based I/O transfer   (D) Programmed I/O transfer

Answer: (A) DMA based I/O transfer

DMA removes the CPU from the per-word copy, so the throughput is limited by the bus and the device rather than by instruction execution. Polling and programmed I/O both cost the CPU a full interval per word; interrupt-driven I/O costs a service time per word.

The word that decides it is bulk. For a single byte, DMA's setup and completion interrupt can cost more than the transfer itself, so the ranking is not universal — see the Edge cases tab.

MCQMediumPYQ — GATE CSE 2018, Q9

Events after a device controller issues an interrupt while process L runs: (P) push the process status of L onto the control stack; (Q) finish the current instruction; (R) execute the interrupt service routine; (S) pop the process status of L; (T) load the new PC value based on the interrupt. Which is the correct order?

(A) QPTRS   (B) PTRSQ   (C) TRPQS   (D) QTPRS

Answer: (A) QPTRS

Q first, because an interrupt is honoured only at an instruction boundary. P before T, because the program counter is part of the status and loading the new value first destroys the return address. R then S, because the restore is the last thing the routine does.

Option D is the interesting wrong answer: it looks like "jump, then save" and it is exactly the ordering that loses the return address.

MSQMediumOriginal practice

A system uses a DMA controller in cycle stealing mode. Which statements are TRUE?

(A) The controller releases the bus after each unit transferred.
(B) The CPU and the controller can both be bus masters at the same instant.
(C) The elapsed time of the transfer is set by the device's word rate, not by the stolen-cycle time multiplied by the word count.
(D) Burst mode has lower throughput than cycle stealing for the same block.

Answer: (A) and (C)

(A) is the definition of cycle stealing: one unit per grant, then release. (C) is the reason the mode exists — the controller waits for the device between words, so the block's duration is the device's pace.

(B) is false: mastership is exclusive at any instant. (D) is false and is the reverse of the truth — burst pays the handshake once, so it is faster, which is what the 2024 Set 1 paper states as a true option.

Practice set — page 2 of 2

Three previous-year numerical items and one counterexample question that exists because a formula is usually trusted.

NATEasyPYQ — GATE CSE 2021 Set 2, Q20

A computer system with DMA support: the DMA module transfers one 8-bit character in one CPU cycle from a device to memory through cycle stealing at regular intervals. The processor runs at 2 MHz. If 0.5 per cent of processor cycles are used for DMA, the data transfer rate of the device is ______ bits per second.

Answer: 80000

Cycles per second = 2 × 106. Stolen = 0.005 × 2 × 106 = 10000. Each moves 8 bits, so 10000 × 8 = 80000 bits per second.

The width given is already in bits, so there is no conversion. On the 2024 Set 2 variant the width is given in bytes and the conversion is required — that is the only difference between the two questions.

NATMediumPYQ — GATE CSE 2023, Q34

A keyboard is used at 1 keystroke per second. The system polls every 10 ms, consuming 100 µs per poll, and a further 200 µs when a key has been pressed. Let T1 be the fraction of a second spent polling and processing. With interrupts, servicing an interrupt and processing a keystroke takes 1 ms, and T2 is that fraction. Find T1/T2, rounded to one decimal place.

Answer: 10.2

Polls per second = 1000/10 = 100. Polling cost = 100 × 100 µs = 10 ms. Processing = 1 × 200 µs = 0.2 ms. T1 = 10.2 ms. T2 = 1 ms. Ratio 10.2.

The ratio is the same whether both are expressed in milliseconds or seconds, which is why the question can ask for a fraction of a second and be answered in milliseconds. Do not convert until the end.

NATMediumPYQ — GATE CSE 2016 Set 1, Q31

The data count register of a DMA controller is 16 bits. A file of 29154 kilobytes must be transferred from disk to main memory, and memory is byte addressable. What is the minimum number of times the DMA controller must get control of the system bus?

Answer: 456

One transfer covers 216 = 65536 bytes = 64 KB. 29154/64 = 455.53125, and the ceiling is 456.

Verify by multiplying back: 455 × 65536 = 29818880 bytes, leaving 34816. The remainder is why 455 is wrong. Note that the ratio is the same in kilobytes and in bytes, because both sides scale by 1024 — a useful check when a question mixes the units.

MCQHardOriginal practice — counterexample

A device raises one interrupt every 80 µs. Servicing each interrupt, including save and restore, costs 100 µs. Which statement is correct?

(A) The CPU spends 125 per cent of its time on this device, so it is overloaded by 25 per cent.
(B) The CPU cannot keep up: requests arrive faster than they can be served, and the backlog grows.
(C) The fraction formula gives 0.8, so the CPU is 80 per cent utilised.
(D) Interrupts are always cheaper than polling here.

Answer: (B)

Cost 100 µs exceeds interval 80 µs, so the fraction formula is not licensed. There is no such thing as 125 per cent of a CPU's time: the backlog grows without bound and events are lost.

(C) is the reciprocal error — 80/100 instead of 100/80. (D) fails because with an interval this short the CPU is saturated, and a polled loop would simply miss events entirely rather than merely being slow.

Revision sheet

Definitions, formulas, decision procedures and traps, in the order a question uses them.

Definitions, one line each

  • Interface / controller — the hardware presenting data, status and control registers to the bus.
  • Port — the name at which one register answers.
  • Memory-mapped I/O — registers inside the memory address space, reached by load and store.
  • Isolated I/O — a separate port space, reached by IN and OUT, distinguished by one control line.
  • Programmed I/O — the CPU polls the status register and copies each word.
  • Interrupt-driven I/O — the interface requests, the CPU copies in a service routine.
  • Vectored — the device supplies the vector, so no discovery is needed.
  • Daisy chain — a hardware grant pulse that ranks by position.
  • NMI — an interrupt software cannot disable.
  • DMA — a controller with address, count and control registers drives the data register.

Formulas, with their licences

memory left = 2k − p

Licence: count addresses, and every address is one unit of memory.

rate = f × p × w

Licence: cycle stealing, one bus cycle per unit, w in bits.

CPU fraction = c / T

Licence: c < T. Above that the CPU is saturated and the formula is meaningless.

transfers = ⌈file / 2n⌉

Licence: one acquisition per chunk, and the count register is n bits wide.

Decision procedure for any question

  1. Name the registers the question is about.
  2. Name who copies: CPU, or controller.
  3. Name the schedule if it is DMA: burst, stealing, transparent.
  4. Convert every rate to an interval.
  5. Write the count in the unit asked, then perform one operation: product, division, or ceiling.
  6. Check the licence, and check the unit on the answer.

Traps, one line each

  • An interrupt announces data; it does not move it.
  • Vectored means no polling for the source.
  • A daisy chain is hardware, not software polling.
  • Save the status before loading the program counter.
  • One bus master at any instant.
  • A count of transfers is a ceiling.
  • A fraction above one means the model failed.
  • Maskability is not priority.
  • Only one disk head reads at a time.
  • Bits against bytes, and 1000 against 1024.

The one sentence

Who reads and writes the three registers of the interface, and how often — the CPU every time, the CPU when called, or a controller while the CPU pays at the two ends. Every definition, mode and calculation in this lesson is that sentence read at a different scale.
