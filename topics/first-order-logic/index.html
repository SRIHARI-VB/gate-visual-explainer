Topic and objective

TOPIC: First-order logic — predicates, the domain of discourse, the two quantifiers, nested quantifiers and their order, quantifier negation, translation between English and quantified formulas, and free versus bound variables, at the depth GATE CSE asks them.

LEARNING OBJECTIVE: Given a domain and a meaning for each predicate, evaluate any formula with at most two quantifiers and one binary predicate by running the quantifiers as loops over the domain; decide whether two quantified formulas are equivalent or only one-way implied; negate a nested formula correctly; and translate a restricted English sentence into the one shape that is faithful to it.

I read "first order logic" as the syllabus item's second half — quantifiers and predicates, not proof systems, not resolution, not Skolemisation. It continues the prerequisite lesson Propositional Logic, which supplies the connectives and truth tables used throughout.

Prerequisites

  • Propositional logic: ¬, ∧, ∨, →, ↔ and their truth tables. This lesson assumes all five.
  • Set membership and subset, used only to name a domain and a predicate's extension.
  • Reading a grid by rows and by columns — that is the whole of nested quantifiers.
  • Nothing about proof, resolution or Skolem normal form is assumed or used.

The five ideas

  1. A predicate is an open sentence; a quantifier is what closes it.
  2. ∀ is a big AND over the domain; ∃ is a big OR. Everything else follows from that picture.
  3. The domain is part of the claim. The same formula changes truth value when the domain changes.
  4. ¬ flips the quantifier and negates the body — never one without the other.
  5. Quantifiers of the same kind commute; ∀∃ and ∃∀ do not, and only ∃∀ implies ∀∃.

Intuition first: the key cupboard

A hostel has rooms and a cupboard of keys. Two sentences sound almost the same and are not. "Every room has a key that opens it" — true if the cupboard holds a different key for each door, however many keys that takes. "There is one key in the cupboard that opens every room" — a master key, a single object that works everywhere. A hostel can satisfy the first and fail the second: thirty rooms, thirty keys, no master.

Educational interpretation "Every room has a key" is ∀room ∃key, and the key may depend on the room. "One key opens every room" is ∃key ∀room, and the key is chosen before the room is named. The whole of nested quantifiers is this one distinction: who is allowed to depend on whom.

Definition 1 — predicate

A predicate is a statement with one or more variables, which becomes a proposition when each variable is given a value. P(x) has arity 1; R(x, y) has arity 2.

"x > 5" is a predicate. "P(x, y): x divides y" is a predicate of arity 2. The set of values for which a predicate is true is its extension; a model fixes that set.

Definition 2 — domain

The domain (universe of discourse) is the non-empty set D that every variable ranges over, unless a question says otherwise.

Exam trap Two questions with the same formula and different domains have different answers. The empty domain is the one case where ∀ and ∃ stop being duals in the way you expect — see Edge cases.

Definition 3 — the two quantifiers

∀x P(x) is true when P(x) holds for every element of D. ∃x P(x) is true when P(x) holds for at least one element of D. The element that makes ∃ true is a witness.

Derivation Over a finite domain D = {d₁, …, dₙ}: ∀x P(x) ≡ P(d₁) ∧ … ∧ P(dₙ) and ∃x P(x) ≡ P(d₁) ∨ … ∨ P(dₙ). These two identities are the definition of the quantifiers on finite domains, and every check in this lesson is computed from them.

Definition 4 — scope, free, bound

A quantifier binds its variable inside its scope — the subformula it governs. An occurrence of a variable outside any quantifier for it is free. A formula with no free variables is a sentence.

Derivation Free variables are found mechanically: collect every variable mentioned, subtract every variable bound by an enclosing quantifier. ∀x(P(x) ∧ Q(y)) has free variables {y}; ∀x∃y R(x, y) has none, so it is a sentence.

Definition 5 — the negation laws

¬∀x P(x) ≡ ∃x ¬P(x) and ¬∃x P(x) ≡ ∀x ¬P(x).

Derivation The first follows from Definition 3 and De Morgan: ¬(P(d₁) ∧ … ∧ P(dₙ)) ≡ ¬P(d₁) ∨ … ∨ ¬P(dₙ). Verified in this lesson on every one of the eight predicates over the three-element domain, and on every one of the 512 binary relations for the two-variable forms.

Definition 6 — model, validity, satisfiability

A model is a domain together with an interpretation of every predicate symbol. A sentence is valid if true in every model, satisfiable if true in at least one, and unsatisfiable if true in none.

Verified fact In first-order logic a tautology is the narrower notion: a formula obtained by uniformly substituting first-order formulas into a propositional tautology. Every tautology is valid, but not conversely — so "valid" and "tautology" are not synonyms here, unlike in propositional logic.

Definition 7 — the two translation templates

For a sentence that restricts a quantifier to a group A and claims B of that group:

EnglishShapeReads as
All A are B∀x (A(x) → B(x))nothing that is A is also not B
Some A are B∃x (A(x) ∧ B(x))there is an object that is both
No A is B∀x (A(x) → ¬B(x))same as ¬∃x (A(x) ∧ B(x))
Some A are not B∃x (A(x) ∧ ¬B(x))one counterexample to "all A are B"

Derivation ∀ takes →, ∃ takes ∧. The reason is the exemption: an implication is automatically true of anything outside A, which is exactly the behaviour "all A" needs, while a conjunction forces the witness to be inside A, which is exactly what "some A" needs.

The one line worth memorising

∀ is a big AND, ∃ is a big OR — and the order of two different quantifiers decides whether the inner witness may depend on the outer variable.

Worked example 1 — read two nested quantifiers off one grid

Domain D = {a, b, c}. R is a binary predicate; the grid marks the pairs where R(x, y) holds: R(a, b), R(b, c), R(c, a) — nothing else. Decide ∀x∃y R(x, y) and ∃y∀x R(x, y).

Step 1 — ∀x∃y: walk the rows

Fix x = a. The row a has exactly one filled cell, at y = b, so ∃y R(a, y) is true with witness b. Row b: witness c. Row c: witness a. Every row has a witness, so ∀x∃y R(x, y) is true.

The three witnesses are b, c, a — all different. That is allowed here, because y is chosen after x is known.

Step 2 — ∃y∀x: walk the columns

Now y is chosen first. Column a is filled only at row c; column b only at row a; column c only at row b. No column is filled all the way down, so no single y works for every x. ∃y∀x R(x, y) is false.

Derivation One model therefore separates the two sentences, which proves ∀x∃y R(x, y) does not imply ∃y∀x R(x, y). A single model is enough to refute a claimed implication; it is never enough to establish one.

Why this is the fastest method

Rows for the outer ∀x, columns for the outer ∃y. "Every row has a green cell" versus "some column is entirely green". On any GATE question with a small stated domain, this settles the truth value without any symbolic manipulation.

Worked example 2 — four English sentences, four shapes

Domain: all people. S(x) = x is a student, T(x) = x studies, L(x, y) = x likes y.

The two easy shapes

  1. All students study. ∀x (S(x) → T(x)). Implication, because the claim exempts non-students.
  2. Some student studies. ∃x (S(x) ∧ T(x)). Conjunction, because the witness must be a student.

The two shapes with two variables

  1. Every student likes some student. ∀x (S(x) → ∃y (S(y) ∧ L(x, y))). The liked student may differ per liker.
  2. Some student is liked by every student. ∃y (S(y) ∧ ∀x (S(x) → L(x, y))). One popular student, chosen before the liker.

Where the arrow goes in sentence 3

In "every student likes some student", the outer quantifier is ∀ so the outer connective is →. The inner quantifier is ∃ so the inner connective is ∧. Each quantifier carries its own connective; they do not have to match.

Exam trap Writing ∀x∃y (S(x) ∧ S(y) ∧ L(x, y)) is not wrong in meaning when every element is a student, but it is wrong in general: it forces every element of the domain to be a student.

Worked example 3 — negate a nested formula, one quantifier at a time

Negate ¬∀x (P(x) → ∃y (Q(x, y) ∧ ¬R(y))) completely, so that no negation sits in front of a quantifier.

The four steps

  1. Start outside. ¬∀x (…) becomes ∃x ¬(…).
  2. Push ¬ through the implication. ¬(P → Z) ≡ P ∧ ¬Z, so the body becomes P(x) ∧ ¬∃y (Q(x, y) ∧ ¬R(y)).
  3. Push ¬ through the second quantifier. ¬∃y W becomes ∀y ¬W, so we get P(x) ∧ ∀y ¬(Q(x, y) ∧ ¬R(y)).
  4. Push ¬ through the conjunction. ¬(Q ∧ ¬R) ≡ ¬Q ∨ R, giving P(x) ∧ ∀y (¬Q(x, y) ∨ R(y)).

Result, and the sanity check

∃x ( P(x) ∧ ∀y ( ¬Q(x, y) ∨ R(y) ) )

Derivation Check by reading it back: there is an x with P, such that for every y, either Q(x, y) fails or R(y) holds — that is, no y simultaneously satisfies Q(x, y) and fails R(y). Which is exactly the denial of "for every x with P there is a y with Q and not R".

The rule that keeps this safe

Work strictly outside-in. Each step touches one quantifier or one connective, and the quantifier that flips is the one the negation is currently in front of. Never flip a quantifier the negation has already passed.

Edge case 1 — the empty domain splits the two quantifiers

On D = ∅: ∀x P(x) is true (an empty conjunction), and ∃x P(x) is false (an empty disjunction). Both were evaluated in code on the empty domain.

Derivation Consequence: ∀x P(x) → ∃x P(x) is not valid. It holds on every non-empty domain and fails on the empty one. Questions that say "assuming non-empty domains" are switching this case off, which is why GATE 2017 Set 1 Q2 states it explicitly.

Edge case 2 — ∀ does not distribute over ∨

D = {a, b}, P = {a}, Q = {b}. Then ∀x (P(x) ∨ Q(x)) is true, but ∀x P(x) is false and ∀x Q(x) is false, so ∀x P(x) ∨ ∀x Q(x) is false.

Counterexample to ∀x(P∨Q) ⇒ (∀xP ∨ ∀xQ). This is exactly GATE 2016 Set 2 Q27, whose answer is that formula.

Edge case 3 — ∃ does not distribute over ∧

D = {a, b}, P = {a}, Q = {b}. Then ∃x P(x) ∧ ∃x Q(x) is true, but ∃x (P(x) ∧ Q(x)) is false because no single element is in both.

The two witnesses may be different objects. That is the whole difference between "some student is tall" and "some student is tall and some student is short".

Edge case 4 — a rebound variable

In ∀x (P(x) ∧ ∃x Q(x)), the inner ∃x binds its own x and shadows the outer one. The formula is equivalent to ∀x P(x) ∧ ∃x Q(x), which is not the same as ∀x (P(x) ∧ Q(x)).

Derivation Rename before reasoning: ∀x (P(x) ∧ ∃z Q(z)) ≡ ∀x P(x) ∧ ∃z Q(z). Renaming a bound variable never changes meaning; failing to rename it does.

Edge case 5 — the vacuous restricted ∀

If no element satisfies A, then ∀x (A(x) → B(x)) is true whatever B is. "All unicorns are blue" and "all unicorns are not blue" are both true on a domain with no unicorns.

This is not a paradox and not a defect: the sentence claims something only about A-things, and there are none.

Edge case 6 — unique existence

∃!x P(x) abbreviates ∃x (P(x) ∧ ∀y (P(y) → y = x)): at least one, and any two are the same one.

Educational interpretation "Exactly one mother" questions are the common appearance of ∃! in GATE-style translation, and the pair "at least one + uniqueness" is the safe way to write it out.

The pattern behind all six

Every edge case here is a case where a familiar algebraic habit fails: distributing, swapping, or dropping a domain condition. When a formula looks like an algebraic identity, test it on the two-element domain {a, b} — that domain is small enough to check by hand and large enough to break almost every false identity in this topic.

Misconception 1 — "∀x∃y means the same as ∃y∀x"

Why it tempts: both sentences use the same two quantifiers and the same predicate, and in English the two readings can be written with the same words in a different order. Minimal counterexample: D = {a, b, c} with R = {(a,b), (b,c), (c,a)} — every row has a filled cell, no column is filled. So ∀x∃y R is true and ∃y∀x R is false. Correct rule: the outer quantifier's variable is fixed first; the inner witness may depend on it, and only in ∀∃ is that dependence available.

Community observation This is the most frequently reported quantifier error in GATE discussions of the logic questions; it is also the reason GATE 2017 Set 1 Q2 asks which sentences a ∀x∃y sentence implies rather than asking for an equivalence.

Misconception 2 — "∀x (S(x) → T(x)) says everything is a student"

Why it tempts: the word "all" feels like it is quantifying over the domain rather than over students. Minimal counterexample: D = {s₁, t₁} with S = {s₁}, T = {s₁}. The sentence is true and t₁ is not a student. Correct rule: the implication is vacuously true of every non-student, so the sentence constrains only the S-things.

If you actually want "everything is a student who studies", that is ∀x (S(x) ∧ T(x)), a strictly stronger sentence.

Misconception 3 — "∃x (S(x) → T(x)) says some student studies"

Why it tempts: it is the sentence most often produced by mechanically turning "all" into "some" without changing the connective. Minimal counterexample: D = {t₁, t₂}, S = ∅. The sentence is true — every element satisfies the implication — while there are no students at all. Correct rule: ∃ takes ∧. ∃x (S(x) ∧ T(x)) is false on that same domain.

The wrong formula is not merely imprecise: it is true in a model where the English sentence is false.

Misconception 4 — "¬∀x P(x) is ∀x ¬P(x)"

Why it tempts: moving a negation past a symbol feels like a rename. Minimal counterexample: D = {a, b}, P = {a}. Then ¬∀x P(x) is true (b fails) while ∀x ¬P(x) is false (a satisfies P). Correct rule: ¬ flips the quantifier and negates the body. "Not all that glitters is gold" is ∃x (glitters(x) ∧ ¬gold(x)), not ∀x (glitters(x) → ¬gold(x)).

This is GATE CSE 2014 Set 1 Q1, and the same sentence appears as "not all rainy days are cold" in GATE CSE 2014 Set 3 Q53.

Misconception 5 — "valid and tautology are the same in first-order logic"

Why it tempts: in propositional logic the two words really are synonyms, and that is the lesson immediately before this one. Minimal distinction: ∀x P(x) → ∃x P(x) is valid on non-empty domains but is not an instance of any propositional tautology. Correct rule: a first-order tautology is a propositional tautology with formulas substituted for the atoms; the valid formulas are a strictly larger class.

Verified fact GATE CSE 2015 Set 2 Q55 turns on exactly this: the correct option is the one where both sides are the same quantifier prefix applied to propositionally equivalent bodies.

How to avoid all five

Never manipulate a quantified formula by feel. Evaluate it on {a, b} with an explicit predicate extension. Two elements are enough to break every misconception on this page, and the computation takes under a minute.

How this topic is actually examined

First-order logic appears inside the syllabus line "Propositional and first order logic". Across the papers indexed in the sources listed at the end, the questions fall into six recognisable shapes. This is an observation about past papers, not a prediction about GATE 2027.

Pattern 1 — translate one sentence

Give an English sentence with a restriction and four formulas; one is faithful. Reasoning: pick the quantifier from "all/some", then the connective from Definition 7, then check the nesting order. Wrong approach: matching the words in order rather than the claim.

Seen as GATE 2014 Set 1 Q1 and GATE 2014 Set 3 Q53.

Pattern 2 — which formula is NOT valid

Four formulas, three valid, one not. Reasoning: for each candidate, try to build a countermodel on two elements; a distribution failure is almost always the culprit. Wrong approach: testing only the "obvious" reading and assuming the rest.

Seen as GATE 2016 Set 2 Q27 and GATE 2020 Q39.

Pattern 3 — what is implied by a given sentence

One sentence F, four candidates, "which are implied by F". Reasoning: implication is one-way; check each candidate for a countermodel, and remember that same-kind quantifiers may be swapped while mixed ones may not. Wrong approach: treating "implied" as "equivalent".

Seen as GATE 2017 Set 1 Q2 and GATE 2023 Q16.

Pattern 4 — which WFF is a tautology

Four quantified biconditionals or implications. Reasoning: a first-order tautology must be propositionally equivalent bodies under identical quantifier prefixes; anything that needs a quantifier law to be true is valid but not a tautology. Wrong approach: choosing the option that is merely valid.

Seen as GATE 2015 Set 2 Q55.

Pattern 5 — counting models

A NAT asking how many relations or functions on a domain of size n satisfy a quantified property. Reasoning: count the truth assignments the quantifier fixes; a binary relation on n elements has n² independent cells, so 2^(n²) relations exist. Wrong approach: counting ordered pairs of predicates instead of cells.

Practised as question 5 on the Practice tab, computed in code.

Pattern 6 — free variables and sentences

"How many free variables does this formula have?" or "which of these is a sentence?" Reasoning: walk the formula, subtract bound occurrences; a variable bound twice is bound, not free. Wrong approach: counting distinct letters rather than free occurrences.

Appears as a sub-part of translation and validity questions rather than on its own.

The one procedure that answers all six

Write the domain. Write the extension of each predicate as a small set. Substitute. For a validity claim, search for a countermodel on two elements. Every question shape above collapses to that, and the two-element domain is small enough to do in the margin.

MCQ PYQ · GATE CSE 2014 Set 1, Q1 1 mark

Consider the statement "Not all that glitters is gold". Predicate glitters(x) is true if x glitters and gold(x) is true if x is gold. Which one of the following logical formulae represents the above statement?

(A) ∀x (glitters(x) → ¬gold(x))
(B) ∀x (gold(x) → glitters(x))
(C) ∃x (gold(x) ∧ ¬glitters(x))
(D) ∃x (glitters(x) ∧ ¬gold(x))

Answer: (D). "Not all that glitters is gold" is ¬∀x (glitters(x) → gold(x)). Flip the quantifier: ∃x ¬(glitters(x) → gold(x)). Push the negation through the implication (¬(P → Q) ≡ P ∧ ¬Q): ∃x (glitters(x) ∧ ¬gold(x)).

Why the others are wrong. (A) is "all that glitters is not gold" — a universal claim about every glittering object, which is much stronger and is a different sentence. (B) reverses the arrow and says every gold thing glitters. (C) swaps the predicates and says some gold thing does not glitter, which the original sentence does not assert.

Exam trap The words "not all" and "all … not" differ by one word and by one quantifier. "Not all" is an existential claim with a conjunction; "all not" is a universal claim with an implication.

MCQ PYQ · GATE CSE 2016 Set 2, Q27 2 marks

Which one of the following well-formed formulae in predicate calculus is NOT valid?

(A) (∀x p(x) → ∀x q(x)) → (∃x ¬p(x) ∨ ∀x q(x))
(B) (∃x p(x) ∨ ∃x q(x)) → ∃x (p(x) ∨ q(x))
(C) ∃x (p(x) ∧ q(x)) → (∃x p(x) ∧ ∃x q(x))
(D) ∀x (p(x) ∨ q(x)) → (∀x p(x) ∨ ∀x q(x))

Answer: (D). Countermodel: D = {a, b}, p = {a}, q = {b}. Then p(a) ∨ q(a) and p(b) ∨ q(b) both hold, so the antecedent is true; but ∀x p(x) is false and ∀x q(x) is false, so the consequent is false.

Why the others are valid. (A): the antecedent is ¬∀x p(x) ∨ ∀x q(x) by the implication identity, which is literally the consequent. (B): if some element satisfies p or some element satisfies q, that same element satisfies p ∨ q. (C): if one element satisfies both, then each existential has that element as a witness — note the witnesses are the same object here, which is why this direction is valid and the converse is not.

Derivation ∀ distributes over ∧ but not over ∨; ∃ distributes over ∨ but not over ∧. Both failures are computed and shown on the Edge cases tab.

MCQ PYQ · GATE CSE 2015 Set 2, Q55 2 marks

Which one of the following well-formed formulae is a tautology?

(A) ∀x ∃y R(x, y) ↔ ∃y ∀x R(x, y)
(B) (∀x [∃y R(x, y) → S(x, y)]) → ∀x ∃y S(x, y)
(C) [∀x ∃y (P(x, y) → R(x, y))] ↔ [∀x ∃y (¬P(x, y) ∨ R(x, y))]
(D) ∀x ∀y P(x, y) → ∀x ∀y P(y, x)

Answer: (C). Both sides have the identical quantifier prefix ∀x∃y, and the bodies are propositionally equivalent: P → R ≡ ¬P ∨ R. Uniformly substituting into a propositional tautology is exactly what makes a first-order tautology.

Why the others fail. (A) fails because mixed quantifiers do not commute — the lesson's own countermodel separates the two sides. (B) fails: take S always false and R always true on a non-empty domain; the antecedent can be satisfied while ∀x∃y S(x, y) is false. (D) fails: P(x, y) and P(y, x) are different atoms; take a domain of two elements with P true only on the diagonal pair (a, b).

Exam trap Option (A) is the one that tempts: it looks like the quantifier-commutation law. In first-order logic "tautology" is narrower than "valid", so a formula that needs a quantifier law to be true is not a tautology even when it is valid.

MSQ Original practice question 2 marks

Let F be the sentence ∀x ∃y R(x, y), with R a binary predicate and a non-empty domain. Which of the following sentences are implied by F?

(I) ∃y ∃x R(x, y)
(II) ∃y ∀x R(x, y)
(III) ∀y ∃x R(x, y)
(IV) ¬∃x ∀y ¬R(x, y)

Answer: (I) and (IV) only. (I): the two existential quantifiers commute, and F gives every x a witness, so at least one pair exists — implied. (IV): ¬∃x∀y¬R(x, y) is equivalent to ∀x ¬∀y ¬R(x, y), which is ∀x ∃y R(x, y) — literally F, so implied.

Why (II) and (III) fail. (II) is the mixed swap; the lesson's three-element countermodel makes F true and (II) false. (III) quantifies over y in the wrong place: F says every x has some y, which says nothing about y's that no x is related to. Countermodel: D = {a, b}, R = {(a, a)}. Then F is true, but for y = b no x satisfies R(x, b), so (III) is false.

Derivation Same-kind quantifiers may be swapped; mixed ones may not; and the outer variable is the one that gets fixed first. All three facts are used in this one question.

NAT Original practice question 2 marks

Let the domain be {1, 2, 3}. How many binary relations R on this domain satisfy ∃y ∀x R(x, y)? (A binary relation is any subset of the nine ordered pairs.)

Answer: 169. A relation is a 3 × 3 grid of independent cells, so there are 2⁹ = 512 relations. Let Aᵢ be the set of relations whose column i is entirely filled. A single column being filled fixes 3 cells and leaves 6 free, so |Aᵢ| = 2⁶ = 64. Two columns filled fix 6 cells and leave 3 free: 2³ = 8. All three filled: 1 relation.

Inclusion–exclusion: 3(64) − 3(8) + 1 = 192 − 24 + 1 = 169.

Derivation The same enumeration run in code gives 169 for ∃y∀x and 343 for ∀x∃y, so 174 relations separate the two sentences — the count shown on the Animation tab.

MCQ Original practice question 1 mark

How many free variables does ∀x (P(x, y) → ∃y Q(x, y)) have, and which are they?

(A) none — it is a sentence
(B) one — y
(C) two — x and y
(D) one — x

Answer: (B), one free variable, y. The outer ∀x binds every x inside its scope, which is the whole body. The ∃y binds every y inside the consequent Q(x, y). The y in P(x, y) is outside the scope of that ∃y, so it is free.

Why the others are wrong. (A) misses that the y in the antecedent is not bound. (C) misses that x is bound by the outer quantifier. (D) inverts the two: the free occurrence is in P, and it is the y, not the x.

Derivation The code in this lesson computes free variables by this exact walk; the animation's scene 9 shows the result for this formula and two others.

MSQ Original practice question 2 marks

Which of the following implications are valid on every non-empty domain?

(A) ∀x (p(x) → q(x)) → (∀x p(x) → ∀x q(x))
(B) (∀x p(x) → ∀x q(x)) → ∀x (p(x) → q(x))
(C) ∀x (p(x) ∨ q(x)) → (∀x p(x) ∨ ∀x q(x))
(D) ∀x (p(x) ∧ q(x)) → (∀x p(x) ∧ ∀x q(x))

Answer: (A) and (D). (A): if every element that satisfies p also satisfies q, and in fact every element satisfies p, then every element satisfies q. (D): ∀ distributes over ∧ in both directions — a conjunction holds of everything exactly when both parts do.

Why (B) and (C) fail. (B): D = {a, b}, p = ∅, q = ∅. Then ∀x p(x) is false, so the antecedent is vacuously true, but p(a) → q(a) is true and p(b) → q(b) is true, so the consequent is true too — take instead p = {a, b}, q = {a}: antecedent true, consequent false at b. (C) is the distribution failure: D = {a, b}, p = {a}, q = {b}.

Derivation Both failures are computed in this lesson over every pair of predicates on the three-element domain, not merely illustrated once.

MCQ Original practice question 1 mark

On the empty domain, which of the following is correct for an arbitrary predicate P?

(A) ∀x P(x) is false and ∃x P(x) is false
(B) ∀x P(x) is true and ∃x P(x) is true
(C) ∀x P(x) is true and ∃x P(x) is false
(D) ∀x P(x) is false and ∃x P(x) is true

Answer: (C). ∀ is an empty conjunction, which is true; ∃ is an empty disjunction, which is false. Both were evaluated in code on the empty domain as part of this lesson's checks.

Why this matters. It is the reason ∀x P(x) → ∃x P(x) is not valid without a non-empty-domain assumption, and the reason GATE questions that depend on it say "assuming non-empty domains".

Exam trap If a question does not state a domain, the convention in this lesson and in the standard textbooks is a non-empty domain. State the assumption in your rough work before using it.

Translation, in four lines

All A are B   →  ∀x (A(x) → B(x))
Some A are B  →  ∃x (A(x) ∧ B(x))
No A is B     →  ∀x (A(x) → ¬B(x))
Some A not B →  ∃x (A(x) ∧ ¬B(x))

∀ takes →, ∃ takes ∧. Each quantifier carries its own connective, including inside a nesting.

Decision procedure for any question

  1. Write the domain. If none is given, assume non-empty and say so.
  2. Write each predicate's extension as a set. Two elements is usually enough.
  3. Substitute and evaluate. ∀ becomes ∧ over the domain, ∃ becomes ∨.
  4. For a validity claim, hunt a countermodel. One model refutes; only a proof establishes.

Traps, in order of how often they are missed

  • Reading ∀x∃y as ∃y∀x.
  • Using ∧ under ∀, or → under ∃.
  • Negating the body without flipping the quantifier.
  • Reading "not all" as "all not".
  • Forgetting that ∀ over an empty domain is true.
  • Calling a valid formula a tautology in first-order logic.

Three lines to carry into the exam

∀ is a big AND, ∃ is a big OR. ¬ flips the quantifier and negates the body. Same-kind quantifiers commute; mixed ones do not, and ∃∀ implies ∀∃ only. Everything else on this sheet is a consequence of those three.

What this lesson did not cover

Resolution and proof systems, Skolem and prenex normal form as algorithms, soundness and completeness, and many-sorted or modal extensions. None of these is named in the GATE 2027 CS syllabus line, so none is taught here; they are listed so the boundary is explicit rather than implied.
