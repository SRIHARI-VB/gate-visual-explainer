Topic and objective

TOPIC: State minimisation of a finite-state machine: equivalent states, partition refinement, the minimum-state machine, and what the reduction does and does not save.

LEARNING OBJECTIVE: Decide whether two states of a completely specified machine are equivalent. Build the output partition, then refine it pass by pass until nothing splits. Read the minimum-state machine off the stable partition, and prove it behaves exactly like the original. Compute the flip-flop count before and after, and say honestly when nothing is saved.

I read this as one question asked three ways: which states are the same, how many states remain, and what that changes in hardware. Every number on this page is computed by the page, on three machines, and checked two further ways.

GATE relevance

Verified fact Class A by clause, with a caveat that is worth stating. Section 2 of the GATE 2027 CS syllabus, published by IIT Madras, reads: “Boolean algebra and minimization – algebraic technique, Karnaugh map, tabular method. Design of combinational and sequential circuits. Number representation and arithmetic (fixed and floating point).” The words Design of … sequential circuits are named verbatim, and state reduction is a step of that design flow.

The caveat: the minimisation words in that sentence — algebraic, Karnaugh map, tabular — name the minimisation of a Boolean function, not the minimisation of a state set. State minimisation is therefore class B in its own right: not named as a clause, but the step the named design clause ends with. The lesson keeps that distinction rather than claiming more than the document says.

Community observation A question catalogue lists 32 items on combinational and sequential circuits from 2011 onward and tags state equivalence and minimisation in 2025 and 2021. That is somebody's indexing of a collection, not official weightage, and not a forecast for 2027.

Prerequisites

  • Sequential circuits: latches, flip-flops, counters and machines — what a state is, Moore against Mealy, and why n states need the ceiling of log base 2 of n flip-flops.
  • Relations and their properties — equivalence relations and the partitions they induce. State equivalence is an equivalence relation, and its classes are the states of the minimal machine.
  • Sets and set operations — a partition is a set of non-empty disjoint sets whose union is the whole state set.
  • Reading a state table: one row per state, one column per input, each cell holding a next state and an output.

No software is needed. The partition refinement, the exact pair search and the string comparison all run in the browser, and their results are printed on the canvas and under it.

The five ideas, in one line each

  • A state is a promise, not a name. Two states are equivalent when every input string produces the same output sequence from both.
  • Start from outputs. One input can only separate states whose output on it differs, so P0 groups states by their output vector.
  • Refine by classes, not by states. Split a class when two members move to different classes on the same input.
  • Stop when a whole pass changes nothing. Every pass only splits, so an early stop merges states that are not equivalent.
  • Fewer states do not always mean fewer flip-flops. Eight states and five states both need three; four states need two.

Intuition first: two shop assistants who answer the same way

A shop has two assistants at two tills. Asked for a refund, both say yes and send the customer to the manager's desk. Asked for a price check, both say no and send the customer to the same shelf. Every question produces the same answer and the same next destination. The shop does not need two people to cover those two tills; one would do, and no customer could tell the difference.

That is state equivalence, and the reason it matters is cost: one assistant, one state, one register. Educational interpretation The metaphor carries the definition and the saving. It does not carry the hard part, which is that two assistants can answer differently in the moment and still be interchangeable, because the customers they send on are interchangeable too. That is the 1996 counterexample, and it gets its own scene.

The vocabulary, every term in words

State table — one row per state, one column per input. A cell holds the next state and the output produced on that transition (Mealy), or the row holds a single output (Moore).

Input string w — any finite sequence of inputs, including the empty string, which is written ε and has length zero.

out(s, w) — the sequence of outputs printed when w is fed in, starting from state s.

Equivalent states — p and q are equivalent when out(p, w) = out(q, w) for every string w.

Distinguishing string — one string on which two states disagree. One witness proves they are not equivalent.

Partition — a grouping of the states into non-empty classes, no state in two classes. The classes of the equivalence relation are exactly the states of the minimal machine.

The definition, and the two directions of proof

p ≡ q iff out(p, w) = out(q, w) for every input string w Read: p is equivalent to q exactly when the output sequence is the same from both, whatever string is fed in. The quantifier is over all strings, not over one row of the table.

To prove two states differ you exhibit one distinguishing string, and that is a complete proof. To prove two states are equivalent you cannot test strings one at a time; you need an argument that covers all of them, which is what the algorithm supplies.

Mathematical derivation The page does both: a brute-force comparison over every string up to length eight, which is evidence, and an exact search over the product graph of state pairs, which is a complete decision procedure.

The algorithm: partition refinement

P0. Group the states by their output vector, that is by the list of outputs they print on each input. States that disagree on some single input are separated by a string of length one, so they can never share a class.

Refine. For each class, replace each member's next state by the class that next state belongs to. Two members stay together only if, for every input, their class vectors are identical. Split the class wherever they are not.

Repeat until a whole pass changes nothing. The classes of that stable partition are the states of the minimal machine.

Read off. One row per class; the next-state entry is the class of the original next state; the output is the output of any member, which is well defined because the partition was built that way.

Why it terminates, and why it is exact

Each pass either changes nothing, in which case we stop, or adds at least one class, because splitting is the only move. There are at most n classes for n states and P0 already has at least one, so the number of passes is at most n − 1.

Exactness runs both ways. If two states survive together in the stable partition, an induction on string length shows no string separates them, so they are equivalent. If two states are in different classes, the pass that separated them found a string that tells them apart, so they are not equivalent.

Mathematical derivation Both directions are checked on this page rather than asserted: the pass count against the bound, and the classes against an exact pair search that shares no code with the refinement loop.

Moore machines, and the one case this does not cover

In a Moore machine the output sits on the state rather than on the transition. P0 then groups states by a single output bit, so it has at most two classes, and every later step is identical. The one visible consequence is a real one: the same behaviour can need fewer states as a Mealy machine than as a Moore machine, because a Mealy machine may print the output on the transition that arrives.

The case this algorithm does not cover is an incompletely specified machine, where some next state or output is a don't-care. There two states are not equivalent or inequivalent but compatible, compatibility is not transitive, and the right object is a maximal compatible set. Every paper item in this family that could be verified here is completely specified, so partition refinement is enough for the exam, and this page says plainly where it stops.

Example 1 — GATE CSE 2025 Set 1, Q59: eight states to five

The table, with the next state and the output for each value of the single input X:

state X=0: next, out X=1: next, out A F, 0 B, 0 B D, 0 C, 0 C F, 0 E, 0 D G, 1 A, 0 E D, 0 C, 0 F F, 1 B, 1 G G, 0 H, 1 H G, 1 A, 0 Question as published: the minimum number of states required to realise this FSM is ______. Answer in integer.

  1. P0 by output vector. A, B, C, E print 00; D and H print 10; G prints 01; F prints 11. Four classes. Outputs are the only thing a string of length one can see.
  2. Refine {A,B,C,E}. A goes to F then B, which is class 3 then class 0. C goes to F then E, also class 3 then class 0. B goes to D then C, class 2 then class 0. E goes to D then C, the same. Two class vectors, so two classes: {A,C} and {B,E}. Replace each next state by its class before comparing.
  3. Refine {D,H}. D goes to G then A, and H goes to G then A. One class vector, so the pair survives. Two different next states in the same class do not separate anything.
  4. Second pass. A and C both go to class 3 then class 0; B and E both go to class 2 then class 0; D and H both go to class 4 then class 0. Nothing splits. Stable means a whole pass changes nothing.
  5. Count. Five classes, so five states. The page's exact pair search finds 25 of the 28 pairs distinguishable and exactly three equivalent: A with C, B with E, D with H.

Trap. Answering 4 from P0 alone. The class {A,B,C,E} does split, and that split is the whole question.

Example 2 — GATE CSE 1996, Q2.23: four states to three

state X=0: next, out X=1: next, out A D, 0 B, 1 B A, 0 C, 1 C A, 0 B, 1 D A, 1 C, 1 Question as published: the number of states in the minimised machine will be 4, 3, 2 or 1.

  1. P0 by output vector. A, B, C print 01; D prints 11. Two classes: {A,B,C} and {D}.
  2. Refine {A,B,C}. A goes to D then B, class 1 then class 0. B goes to A then C, class 0 then class 0. C goes to A then B, class 0 then class 0. So A separates from the pair, and {B,C} stays together.
  3. Second pass. B goes to class 0 then class 0; C goes to class 0 then class 0. Nothing splits. Three classes: {A}, {B,C}, {D}.
  4. Answer: three states. B and C have different rows — on input 1, B goes to C and C goes to B — and they are still the same state.

Why this is the useful example. It is the counterexample to “same row means merge, different row means don't”. The page confirms the merge independently: B and C agree on all 511 input strings up to length eight, and the exact pair search finds no distinguishing string at all.

Example 3 — the twin machine: two passes, seven states to four

A Moore machine with two inputs. On 0 it walks a chain; on 1 every state returns to A0. A3 is the only state whose output is 1, and the second chain B0 → B1 → B2 also ends at A3.

next on 0: A0->A1 A1->A2 A2->A3 A3->A3 B0->B1 B1->B2 B2->A3 next on 1: every state -> A0 output: 1 at A3, 0 at every other state

  1. P0. Output 1 at A3 only, so two classes: the six output-0 states, and {A3}.
  2. Pass 1. A2 and B2 both go to A3, which is class 1; the rest go to class 0. Three classes: {A0,A1,B0,B1}, {A2,B2}, {A3}.
  3. Pass 2. A1 and B1 go to class 1; A0 and B0 go to class 0. Four classes: {A0,B0}, {A1,B1}, {A2,B2}, {A3}.
  4. Pass 3. No change, so stop. Four states, from seven.

What it demonstrates. One pass gives three classes and the answer is four, so stopping early under-counts. The longest shortest distinguishing string here has length 3, which is exactly one more than the number of passes.

Example 4 — the reduced table of the 2025 machine, and what it costs

Five classes, so five rows. Each entry is the class of the original next state, and the output is the output of any member:

class members next on 0 next on 1 out 0, out 1 q0 {A,C} q3 (was F) q1 (was B) 0, 0 q1 {B,E} q2 (was D) q0 (was C) 0, 0 q2 {D,H} q4 (was G) q0 (was A) 1, 0 q3 {F} q3 (was F) q1 (was B) 1, 1 q4 {G} q4 (was G) q2 (was H) 0, 1 Sixteen next-state entries become ten. The table is well defined because every member of a class prints the same output and lands in one class.

The page then runs every input string up to length eight from every one of the eight original states and compares with the reduced machine: 4,088 comparisons, no mismatch. That is evidence, and the exact pair search is the proof.

The cost, computed. Eight states need three flip-flops and five states need three, so this reduction saves no register. The twin machine is the contrast: seven states need three and four need two, so there one register goes. Mathematical derivation The count is the ceiling of log base 2 of the state count, and nothing else.

The boundaries: where each rule stops, and what changes when it does

Each card states the condition a rule needs and what happens when it fails. These are the cases that separate a correct answer from an almost-correct one.

Different rows do not mean different states

In the 1996 machine, B goes to A then C while C goes to A then B. The rows differ and the states are equivalent, because A and B are themselves interchangeable from that point on.

The condition that matters. Compare the classes of the next states, never the next states themselves. Row comparison is a sufficient test for a merge and never a necessary one.

One pass is enough on some machines and not on others

The 2025 machine stabilises after one pass, and the 1996 machine after one. The twin machine needs two, and one pass there reports three states where the answer is four.

The safe rule. Stop when a whole pass makes no change. The pass count is bounded by n − 1, and on these machines it equals the longest shortest distinguishing string minus one.

Fewer states do not always mean fewer flip-flops

Eight states and five states both need three flip-flops, so the 2025 reduction saves nothing in registers. Seven to four does save one, because it crosses from the 5–8 step to the 3–4 step.

What is always saved. Rows. Sixteen next-state entries become ten, and the next-state logic shrinks whether or not a register goes.

Unreachable states are not part of the behaviour

On the twin machine, starting at A0, only A0, A1, A2 and A3 can ever be reached: input 1 returns to A0 and input 0 walks forward, so the B chain is dead code. The reduced machine has exactly the four reachable classes.

Which the question wants. If it asks about the table, count the table. If it asks about the machine, delete what cannot be reached first. The two answers coincide here, and they need not in general.

A don't-care entry puts the machine outside this algorithm

With a don't-care next state or output, two states become compatible rather than equivalent, and compatibility is not transitive. Three states can be pairwise compatible and not mergeable together.

What to do. Recognise the shape and say so. The object you need is a maximal compatible set, which is a different problem, and no verified paper item in this family is of that kind.

A Moore machine's minimum can exceed the Mealy minimum

Detect two consecutive ones: two states as a Mealy machine, three as a Moore machine. Both are minimal, and refinement splits neither.

The assumption to check. The word “minimum” is only meaningful once the machine type is fixed. A question that does not say which type has not been read carefully enough.

Six beliefs that produce a plausible wrong integer

Each card gives the belief, why it is tempting, the smallest case that refutes it, and the rule to use instead. They are drawn from the shapes of the wrong answers this family of questions generates, not from a survey of learners.

1. “States with the same output are the same state”

Why it tempts. P0 is built from outputs, so outputs clearly matter, and on the 2025 machine four states do share one output vector.

Refutation. In the 2025 machine A and B both print 00 and are not equivalent: the string 01 separates them. The output vector is the starting point, not the answer.

Correct rule. Group by outputs, then refine by where the states go.

2. “Different next states mean different states”

Why it tempts. The next state is the visible difference in the table, and it feels like the definition of behaving differently.

Refutation. GATE CSE 1996 Q2.23: B and C have different next states on input 1 and are equivalent, and the answer key is three states, not four.

Correct rule. Compare the classes the next states belong to, not the next states.

3. “One refinement pass is the algorithm”

Why it tempts. Both paper items in this lesson need exactly one pass, so the habit is never punished by the papers people practise on.

Refutation. The twin machine needs two: one pass gives three classes, and the answer is four. A paper can ask for a machine of that kind.

Correct rule. Repeat until a whole pass changes nothing.

4. “A smaller machine means fewer flip-flops”

Why it tempts. States are stored in flip-flops, so fewer states sounds like less hardware.

Refutation. Eight states and five states both need three flip-flops. The ceiling of log base 2 is a step function, and a reduction inside one step saves no register.

Correct rule. Compute the ceiling before and after, and claim a saving only when it falls.

5. “The minimal machine is one of several choices”

Why it tempts. There are many ways to group a set, so a minimal grouping sounds like a matter of taste.

Refutation. There is exactly one coarsest correct partition. The page computes it two independent ways, refinement and an exact pair search, and both give the same five classes on the 2025 machine.

Correct rule. The minimal machine is unique up to renaming its states.

6. “The algorithm works on any state table”

Why it tempts. The tables in papers are complete, so the boundary is invisible until it is crossed.

Refutation. With a don't-care entry, compatibility is not transitive, and the classes a partition produces need not be mergeable sets at all.

Correct rule. Check that every entry is specified before you run the passes. If one is not, the problem has changed.

Three question shapes, one algorithm

Every item in this family hands you a machine and asks for one of three things. Identify which, and the work is the same four lines. The previous-year items quoted carry their year and question number, and each answer was recomputed here rather than copied from a key.

Shape 1 — the minimum number of states

“The minimum number of states required to realise this FSM is ______.” Run the passes to stability and count the classes. Seen as GATE CSE 2025 Set 1 Q59, where eight states reduce to five.

The check. The answer cannot exceed the number of rows given, and cannot be below the number of classes P0 forces. On that item: at least 4, at most 8, answer 5.

Shape 2 — which states are equivalent

“Which of the following pairs can be merged?” or “the number of equivalent pairs is ______.” Read the classes off the stable partition; a pair is equivalent exactly when the two states share a class.

The check. On the 2025 machine there are 28 pairs and exactly three equivalent ones. An answer naming a pair from an unstable partition is wrong however plausible it looks.

Shape 3 — design, then minimise

A behavioural description is given, and the question asks for the number of states, sometimes of the minimum machine. Design first, expect one state too many, then minimise. GATE CSE 1996 Q2.23 is the pure form: four states given, three required.

The check. A machine you have just designed is rarely minimal, so a design question with a state count in it is a minimisation question in disguise.

The four-line procedure, written down once

Line one: group by output vector, which gives P0. Line two: inside each class, replace every next state by its class and split where the class vectors differ. Line three: repeat until a whole pass changes nothing, then count the classes. Line four: read the reduced table off the classes, one row per class.

Why this order. Every error in this family is in line one, by starting from rows instead of outputs, or in line three, by stopping too early. Doing them in a fixed order makes the error visible at the step that caused it.

The five traps, by sight

  • Comparing rows instead of classes.
  • Stopping after one pass.
  • Claiming a saved flip-flop when the ceiling did not fall.
  • Reading a Moore machine's minimum off a Mealy machine, or the reverse.
  • Running the passes on a table with don't-care entries.

The sanity checks that cost one line

  • The answer is a whole number between the count of P0 classes and the number of rows.
  • A reduction never creates states.
  • Two states a single input already separates can never be merged.
  • A flip-flop count is the ceiling of log base 2 of the state count, and it never exceeds the number of state bits the table was written with.
  • If your classes are not disjoint and do not cover every state, they are not a partition.

NATGATE CSE 2025 Set 1 Q59

Consider a finite state machine with one input X and one output f, given by this transition table. The minimum number of states required to realise this FSM is ______. (Answer in integer)

state X=0: next, f X=1: next, f A F, 0 B, 0 B D, 0 C, 0 C F, 0 E, 0 D G, 1 A, 0 E D, 0 C, 0 F F, 1 B, 1 G G, 0 H, 1 H G, 1 A, 0

Answer: 5

P0 by output vector is {A,B,C,E} with 00, {D,H} with 10, {G} with 01 and {F} with 11. One refinement pass splits {A,B,C,E} into {A,C} and {B,E}, because A and C go to class 3 then class 0 while B and E go to class 2 then class 0. The second pass changes nothing, so the classes are {A,C}, {B,E}, {D,H}, {F}, {G}.

Why 4 appears. P0 counted and the refinement skipped. Why 6 appears. Splitting {D,H} because the two states reach different next states, when both reach the same classes.

MCQGATE CSE 1996 Q2.23

Consider the following state table for a sequential machine. The number of states in the minimised machine will be

state X=0: next, out X=1: next, out A D, 0 B, 1 B A, 0 C, 1 C A, 0 B, 1 D A, 1 C, 1

  1. 4
  2. 3
  3. 2
  4. 1

Answer: B — 3 states

P0 is {A,B,C} with output 01 and {D} with output 11. The first pass separates A, which goes to class 1 then class 0, from B and C, which both go to class 0 then class 0. The second pass changes nothing, so the classes are {A}, {B,C}, {D}.

Why 4 appears. B and C have different rows, so a row comparison keeps them apart. Why 2 appears. Merging all of {A,B,C} because the outputs agree, which the string 00 refutes: A and B print different sequences.

NATOriginal practice

A Moore machine has two inputs and these transitions, with output 1 at A3 and 0 everywhere else. On input 1 every state returns to A0. On input 0 the transitions are A0→A1, A1→A2, A2→A3, A3→A3, B0→B1, B1→B2, B2→A3. What is the minimum number of states?

Answer: 4

P0 has two classes. Pass 1 separates {A2,B2}, which reach the one-output state, giving three classes. Pass 2 separates {A0,B0} from {A1,B1}, giving four. Pass 3 changes nothing: {A0,B0}, {A1,B1}, {A2,B2}, {A3}.

Why 3 appears. One pass and no more, which is exactly the trap. Why 7 appears. No minimisation at all, although the two chains behave identically.

MSQOriginal practice

For the eight-state machine of GATE CSE 2025 Set 1 Q59, which statements are CORRECT?

  1. A and C are equivalent states.
  2. The minimum machine has five states.
  3. Eight states and five states both require three flip-flops.
  4. Every pair of the eight states is distinguishable.

Answer: A, B and C

The page computes all three. The classes are {A,C}, {B,E}, {D,H}, {F}, {G}; the ceiling of log base 2 is 3 for both eight and five; and 25 of the 28 pairs are distinguishable, so three are not.

Why D is false. A with C, B with E and D with H have no distinguishing string at all, which the exact pair search confirms.

NATOriginal practice

In the eight-state machine above, how many of the 28 unordered pairs of states are equivalent?

Answer: 3

A class of size k contributes k(k−1)/2 equivalent pairs. Here the classes have sizes 2, 2, 2, 1, 1, so 1 + 1 + 1 = 3.

Why 5 appears. Counting classes instead of pairs. Why 4 appears. Counting the class of size two twice, or adding the single states.

MCQOriginal practice

A Moore machine and a Mealy machine are both required to print 1 on the clock cycle in which the second of two consecutive 1s arrives. Which statement is correct?

  1. Both need two states, because the behaviour is the same.
  2. The Mealy machine needs two states and the Moore machine needs three.
  3. The Moore machine needs two states and the Mealy machine needs three.
  4. Both need three states, because the output must be stored.

Answer: B

The Mealy machine prints on the transition into its second state, so two states suffice. The Moore machine must print from a state, and the state that carries output 1 is a third state. The page runs refinement on both and neither splits, so both counts are minimal.

Why A tempts. It is true that the behaviour is the same, and false that the minimum is a property of the behaviour alone. Why C tempts. Reversing the machine types.

MCQOriginal practice

Which one of the following is TRUE of the partition refinement used to minimise a completely specified machine?

  1. A refinement pass can merge two classes into one.
  2. Two states in different classes of P0 can still be equivalent.
  3. Two states that print different outputs on some input can never share a class.
  4. The number of classes can fall as the passes proceed.

Answer: C

A single input already separates them, so no later pass can put them together. That is exactly why P0 is the starting point rather than the answer.

Why A and D are false. A pass only splits, so the class count is non-decreasing; the page checks this monotonicity on every machine. Why B is false. Different P0 classes means different output vectors, which means a distinguishing string of length one exists.

Revision sheet

Everything needed for a question in this family, on one screen. If a line here is unfamiliar, the scene that explains it is named beside it.

Definitions

  • out(s, w) — the output sequence printed from s on the string w (scene 2).
  • p ≡ q when out(p, w) = out(q, w) for every w (scene 2).
  • Distinguishing string — one w on which a pair disagrees; one witness settles a pair (scene 2).
  • P0 — the classes of states with the same output vector (scene 3).
  • Refinement — split a class when two members reach different classes on the same input (scene 4).
  • Stable — a whole pass changes nothing (scene 5).

The numbers on this page

  • 2025 machine: 8 → 5 states, P0 has 4 classes, one pass, 3 of 28 pairs equivalent (scene 4).
  • 1996 machine: 4 → 3 states, {B,C} merged, one pass (scene 2).
  • Twin machine: 7 → 4 states, two passes, P1 has 3 classes (scene 5).
  • Reduced 2025 table: 16 next-state entries → 10 (scene 6).
  • String comparison: 4,088 evaluations, 0 mismatches (scene 6).
  • Flip-flops: 8 and 5 both need 3; 7 needs 3 and 4 needs 2 (scene 7).

The procedure in four lines

  • Group by output vector: that is P0.
  • Inside each class, replace every next state by its class and split where the class vectors differ.
  • Repeat until a whole pass changes nothing, then count the classes.
  • Read the reduced table off the classes, one row per class.

Traps, and the one-line check for each

  • Rows instead of classes — ask “same class?” at every comparison.
  • Stopping after one pass — require a full pass with no change.
  • Claiming a saved flip-flop — compute the ceiling on both sides.
  • Moore against Mealy — find the word in the question before computing.
  • Don't-cares — check that every entry is specified.

Three questions to answer from memory before you close this tab

A four-state machine reduces to three. How many flip-flops before and after? (Two and two: the ceiling of log base 2 is 2 for both.)

Two states print the same output on every input and reach different next states. Are they equivalent? (Not necessarily: compare the classes of the next states, and check for a distinguishing string.)

A partition has four classes and the table has eight rows. What are the two bounds on the answer? (At least 4, at most 8, and the answer is between them.)

Honest limits of this page

The two previous-year items are transcriptions from community archives, not scans of the official papers. The 2025 table is reproduced in full because two independent archives agree on it; the 1996 item is reproduced without its answer letters being re-verified beyond the recorded key.

The state counts are computed, not measured: refinement, an exact pair search over all pairs, and a brute-force comparison on every string up to length eight. The third is evidence and the second is a proof, and the page labels them that way rather than calling all three proofs.

Incompletely specified machines are described but not computed, because they need maximal compatible sets and no verified paper item in this family is of that kind.
