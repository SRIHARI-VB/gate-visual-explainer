Topic and objective

TOPIC: Monoids and groups — a binary operation as a complete table; the five promises (closure, associativity, an identity, inverses, commutativity); the named rungs semigroup, monoid, group and abelian group; the order of an element and cyclic groups; subgroups, cosets and Lagrange's theorem; and the counterexample that stops Lagrange running backwards.

LEARNING OBJECTIVE: Given a set and an operation, decide which rung of the ladder the structure reaches and name the first promise it breaks; find the identity and the inverse of any element from the table; compute the order of an element and decide whether the group is cyclic; list the subgroups of a small group; and answer a subgroup-size question from the divisors of the group order, while saying when that inference is only a bound.

I read this as the syllabus item "Monoids, Groups" — the tracker's unit "Algebraic structures" — and not as general ring or field theory, which the GATE CS syllabus does not name. It builds on Sets and Set Operations (the set, the power set, the product) and Functions and Their Properties (composition, bijections, which is what a permutation is). It is a sibling, not a continuation, of Partial Orders and Lattices: a lattice is an ordered set with two operations, a group is a set with one, and the two lessons share no definitions.

GATE relevance

Verified fact Class A — explicitly in the syllabus.

Section 1 of the official GATE 2027 CS syllabus (IIT Madras), Discrete Mathematics, reads: "Propositional and first order logic. Sets, relations, functions, partial orders and lattices. Monoids, Groups. Graphs: connectivity, matching, colouring. Combinatorics: counting, recurrence relations, generating functions."

Both words are named. In the papers this unit appears as a subgroup-size question settled by divisors, a "which statements are true for every group" multiple-select question, a classification question on a named set and operation, or a count of self-inverse elements. Six previous-year questions are worked in the GATE patterns tab, each with its year, set and question number.

Prerequisites

  • Sets. A structure is a set plus an operation; the power set and the cartesian product are two of the examples.
  • Functions. A permutation is a bijection from a set to itself, and composition is the operation of the symmetric group.
  • Modular arithmetic. Remainders after division; "modulo 6" means the answer is taken in 0 to 5.
  • Divisibility. The divisor list of 6, 12, 15, 35 and 84 is used directly, so factorising small numbers must be automatic.

Nothing in this lesson needs linear algebra, calculus or probability.

1. Intuition — a rule on a set is a table you can fill in

Think of a clock. On a six-hour clock, "three hours after four" is one, because 7 wraps round to 1. That rule takes two numbers and returns one, and it is completely described by a six-by-six table: the row is the first number, the column is the second, the cell holds the answer. Educational interpretation The clock is an analogy for a binary operation, nothing more: a clock is a picture of addition modulo 6, not of every group.

Once the table is written, every question in this topic becomes a question about cells. Is there a row that repeats the column headings? That is an identity. Does every row contain the identity cell? That is inverses. Is the table a mirror image of itself across its diagonal? That is commutativity. Nothing is hidden.

2. Formal definitions — each promise, and each name it earns

Binary operation. A rule that takes an ordered pair of elements of a set S and returns a single element of S. Written a ★ b. The symbol ★ is a placeholder for whatever the rule is; it is not multiplication unless stated.

Closure. Every a ★ b is again an element of S. This is part of being an operation at all, which is why a question that names a set and a rule is testing closure first.

Associativity. (a ★ b) ★ c = a ★ (b ★ c) for all a, b, c in S. Bracketing does not change the answer.

Identity. An element e with e ★ a = a ★ e = a for every a. At most one exists.

Inverse. For a, an element b with a ★ b = b ★ a = e. Exists only if an identity exists.

Commutativity. a ★ b = b ★ a for all a, b. This is a separate promise and is not implied by any of the others.

The names. Closed and associative is a semigroup. A semigroup with an identity is a monoid. A monoid in which every element has an inverse is a group. A group whose operation commutes is an abelian group. Verified fact These are the standard definitions (see Sources).

3. The two numbers attached to a group

Order of the group, |G|. The number of elements. Z6 has order 6.

Order of an element, ord(a). The smallest positive k with a to the power k equal to the identity, where a to the power k means a ★ a ★ … ★ a, k times. The element 3 in Z6 has order 2, because 3 + 3 is 0.

Cyclic. A group is cyclic when some element has order equal to |G|. That element is called a generator, and its powers list every element exactly once.

Subgroup. A subset H of G that is itself a group under the same operation: the identity is in H, H is closed, and every element of H has its inverse in H. H = {e} and H = G are the two trivial subgroups.

4. The classification ladder

Climb in this order and stop at the first failure. The rung you stopped at is the answer, and the vocabulary is fixed.

  • Closed? No → not an operation on that set.
  • Associative? No → not a semigroup.
  • Identity? No → semigroup.
  • Every inverse? No → monoid.
  • Commutative? Yes → abelian group; no → group.

Derivation The ladder is just the definitions stacked in dependency order: inverses are defined against an identity, so that rung cannot be tested first.

5. Worked examples, each computed in the page

(Z6, +) is an abelian group. Identity 0, inverse of a is 6 − a, all 216 triples associative, table symmetric.

(Z6, ×) is a commutative monoid and not a group. Identity 1; the elements 0, 2, 3 and 4 have no inverse, because every product with them is even or zero and never 1.

S3 is a group of order 6 and is not abelian. Six permutations of three letters under composition; the transposition 021 and the cycle 120 multiply to different answers in the two orders.

The units of 7 form a cyclic group of order 6. Elements 1 to 6 under multiplication modulo 7; generators 3 and 5; the element 2 has order 3.

Z4 and U(8) are both abelian of order 4, and only Z4 is cyclic. Every element of U(8) squares to 1, so no element has order 4.

(2^X, symmetric difference) is an abelian group of order 8 when |X| = 3. Identity the empty set, every element its own inverse, which is the same shape as Z2 × Z2 × Z2.

6. Boundaries — what these words do not promise

A group does not promise commutativity (S3 is the standard counterexample), does not promise that every divisor of its order is a subgroup size (A4), and does not promise that the group is cyclic (S3 again).

A monoid does not promise inverses, and the missing inverse is usually one element with an arithmetic reason: 2 in the integers, 0 in any Z_n under multiplication, the constant-1 function under pointwise addition.

Six worked examples, every verdict recomputed in the page

Each example is a set and an operation. Read the table row by row: identity first (the row that copies the headings), then inverses (the identity cell in every row), then commutativity (the mirror test). The page performs these scans over the whole table and prints the count under "Model checks" in the Animation tab.

Example 1 — (Z6, +), an abelian group

Elements 0 to 5, operation addition modulo 6. Closure: every sum of two elements is again in 0 to 5. Associativity: the page checks all 216 triples and finds no disagreement. Identity: 0, because 0 + a = a. Inverses: the inverse of a is 6 − a, which is in the set; 0 is its own inverse. Commutative: the table is symmetric, since a + b = b + a. Verdict: abelian group of order 6.

Order of elements: ord(0) = 1, ord(1) = 6, ord(2) = 3, ord(3) = 2, ord(4) = 3, ord(5) = 6. So the group is cyclic, with generators 1 and 5. Every order divides 6, as the theorem requires. Derivation Computed from the table by repeated addition until 0 returns.

Example 2 — (Z6, ×), a monoid that is not a group

Same set, different operation. The identity is 1, because 1 × a = a. Now look for a cell holding 1 in each row. Row 0 never holds 1. Rows 2, 3 and 4 never hold 1 either: products with 2 are 0, 2 or 4; with 3 are 0 or 3; with 4 are 0, 2 or 4.

So four of the six elements have no inverse, and the structure is a commutative monoid. The elements that do have inverses are 1 and 5, and those two form a group of order 2 — the units of 6, whose count is Euler's totient φ(6) = 2.

Example 3 — S3, a group that is not abelian

Elements are the six orderings of 0, 1, 2, meaning "0 goes to 012[0], 1 to 012[1], 2 to 012[2]". The operation is composition: apply the left permutation, then the right one. The identity is 012. Every permutation has an inverse, because every bijection can be undone.

Commutativity fails at 021 and 120: composing them in the two orders gives different permutations. So S3 is a group of order 6 that is not abelian. Its element orders are 1, 2, 2, 2, 3, 3 — no element has order 6, so S3 is not cyclic, and its order profile differs from Z6's 1, 2, 3, 3, 6, 6, which proves the two are not isomorphic.

Example 4 — the units of 7, a cyclic group of order 6

Take 1 to 6 under multiplication modulo 7. Every element has an inverse: 1↔1, 2↔4, 3↔5, 6↔6. The identity is 1. The group is abelian.

Powers of 2: 2, 4, 1 — so ord(2) = 3. Powers of 3: 3, 2, 6, 4, 5, 1 — six values before 1 returns, so ord(3) = 6 and 3 generates the group. The element 5 also generates it. Derivation The generator count is not a coincidence: a cyclic group of order 6 has φ(6) = 2 generators.

Example 5 — two groups of order 4: Z4 and U(8)

Z4 is 0 to 3 under addition modulo 4. The element 1 has order 4, so Z4 is cyclic. Element orders: 1, 4, 2, 4.

U(8) is 1, 3, 5, 7 under multiplication modulo 8. Each of 3, 5 and 7 squares to 1: 9 ≡ 1, 25 ≡ 1, 49 ≡ 1. Element orders: 1, 2, 2, 2. No element has order 4, so U(8) is not cyclic. It is the Klein four group, isomorphic to Z2 × Z2.

Both are abelian. This is the cleanest demonstration that cyclic is strictly stronger than abelian, and that "same order" does not mean "same group". Derivation Both tables are built and their element orders computed in the page.

Example 6 — subgroups of Z6, and the coset split

A subset is a subgroup when it contains 0, is closed under addition modulo 6, and contains the inverse of each of its elements. The four subsets that pass are {0}, {0,3}, {0,2,4} and {0,1,2,3,4,5}, of sizes 1, 2, 3 and 6.

Cosets of {0,3}. Shift it by 0, by 1 and by 2: you get {0,3}, {1,4} and {2,5}. Three disjoint blocks, each of size 2, covering all six elements. The index is 3, and 6 = 3 × 2.

Shift by 3 and you get {0,3} again, which is why the blocks are counted by distinct shifts and not by elements. Derivation The page computes the partition and checks that the blocks are equal in size and cover the group.

Boundary cases, and the exact words that decide them

Most lost marks in this unit come from a boundary of a definition rather than from the arithmetic: a trivial subgroup counted when only proper ones were asked for, a divisor treated as a guarantee, a finite set used where the question needed an infinite one. Read these before the practice set.

The group of order 1

{e} with e ★ e = e is a group: the identity is e, its inverse is e, and it is abelian and cyclic. Its only subgroup is itself, so it has no proper subgroup at all.

A question asking for the largest proper subgroup of a group of order 1 or of prime order therefore has no answer among proper subgroups except the trivial one — which is why "proper" and "non-trivial" are usually both stated.

Proper, non-trivial, and the count of subgroups

Proper means H ≠ G. Non-trivial means H ≠ {e}. The two trivial subgroups are {e} and G, and both always exist.

A cyclic group of order n has exactly one subgroup for each divisor of n, so its total subgroup count is the number of divisors. Z12 therefore has 6 subgroups; Z35 has 4; Zp for prime p has exactly 2.

Multiplication modulo n is never a group for n ≥ 2

0 has no inverse: 0 × b = 0 for every b, and 0 ≠ 1. So (Z_n, ×) is at best a monoid.

The units — the elements coprime to n — do form a group, written U(n), of order φ(n). U(6) = {1, 5} has order 2; U(7) has order 6; U(8) = {1, 3, 5, 7} has order 4. U(n) is cyclic exactly when n is 1, 2, 4, a power of an odd prime, or twice a power of an odd prime; that last fact is beyond the syllabus and is given only so the claim "U(n) is cyclic" is not over-generalised.

Finiteness is doing real work

Lagrange's theorem is stated for finite groups. The index form |G| = [G:H]·|H| survives for infinite groups as an equation of cardinals, but the divisor statement does not: the even integers form a subgroup of (Z, +) whose "size" is not a divisor of anything.

The same finiteness appears in two other places: in a finite semigroup a left identity and left inverses are enough, and a finite cancellation monoid is a group. Neither implication survives without finiteness.

Closure fails more often than people expect

Positive integers under subtraction: 1 − 2 = −1, outside. Positive integers under division: 1 ÷ 2, outside. A finite set of functions under pointwise addition: 2 + 2 can leave a three-value set.

This is why the 2025 question uses the non-negative integers rather than a finite set: only there is pointwise addition closed. Closure was the point of the question, not a detail.

Orders, powers and the identity

Every element of every group has finite order when the group is finite, and that order divides |G|. Hence a to the power |G| is the identity for every a.

Two consequences worth carrying: the identity has order 1 and is the only element that does; and in a group of prime order p, every non-identity element has order p, which is why such a group is cyclic.

Cosets are not subgroups

The cosets of H are the shifted copies aH. Only the copy with a in H contains the identity, so the others cannot be subgroups. They are equal in size to H and they partition G.

In an abelian group every left coset equals the corresponding right coset; in S3 they can differ, which is the doorway to normal subgroups — outside this syllabus, and not needed for any question in it.

Same order, different group

Order 4 has two groups, Z4 and Z2 × Z2. Order 6 has two, Z6 and S3. Order 8 has five. Knowing the order alone never identifies the group.

The cheapest invariant is the sorted list of element orders; the second cheapest is commutativity. Together they separate every pair that appears in GATE papers.

Seven beliefs that cost marks, each with the smallest counterexample

A counterexample is a complete refutation. For each belief below, one structure is enough to kill it — and in a multiple-select question that is exactly what you have to produce.

1. "A group is commutative"

Wrong. Commutativity is an extra promise. Counterexample: S3, the six permutations of three letters under composition, has order 6 and two elements that fail to commute (021 then 120 gives a different permutation from 120 then 021).

The smallest non-abelian group has order 6, so every group of order 2, 3, 4 or 5 is abelian — a fact worth knowing because it decides several statements instantly.

2. "If d divides |G|, a subgroup of order d exists"

Wrong. Lagrange's theorem is one-way. Counterexample: A4 has 12 elements and no subgroup of order 6. The page tests all 4096 subsets and finds subgroup sizes 1, 2, 3, 4 and 12 only.

The converse is true for cyclic groups, and only for them among the groups you will meet here.

3. "Multiplication modulo n is a group"

Wrong. Counterexample: in Z6 under multiplication, 0, 2, 3 and 4 have no inverse, so it is a monoid. Restricting to the units repairs it: U(6) = {1,5} is a group of order 2.

This is the same error as saying the integers under multiplication are a group because 1 exists. An identity is not an inverse.

4. "The order of an element is its value"

Wrong. The order is the number of times you must repeat the operation to return to the identity. Counterexample: in the units of 7, the element 2 has order 3, and the element 6 has order 2, because 6 × 6 = 36 ≡ 1.

Only the identity has order 1. Nothing in a group of order n need have order n.

5. "(xy)² = x²y² for all x, y implies commutative" — true. "For one pair it implies xy = yx" — false

For all pairs, the implication holds: expand (xy)² = xyxy = x²y², cancel x on the left and y on the right, and yx = xy. The 2022 question uses exactly this.

But for a single pair the identity can hold while the pair fails to commute. In S3, take x = 021 and y = 120. The product xy has order 3 and yx has order 2, so (xy)² and x²y² are different elements — and even where a coincidence makes them equal, the cancellation step is invalid because the group is not abelian. The quantifier "for all" is the whole content of the statement. Exam trap

6. "A subgroup of an abelian group can be non-abelian"

Wrong. If every pair in G commutes, every pair in a subset also commutes, so every subgroup of an abelian group is abelian. This was option D of the 2022 question and it is the one false statement there.

The implication does not reverse: a non-abelian group can have only abelian subgroups. S3 has subgroups of order 2 and 3, both cyclic and therefore abelian.

7. "An identity must work on both sides, so one-sided identities are useless"

Half wrong. In a finite semigroup a left identity together with left inverses already forces a two-sided identity and a group; in an infinite one it does not. The definition still demands both sides, so an exam answer must check both.

In practice this matters only when the operation is written as a formula rather than a table: a proposed identity must give back the other element whichever side it sits on.

The distinctions most often confused

Cyclic against abelian. Cyclic implies abelian; abelian does not imply cyclic. Z4 is both, Z2 × Z2 is abelian and not cyclic.

Order of the group against order of an element. |G| counts elements; ord(a) counts repetitions until the identity. ord(a) divides |G|.

Monoid against group. The difference is exactly the inverses, and it is decided by one row of the table.

Subgroup against coset. A subgroup contains the identity; a coset need not, and only one coset of a subgroup is a subgroup.

Necessary against sufficient. "|H| divides |G|" is necessary. "G is cyclic" makes it sufficient as well.

How this unit is actually asked

Four patterns cover every paper in this unit that I could verify. Pattern A, the divisor question: a group order is given, a subgroup size is asked for. Pattern B, the classification question: a set and a formula for the operation are given, and the options are the rungs of the ladder. Pattern C, the universal-statement question: "which of the following is true for every group G", answered by a counterexample. Pattern D, the counting question: count the elements of a product group that satisfy an order condition. Pattern A — the divisor question

GATE CSE 2020, Question 18 (NAT). "Let G be a group of 35 elements. Then the largest possible size of a subgroup of G other than G itself is ______."

Divisors of 35 are 1, 5, 7, 35. Excluding 35, the largest is 7. The subgroup of order 7 exists: the element 5 generates it in Z35, and 7 elements is 35/5.

GATE CSE 2018, Question 19 (NAT). "Let G be a finite group on 84 elements. The size of a largest possible proper subgroup of G is ______." 84 = 2²·3·7, so the largest proper divisor is 42, attained by the subgroup generated by 2 in Z84.

GATE CSE 2014, Set 3, Question 3 (NAT). "Let G be a group with 15 elements. Let L be a subgroup of G. It is known that L ≠ G and that the size of L is at least 4. The size of L is ______." Divisors of 15 are 1, 3, 5, 15; the only one at least 4 and below 15 is 5. Derivation All three answers are recomputed in the page, including that a subgroup of the claimed size exists.

The three-second procedure

1. Factorise |G|. 2. List its divisors. 3. Apply the words of the question — largest proper, smallest above a bound, or exactly a given size. 4. Say whether the question asks for a size that must exist or merely may exist.

Exam trap "Largest possible size" in a group you know nothing about means the largest divisor, because Lagrange forbids anything else. In a specific group the largest subgroup could be smaller than that bound.

Pattern C — the universal statement

GATE CSE 2022, Question 27 (MSQ). "Which of the following statements is/are TRUE for a group G?" — (A) if (xy)² = x²y² for all x, y in G then G is commutative; (B) if x² = 1 for all x in G then G is commutative; (C) if the order of G is 2 then G is commutative; (D) if G is commutative then a subgroup of G need not be commutative.

A is true: xyxy = x²y², cancel x on the left and y on the right, and yx = xy. B is true: x² = 1 makes x its own inverse, so xy = (xy)⁻¹ = y⁻¹x⁻¹ = yx. C is true: the only group of order 2 is Z2. D is false: every subgroup of an abelian group is abelian.

Answer: A, B and C. Derivation Each part is proved, not sampled; the page additionally verifies B and C on the concrete groups of order 2, 4 and 6.

Pattern C continued — the order-6 question

GATE CSE 2021, Set 1 (MCQ). "Let G be a group of order 6, and H be a subgroup of G such that 1 < |H| < 6. Which one of the following options is correct?" The correct option is: G may not be cyclic, but H is always cyclic.

|H| is 2 or 3, and both are prime, so H is cyclic whichever group of order 6 G is. G itself may be S3, which is not cyclic. The two halves have different reasons, and an answer that gives one reason for both is usually wrong.

Pattern B — classification from a formula

GATE CSE 2025, Set 1, Question 49 (MSQ). A is the set of non-negative integers, F is the set of all functions from A to itself, and (f₁ ⊙ f₂)(n) = f₁(n) + f₂(n). The correct statement is that (F, ⊙) is an abelian monoid.

Closed: the sum of two non-negative integers is non-negative. Associative and commutative: pointwise. Identity: the zero function. Not a group: the inverse of the constant function 1 would have to send every n to −1, which is not in A. So the ladder stops at monoid, with commutativity.

GATE CSE 2023, Question 51 (MSQ). On the power set of X with A Δ B = (A − B) ∪ (B − A): the structure is a group, it is abelian, the identity is the empty set, and every element is its own inverse because A Δ A = ∅. The page computes the order-8 case and reports all four facts. Verified fact The wording of the options is paraphrased here; the mathematical content of each is verified in the page.

Pattern D — counting elements of a product

GATE CSE 2024, Set 2 (NAT). "The number of elements in the group Z2 × Z3 × Z4 that are their own inverses is ______." An element equals its own inverse exactly when its order is 1 or 2, that is, when doubling it gives the identity in every coordinate.

In Z2 every element doubles to 0: 2 choices. In Z3 only 0 doubles to 0: 1 choice. In Z4 the elements 0 and 2 double to 0: 2 choices. The count is 2 × 1 × 2 = 4.

Derivation The page builds the 24-element table and counts the elements of order at most 2, getting 4. Exam trap Counting elements of order exactly 2 would give 3, not 4: the identity is its own inverse too.

Pattern B again — a presentation instead of a table

GATE CSE 2014, Set 3, Question 50 (NAT). Two elements x, y generate G, and x² = y² = xyxy = yxyx = e. The maximum number of elements is ______.

Every element is a word in x and y. From (xy)² = e we get xy = (xy)⁻¹ = y⁻¹x⁻¹ = yx, so the group is abelian, and every word reduces to e, x, y or xy. That is at most 4, and the Klein four group attains it. Derivation The page checks that V4 satisfies all four given relations and has exactly 4 elements.

NAT PYQ · GATE CSE 2020, Q18 1 mark

Let G be a group of 35 elements. Then the largest possible size of a subgroup of G other than G itself is ______.

Answer: 7. By Lagrange's theorem the size of a subgroup divides 35. The divisors of 35 are 1, 5, 7 and 35, and excluding the group itself leaves 1, 5 and 7.

Why 7 is attainable. Take G = Z35 and the element 5. Its powers are 5, 10, 15, 20, 25, 30, 0 — seven distinct elements, so a subgroup of order 7 exists. The bound is not merely an upper limit here.

Exam trap Answering 5 is the common error: 5 is the smallest prime factor, not the largest proper divisor. The largest proper divisor is 35 divided by the smallest prime factor, which is 35/5 = 7. Derivation The page computes the divisors and the size of the subgroup generated by 5, and reports both.

NAT PYQ · GATE CSE 2018, Q19 1 mark

Let G be a finite group on 84 elements. The size of a largest possible proper subgroup of G is ______.

Answer: 42. 84 = 2² × 3 × 7, so the divisors are 1, 2, 3, 4, 6, 7, 12, 14, 21, 28, 42, 84. The largest below 84 is 42, and in Z84 the element 2 generates a subgroup of order 42.

Exam trap 28 is a tempting wrong answer if the factorisation is done by halves rather than systematically. List the divisors from the prime factorisation, not by trial division under time pressure. Derivation The page computes both the divisor list and the order of the element 2 in Z84.

NAT PYQ · GATE CSE 2014, Set 3, Q3 1 mark

Let G be a group with 15 elements. Let L be a subgroup of G. It is known that L ≠ G and that the size of L is at least 4. The size of L is ______.

Answer: 5. The divisors of 15 are 1, 3, 5 and 15. "L ≠ G" removes 15, and "at least 4" removes 1 and 3. The only survivor is 5.

Note that no information about the structure of G is used, and none is needed: the two conditions plus Lagrange leave exactly one candidate, so the answer is forced in every group of order 15. Derivation The page computes the divisors of 15 and filters them by both conditions, and reports that one survives.

MCQ PYQ · GATE CSE 2021, Set 1 2 marks

Let G be a group of order 6, and H be a subgroup of G such that 1 < |H| < 6. Which one of the following options is correct?

(A) G is always cyclic, but H may not be cyclic.
(B) G may not be cyclic, but H is always cyclic.
(C) Both G and H are always cyclic.
(D) Both G and H may not be cyclic.

Answer: (B). There are two groups of order 6: Z6, which is cyclic, and S3, which is not. So G is not always cyclic, which removes (A) and (C).

H is always cyclic. By Lagrange, |H| divides 6, and 1 < |H| < 6 leaves |H| = 2 or |H| = 3. Both are prime, and a group of prime order is cyclic, so H is cyclic in either case. That removes (D).

Exam trap (D) is chosen by candidates who reason "S3 is not cyclic, so its subgroups need not be". S3's subgroups have orders 1, 2, 3 and 6, and the proper non-trivial ones are all cyclic. Derivation The page enumerates every subgroup of both groups of order 6 and confirms that each of size 2 or 3 contains an element of that order.

MSQ PYQ · GATE CSE 2022, Q27 1 mark

Which of the following statements is/are TRUE for a group G?

(A) If for all x, y in G, (xy)² = x²y², then G is commutative.
(B) If for all x in G, x² = 1, then G is commutative.
(C) If the order of G is 2, then G is commutative.
(D) If G is commutative, then a subgroup of G need not be commutative.

Answer: (A), (B) and (C). (A): xyxy = x²y², cancel x on the left and y on the right, and yx = xy. (B): x² = 1 makes every element its own inverse, so xy = (xy)⁻¹ = y⁻¹x⁻¹ = yx. (C): the only group of order 2 is Z2, whose table is symmetric.

(D) is false: a subgroup inherits the operation, so if every pair in G commutes then every pair in a subset commutes too. Exam trap (B) looks false because S3 is non-abelian, but S3 has elements of order 3, so the hypothesis fails there and S3 is not a counterexample. Test whether the hypothesis can hold before hunting for a counterexample.

NAT PYQ · GATE CSE 2024, Set 2 1 mark

Let Z_n be the group of integers {0, 1, …, n−1} with addition modulo n. The number of elements in the group Z2 × Z3 × Z4 that are their own inverses is ______.

Answer: 4. An element is its own inverse when doubling it gives the identity, so its order is 1 or 2. Work coordinate by coordinate.

Z2: every element doubles to 0, giving 2 choices. Z3: 2a ≡ 0 mod 3 forces a = 0, giving 1 choice. Z4: 2a ≡ 0 mod 4 allows a = 0 and a = 2, giving 2 choices. Multiply: 2 × 1 × 2 = 4.

Exam trap The identity is counted, because it too equals its own inverse. Counting only elements of order exactly 2 gives 3 and loses the mark. Derivation The page builds the 24-element table and counts elements of order at most 2, obtaining 4.

MSQ Original practice question no official marks

Consider the set {0, 1, 2, 3, 4, 5} with multiplication modulo 6. Which of the following statements are TRUE?

(A) The operation is associative and commutative.
(B) The structure is a monoid.
(C) The structure is a group.
(D) The subset {1, 5} is a subgroup of this structure.

Answer: (A) and (B). The identity is 1 and the table is symmetric and associative, so it is a commutative monoid.

(C) is false: 0, 2, 3 and 4 have no inverse. For 2, every product 2b is 0, 2 or 4, never 1. For 3, every product is 0 or 3. So four of six rows are missing the identity cell.

(D) is false as stated, and this is the subtle one: {1, 5} is a group under multiplication modulo 6, but it is not a subgroup of the monoid, because a subgroup is defined only inside a group. Read the parent structure before calling a subset a subgroup. Exam trap Derivation The page computes the inverse list for all six elements and reports exactly which are missing.

NAT Original practice question no official marks

The number of distinct subgroups of the additive group Z12 is ______.

Answer: 6. Z12 is cyclic, and a cyclic group has exactly one subgroup for each divisor of its order. The divisors of 12 are 1, 2, 3, 4, 6 and 12, so there are six subgroups.

They are generated by 0, 6, 4, 3, 2 and 1 respectively, with sizes 1, 2, 3, 4, 6 and 12. Exam trap Do not apply the divisor count to a non-cyclic group: A4 has order 12, six divisors, and only five subgroup sizes, because there is no subgroup of order 6. Derivation The page enumerates all 4096 subsets of Z12 and finds exactly six that are subgroups, with those six sizes.

MCQ Original practice question no official marks

Let G be a group and let a, b be elements of G. Which one of the following is necessarily TRUE?

(A) ab = ba
(B) (ab)² = a²b²
(C) the inverse of ab is the inverse of b times the inverse of a
(D) the order of a equals the order of b

Answer: (C). (ab)(b⁻¹a⁻¹) = a(bb⁻¹)a⁻¹ = aa⁻¹ = e, and similarly the other way round, so the inverse of ab is b⁻¹a⁻¹. The reversal of order is forced precisely because the group may not be commutative.

(A) and (B) fail in S3, where two elements do not commute. (D) fails in Z6, where ord(1) = 6 and ord(3) = 2.

Exam trap Writing the inverse of ab as a⁻¹b⁻¹ is the standard slip: it is right only in an abelian group, where the two orders coincide. Derivation The page finds a non-commuting pair in S3 and reports the differing element orders in Z6.

MSQ Original practice question no official marks

Let X = {a, b, c} and let the operation on the power set of X be symmetric difference, A Δ B = (A − B) ∪ (B − A). Which of the following statements are TRUE?

(A) The structure is a group of order 8.
(B) The identity element is X.
(C) Every element is its own inverse.
(D) The structure is cyclic.

Answer: (A) and (C). The power set has 2³ = 8 elements; the empty set is the identity, since A Δ ∅ = A; and A Δ A = ∅ for every A, so every element is its own inverse.

(B) is false: X Δ A = X − A, which is A only when A is empty. The identity is the empty set.

(D) is false: every element has order 1 or 2 and the group has order 8, so no element has order 8 and no element generates it. The structure is Z2 × Z2 × Z2, abelian and not cyclic. Exam trap "Abelian and every element of order 2" describes a group that can never be cyclic once it has more than two elements. Derivation The page builds the 8×8 table, classifies it, and computes every element order.

One-page revision sheet

Definitions, decision procedures, the four formulas, the two standard counterexamples, and the traps. Everything here is recomputed by the page's model.

Definitions in the order they are needed

Operation: a rule taking two elements to one, inside the set (closure). Semigroup: closed and associative. Monoid: semigroup with an identity. Group: monoid with an inverse for every element. Abelian group: group with a ★ b = b ★ a.

Order of a group: the number of elements. Order of an element a: the smallest k > 0 with a to the power k equal to the identity. Cyclic: some element has order |G|; that element is a generator. Subgroup: a subset that is a group under the same operation. Index: the number of cosets, |G| / |H|.

Proper excludes G. Non-trivial excludes {e}. Units of n: the elements coprime to n, forming a group of order φ(n).

Formulas and facts

Lagrange: |H| divides |G|, and |G| = [G:H] · |H|.

Largest proper subgroup order = |G| / (smallest prime factor of |G|).

ord(a) divides |G|, and a to the power |G| is the identity.

A group of prime order is cyclic; a cyclic group of order n has one subgroup per divisor, so d(n) subgroups and φ(n) generators.

Cyclic implies abelian; the converse fails. Every group of order 2, 3, 4 or 5 is abelian.

The two counterexamples to memorise

S3, order 6: a group that is not abelian, and not cyclic. Kills "groups are commutative" and "same order means same group".

A4, order 12: no subgroup of order 6 although 6 divides 12. Kills "every divisor is a subgroup size".

Decision procedures

Classify (S, ★): closure, then associativity, then identity, then inverses, then commutativity. Stop at the first failure and name the rung below it.

Find inverses: locate the identity e, then scan each row for the cell holding e; the column index is the inverse.

Order of an element: multiply repeatedly until e returns and count the steps.

Subgroup sizes: list the divisors of |G|, filter by the words of the question, then state whether existence is guaranteed (cyclic group, or supplied in the question) or merely possible.

Traps, one line each

The verdict belongs to the pair (set, operation), not to the set. · An identity is not an inverse. · Multiplication modulo n is never a group for n ≥ 2. · Cyclic is stronger than abelian. · Order of an element is not its value. · The identity is its own inverse and counts in a self-inverse count. · Lagrange bounds; it does not guarantee. · "For all x, y" is the whole content of a commutativity statement. · A coset need not contain the identity, so it need not be a subgroup. · The inverse of ab is b⁻¹a⁻¹, in that order.
