Topic and objective

TOPIC: Sets and set operations — membership, the empty set, subset and equality, the power set, the five basic operations, the complement laws, cardinality by inclusion and exclusion, the Cartesian product, and the bit-string picture of a subset.

LEARNING OBJECTIVE: Given any two or three finite sets drawn from a stated universe, compute every basic operation and its size by testing elements rather than recalling formulas; decide whether a claimed identity holds by expanding it into statements about membership; prove two sets equal by double inclusion; and count a power set, a union and a product correctly, including the empty-set and off-by-one cases.

I read "sets and set operations" as the first half of the syllabus item "Sets, relations, functions, partial orders and lattices" — sets and the operations on them, stopping before relations. It uses the connectives from Propositional Logic and the quantifier language from First-Order Logic, and it is the prerequisite for relations, functions, partial orders, and relational algebra.

GATE relevance

Verified fact Class A — explicitly in the syllabus.

Section 1 of the official GATE 2027 CS syllabus (IIT Madras) contains the sentence: "Discrete Mathematics: Propositional and first order logic. Sets, relations, functions, partial orders and lattices. Monoids, Groups. Graphs: connectivity, matching, colouring. Combinatorics: counting, recurrence relations, generating functions."

Sets are named directly, and they are also the vocabulary every later Discrete Mathematics item is written in — a relation is a set of pairs, a function is a special relation, a lattice is a set with two operations.

Prerequisites

  • Propositional logic: not, and, or, and the truth of an implication whose hypothesis is false. The whole of set algebra is this logic applied to membership statements.
  • First-order logic: reading "for every x, if x is in A then x is in B" as a definition. Used here for subset.
  • Counting in the very basic sense: multiplying independent choices.
  • Nothing about relations, functions, partial orders or cardinality of infinite sets is assumed.

The five ideas

  1. Membership is the primitive. Every other notion is defined by a membership test.
  2. Order and repetition do not exist in a set; a listing is a way of naming one, not the set.
  3. The empty set is not the set holding zero, and not the set holding itself.
  4. Subset is an implication, so the empty set is a subset of everything — automatically.
  5. Sizes follow two formulas: the union subtracts the overlap, the product multiplies the sizes.

Intuition first: the guest list

A wedding has a guest list. The list answers exactly one question about any person: are they on it or not? Writing a name twice does not invite the person twice, and moving a name to the top of the list does not change who is coming. That is a set: the only fact it records is membership.

Educational interpretation A subset is a smaller list drawn only from the big one — a table of people who have confirmed. The power set is the collection of every possible confirmation list, including the empty one and the full one. The Cartesian product is different: it pairs a host with a guest, so (host A, guest B) and (host B, guest A) are two different pairings. Keep the guest list in mind and every definition below is a sentence about it.

Definition 1 — set, element, membership

A set is a collection of distinct objects. Each object in it is an element. We write x ∈ A when x is an element of A, and x ∉ A otherwise.

Derivation Two listings name the same set exactly when they contain the same elements, so {1, 2, 3} = {3, 1, 2, 2}. Order and repetition are not part of the object, and no counting of how an element was written can change a set.

Definition 2 — roster and set-builder

Roster form lists the elements: {2, 4, 6, 8}. Set-builder form gives a rule: { x ∈ U : x is even and x < 9 }, read "the set of all x in U such that x is even and less than nine".

The colon is read as "such that". Everything before it says where the elements come from; everything after it is the test each candidate must pass.

Definition 3 — the empty set

The empty set ∅ is the set with no elements; |∅| = 0. There is only one: any two sets with no elements have the same elements, namely none.

Exam trap ∅, {0} and {∅} are three different sets with sizes 0, 1 and 1. The braces are not decoration: they add a level.

Definition 4 — subset and proper subset

A ⊆ B when every element of A is an element of B: for all x, if x ∈ A then x ∈ B. A ⊂ B means A ⊆ B and A ≠ B.

Derivation Two consequences follow from the implication, not from intuition: A ⊆ A for every A, and ∅ ⊆ A for every A. In both cases no element can produce a true hypothesis and a false conclusion.

Definition 5 — equality by double inclusion

A = B exactly when A ⊆ B and B ⊆ A. To prove equality, prove both inclusions. To refute equality, exhibit one element in exactly one of the two sets.

Derivation Each inclusion is an implication over the universe; their conjunction is the biconditional "x ∈ A if and only if x ∈ B" for every x, which is exactly what equal sets satisfy. Verified on all 64 pairs of subsets of {a, b, c}.

Definition 6 — the power set

P(A), also written 2A, is the set of all subsets of A. Its elements are sets, so every element is written inside braces.

Derivation |P(A)| = 2|A|, because each element of A independently chooses to be in a given subset or not. Consequently P(∅) = {∅} with one element, and |P(P(∅))| = 2.

Definition 8 — the Cartesian product

A × B is the set of all ordered pairs (a, b) with a ∈ A and b ∈ B. Order inside the pair matters, and the order of the two sets matters.

Derivation |A × B| = |A| · |B|, since each of the |A| first coordinates is paired with each of the |B| second coordinates. A × ∅ = ∅ for every A, because no second coordinate exists.

The one line worth memorising

Membership is the primitive — subset is an implication over members, equality is a biconditional over members, and every set identity is a truth table in disguise.

Worked example 1 — one pair of sets, five operations

Universe U = {a, b, c}. A = {a, b} and B = {b, c}. Compute A ∪ B, A ∩ B, A − B, B − A, A △ B and the two complements.

Step 1 — test each element, not each set

  1. a: in A, not in B. So a is in the union, in A − B, in the symmetric difference, and in B̄.
  2. b: in A and in B. So b is in the union and the intersection, but in neither difference and in neither complement.
  3. c: in B, not in A. So c is in the union, in B − A, in the symmetric difference, and in Ā.

Step 2 — read off the answers

A ∪ B = {a, b, c}   (3)
A ∩ B = {b}   (1)
A − B = {a}   (1)
B − A = {c}   (1)
A △ B = {a, c}   (2)
Ā = {c}   (1), B̄ = {a}   (1)

Derivation Every roster on the Animation tab is produced by this test, and the page asserts the whole set of answers as one of its model checks.

The two traps inside this one example

A − B = {a} and B − A = {c} are different sets, so difference does not commute. And the sizes satisfy 3 = 2 + 2 − 1, not 2 + 2: the union is smaller than the sum because b was counted twice.

Exam trap A complement is meaningless until U is stated. With U = {a, b, c, d} the same A has complement {c, d}; the question's universe is part of the question.

Why testing elements beats recalling formulas

With three elements there are only three tests, and every operation is one of four boolean patterns on the pair (in A, in B): true-false is A − B, true-true is the intersection, false-true is B − A, false-false is outside both. Any question with a stated finite universe can be settled this way, and a formula can then be used as a cross-check rather than as the method.

Worked example 2 — enumerate a power set, then count it

Write out P({a, b, c}) completely, then use the same reasoning for n = 0 to 4, and for the power set of the empty set.

Step 1 — the eight subsets, by size

size 0: ∅
size 1: {a}, {b}, {c}
size 2: {a,b}, {a,c}, {b,c}
size 3: {a,b,c}

Derivation 1 + 3 + 3 + 1 = 8 = 2³. The four counts are the binomial coefficients C(3,0), C(3,1), C(3,2), C(3,3): the number of subsets of each size is the number of ways to choose that many elements.

Step 2 — the same count for other sizes

n = 0 → 2⁰ = 1
n = 1 → 2¹ = 2
n = 2 → 2² = 4
n = 3 → 2³ = 8
n = 4 → 2⁴ = 16

Derivation Each element answers one yes-or-no question, and the answers are independent, so the number of complete answer sheets is 2 multiplied by itself n times. This is the product rule from counting, not a coincidence about powers.

Step 3 — the empty set, twice over

P(∅) = {∅}: one element, and 2⁰ = 1 agrees. Then P(P(∅)) = P({∅}) = {∅, {∅}}: two elements, and 2¹ = 2 agrees.

Exam trap The tempting wrong answer for |P(∅)| is 0. A power set is never empty, because the empty set is a subset of everything — including the empty set.

The off-by-one trap in a stated range

The set {0, 1, 2, …, 10} has eleven elements, not ten, because zero is included. Its power set therefore has 2¹¹ = 2048 elements. Whenever a question writes a range starting at 0 or ending at 10, count the elements before you exponentiate: |{a, a+1, …, b}| = b − a + 1.

Worked example 3 — inclusion and exclusion with numbers

In a class, 10 students play chess, 8 play carrom, 6 play badminton. 4 play chess and carrom, 3 play carrom and badminton, 2 play chess and badminton, and 1 plays all three. How many students play at least one of the three?

Step 1 — apply the three-set formula

  1. Add the three sizes: 10 + 8 + 6 = 24. Every student in one game is now counted once; every student in two games twice; every student in all three three times.
  2. Subtract the three pairwise overlaps: 24 − (4 + 3 + 2) = 15. A student in exactly two games is now counted once. A student in all three has been counted three times and removed three times, so is currently counted zero times.
  3. Add the triple overlap back: 15 + 1 = 16. Now everyone in at least one game is counted exactly once.

Step 2 — check the answer against its bounds

The union must be at least the largest single set (10) and at most the sum of the sizes (24). 16 lies inside both bounds, so no option outside 10 to 24 could have been right, and the arithmetic passes the sanity check.

Derivation This is not a memorised formula: each line above is a statement about how many times a particular kind of student has been counted. The page verifies the same identity on all 512 triples of subsets of a four-element universe.

The term everyone forgets

Dropping the final + 1 gives 15, which is wrong by exactly the number of students in all three games. Whenever a question gives a triple intersection, the formula needs it back.

Exam trap "Exactly one game" is not the union. It is |A| + |B| + |C| − 2(sum of pairwise) + 3(triple). Read whether the question asks for at least one or exactly one.

Step 3 — the same shape as a product question

Counting ordered pairs is the other half of this toolkit: if A has 3 elements and B has 4, then A × B has 12 elements and A × A has 9. A question that gives you |A × A| = |A ∪ B| is asking you to equate a product with an inclusion–exclusion expression, which is exactly what the 2024 paper did.

Edge case 1 — three symbols, three different sets

∅ has size 0. {0} has size 1, and its element is the number zero. {∅} has size 1, and its element is the empty set. All four tests on the Animation tab are computed: ∅ ∈ {∅} is true, ∅ ∈ ∅ is false, ∅ ⊆ {∅} is true, {∅} ⊆ ∅ is false.

Derivation The nesting rule is mechanical: braces around a set produce a new set with one element, whatever that set was. Applying it to ∅ gives {∅}, and applying it again gives {∅, {∅}}, a set of size two.

Edge case 2 — subset is not membership

Let A = {a, b} and B = {{a}, b}. Then {a} ∈ B is true, but {a} ⊆ B is false, because a is an element of {a} and a is not an element of B.

Membership compares an object with a set. Subset compares two sets, element by element. The symbol changes the question, not just the notation.

Edge case 3 — the empty set is inside everything, twice over

For every set A: ∅ ⊆ A (as a subset), and ∅ ∈ P(A) (as an element of the power set). Both are true for A = ∅ as well, which is why |P(∅)| = 1 rather than 0.

What is not automatic is ∅ ∈ A. That holds only when A happens to contain the empty set as one of its elements.

Edge case 4 — products with the empty set

A × ∅ = ∅ and ∅ × A = ∅ for every A, since no pair can be completed. But {∅} × A is not empty when A is not empty: it holds one pair for each element of A.

Derivation The size formula agrees throughout: |A| · 0 = 0, and 1 · |A| = |A|. A product is empty exactly when at least one factor is empty.

Edge case 5 — equal size is not equal set

With A = {a, b} and B = {x, y}: |A × B| = 4 = |B × A|, but the two products share no pair at all. Similarly |A| = |B| does not make A equal B.

Size is one number about a set. Equality needs every element to match, which is the double-inclusion test.

Edge case 6 — the complement needs a universe

With U = {a, b, c} and A = {a, b}, Ā = {c}. With U = {a, b, c, d}, the same A gives Ā = {c, d}. The expression "everything not in A" names nothing until U is fixed.

Exam trap Both complement laws are checked in this page relative to a stated U. Change U and the identities still hold, but every individual complement changes.

The pattern behind all six

Every edge case here is one of two mistakes: confusing the level of nesting (element versus subset, ∅ versus {∅}), or forgetting a condition that the formula silently assumed (a stated universe, a non-empty factor, equality of sets rather than of sizes). Before computing, ask which universe you are in and whether the objects you are comparing live at the same level.

Misconception 1 — "the empty set is {0}"

Why it tempts: a set with nothing in it looks like a set with a zero in it, and in many programming languages an empty collection and the number zero both print as something small and round. Counterexample: |{0}| = 1 and |∅| = 0, so the two cannot be the same set; also 0 ∈ {0} is true while 0 ∈ ∅ is false.

Community observation A study of teachers' knowledge of student errors in sets lists exactly this as one of the errors they could identify: writing the empty set as a set containing zero instead of as empty braces. Correct rule: ∅ = { }, and its size is zero.

Misconception 2 — "subset means the same as element"

Why it tempts: for a one-element set the two often give the same verdict, so the distinction stays invisible. Counterexample: with B = {{a}, b}, the set {a} is an element of B but not a subset of B.

Correct rule: A ⊆ B is a claim about the elements of A; A ∈ B is a claim about A as a single object. Check the level before answering.

Misconception 3 — "the union size is the sum of the sizes"

Why it tempts: it is true exactly when the sets are disjoint, which is the case most pictures show. Counterexample: A = {a, b}, B = {b, c} gives 2 + 2 = 4 but |A ∪ B| = 3.

Correct rule: |A ∪ B| = |A| + |B| − |A ∩ B|. The sum is an upper bound, reached only when the intersection is empty.

Misconception 4 — "A × B and B × A are the same set"

Why it tempts: the sizes are equal, and the notation looks commutative like multiplication of numbers. Counterexample: A = {a}, B = {x}. Then A × B = {(a, x)} and B × A = {(x, a)}, which share no element.

Correct rule: an ordered pair records which coordinate is which, so the order of the factors is part of the object.

Misconception 5 — "the power set has n² elements"

Why it tempts: n² appears in adjacent topics, such as the number of relations on a set of n elements, which is 2n². Counterexample: for n = 3 the power set has 8 elements and n² is 9.

Correct rule: |P(A)| = 2n. Keep the three counts apart: subsets 2n, relations 2n², functions from A to A nn.

Misconception 6 — "the empty set is an element of every set"

Why it tempts: the true statement "∅ is a subset of every set" is learned first and then misquoted with the wrong symbol. Counterexample: ∅ ∈ {a, b} is false.

Correct rule: ∅ ⊆ A always; ∅ ∈ A only when A was built with the empty set inside it, as in {∅} or P(A).

How to stop making these

For every set question, write the universe at the top of your rough work, then write each set in roster form with its size beside it. Almost every misconception above disappears the moment the sizes are on paper: 0 against 1 kills the empty-set confusions, and 3 against 4 kills the union-as-sum error.

What GATE actually asks about sets

Four patterns cover almost every set question in the recent papers: a power-set size with an inclusive range, a comparison of two constructed sets to decide whether an injection or bijection exists, a numerical inclusion–exclusion or product identity, and a counting argument over subset pairs. Set identities such as De Morgan appear mostly as one option inside a larger question.

Pattern 1 — power set of a stated set

Asks: "the cardinality of the power set of {0, 1, …, 10}". Procedure: count the elements of the set first (eleven, because zero is included), then raise two to that count.

Verified fact Asked as a one-mark numerical question in GATE CSE 2015 Set 2. Common wrong approach: 2¹⁰, from counting the set as ten elements.

Pattern 2 — two constructed sets, which mappings exist

Asks: two sets described by constructions (matrices over an alphabet, functions into a small set), then which of bijection, surjection, injection exist. Procedure: compute both sizes. Equal sizes give a bijection between finite sets, and a bijection is also an injection and a surjection; unequal sizes kill the bijection outright.

Verified fact Asked as a multiple-select question in GATE CSE 2021 Set 2, Q11. Common wrong approach: checking only "bijection exists" and forgetting that the other two statements then also hold.

Pattern 3 — a product equals a union

Asks: "there exist bijections from A to B and from A × A to A ∪ B; the number of possible values of |A| is ___". Procedure: set |A| = |B| = n, so |A × A| = n² and |A ∪ B| = 2n − k with 0 ≤ k ≤ n. Solve n² = 2n − k, and check each small n.

Verified fact Asked as a numerical question in GATE CSE 2024 Set 1, Q32. Common wrong approach: assuming A and B must be disjoint, which loses the case n = 1.

Pattern 4 — counting subset pairs

Asks: "the number of tuples (A, B) of subsets of a 10-element set with A ⊆ B". Procedure: each element has three exclusive options — in neither, in B only, in both — so the count is 3n. For n = 10 that is 59049.

Derivation Verified on this page by listing all 64 pairs on a three-element set and counting the 27 that satisfy A ⊆ B, which is 3³. Common wrong approach: 2n · 2n, which counts ordered pairs of subsets without the inclusion condition.

Pattern 5 — an identity hidden in an option list

Asks: which of four set statements is true. Procedure: expand each statement into membership statements and test it on the two-element universe, where nearly every false identity fails. For example A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) survives; A ∪ (B ∩ C) = (A ∪ B) ∩ C does not.

Derivation Distributivity of intersection over union was checked on all 512 triples here; the second form fails on A = {a}, B = {b}, C = {c}, where the left side is {a, b} and the right is {c}.

The three-step habit for any set question

Write the universe. Write every set in roster form with its size. Then choose: count it (power set, product, inclusion–exclusion), test it (an identity, on a two-element universe), or compare it (two cardinalities, to decide which mappings exist). The reasoning is short; the marks are lost in the first two steps, not the third.

NAT PYQ · GATE CSE 2015 Set 2 1 mark

The cardinality of the power set of {0, 1, 2, …, 10} is _______.

Answer: 2048. The set {0, 1, 2, …, 10} contains eleven elements, because zero is included: 10 − 0 + 1 = 11. The power set of an n-element set has 2n elements, so the answer is 2¹¹ = 2048.

Where 1024 comes from. Counting the set as ten elements gives 2¹⁰ = 1024, and that is the intended trap. The interval is inclusive at both ends.

Exam trap Write the element count down before exponentiating. For any set written as a run of integers from a to b, the size is b − a + 1.

MSQ PYQ · GATE CSE 2021 Set 2, Q11 1 mark

Consider the following sets, where n ≥ 2. S₁: the set of all n × n matrices with entries from the set {a, b, c}. S₂: the set of all functions from the set {0, 1, 2, …, n² − 1} to the set {0, 1, 2}. Which of the following choice(s) is/are correct?

(A) There does not exist a bijection from S₁ to S₂
(B) There exists a surjection from S₁ to S₂
(C) There exists a bijection from S₁ to S₂
(D) There does not exist an injection from S₁ to S₂

Answer: (B) and (C). A matrix is an assignment of one of three symbols to each of its n² cells, so |S₁| = 3n². A function assigns one of three values to each of the n² inputs in {0, …, n² − 1}, so |S₂| = 3n² as well.

Equal finite cardinalities mean a bijection exists, which makes (C) true and (A) false. That same bijection is a surjection and an injection, so (B) is true and (D) is false.

Exam trap This is a multiple-select question, and the trap is stopping at (C). Once a bijection exists, the injection and surjection statements follow from it; in an MSQ every true statement must be selected.

NAT PYQ · GATE CSE 2024 Set 1, Q32 1 mark

Let A and B be non-empty finite sets such that there exist one-to-one and onto functions (i) from A to B and (ii) from A × A to A ∪ B. The number of possible values of |A| is _______.

Answer: 2. A one-to-one and onto function from A to B means |A| = |B| = n. The second condition gives |A × A| = |A ∪ B|, that is n² = 2n − |A ∩ B|. Since 0 ≤ |A ∩ B| ≤ n, we need n² ≤ 2n, so n ≤ 2. With n ≥ 1 there are only two candidates.

n = 1 works: A = B = {x}, and both A × A and A ∪ B have one element. n = 2 works with A and B disjoint of size two: |A × A| = 4 and |A ∪ B| = 4. So the possible values of |A| are 1 and 2, and the number of possible values is 2.

Derivation The bound comes from inclusion and exclusion plus the product count: the union is at most 2n and the product is exactly n², so n² ≤ 2n. Solving the inequality first, and checking the candidates second, is faster than trying values.

NAT Original practice question 1 mark

Let A = {1, 2, {3}}. The cardinality of the power set of A is _______.

Answer: 8. A has three elements: the number 1, the number 2, and the set {3}. The third element is a set, but it is a single element of A, so |A| = 3 and |P(A)| = 2³ = 8.

The eight subsets include {1, {3}} and {{3}}, and the element {3} appears inside braces whenever it is selected.

Exam trap The tempting answer is 16, from counting 3 as an element of A as well. Nested braces make the inner set one object; nothing inside it is an element of A.

NAT Original practice question 2 marks

Let S be a set with 10 elements. The number of ordered pairs (A, B) such that A and B are subsets of S and A ⊆ B is _______.

Answer: 59049. Decide the pair element by element. For each element of S there are exactly three possibilities: in neither set, in B only, or in both — "in A only" is excluded because A ⊆ B. That is 3 choices per element, independently, so the count is 3¹⁰ = 59049.

The page checks the same argument on a three-element set: all 64 ordered pairs are listed and 27 satisfy the inclusion, and 3³ = 27.

Exam trap 4¹⁰ counts all ordered pairs of subsets with no inclusion condition, and 2¹⁰ counts the subsets B alone. The three-way choice is what encodes A ⊆ B.

MCQ Original practice question 1 mark

Which one of the following statements is TRUE for every set A?

(A) ∅ ∈ A
(B) ∅ ⊆ A
(C) {∅} ⊆ A
(D) {∅} ∈ A

Answer: (B). For any set A, the implication "if x ∈ ∅ then x ∈ A" has a false hypothesis for every x, so it is true, and therefore ∅ ⊆ A. The page checks this on all eight subsets of {a, b, c}.

Why the others fail. (A) fails for A = {a}: the empty set is not one of its elements. (C) fails for the same A: {∅} has an element, namely ∅, which is not in {a}. (D) fails for A = {a} too, and would need A to be built with {∅} inside it.

Exam trap Three of the four options are about membership and one is about subset. Read the symbol before evaluating the statement.

MSQ Original practice question 2 marks

Let A, B, C be subsets of a universe U. Which of the following identities hold for all A, B, C?

(A) A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
(B) A ∪ (B ∩ C) = (A ∪ B) ∩ C
(C) complement of (A ∪ B) = (complement of A) ∩ (complement of B)
(D) A − B = B − A

Answer: (A) and (C). (A) is distributivity of intersection over union and was checked here on all 512 triples of subsets of a four-element universe. (C) is one of De Morgan's laws and was checked on all 64 pairs of subsets of a three-element universe.

Why (B) fails. Take A = {a}, B = {b}, C = {c}. The left side is {a}, because B ∩ C is empty. The right side is {a, b} ∩ {c} = ∅. Not equal, so (B) is not an identity.

Why (D) fails. With A = {a, b}, B = {b, c}: A − B = {a} and B − A = {c}. Difference is not symmetric; the symmetric difference A △ B is the operation that is.

NAT Original practice question 2 marks

In a survey of 100 students, 60 read newspaper A, 45 read B, 30 read C. 20 read both A and B, 15 both B and C, 10 both A and C, and 5 read all three. The number of students who read at least one newspaper is _______, and the number who read none is _______.

Answers: 95 and 5. By inclusion and exclusion: 60 + 45 + 30 = 135; subtract the three pairwise overlaps, 135 − 45 = 90; add the triple back, 90 + 5 = 95. Then 100 − 95 = 5 read none.

Check the bounds: the union must be at least the largest set (60) and at most the sum (135). 95 is inside, so the arithmetic is plausible before any further checking.

Exam trap The phrase "at least one" is the union. A question asking for "exactly one" would subtract the pairwise overlaps twice and add the triple three times, which is a different number.

Revision sheet — sets and set operations

One screen. Definitions in words, formulas with their assumptions, the decision procedure for each question type, and the traps that cost marks.

Definitions in one line each

  • Membership: x ∈ A when x is one of the objects in A. The primitive.
  • Subset: A ⊆ B when every element of A is in B — an implication over the universe.
  • Equality: A = B when A ⊆ B and B ⊆ A.
  • Power set: P(A) is the set of all subsets of A.
  • Cartesian product: A × B is the set of ordered pairs (a, b).
  • Complement: Ā = U − A, and it needs a stated U.

Formulas, with their conditions

|P(A)| = 2|A|
|A × B| = |A| · |B|
|A ∪ B| = |A| + |B| − |A ∩ B|
|A △ B| = |A| + |B| − 2|A ∩ B|
|A − B| = |A| − |A ∩ B|
|A ∪ B ∪ C| = Σ|A| − Σ|pairwise| + |A∩B∩C|

Derivation Each formula assumes finite sets. The union formula needs the intersection term; dropping it is correct only when the sets are disjoint, which must then be stated.

Decision procedure

  1. Write U, and every set in roster form with its size. Nearly every error is a level error or a missing universe.
  2. If the question asks for a size, choose a formula and check the answer against its bounds. Union at least the largest set, at most the sum.
  3. If the question asks whether an identity holds, expand it into membership statements and test the smallest interesting universe. Two elements for pairs, three for triples.
  4. If the question asks for a count of constructions, count the independent choices per element. 2 per element for subsets, 3 for subset pairs, |B| per element for functions into B.

Traps, in the order they appear

  • ∅, {0}, {∅}: sizes 0, 1, 1.
  • ∈ versus ⊆: an object versus a set of objects.
  • Inclusive ranges: {0, …, 10} has eleven elements.
  • |P(∅)| = 1, not 0.
  • A × B ≠ B × A even when the sizes agree.
  • A − B ≠ B − A.
  • Complement without a universe is undefined.
  • Union size is the sum only when the intersection is empty.

Three numbers worth keeping apart

On a set of n elements: the number of subsets is 2n; the number of binary relations is 2n²; the number of functions from the set to itself is nn. The first belongs to this lesson, the second to relations, the third to functions — and confusing them is the most common arithmetic slip in Discrete Mathematics.

If you remember only one sentence

A set is defined by membership alone, so every definition and every identity in this topic is a statement about which elements are in — which is why a truth table settles set algebra.
