Topic and objective

TOPIC: Graphs: connectivity and structure — the graph as two sets, adjacency matrix and adjacency list, degree and the handshake lemma, walks, trails, paths, cycles and components, trees and their three equivalent tests, spanning trees, cut vertices and bridges, vertex and edge connectivity with Whitney's chain, bipartite graphs and odd cycles, and Euler trails against Hamiltonian cycles.

LEARNING OBJECTIVE: Given an unfamiliar graph question, compute the degree sequence, the edge count and the component count, then name the object the question asks you to break or traverse; justify every claim from a definition rather than from the drawing; and state the hypothesis of every criterion before using it.

I read this as the syllabus phrase "Graphs: connectivity, matching, colouring" cut after the word connectivity, with trees, spanning trees and Euler trails folded in because they are the connectivity facts the rest of the syllabus is built on. Matching and colouring are a separate lesson and are not taught here, though bipartiteness — which is the two-colour case — is, because it is the bridge to both.

Prerequisites

  • Sets and set operations: a set, an element, a subset, the cartesian product. A graph is literally a pair of sets, and an edge set is a set of two-element subsets of the vertex set.
  • Relations and their properties: a binary relation as a set of ordered pairs. An undirected graph's adjacency is a symmetric, irreflexive relation; the adjacency matrix is its matrix.
  • Counting and combinatorics: for the spanning-tree count and for counting degree sequences. Only the sum and product rules are used.
  • No algorithms background is assumed. Breadth-first search appears once, as the reason the bipartite test is fast, and is explained where it is used.

The five ideas

  1. Every edge is counted at two ends, so the degree sum is twice the edge count. Almost every parity argument in the unit comes from that one sentence.
  2. A tree is what is left when you delete every cycle. That is why trees have exactly n − 1 edges, and why every connected graph contains one.
  3. "Connected" is a yes-or-no word; connectivity is a number. The number is the size of the smallest cut, and it can be measured on vertices or on edges.
  4. Bipartite is the same property as "no odd cycle", because alternating two colours around an odd number of steps returns you to where you started.
  5. Euler asks about edges and has a degree test; Hamilton asks about vertices and has none. They are independent questions, and a graph can answer one yes and the other no.

Conventions used throughout

Every graph here is simple (no loop from a vertex to itself, at most one edge between a pair) and undirected (the edge between a and b is the same edge as between b and a). n is the number of vertices and m the number of edges. deg(v) is the number of edges at v. A graph on one vertex is connected, has 0 edges, and is a tree. Kappa, written κ, is vertex connectivity; lambda, written λ, is edge connectivity; delta, written δ, is the smallest degree. Where a definition needs a convention at its edge — κ of a complete graph, κ of a disconnected graph — the convention is stated at the point of use, not left implicit.

Intuition first: a road map, not a mathematics

Take a road map. Towns are points, roads are lines between them. Three questions you can ask about it are genuinely different. First: can I get from here to there at all? Second: if one town is closed, am I cut off? Third: is there a round trip that uses every road exactly once? The first is connectivity, the second is a cut, the third is Euler. The whole unit is those three questions asked precisely.

The reason this needs care is that a drawing lies. A map printed on paper makes one town look central because it happens to sit in the middle of the page, and a road that crosses another on the page looks like a junction. Neither is a fact about the graph. So the first move in every question is to write the graph down as two sets — V and E — and then answer from those, not from the picture. Educational interpretation The road map is an analogy for intuition only; a road map is a plane drawing, and planarity is a separate question that this lesson does not test.

Level 2 — the formal definitions, in the order they build

A graph is a pair G = (V, E) where V is a finite set of vertices and E is a set of two-element subsets of V, called edges. Writing an edge as {a, b} rather than (a, b) is what makes the graph undirected: the order in the braces carries no information. A loop {a, a} and a parallel pair are excluded by the word simple, and every theorem below assumes that exclusion somewhere.

Degree. deg(v) is the number of edges containing v. Because each edge contains exactly two vertices, summing deg over all of V counts every edge exactly twice: Σ deg(v) = 2|E|. This is the handshake lemma, and it is a one-line proof, not a fact to memorise.

Walk, trail, path, cycle. A walk is a sequence of vertices where consecutive ones are joined. A trail is a walk with no repeated edge. A path is a walk with no repeated vertex. A cycle is a closed path of length at least three. Each word forbids one more thing than the one before it, which is the only reason four words exist.

Connected, component, distance. Two vertices are connected when some path joins them; the graph is connected when every pair is. A component is a maximal connected subgraph, so the components partition V. The distance between two vertices is the length of a shortest path between them, and it is undefined between different components — not infinite, undefined, because there is no path whose length could be measured.

Tree, forest. A tree is a connected graph with no cycle. A forest is a graph with no cycle, so every component of a forest is a tree. A spanning tree of a connected graph is a tree on the same vertex set using a subset of the edges.

The one proof that pays for itself

A graph on n vertices that is connected and acyclic has exactly n − 1 edges. Reason by building: start from the n vertices with no edges and add the edges one at a time. Each added edge that keeps the graph acyclic must join two different components, so it reduces the component count by one. You start with n components and must reach 1, so exactly n − 1 additions are needed. Derivation This is a proof, and the same argument read backwards proves that a graph with n − 1 edges and no cycle is connected. Both directions were also checked by brute force on all 1,099 labelled graphs with at most five vertices.

Level 3 — visual understanding: what each picture is actually showing

Degrees are local, edge counts are global. The animation's first two scenes show a five-vertex graph beside its adjacency matrix. The row sums of the matrix are the degrees, and their total is twice the edge count. Nothing about the positions of the dots enters that arithmetic — which is exactly the point.

A component is a maximal piece. Scene 3 draws a graph with three components, one of which is a single vertex with no edge. Isolated vertices are the ones people forget, and a graph with no edges at all on n vertices has n components, not zero.

Deleting edges reveals the skeleton. Scene 5 deletes an edge of a cycle, and the graph stays connected. Repeat that and you are left with a spanning tree. This is the cleanest way to see why a spanning tree must exist: it is what the deletion process cannot avoid reaching.

Cuts are about what survives removal. Scene 6 highlights two cut vertices and one bridge in the same graph, and the table beside it shows the component count before and after each deletion. A bridge and a cut vertex are visible as different things: one is an edge, one is a dot.

Colour is the bipartite test. Scene 8 colours an even cycle 0, 1, 0, 1 and fails to colour an odd one. The failure is not a lack of imagination: alternating around five steps returns you to the colour you started with, and the closing edge then has both ends the same colour.

Euler is a degree count; Hamilton is a search. Scene 9 puts three small graphs side by side with their odd-degree counts: zero, two, four. The verdicts are circuit, trail, neither — and the Hamiltonian question is shown separately because it cannot be read off a degree list.

Level 5 and 6 — where the definitions stop applying

Every theorem in this unit has a hypothesis, and the marks lost on this topic are almost always lost by using the conclusion where the hypothesis fails. The tree test needs connectivity as well as acyclicity. The Euler test needs every edge in one component as well as all degrees even. Cayley's formula needs a complete graph. Whitney's chain gives a bound and not a value. κ of a complete graph is defined by convention as n − 1, because a complete graph has no vertex cut at all — and κ of a disconnected graph is 0, because it is already broken. Five worked examples, each one step at a time

Every number below was computed twice — once from the definition and once by enumeration or search — and the agreement is one of the page's model checks. The examples are in the order the reasoning builds.

1. A degree sequence that no graph has

Question. Is there a simple undirected graph on 7 vertices in which every vertex has degree 3?

Step 1. Assume there is one. The handshake lemma gives Σ deg = 2m.

Step 2. Here Σ deg = 7 × 3 = 21, which is odd.

Step 3. 2m is even for every integer m. An odd number cannot equal an even number, so the assumption is false: no such graph exists.

Why this is the whole answer. You do not need to try to draw one. The parity of the degree sum settles it, and it settles every question of this shape in one line. Derivation

2. Connected, 12 vertices, 12 edges

Question. A connected graph has n = 12 vertices and m = 12 edges. How many cycles does it contain?

Step 1. A connected graph on 12 vertices needs at least 11 edges, because a spanning tree has exactly n − 1 = 11.

Step 2. It has one edge beyond that. Each edge you add to a spanning tree creates exactly one new cycle, and no two added edges can share a cycle.

Step 3. So there is exactly one cycle. The number m − n + 1 is called the cycle rank, and here it is 12 − 12 + 1 = 1.

The trap. "Exactly one cycle" does not mean the cycle is a triangle. It may have any length from 3 up to 12, and it may pass through all twelve vertices. Derivation

3. Two triangles joined by one edge

Question. The graph below has six vertices: a triangle on {0, 1, 2}, a triangle on {3, 4, 5}, and one edge joining 2 to 5. Find its cut vertices, its bridges, κ, λ and δ, and decide whether it has an Euler circuit, an Euler trail, or neither.

Degrees. 2, 2, 3, 2, 2, 3. The sum is 14, so there are 7 edges — which matches the six triangle edges plus the joining edge.

Cut vertices. Deleting vertex 2 leaves the triangle {0, 1} plus vertex 2's removal splitting off nothing inside its triangle — but the other triangle becomes separate, so the component count rises from 1 to 2. The same happens for vertex 5. No other vertex does this: deleting vertex 0 leaves {1, 2} still joined to everything through 2. So the cut vertices are 2 and 5.

Bridges. Only the edge 2–5. Deleting any triangle edge leaves its endpoints joined the long way round the triangle.

Connectivity. κ = 1 because {2} is a vertex cut; λ = 1 because {2–5} is an edge cut; δ = 2. The chain 1 ≤ 1 ≤ 2 holds, and is strict at its last link.

Trails. Exactly two vertices have odd degree — 2 and 5, both of degree 3 — and every edge lies in one component, so an Euler trail exists and no Euler circuit does. A Hamiltonian cycle does not exist: any cycle would have to cross the bridge and come back, and a cycle may not use an edge twice. Verified fact Both verdicts were confirmed by exhaustive search in the page's checks, not by inspection.

4. Is this graph bipartite?

Question. Decide for the 5-cycle and for the 6-cycle, and say why the answer differs.

Method. Colour any vertex 0, then colour each neighbour 1, and continue. This is what a breadth-first search does automatically, colouring by the parity of the distance from the start.

6-cycle. The colours come out 0, 1, 0, 1, 0, 1 and the closing edge joins 1 to 0. Every edge joins different colours, so the graph is bipartite.

5-cycle. The colours come out 0, 1, 0, 1, 0 and the closing edge joins 0 to 0. That edge has both ends the same colour, so no colouring exists and the graph is not bipartite.

Why it is a proof and not an observation. Any attempt at a colouring is forced: once one vertex is coloured, its neighbours are forced, and so on around the cycle. So the failure of the 5-cycle is not one failed attempt but the failure of the only possible attempt. Derivation

5. Reading kappa off a graph you cannot draw

Question. G is K5 with one edge removed. Find κ, λ and δ.

Degrees. Removing an edge lowers the degree of its two endpoints by one, so the degrees are 4, 4, 4, 3, 3 and δ = 3.

λ. Delete the three edges at a degree-3 vertex and that vertex is isolated, so λ ≤ 3. Two edge deletions cannot disconnect it, because the graph is dense, so λ = 3.

κ. Delete the three neighbours of a degree-3 vertex and it is isolated, so κ ≤ 3. And κ ≥ λ is false in general, so this direction needs the other argument — here, deleting any two vertices leaves at least three vertices that are still well connected, so κ = 3.

The lesson. κ ≤ λ ≤ δ gives you an upper bound on both from δ, and the two bounds coincide here. When they coincide you are done; when they do not, you must argue. Derivation Community observation Questions of this shape are usually 1-mark and are meant to be answered from the chain plus one argument, not from an exhaustive search.

The boundaries where a correct-looking rule gives a wrong answer

Each item below is a place where the hypothesis of a theorem quietly fails. The counterexample given is the smallest one that shows the failure, so you can check it in the exam in under a minute.

κ of a complete graph is a convention

The claim that fails. "κ is the size of the smallest vertex cut."

Counterexample. K4 has no vertex cut at all: delete any three vertices and one remains, so the graph never becomes disconnected. The size of the smallest cut does not exist.

Repair. By convention κ(Kn) = n − 1. The convention is forced, because λ(Kn) = n − 1 and δ(Kn) = n − 1, and the chain must hold. Verified fact

κ of a disconnected graph is zero

The claim that fails. "κ is at least 1 for any graph with at least two vertices."

Counterexample. Two vertices with no edge. It is already disconnected, so zero deletions are needed, and κ = 0.

Repair. Read κ as "the fewest deletions that disconnect it", not "the fewest that keep it connected". A graph that is already broken needs none. Derivation

A bridge need not produce two cut vertices

The claim that fails. "The endpoints of a bridge are cut vertices."

Counterexample. Two vertices joined by one edge. The edge is a bridge — delete it and there are two components. Delete either endpoint and one vertex remains, one component, so neither endpoint is a cut vertex.

Repair. The endpoints of a bridge are cut vertices only when both have degree at least 2. The degree condition is the whole content. Derivation

A cut vertex need not be on a bridge

The claim that fails. "Every cut vertex is the endpoint of a bridge."

Counterexample. Two triangles sharing exactly one vertex — a "bowtie". That shared vertex is a cut vertex: remove it and the graph becomes two components. But there is no bridge anywhere, because every edge lies on a triangle.

Repair. The two notions are independent in both directions. Only "a cycle has neither" is safe. Derivation

The all-even test needs the edges in one component

The claim that fails. "A graph has an Euler circuit exactly when every vertex has even degree."

Counterexample. Two disjoint triangles. All six degrees are 2, all even, and no single closed trail covers all six edges, because the trail cannot jump between components.

Repair. The criterion is: every edge lies in one component and every degree is even. Note what the condition does not say — it does not say the graph is connected, because an isolated vertex elsewhere is harmless. Verified fact

Cayley's formula is for complete graphs only

The claim that fails. "A graph on n vertices has nn−2 spanning trees."

Counterexample. A 4-cycle has 4 spanning trees, not 42 = 16. Each spanning tree is the cycle with one edge deleted, and there are four edges.

Repair. Cayley counts the spanning trees of Kn. For any other graph the count is smaller, and needs a different method. Derivation

An isolated vertex is a component

The claim that fails. "A graph with no edges has no components."

Counterexample. Five vertices and no edges. Every vertex is a maximal connected piece, so there are five components — and the graph is certainly not connected.

Repair. Count the lone dots. The empty graph on n vertices has n components and n − 1 = −1 is not its edge count, which is why the tree test needs n ≥ 1 and connectivity. Derivation

Two odd degrees is a trail, not a circuit

The claim that fails. "A graph with at most two odd-degree vertices has an Euler circuit."

Counterexample. A path on three vertices: degrees 1, 2, 1. A trail exists — walk from one end to the other — but it does not return to its start, so it is not a circuit.

Repair. Zero odd vertices gives a closed trail; exactly two gives an open one, whose endpoints are the two odd vertices. Four or more gives neither. Derivation

Six beliefs that feel right and are not

Each is stated as a student would state it, then broken with the smallest counterexample, then repaired. The pairs at the end are the ones that get swapped under exam pressure.

"A drawing shows the graph"

Why it feels right. Every textbook draws graphs, and the drawings are usually chosen to be readable.

Why it fails. A crossing in a drawing is not a vertex. Two edges that cross on the page share no endpoint unless a dot is drawn at the crossing. And the same graph can be drawn with a vertex in the middle of the page or at the edge of it, changing every visual impression and no fact.

Repair. Write down V and E and answer from them. If a drawing is given, relabel it in your head: the answers must not change. Derivation

"A tree is a graph with n − 1 edges"

Why it feels right. It is one of the three equivalent statements, and it is the easiest to check.

Why it fails. Take four vertices and three edges arranged as a triangle plus an isolated vertex. It has n − 1 = 3 edges, and it is not a tree: one component has a cycle and the other is isolated.

Repair. The statement is "connected and n − 1 edges", or equivalently "acyclic and n − 1 edges". The edge count alone is not enough; one of the other two properties must be added. Derivation

"More edges means more connected"

Why it feels right. Adding edges can only help, and κ ≤ λ ≤ δ suggests density helps.

Why it fails. Connectivity is not monotone in the edge count across different graphs. A graph with 8 edges can have κ = 1 while a graph with 6 edges has κ = 2. Two triangles joined by a bridge have 7 edges and κ = 1; a 6-cycle has 6 edges and κ = 2.

Repair. Compare within one graph, not across graphs. Adding an edge to a fixed graph never decreases κ, but the edge count alone tells you nothing. Derivation

"Bipartite means no triangle"

Why it feels right. A triangle is the smallest odd cycle, and it is the one you can see.

Why it fails. The 5-cycle has no triangle and is not bipartite. Any odd cycle obstructs, and there are odd cycles of every length from 3 upwards.

Repair. Test for any odd cycle, by 2-colouring. A graph with no triangle can still fail, and a 2-colouring finds the failure in one pass. Derivation

"Euler and Hamilton are the same question"

Why it feels right. Both are about a round trip that covers everything exactly once, and both are called "circuits" in casual speech.

Why it fails. Euler covers every edge; Hamilton visits every vertex. Two triangles joined by a bridge have an Euler trail and no Hamiltonian cycle. K4 minus an edge has a Hamiltonian cycle and no Euler circuit. Both directions of the confusion are realised by a graph you can draw in ten seconds.

Repair. Ask which object the word "every" refers to. If it is edges, count degrees. If it is vertices, you have no cheap test and the question is telling you to search or to use a sufficient condition. Derivation

"The chain gives me kappa"

Why it feels right. κ ≤ λ ≤ δ is memorable, and in most small examples the three values coincide.

Why it fails. A graph on this page has κ = 1, λ = 2 and δ = 3. All three differ, so the chain gives you only an interval.

Repair. Use the chain as a bound and then argue one side. If you can exhibit a cut of size k and show no smaller cut exists, you have κ = k without needing the chain at all. Verified fact The 1, 2, 3 example was built and its three values computed by brute force over every cut, in the page's checks.

The pairs that get swapped

Cut vertex against bridge. A cut vertex is a vertex; a bridge is an edge. In the two-triangle graph the count of cut vertices is 2 and the count of bridges is 1. A question that asks for one and gets the other is a whole mark.

Connected against 2-connected. Connected means one component. 2-connected means no cut vertex — that is, it survives the loss of any single vertex. Every 2-connected graph is connected; the reverse is false, and a path on four vertices is the smallest counterexample.

Tree against spanning tree. A tree is a graph. A spanning tree is a subgraph of a given graph that happens to be a tree. A graph has many spanning trees; it is a tree itself exactly when it has exactly one.

Path against walk. A path repeats no vertex; a walk may repeat anything. A question that says "walk of length 3" is not asking for a path, and in a graph with a triangle there are more walks than paths.

Distance against shortest path. Distance is a number; the shortest path is the route that realises it. Two different shortest paths can share the same distance, so "the shortest path" may not be unique — a detail that matters in the algorithms paper.

The five-question procedure

Run this in order on any graph question. It costs a minute and answers most of them outright.

  1. Count. Write n = |V| and m = |E|. If m is given and degrees are given, the handshake lemma relates them instantly.
  2. Degrees. List them. If any question mentions odd, even, Euler or a minimum, this list is the answer.
  3. Components. Find them, including isolated vertices. Connectivity questions end here.
  4. The tree test. If m = n − 1, ask whether it is connected. If yes it is a tree; if no it has a cycle somewhere.
  5. The object to break. Vertex, edge, colour, or trail? That word picks the definition, and the definition picks the argument.

Question patterns

Parity. "Does a graph with these degrees exist?" or "how many edges?" — settled by Σ deg = 2m. If the sum is odd, the answer is "no graph".

Edge count against connectivity. "A connected graph has n vertices and m edges; how many cycles?" — the answer is m − n + 1, and the reasoning is spanning tree plus added edges.

Cut identification. "How many cut vertices / bridges / articulation points?" — delete each candidate and compare the component count. On small graphs this is faster than any algorithm.

Connectivity value. "What is κ / λ?" — exhibit a cut of that size, then argue nothing smaller works. Use κ ≤ λ ≤ δ to bound first.

Trail or circuit. "Which of these graphs has an Euler circuit / Hamiltonian cycle?" — count odd degrees for Euler; for Hamilton, look for a bridge or a degree-1 vertex, which both forbid a Hamiltonian cycle.

Shortcuts and the assumptions they need

Σ deg = 2m. Needs: simple, undirected. In a multigraph a loop contributes 2 to one vertex, and in a directed graph in-degree and out-degree are separate.

m − n + 1 cycles. Needs: connected. For a graph with c components the cycle rank is m − n + c, and using m − n + 1 on a disconnected graph gives the wrong count.

m = n − 1 ⟹ tree. Needs: connected. Without it you have a forest with one cycle, as in the triangle-plus-isolated-vertex example.

nn−2 spanning trees. Needs: complete graph.

All even degrees ⟹ Euler circuit. Needs: every edge in one component.

What a question is really asking

Almost every graph question in this unit is one of four sentences in disguise. "Is it possible?" is a parity question about degrees. "How many?" is an edge count or a cycle-rank question. "If I remove this, what breaks?" is a cut question. "Can I cover everything once?" is an Euler-or-Hamilton question, and the word edge or vertex in the question tells you which. Naming the sentence is most of the work; the arithmetic after that is short. When a question gives a picture, redraw it as a list of edges first — the picture is the one part of the question that carries no information you can compute with.

Original practice MCQ Q1. A simple undirected graph has 7 vertices, and every vertex has degree 3. How many edges does it have?

(A) 10    (B) 10.5    (C) 21    (D) No such graph exists

Answer: (D). The handshake lemma gives Σ deg = 2m, so 2m = 7 × 3 = 21, and 2m must be even. No integer m satisfies it, so the graph does not exist.

Why the others are wrong. (C) is Σ deg, not m — it forgets to divide by 2. (B) is 21 ÷ 2 left as a fraction, which no edge count can be. (A) is 21 ÷ 2 rounded down, which is arithmetic on a quantity that must be an integer.

Trap. The reflex is to divide and round. The correct reflex is to check the parity first, and then report impossibility.

Original practice NAT Q2. A tree has 10 vertices. How many edges does it have?

Answer: 9. A tree on n vertices has exactly n − 1 edges, so 10 − 1 = 9.

Why it is exactly, not at most. Connectedness forces at least n − 1 edges, and acyclicity forbids more than n − 1. The two bounds meet at n − 1, so the count is forced. This is the argument from the Build-up tab, and it is what makes the number a theorem rather than a convention.

Common slip. Writing 10. The count is of edges, and the edge count of a tree is one less than its vertex count, always.

Original practice MCQ Q3. G is a connected graph with 12 vertices and 12 edges. Which statement is necessarily true?

(A) G is a tree    (B) G contains exactly one cycle    (C) G contains at least two cycles    (D) G has a cut vertex

Answer: (B). A connected graph on 12 vertices has a spanning tree with 11 edges. The twelfth edge closes exactly one cycle, and since the tree had no cycle, no second cycle exists. Equivalently the cycle rank is m − n + 1 = 1.

Why the others are wrong. (A) A tree on 12 vertices has 11 edges, not 12, so G has one edge too many. (C) Two independent cycles need at least 13 edges: a spanning tree has 11, and each extra edge adds exactly one cycle. (D) Take the 12-cycle itself: 12 vertices, 12 edges, exactly one cycle, and deleting any vertex leaves a path on 11 vertices, which is still connected. So it has no cut vertex, and (D) is not necessary.

Trap. "Exactly one cycle" does not mean "a triangle". The single cycle may be long and may pass through every vertex.

Original practice MSQ Q4. Which of the following hold for every connected simple undirected graph G with at least three vertices?

(A) κ(G) ≤ λ(G)    (B) λ(G) ≤ δ(G)    (C) κ(G) = λ(G)    (D) G has a spanning tree

Answer: (A), (B), (D). (A) and (B) are Whitney's chain. (D) holds because the edge-deletion argument always terminates in a spanning tree.

Why (C) is wrong. Two triangles joined by one edge have κ = 1 and λ = 1, so the chain is tight there — but a 12-vertex graph in this lesson's checks has κ = 1, λ = 2, δ = 3. Equality is common and is not a theorem.

Assumption to state. The chain is stated for a graph with at least two vertices; for the one-vertex graph the conventions differ and the question excludes it by asking for at least three.

Original practice NAT Q5. How many spanning trees does K4 have?

Answer: 16. Cayley's formula gives nn−2 = 42 = 16 for a complete graph.

Independent check. K4 has 6 edges and a spanning tree uses 3 of them, so there are C(6, 3) = 20 subsets of size 3. Four of those are triangles (one for each choice of 3 vertices), leaving 16 that are trees. The page's check does this by listing every subset and testing each one, and gets 16.

Trap. Applying the formula to a non-complete graph. A 4-cycle has 4 spanning trees, not 16, because the formula counts trees that use edges the cycle does not have.

Original practice MCQ Q6. Which of these graphs is not bipartite?

(A) C4    (B) C6    (C) K2,3    (D) C5

Answer: (D). A graph is bipartite exactly when it has no odd cycle. C5 is an odd cycle, so it fails: alternating two colours around five steps returns to the starting colour, and the closing edge joins two vertices of the same colour.

Why the others are bipartite. C4 and C6 are even cycles, coloured alternately. K2,3 is bipartite by construction: its two sides are the parts, and every edge crosses between them.

Trap. Answering "not bipartite" only for graphs with a triangle. The obstruction is oddness, and C5 has no triangle.

Original practice MCQ Q7. G is a connected graph in which every vertex has even degree. Which is true?

(A) G has an Euler circuit    (B) G has a Hamiltonian cycle    (C) G is bipartite    (D) G is a tree

Answer: (A). Connected with every degree even is exactly the Euler circuit criterion, and here connectedness is given, so the criterion is fully met.

Why the others are wrong. (B) Take two triangles sharing exactly one vertex — a bowtie. The shared vertex has degree 4 and the other four have degree 2, so every degree is even and the graph is connected; yet the shared vertex is a cut vertex, so no cycle can pass through all five vertices. All even degrees do not give a Hamiltonian cycle. (C) K5 has all degrees 4 and is not bipartite, because it contains triangles. (D) A tree with more than one vertex always has at least two leaves of degree 1, which is odd.

Assumption to state. The Euler criterion needs every edge in one component as well as even degrees. Here connectivity is given, which is why (A) follows.

Original practice NAT Q8. Two triangles are joined by a single edge between one vertex of each. How many cut vertices does the resulting graph have?

Answer: 2. The two endpoints of the joining edge, and only those. Deleting either one separates the far triangle from the near one, so the component count rises from 1 to 2.

Check the others. Deleting any of the four remaining vertices leaves a triangle minus a vertex — a path — still attached to everything else, so the count stays at 1. The page computes the component count after each of the six deletions and gets exactly two that change it.

Do not confuse the count. The number of bridges here is 1, not 2. A question asking for bridges wants 1.

Original practice NAT Q9. What is the vertex connectivity κ of K5?

Answer: 4. K5 has no vertex cut at all — delete any three vertices and two remain joined. The value is fixed by the convention κ(Kn) = n − 1, which gives 4.

Why the convention is forced. λ(K5) = 4, because deleting the four edges at any vertex isolates it. δ(K5) = 4. The chain κ ≤ λ ≤ δ then forces κ ≤ 4, and since no smaller cut exists, κ = 4.

Trap. Writing 0 because "no cut exists", or 5 because "all five vertices". Neither is the convention, and the chain rules both out.

Original practice MSQ Q10. Which statements are true for every simple undirected graph?

(A) Every bridge has two cut-vertex endpoints    (B) No cycle has a bridge    (C) Every edge of a tree is a bridge    (D) Every cut vertex is an endpoint of some bridge

Answer: (B), (C).

(B) is true. Delete any edge of a cycle and its endpoints are still joined the long way round, so the component count does not rise.

(C) is true. Deleting any edge of a tree destroys the only route between its endpoints, so the tree splits in two.

(A) is false. Two vertices joined by one edge: the edge is a bridge, and deleting either endpoint leaves one component, so neither is a cut vertex. The endpoints are cut vertices only when both have degree at least 2.

(D) is false. Two triangles sharing exactly one vertex: that vertex is a cut vertex, and no edge is a bridge, because every edge lies on a triangle.

The distinction to keep. A cut vertex is a vertex and a bridge is an edge. Neither implies the other; only "a cycle has neither" is safe in both directions.

One-page revision sheet

Definitions, the four formulas, the decision procedure, and the traps. If you have ten minutes before the paper, this is the tab to read.

Definitions in one line each

  • Graph (V, E): V a finite set, E a set of two-element subsets of V.
  • Degree deg(v): the number of edges at v.
  • Walk / trail / path: no restriction / no repeated edge / no repeated vertex.
  • Cycle: a closed path of length at least 3.
  • Connected: a path joins every pair of vertices.
  • Component: a maximal connected subgraph; components partition V.
  • Tree: connected and acyclic.
  • Spanning tree: a tree on the same vertex set, using a subset of E.
  • Cut vertex: a vertex whose deletion raises the component count.
  • Bridge: an edge whose deletion raises the component count.
  • κ: fewest vertices whose deletion disconnects; κ(Kn) = n − 1, κ(disconnected) = 0.
  • λ: fewest edges whose deletion disconnects.
  • δ: the smallest degree.
  • Bipartite: V splits into two parts with every edge crossing.
  • Euler circuit / trail: closed / open trail using every edge once.
  • Hamiltonian cycle: a cycle visiting every vertex once.

The formulas and criteria

Σ deg(v) = 2|E| — handshake. Consequence: the number of odd-degree vertices is even.

Tree on n vertices: |E| = n − 1 — and equivalently, exactly one path between every pair.

Cycle rank = |E| − |V| + c, where c is the component count. For a connected graph this is |E| − |V| + 1, the number of independent cycles.

Spanning trees of Kn = nn−2 (Cayley). Complete graphs only.

κ ≤ λ ≤ δ (Whitney). A bound, not a value.

Bipartite ⟺ no odd cycle; decided by 2-colouring, which a breadth-first search does by parity of distance.

Euler circuit ⟺ every edge in one component and all degrees even. Two odd vertices gives an open trail instead; four or more gives neither.

Hamiltonian cycle: no simple exact criterion is known; the problem is NP-complete. A degree-1 vertex or a bridge rules it out immediately.

The procedure, compressed

  1. n, m, and Σ deg — does the parity work?
  2. Degrees listed — odd, even, minimum?
  3. Components — including isolated vertices.
  4. m = n − 1 and connected? Then it is a tree.
  5. What must be broken: vertex, edge, colour, or trail?

Traps, in the order they cost marks

  1. Reading a picture. A crossing is not a vertex; positions carry no information.
  2. Cut vertex against bridge — a vertex against an edge, and the counts differ.
  3. Euler against Hamilton — edges against vertices, and only Euler has a degree test.
  4. Applying a criterion without its hypothesis: connectivity for the tree test, one component for Euler, complete for Cayley.
  5. Reading κ = λ = δ off the chain. The chain bounds; it does not determine.
  6. Forgetting that an isolated vertex is a component.

Six quick self-questions

(1) Can a graph have exactly three vertices of odd degree? (2) A connected graph has 20 vertices and 20 edges — how many cycles? (3) What is κ of a 10-cycle? (4) Is K3,3 bipartite? (5) A tree with 8 vertices has how many bridges? (6) Does a graph with all degrees even and two components have an Euler circuit? Answers: (1) no, the count is even; (2) exactly one; (3) 2, since deleting one vertex leaves a path; (4) yes, by construction; (5) all 7, every edge of a tree is a bridge; (6) no, the edges are not all in one component.
