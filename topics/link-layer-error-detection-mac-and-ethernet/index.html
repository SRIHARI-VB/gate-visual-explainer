Topic and objective

TOPIC: The second clause of Section 10 of the official GATE 2027 CS syllabus — the link layer: error detection, Medium Access Control, and Ethernet. Three jobs that look unrelated and share one question: what can a receiver conclude from bits that may be wrong, and what can several stations conclude from a wire they must share?

LEARNING OBJECTIVE: Compute a CRC remainder by modulo-2 division and state exactly which error patterns the generator catches; read a code's minimum Hamming distance and convert it into a detection and a correction capability; compute an Internet checksum and explain the error pattern that passes it; compute the vulnerable period of pure ALOHA, slotted ALOHA and carrier-sense protocols and the throughput ceiling each one implies; and derive the minimum Ethernet frame size from a round trip, solving for whichever of the four quantities a question leaves out.

I read this topic as one question asked at three depths. Detection asks "is this wrong?". Correction asks "what was it?". Medium access asks "was anybody else talking?". Every formula in the clause is a consequence of one of those three, and the practice set is built on that reading.

GATE relevance

Verified fact Class A — explicitly in the syllabus.

Section 10 of the official GATE 2027 CS syllabus (IIT Madras, CS_GATE2027_Syllabus.pdf) reads: "Principles of Layering; Basics of switching (circuit, packet and virtual circuit) and performance metrics; link layer: error detection, Medium Access Control, Ethernet; Distance vector and link state routing; IPv4 - Fragmentation, CIDR Notation, Network Address Translation; TCP- flow control and congestion control, socket API; DNS and HTTP."

This lesson is the clause link layer: error detection, Medium Access Control, Ethernet, in full. The clause before it is taught in layering, switching and performance metrics.

Class A means a question here is inside the declared boundary. It does not mean one is guaranteed. Historical frequency is an observation about past papers, never a prediction, and nothing in this lesson is offered as a forecast.

Prerequisites

Layering, switching and performance metrics — that lesson. Transmission delay L/R, propagation delay d/v, and the fact that the link layer is scoped to one hop are assumed throughout. Every question in this clause is that arithmetic with a link-layer question attached.

Boolean algebra and minimisation — that lesson. CRC arithmetic is XOR and nothing else, and parity is XOR written as a sum modulo two.

Sets, relations and counting — counting and combinatorics. Counting codewords and counting error patterns is what the distance arguments actually are.

The five ideas this lesson turns on

  1. Detection is a parity question; correction is a distance question. One bit of redundancy can say "wrong". Naming a position needs enough redundancy to encode a position.
  2. CRC is division, and its guarantees come from the generator's algebra. Degree r bounds the burst length it catches; a constant term makes bursts detectable at all; x+1 being a factor is what catches every odd-weight error.
  3. dmin ≥ s+1 detects s errors; dmin ≥ 2t+1 corrects t. Distance three corrects one error, not three.
  4. ALOHA's cost is the vulnerable period. Two frame times without listening, one with slots, one propagation delay with carrier sense. The ceilings 18.4% and 36.8% follow from that.
  5. The minimum frame is a round trip turned into bits. L ≥ 2τR, and every CSMA/CD question is that line solved for whichever quantity is missing.

Intuition: a parcel, a checklist, and a doorway

A parcel arrives. Three separate questions get asked about it, by three different people. Is this a complete parcel or two parcels stuck together? (framing) Is anything inside damaged? (error detection) Was somebody else pushing a parcel through the same door at the same time? (medium access).

The packing slip is the checksum: cheap, quick, catches a dropped item. The sealed tamper strip is the CRC: harder to fake. The doorway argument is settled by listening before you push.

Educational interpretation The analogy carries the separation of the three jobs, which is the thing learners collapse. It does not carry the terminology, and a packing slip is not a checksum in any formal sense.

Formal definitions

A frame is the unit the link layer hands to the physical layer: a bounded block of bits with a header, a payload and a trailer. Framing is the rule that makes its boundaries recoverable.

An error-detecting code maps each message to a longer codeword; the minimum Hamming distance dmin is the smallest number of positions in which two distinct codewords differ.

A medium access control protocol decides which station transmits next on a shared channel. A collision domain is the set of stations whose transmissions can collide.

dmin ≥ s + 1  ⟹  detects s errors   ·   dmin ≥ 2t + 1  ⟹  corrects t errorsDetection needs every error pattern to land off the code. Correction needs the radius-t balls around codewords to stay disjoint, which costs twice as much distance.

Verified fact Both inequalities are standard coding-theory results, stated in this form in Tanenbaum and Wetherall, Computer Networks, and in Forouzan, Data Communications and Networking.

Framing, precisely

Character count — a length field. One corrupted count destroys the rest of the stream, which is why it is rarely used alone.

Flag bytes with byte stuffing — a delimiter, escaped inside the data with an escape byte.

Flag bits with bit stuffing — the HDLC rule: the flag is 01111110, so the sender inserts a 0 after every run of five 1s, and the receiver deletes it.

Mathematical derivation Five 1s followed by an inserted 0 can never become six 1s, so the flag cannot occur in stuffed data. The rule never looks ahead, so sender and receiver agree without negotiation. GATE CSE 2014 Set 3 Q24 is this rule run backwards: stuffed 01111100101 destuffs to 0111110101.

CRC: the arithmetic, in one paragraph

Treat the message bits as coefficients of a polynomial over GF(2). Pick a generator G of degree r. Append r zeros to the message, divide by G using XOR at each step, and the r-bit remainder is the check value. Transmit message followed by remainder.

T(x) = xr·M(x) + R(x),   where R(x) = xrM(x) mod G(x)The transmitted word is a multiple of the generator by construction, so the receiver's division gives remainder zero unless something changed.

The receiver divides the whole received word by G. Remainder zero: no detected error. Anything else: detected, and the remainder is the syndrome.

Verified fact This construction, and the three guarantees below, are the standard treatment in Forouzan chapter 10 and Tanenbaum section 3.2. The lesson recomputes every example rather than quoting a key.

What a generator guarantees, and what it does not

Guaranteed: every single-bit error, if the constant term is 1. Every burst of length at most r, under the same condition. Every odd-weight error, exactly when x+1 divides G.

Not guaranteed: bursts of length r+1. The generator itself, used as an error pattern, is a burst of length r+1 and is a multiple of G, so it passes. The model on this page finds that pattern for G = 1011 and reports it.

Mathematical derivation x+1 divides G exactly when G(1) = 0, which over GF(2) means G has an even number of ones. 1011 has three ones, so it does not divide, and the model exhibits an odd-weight error it misses. 1001 has two ones, so it does, and the model checks all odd-weight patterns on a 12-bit codeword.

Checksum and 2-D parity: the weaker pair

The Internet checksum adds the data as 16-bit words in one's complement, wrapping any carry into the low bit, and complements the total. It costs one pass through an adder, which is why IP, TCP and UDP all carry one.

Two-dimensional parity appends a parity bit to every row and every column. One flip fails one row check and one column check, and their crossing names the bit — so the grid corrects single errors as well as detecting them.

Mathematical derivation Two flips in a row restore that row's parity, and two in a column restore the column's. Four flips at the corners of a rectangle therefore leave every check satisfied. That is the minimal blind spot, and the model verifies it on the 4×7 grid from the classic GATE item.

Hamming code: correction by syndrome

Place check bits at positions 1, 2, 4, 8, …, so every position has a unique binary address. Choose r so that 2r ≥ m + r + 1. For m = 8, r = 4 and the codeword is 12 bits.

At the receiver, recompute each check group. Each failing group contributes its own position number to the syndrome. Syndrome 0 means no single-bit error; syndrome k means bit k flipped.

Mathematical derivation The model encodes d8…d1 = 10110010 into 101001110010, then flips each of the twelve positions in turn and confirms the syndrome equals the position every time. It then flips positions 3 and 5 together and shows the syndrome naming bit 6, which is innocent: single-error correction is a promise about at most one error.

Random access: the vulnerable period is the whole story

Pure ALOHA transmits at will. A frame survives only if no other frame begins within one frame time either side, so the vulnerable period is 2T and throughput is G·e−2G, peaking at 1/(2e) ≈ 18.4% when G = 0.5.

Slotted ALOHA allows starts only at slot boundaries. The window halves to T, throughput is G·e−G, and the peak is 1/e ≈ 36.8% at G = 1.

CSMA listens first, so only a station that began before your first bit arrived can hurt you: the window is one propagation delay τ.

Verified fact Both closed forms and both ceilings are the standard results in Tanenbaum section 4.2. The lesson also simulates both protocols with a fixed seed over 40 000 frame times and checks the simulated throughput against the closed form to within 1.5 percentage points.

CSMA/CD: the condition that forces a minimum frame

With collision detection the sender learns of a collision only when the corrupted signal returns, one round trip after it began. So the frame must still be in transit then:

L / R ≥ 2τ   ⟺   L ≥ 2τR,   τ = d / vτ is one way; the factor of two is the round trip. The condition is about the worst case: the station at the far end starting just before your first bit arrives.

Verified fact This is the standard derivation, and GATE CSE 2015 Set 3 Q6 is the same line solved for v: 1250 bytes at 108 bps over 1 km gives 2 × 107 m/s, which the model recomputes.

The 802.3 frame, field by field

Destination 6 bytes, source 6, type or length 2, payload 46 to 1500, frame check sequence 4. That is 18 bytes of overhead and a frame of 64 to 1518 bytes. The preamble (7 bytes) and start-of-frame delimiter (1 byte) are transmitted but are not counted in that 64.

Slot time is 512 bit times, which is 51.2 µs at 10 Mbps. The 2500-metre maximum diameter at 2 × 108 m/s has a round trip of 25 µs, and the remaining margin pays for repeaters and transceivers.

Verified fact Field widths and the 64-byte minimum are IEEE 802.3. The claim that the whole 51.2 µs is needed for propagation alone is not correct and is not made here: propagation accounts for about half of it.

Level 5 to 7 in one line each

Boundary: every guarantee above is conditional. No constant term, no burst guarantee. No x+1 factor, no odd-error guarantee. No collision detection, no factor of two.

Edge case: a code with dmin = 2 detects one error and corrects none. A hub is one collision domain; a switch gives each port its own.

GATE application: four question shapes cover almost every item — compute a remainder, read a distance, compute a vulnerable window, and solve L = 2τR for the missing quantity. The next tab names them.

Examples, page 1 of 2 — detection, worked digit by digit

Every arithmetic step below is reproduced by the model on this page; none is copied from an answer key.

Example 1 — CRC, GATE CSE 2017 Set 1 Q32

Message 01011011, generator x3 + x + 1, that is 1011. Degree 3, so append three zeros: 01011011000. Divide modulo 2.

  1. Take the first four bits 0101. Leading bit 0, so shift with no XOR.
  2. Bring down to 1011, XOR 1011 → 0000, continue.
  3. Each subsequent pass XORs 1011 only where the running remainder has a leading 1.
  4. The three bits left at the end are 101.
transmitted = 01011011  ·  101 = 01011011101Option (C) on the paper. The model divides the codeword again and gets remainder 000, which is the check that the append was right.

The wrong options are instructive: 01011011010 keeps two of the three check bits correctly, and 01011011000 is the message with the zeros still appended and no division done at all.

Example 2 — CRC, GATE CSE 2021 Set 2 Q34

Message m4…m0 = 11000, same generator 1011, check bits c2c1c0 appended. Append three zeros: 11000000. Divide by 1011.

XOR passes give 0111, then 0101, then 0001, and after bringing the last zeros down the remainder is 100.

c2c1c0 = 100The model computes this independently and also confirms that 11000100 divides by 1011 with remainder zero.

A five-bit message with a degree-three generator gives an eight-bit codeword. Getting 1000 or 010 here usually means one extra or one missing bring-down.

Example 3 — two-dimensional parity, and its rectangle

The classic 4×7 data block, padded with an even-parity column d0 and an even-parity row r4, is transmitted as 40 bits.

Flip one bit: exactly one row check and one column check fail, and their crossing is the flipped bit. The model confirms the located row and column.

Flip four bits at the corners of a rectangle — say (r0,d7), (r0,d5), (r2,d7), (r2,d5). Each affected row now has two flips and each affected column two, so every check passes and the receiver reports a clean block.

Flip three bits anywhere and at least one check fails: the model tests a triple and detects it. That is the whole content of the honest claim "all patterns of weight up to three".

Example 4 — the Internet checksum, and two errors that cancel

Words 0x1234, 0x5678, 0x9ABC, 0xDEF0. Add with end-around carry, then complement.

Now raise the first word by 1 to 0x1235 and lower the second by 1 to 0x5677. The word sum is unchanged, so the receiver's total including the check value is still 0xFFFF, and the error passes.

checksum = complement of the one's complement sum  ·  receiver tests sum = 0xFFFFThe blind spot is structural: any change whose per-word deltas sum to zero is invisible. That is why a checksum is called weak and a CRC is not.

The model computes both blocks and reports that both verify — the honest way to show a weakness is to exhibit it, not to assert it.

Example 5 — a Hamming codeword, built and repaired

Data d8…d1 = 10110010. m = 8 needs r = 4, because 23 = 8 < 13 and 24 = 16 ≥ 13. Positions 1, 2, 4, 8 carry check bits; data fills 3, 5, 6, 7, 9, 10, 11, 12.

Even parity over each check group gives the codeword 101001110010.

Flip bit 7: the syndrome is 7, so the receiver flips position 7 back. The model repeats this for all twelve positions and gets the position every time.

Now flip bits 3 and 5 together. The syndrome is 6, which points confidently at bit 6 — a bit that was never touched. Correcting it makes the word three bits wrong. This is why the guarantee is stated as "at most one error".

Example 6 — reading a distance, GATE CSE 2017 Set 2 Q34

Codewords 00000, 01011, 10101, 11110. All six pairwise distances are 3, 3, 4, 4, 3, 3, so dmin = 3.

t = ⌊(dmin − 1) / 2⌋ = ⌊2/2⌋ = 1Distance 3 detects two errors and corrects one. The two answers are different numbers, which is the trap.

The model recomputes all six distances and the floor, so the answer on the page is derived rather than quoted.

Example 7 — ALOHA by simulation and by formula

Pure ALOHA at G = 0.5 over 40 000 frame times: a frame succeeds only if no other arrival falls within one frame time either side. The simulation reports its own measured throughput.

Slotted ALOHA at G = 1 over 40 000 slots: a slot carries a frame only if exactly one arrival lands in it.

Spure = G·e−2G, max 1/(2e) ≈ 0.1839  ·  Sslotted = G·e−G, max 1/e ≈ 0.3679The seed is fixed, so the numbers on the canvas are reproducible. Agreement is checked to within 1.5 percentage points, and the check is one of the forty reported under the canvas.

The model also verifies that slotted ALOHA is never worse than pure ALOHA at any load in (0, 1].

Example 8 — minimum frame size, both directions

Given L, R, d; find v. GATE CSE 2015 Set 3 Q6: 1250 bytes = 104 bits, R = 108 bps, d = 1000 m. From L = 2dR/v, v = 2·1000·108/104 = 2 × 107 m/s = 20000 km/s.

Given v, d, R; find L. A 1 km segment at 10 Mbps with v = 2 × 108 m/s: τ = 5 µs, so L = 2 × 5 µs × 107 = 100 bits. That is why real Ethernet at 10 Mbps has a maximum diameter of 2500 m rather than 1 km: the standard chose 512 bits and derived the diameter.

L ≥ 2τR  ·  τ = d/v  ·  a = τ/Tt  ·  Ustop-and-wait = 1/(1 + 2a)On a 1 km, 10 Mbps LAN with 8000-bit frames, a is about 0.006 and the utilisation about 98.8%: small a means the wire is busy.

All three quantities are computed on the canvas, not typed into it.

Boundaries and counterexamples

Each card names the condition that fails and the smallest structure that shows the failure. Every counterexample here is computed by the model on this page.

Counterexample: the generator as an error pattern

With G = 1011 on the 13-bit codeword from GATE 2017 Set 1, flip the four bits aligned exactly with the generator. The received word differs by G, which is a multiple of G, so the remainder is still zero and the error passes.

Condition violated: "a CRC catches every burst". It catches bursts of length at most r = 3. This one has length 4. The model searches for it and reports the offset.

Counterexample: an odd number of errors that passes

G = 1011 has three ones, so x+1 does not divide it, so the odd-error guarantee does not apply. The model finds an odd-weight pattern on that codeword with remainder zero.

Condition violated: "a CRC catches all odd numbers of errors". True only when G has an even number of ones, which is why 1001 — x3 + 1 — does have the guarantee and the model checks all 4096 patterns to confirm it.

Counterexample: four parity errors that cancel

On the 4×7 parity grid, flip the four corners of any rectangle. Every row check and every column check still passes.

Condition violated: "two-dimensional parity detects up to four errors". It detects every pattern of weight up to three, and a weight-four pattern only when the four bits do not form a rectangle.

Counterexample: two checksum errors that cancel

Raise one 16-bit word by 1 and lower another by 1. The one's complement sum is unchanged, so the receiver's total is still 0xFFFF.

Condition violated: "the checksum detects corruption". It detects changes whose word deltas do not sum to zero. This is a structural weakness, not an unlucky accident.

Counterexample: a syndrome that names an innocent bit

Flip bits 3 and 5 of the 12-bit Hamming codeword. The syndrome is 6, and the receiver "corrects" bit 6, leaving three bits wrong.

Condition violated: "a Hamming code corrects errors". It corrects at most one. With two errors it fails silently, which is worse than detecting nothing — this is why real memories use an extra overall parity bit to make SEC-DED.

Boundary: a code with dmin = 2

Single parity has dmin = 2. It detects one error and corrects none: ⌊(2−1)/2⌋ = 0. Every "detect" and "correct" question must therefore be answered with two separate numbers.

A repetition code of three bits has dmin = 3 and corrects one error, at the cost of tripling every bit. Distance is bought with redundancy, and there is no free lunch in the table.

Boundary: CSMA/CD on a satellite link

Take d = 36 000 km and v = 3 × 108 m/s: τ = 0.12 s, so at 10 Mbps the minimum frame would be 2.4 × 106 bits, about 300 KB. No practical frame is that long.

That is the boundary of the protocol, not a numerical curiosity: CSMA/CD is a LAN protocol because the 2τR product must stay smaller than a sensible frame. On a satellite link you use a different MAC entirely.

Boundary: what the 64 bytes does not include

The 64-byte minimum counts destination, source, type, payload and FCS. It does not count the 7-byte preamble, the 1-byte start-of-frame delimiter, or the 12-byte interframe gap.

A question that asks for "the minimum transmission time of a frame" usually means 64 bytes = 512 bit times; one that asks for "wire time including preamble and gap" means 84 bytes. Read which one is asked, and say which you used.

Six wrong beliefs that cost marks

Each is stated as a learner would state it, then killed with the smallest structure that does the job. The ones marked Community observation are reported difficulties in study forums, not measurements.

"A CRC catches every burst error."

Why it tempts: the textbook sentence says "burst errors", and the qualifier "of length at most r" gets dropped in revision.

Why it is wrong: the generator is itself a multiple of the generator. A burst of length r+1 aligned with it passes.

Minimal counterexample: G = 1011 on the 13-bit codeword, error pattern 1011 at the start. Remainder zero.

Correct rule: every burst of length ≤ r is caught, provided the constant term is 1. Longer bursts are caught with high probability, not certainty. Community observation

"Distance three corrects three errors."

Why it tempts: the number in the formula and the number in the question look the same.

Why it is wrong: correction needs disjoint radius-t balls, which costs 2t+1 distance.

Minimal counterexample: the four codewords of GATE 2017 Set 2 Q34 have dmin = 3 and correct exactly one error.

Correct rule: t = ⌊(dmin − 1)/2⌋ and s = dmin − 1. Different questions, different formulas.

"ALOHA efficiency is 18.4%, so that is the throughput."

Why it tempts: the figure is memorable and appears in every summary table.

Why it is wrong: it is the maximum over load, reached only at G = 0.5. At light load the throughput is close to the offered load.

Minimal counterexample: at G = 0.05, S = 0.05·e−0.1 ≈ 4.5%, which is far below 18.4% — the figure is a ceiling, not a constant.

Correct rule: S = G·e−2G. Quote the peak and the load at which it occurs together, or not at all.

"The minimum frame size has a 2 because there are two stations."

Why it tempts: CSMA/CD involves a sender and a receiver, and the factor is unexplained in most one-line summaries.

Why it is wrong: the 2 is the round trip: the collision signal must travel to the far end and back before the sender can know.

Minimal counterexample: the same formula with one station would still carry a factor of two; the factor survives because it is a time, not a count.

Correct rule: L ≥ 2τR with τ one way. Doubling the distance or the rate doubles the minimum frame; adding stations does not change it.

"A checksum is a CRC."

Why it tempts: both are called "check bits" and both go in a trailer.

Why it is wrong: one is addition, the other is polynomial division; they catch different error families.

Minimal counterexample: two errors that cancel in the sum pass the checksum, while a CRC with a constant term would detect them.

Correct rule: checksum for speed, CRC for strength. A question that names one is not asking for the other, and an Ethernet FCS is a CRC while the IP header check is a checksum.

"A switch and a hub differ in speed."

Why it tempts: switches are faster in practice, so speed is assumed to be the definition.

Why it is wrong: the defining difference is that a hub repeats every bit to every port, so all ports share one collision domain, while a switch forwards per port.

Minimal counterexample: a two-port hub and a two-port switch can run at the same bit rate; only the switch lets both ports transmit at once.

Correct rule: a switch splits collision domains, not broadcast domains. Both are one broadcast domain unless a VLAN or router intervenes.

Question categories that apply here

Six of the eight standard categories fit this clause. Category D (construction) appears only as "build a codeword", and category H (multi-step) is rare — most items are one computation with one trap. A and B are covered in the Build-up tab; C and G dominate the papers.

C — Calculation: the CRC remainder

Reasoning path: read the generator as a bit pattern, take its degree r, append r zeros, divide by XOR, read the last r bits, append them to the message.

Common wrong approach: appending the wrong number of zeros, or subtracting with borrows instead of XOR.

Check: dividing the codeword must give remainder zero. If it does not, the append was wrong, not the division.

C — Calculation: the vulnerable window

Reasoning path: name the protocol, then name its window — 2T for pure ALOHA, T for slotted, τ for sensing, 2τ for detection — and convert the question's numbers into that window.

Common wrong approach: using 2τ for a protocol that never detects collisions. GATE CSE 2018 Q55 is exactly this trap: sensing only, so one τ.

Check: does the protocol ever learn that a collision happened? If not, no factor of two.

B — Property verification: distance and capability

Reasoning path: compute all pairwise distances, take the minimum, then apply t = ⌊(dmin−1)/2⌋ for correction and s = dmin−1 for detection.

Common wrong approach: computing only the distance between two convenient codewords, or reading dmin as the correction capability.

Check: for k codewords there are k(k−1)/2 distances. Four codewords means six distances, and one of them may be the smallest.

G — Misconception trap: Ethernet statements

Reasoning path: test each statement against the mechanism, not against the vocabulary. "Stops sensing" is false because detection requires sensing during transmission; "jamming pads frames" is false because padding is a separate mechanism.

Common wrong approach: accepting a statement because the words are all real Ethernet words.

Check: every option in GATE CSE 2016 Set 2 Q24 names a real mechanism. Only one names the right purpose.

A — Direct definition: framing rules

Reasoning path: for bit stuffing, find the runs of five ones and delete the zero after each. For byte stuffing, find the escape byte.

Common wrong approach: counting six ones and removing the bit after them.

Check: after destuffing, no run of five ones should still be followed by a zero that was inserted — the result should look like ordinary data.

F — Multiple conditions: which guarantee applies

Reasoning path: a CRC question can ask about single-bit, burst, or odd-weight errors. Each has its own condition — constant term 1 for the first two, x+1 dividing G for the third.

Common wrong approach: answering "all of them" because the generator is "good".

Check: count the ones in the generator. Even means x+1 divides it and the odd-error guarantee holds; odd means it does not.

Practice set — twelve questions

Seven are previous-year items with year and paper named and every answer recomputed by the model on this page. Five are original practice written for this lesson and labelled as such. Answers are hidden until you reveal them.

GATE CSE 2014 Set 3, Q24 Q1 (MCQ, 1 mark)

A bit-stuffing based framing protocol uses an 8-bit delimiter pattern 01111110. If the output bit-string after stuffing is 01111100101, then the input bit-string is:

(A) 0111110100   (B) 0111110101   (C) 0111111101   (D) 0111111111

(B). After the run of five ones the sender inserted one 0. Delete that single bit: 011111 0101.

(A) deletes the wrong bit, turning the trailing 0101 into 0100. (C) deletes nothing and invents a one. (D) treats the stuffed output as if all zeros were data. The model performs the deletion and compares against the stated input.

GATE CSE 2017 Set 1, Q32 Q2 (MCQ, 1 mark)

A computer network uses polynomials over GF(2) for error checking with 8 information bits and generator x3 + x + 1. The message 01011011 is transmitted as:

(A) 01011011010   (B) 01011011011   (C) 01011011101   (D) 01011011100

(C). Generator 1011, degree 3, so append 000 and divide. Remainder 101. Frame = 01011011 · 101 = 01011011101.

(A) and (B) carry a plausible-looking but wrong remainder, which is what a single mis-shifted bring-down produces. (D) has the right length and the wrong bits. The model recomputes the remainder and then divides the codeword again to confirm remainder zero.

GATE CSE 2021 Set 2, Q34 Q3 (MCQ, 1 mark)

CRC with generator X3 + X + 1. Message m4…m0 = 11000. Check bits c2c1c0 are appended. The value of c2c1c0 is:

(A) 000   (B) 010   (C) 100   (D) 110

(C). 11000 with three zeros appended is 11000000. Dividing by 1011 leaves 100.

(A) is what you get by assuming the remainder is always the appended zeros — a common guess. (B) and (D) come from stopping the division one step early. The model computes the remainder and confirms 11000100 divides exactly by 1011.

GATE CSE 2017 Set 2, Q34 Q4 (MCQ, 1 mark)

A binary code has exactly four valid codewords: 00000, 01011, 10101, 11110. Let the minimum Hamming distance be p and the maximum number of erroneous bits that can be corrected be q. Then p and q are:

(A) p = 3, q = 1   (B) p = 3, q = 2   (C) p = 4, q = 1   (D) p = 4, q = 2

(A). The six pairwise distances are 3, 3, 4, 4, 3, 3, so p = 3. Correction is ⌊(3−1)/2⌋ = 1.

(B) reads p as q. (C) and (D) take the largest distance instead of the smallest, which is the other common error. The model computes all six distances.

GATE CSE 2015 Set 3, Q6 Q5 (MCQ, 1 mark)

A CSMA/CD network transmits at 100 Mbps over a 1 km cable with no repeaters. The minimum frame size required is 1250 bytes. The signal speed in the cable, in km/sec, is:

(A) 8000   (B) 10000   (C) 16000   (D) 20000

(D). L = 2dR/v, so v = 2·1·108/104 = 2 × 104 km/s.

(B) drops the factor of two and gives half the answer — the single most common slip on this item. (A) and (C) come from using the frame size in bytes rather than bits. The model solves the equation and then re-derives the frame size from the answer as a check.

GATE CSE 2018, Q55 Q6 (NAT)

Nodes use a carrier-sense protocol: sense for 5 time units, then transmit for 20; no collision detection. Signal speed 10 m per unit time. P starts at t = 0 after sensing; Q has a frame at t = 0 and starts sensing. The maximum distance d, in metres, that lets Q avoid a collision is ______.

50. Q must hear P within its 5-unit window, so d/10 ≤ 5, giving d ≤ 50 m.

The trap is using 2τ: these nodes never detect collisions, so only the one-way delay against the sensing window matters. 250 and 100 both come from adding the 20-unit transmission time into the inequality, which is not what the protocol requires. The model computes the window and the distance.

GATE CSE 2016 Set 2, Q24 Q7 (MCQ, 1 mark)

In an Ethernet local area network, which one of the following statements is TRUE?

(A) A station stops sensing the channel once it starts transmitting. (B) The jamming signal pads frames smaller than the minimum. (C) A station continues to transmit after detecting a collision. (D) Exponential backoff reduces the probability of collision on retransmissions.

(D). The backoff window doubles with each collision, spreading retransmissions apart.

(A) is false: sensing during transmission is precisely how a collision is detected. (B) confuses jamming with padding, which are separate mechanisms. (C) is the opposite of CSMA/CD: the station aborts and jams. The model computes the backoff ranges and confirms the window doubles up to ten collisions.

GATE CSE 2007, Q73 Q8 (MCQ, 2 marks)

The message 11001001 is transmitted using the CRC polynomial x3 + 1 to protect it from errors. The message that should be transmitted is:

(A) 11001001000   (B) 11001001011   (C) 11001010   (D) 110010010011

(B). Generator 1001, degree 3, append 000, divide: remainder 011. Frame = 11001001 · 011.

(A) is the message with the zeros still attached and no division done. (D) appends four bits for a degree-three generator. (C) drops the check bits entirely. The model computes remainder 011 and confirms the codeword divides exactly.

Original practice Q9 (NAT)

A generator polynomial has degree 5 and a non-zero constant term. How many check bits are appended, and what is the longest burst of bit errors that is guaranteed to be detected? Give the burst length as a number of bits.

5 check bits; every burst of length up to 5 is guaranteed detected.

The degree sets both numbers: r bits of remainder, and a guaranteed burst-detection length of r. The constant term is what makes bursts detectable at all — without it, a burst aligned at the end of the word can divide exactly. The model checks this claim exhaustively for r = 3 on both of its generators and finds the length-4 pattern that escapes.

Original practice Q10 (MSQ)

Which of the following are true of the 802.3 frame?

(A) The minimum frame is 64 bytes including the FCS. (B) The preamble is counted in the 64 bytes. (C) A payload shorter than 46 bytes is padded. (D) The FCS is a CRC, not a checksum.

(A), (C) and (D).

(B) is false: the 7-byte preamble and 1-byte start-of-frame delimiter are transmitted but sit outside the frame length the 64-byte minimum refers to. The model adds the fields: 6 + 6 + 2 + 46 + 4 = 64, and 6 + 6 + 2 + 1500 + 4 = 1518.

Original practice Q11 (MCQ)

A slotted ALOHA channel carries an offered load of G = 1. A pure ALOHA channel carries the same load. Which statement is correct?

(A) Both achieve 1/e. (B) Slotted achieves 1/e, pure achieves 1/e2. (C) Slotted achieves 1/e, pure achieves e−2. (D) Pure is better because it needs no synchronisation.

(C). Slotted: G·e−G = 1·e−1 = 1/e ≈ 0.368. Pure: G·e−2G = e−2 ≈ 0.135.

(A) is the peak-versus-load confusion: 1/(2e) is pure ALOHA's peak, at G = 0.5, not at G = 1. (D) is a real advantage but not a throughput one — at equal load slotted is always at least as good, which the model verifies across (0, 1].

Original practice Q12 (NAT)

A CSMA/CD LAN runs at 1 Gbps over a 1 km cable with signal speed 2 × 108 m/s. What is the minimum frame size in bits?

10000 bits. τ = 1000/2 × 108 = 5 µs, so L ≥ 2 × 5 µs × 109 = 104 bits.

That is 1250 bytes — which is why gigabit Ethernet extends the slot rather than shortening the frame, and why the classic 1 Gbps textbook exercise and the 2015 paper share an answer. Dropping the factor of two gives 5000 bits, the most common wrong answer. The model computes both quantities from the same formula.

Revision sheet

One screen: the definitions, the formulas with their conditions, the decision procedures, and the traps with the counterexample that defuses each.

Definitions in one line

Frame — the bounded block the link layer hands down. Framing — the rule that makes boundaries recoverable.

dmin — smallest number of positions in which two codewords differ.

Syndrome — the remainder after dividing a received word by the generator, or the failed-check number in a Hamming code.

Vulnerable period — the interval in which another station's start destroys your frame.

Collision domain — the stations whose transmissions can collide. A hub is one; each switch port is its own.

Formulas, with the condition attached

CRC: append r zeros, divide by G, remainder has r bits. Condition: r is the degree of G.

Guarantees: all single-bit errors and all bursts of length ≤ r, if the constant term is 1. All odd-weight errors iff x+1 divides G, i.e. G has an even number of ones.

Detect s: dmin ≥ s+1. Correct t: dmin ≥ 2t+1, so t = ⌊(dmin−1)/2⌋.

Hamming: smallest r with 2r ≥ m + r + 1; check bits at 1, 2, 4, 8.

ALOHA: Spure = G·e−2G, peak 1/(2e) at G = 0.5. Sslotted = G·e−G, peak 1/e at G = 1.

CSMA/CD: L ≥ 2τR with τ = d/v one way.

Stop-and-wait: U = 1/(1+2a) with a = τ/Tt. Ethernet: min frame 64 B, max 1518 B, overhead 18 B, slot time 512 bit times.

Decision procedures

To compute a CRC: write G as bits, r = len−1, append r zeros, XOR at each leading one, take the last r bits, append to the message, then verify by dividing the whole word.

To find what a code can do: list all codewords, compute all pairwise distances, take the minimum, apply the two inequalities.

To repair a Hamming word: recompute each check group, add the position numbers of the failing groups, flip that position. Zero means no single-bit error.

To choose the window: does the protocol sense? does it detect? Sense only → τ. Detect → 2τ. Slots only → T. Nothing → 2T.

Traps, each with its defusing counterexample

"CRC catches all bursts" — the generator itself is a length r+1 burst that passes.

"dmin = 3 corrects 3" — the four-codeword code corrects one.

"18.4% is the throughput" — at G = 0.05 pure ALOHA gives 4.5%.

"2-D parity catches four errors" — the rectangle of four is invisible.

"Checksum catches corruption" — a +1/−1 pair passes.

"The 2 is two stations" — it is the round trip, and it survives with one station.

Six questions to test yourself, answers below

1. Generator 1011, message 1101: what is the remainder?   2. A code has dmin = 4: how many errors can it detect and correct?   3. Pure ALOHA at G = 0.25: what is the throughput?   4. Why does the minimum frame size double when the rate doubles?   5. Which single condition makes a CRC catch every odd-weight error?   6. A frame arrives with syndrome 0 in a Hamming code: is it certainly correct?

Answers. 1. 1101 with 000 appended is 1101000; dividing by 1011 leaves 001.   2. Detects 3, corrects 1.   3. 0.25·e−0.5 ≈ 0.1516.   4. Because L ≥ 2τR: the same round trip at twice the rate needs twice as many bits.   5. x+1 must divide G, equivalently G has an even number of ones.   6. No — syndrome 0 rules out a single-bit error, not a two-bit error that mimics a valid codeword.
