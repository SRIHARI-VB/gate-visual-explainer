Topic and objective

TOPIC: The first clause of Section 10 of the official GATE 2027 CS syllabus — principles of layering, the three switching designs (circuit, packet, virtual circuit), and performance metrics. Layering is taught as the mechanism that makes the other two teachable: a message grows a header at each layer down and loses one at each layer up, and the arithmetic of a network is the arithmetic of what each header and each hop costs.

LEARNING OBJECTIVE: Name the layer that owns any given job and the unit of data it carries; explain why the link-layer header is rewritten at every router while the network-layer header is not; distinguish circuit, datagram and virtual-circuit switching by what is set up and what is reserved; and compute end-to-end delay, throughput and bandwidth-delay product for one packet, for many packets, and for a circuit, from the question's own numbers.

I read this topic as one arithmetic, asked three ways. Whatever the question, you name the links, name the packet size, name what each hop costs, and add. Circuit switching adds a setup and no per-hop packet time; one packet adds one transmission term per link; many packets add the same total minus the overlap. The lesson builds that single sum and then reuses it.

The five ideas this lesson turns on

  1. A layer is a promise, not a wire. Layer n talks to layer n only in the header it writes. The bits always travel down and up.
  2. Headers are per hop or per journey. Link-layer headers are rewritten at every router; the network-layer header survives to the far end. That single fact decides which address means what.
  3. Transmission delay is L/R, propagation delay is d/v. The packet size changes the first and never the second. This is the confusion the chapter is built on.
  4. Store-and-forward pays one transmission time per link. Many packets overlap those payments, so P packets over N links cost N + P − 1 transmission times, not N × P.
  5. Circuits buy a guarantee with a setup. A circuit costs setup + F/R; packets cost F/R + (N − 1)·L/R. The circuit wins exactly when the setup is the smaller of the two.

Build-up, page 1 of 2 — layers, headers, and the one hop that is not like the others

Levels 1 to 4: the analogy, the definitions, the structure, and the first worked decision. Nothing here needs the animation to be running.

Intuition: the letter with four envelopes

You write a letter. You put it in an envelope addressed to a person in a building. You put that envelope in a sack labelled for a sorting office. You put the sack in a lorry booked to a city. Each wrapper answers a different question, and each is opened by a different person.

The person in the building never sees the lorry label. The sorting office never reads the letter. That is the whole of layering: each wrapper is addressed to exactly one reader, and that reader ignores everything inside.

Educational interpretation The analogy carries the mechanism — one wrapper per reader, opened in order — and not the terminology. What makes the analogy exact is that the lorry label is replaced at every depot while the envelope inside keeps the same name on it.

Formal definition: layer, service, protocol, PDU

A layer is a set of functions that solves one class of problem. A layer offers a service to the layer above it — a promise about what the data will look like on arrival — and uses the service of the layer below.

A protocol is the agreement between two peer layers on the same level, and it is realised entirely in the header that layer writes. The unit of data a layer hands down is its PDU: message, segment, packet, frame, bit.

headern + (everything above) = the PDU of layer nThe layer below never parses what it carries. It reads its own header, and treats the rest as an opaque block of bytes.

Verified fact The five-layer Internet stack used here — application, transport, network, link, physical — is the presentation in the standard networking texts (Kurose and Ross; Tanenbaum and Wetherall). OSI names seven by splitting the application layer three ways and keeping the physical and link layers apart.

What each layer is allowed to know

Application — the conversation. HTTP, DNS, mail. Knows about documents and names, nothing about wires.

Transport — end to end, process to process. Knows about ports and about reliability. Runs only in the two end hosts.

Network — host to host across many networks. Knows about addresses and routes. This is the highest layer a router implements.

Link — one hop on one wire. Knows about frames and hardware addresses. Rewritten at every router.

Physical — bits as signals. Knows about voltages, wavelengths and pins, and nothing about meaning.

The consequence that earns the marks

Because the link layer is scoped to one hop and the network layer to the whole journey, a router must decapsulate to the network layer: strip the old link header, read the destination address in the network header, choose a next hop, and write a new link header for that hop.

So the link-layer destination address on the last hop names the previous router, not the original sender. The network-layer destination address is the only one that stays constant from end to end.

Mathematical derivation A header written by a layer that runs in k devices must be rewritten k − 1 times. The link layer runs in every router on the path, so it is rewritten at every hop. The network layer runs in the two hosts and is only read by routers, so it is never rewritten.

Build-up, page 2 of 2 — switching, and the arithmetic of a hop

Levels 5 to 7: the boundaries, the edge cases, and the arithmetic that GATE actually asks for. Every number below is computed by the model on this page.

Circuit switching: three phases and a reservation

Setup. A setup message walks the path and every switch reserves a fixed slice of capacity. If one link cannot spare it, the call is refused.

Data. Bits stream straight through the reserved slice. No switch stores a whole packet, so no switch pays a per-packet transmission delay.

Teardown. The reservation is released.

Cost: T = S + F/R + Σdi/v where S is the setup time and F the total bits. The reservation buys a constant rate and no contention, and charges for silence.

Packet switching: datagram against virtual circuit

Datagram. No setup. Every packet carries a full destination address and is routed independently. Two packets of one message may take different paths and arrive out of order.

Virtual circuit. A label is established once, in every switch along the path. Every packet of the flow carries the short label and follows the same path, in order. But no capacity is reserved, so a virtual circuit can still queue and still lose packets.

Verified fact Both designs are packet-switched, and the distinction is exactly the one above: per-packet routing state against per-flow routing state. This is the standard treatment in the networking texts and in the syllabus's own three-way wording.

The four delays, precisely

Transmission delay Tt = L/R. L is the packet size in bits, R the link rate in bits per second. It is the time to push every bit of the packet onto the wire.

Propagation delay Tp = d/v. d is the link length in metres, v the propagation speed in the medium. It is the time for one bit to cross the wire.

Processing delay — reading the header and choosing an output port.

Queuing delay — waiting in the output buffer behind other packets. Unless the question gives them, processing and queuing are taken as zero, and the lesson says so each time it does it.

The three totals you will be asked for

one packet: Σ(L/Ri) + Σ(di/v)One transmission term and one propagation term per link. With unequal links, sum link by link; there is no single "the" rate.
P packets, N equal links: (N + P − 1)·L/R + N·d/vThe first packet pays every link; each of the remaining P − 1 pays exactly one transmission time, because the pipeline is already full.
throughput = min Ri  ·  bits in flight = R × TpBits cannot arrive faster than the narrowest link can carry them, and the bandwidth-delay product says how much data must be outstanding to keep even that rate busy.

Mathematical derivation The second formula is not a convention: the model on this page simulates every packet on every link, event by event, and the checks below confirm the simulation equals the closed form on five equal-link configurations.

Boundaries — when these formulas do not apply

The pipelined formula assumes store-and-forward at every node, packets of equal size sent back to back, and no queuing beyond waiting behind earlier packets. Cut-through switching forwards after reading the header only, and breaks the per-hop transmission term entirely.

The throughput minimum assumes links in series and no other traffic. With a shared bottleneck, throughput becomes the minimum of each flow's share on every link it crosses.

The bandwidth-delay product uses the one-way propagation delay. R × RTT gives the bits in flight over a whole round trip, which is a different number and answers a different question.

Worked examples, page 1 of 2 — two previous-year items, worked line by line

Every answer below was recomputed by the model on this page, not copied from a key. The Animation tab draws the same arithmetic in scenes 7 and 8.

Example 1 — GATE CSE 2022, Q59

A 100 Mbps link between an earth station and a satellite at 2100 km. Signal speed 3 × 108 m/s. Time for the receiver to completely receive a 1000-byte packet, in milliseconds.

Step 1, units. 1000 bytes = 8000 bits. 100 Mbps = 108 bits/s. 2100 km = 2.1 × 106 m. One link.

Step 2, transmission. Tt = 8000 / 108 = 8 × 10−5 s = 0.08 ms.

Step 3, propagation. Tp = 2.1 × 106 / 3 × 108 = 7 × 10−3 s = 7 ms.

Step 4, add. 0.08 + 7 = 7.08 ms. Propagation is 87.5 times the transmission delay, which is the sanity check: on a satellite link, distance is the whole cost.

Example 2 — GATE CSE 2012, Q44

A 106-bit file sent from S to D over two routers and three links. Each link 100 km, signal at 108 m/s, each link 1 Mbps. The file is broken into 1000 packets of 1000 bits. Total transmission plus propagation delay.

Step 1, per link per packet. Tt = 1000 / 106 = 1 ms. Tp = 105 / 108 = 1 ms. Three links, 1000 packets.

Step 2, the transmission terms. N + P − 1 = 3 + 1000 − 1 = 1002, so 1002 ms.

Step 3, the propagation terms. One per link, regardless of how many packets: 3 × 1 = 3 ms.

Step 4, add. 1002 + 3 = 1005 ms. The tempting wrong answer is 3 × 1000 + 3 = 3003 ms, which multiplies the transmission by the link count for every packet and forgets that the links overlap.

Worked examples, page 2 of 2 — the two items that punish a remembered formula

Example 3 — GATE 2024 CS1, Q36

Path P—Q—R. P sends 106 bytes split into chunks of 103 bytes, back to back. Both links 106 bits/s, propagation and processing negligible. Q can receive and transmit simultaneously. When does R have the whole file?

Step 1. 106 / 103 = 1000 chunks, each 8000 bits. Per link per chunk: 8000 / 106 = 0.008 s.

Step 2, the first link alone. The last chunk finishes arriving at Q at 1000 × 0.008 = 8.000 s.

Step 3, the second link. Q has been forwarding throughout, so link Q—R is free the instant each chunk arrives. The last chunk needs one more 0.008 s.

Step 4. 8.000 + 0.008 = 8.008 s. The formula gives the same thing: (2 + 1000 − 1) × 0.008 = 8.008. The option 16.000 s is the answer to a question where Q waited for the entire file before forwarding anything.

Example 4 — GATE CSE 2014 Set 2

A 103-byte file from A to B over two routers, three links of 106 bytes/s. Each packet carries 100 bytes of header. The file is sent whole, then in 10 parts, then in 20 parts. Transmission time only. Order T1, T2, T3.

Case 1, one packet. 1000 + 100 = 1100 bytes. (3 + 1 − 1) × 1100 = 3300 µs.

Case 2, ten packets. 100 + 100 = 200 bytes each. (3 + 10 − 1) × 200 = 12 × 200 = 2400 µs.

Case 3, twenty packets. 50 + 100 = 150 bytes each. (3 + 20 − 1) × 150 = 22 × 150 = 3300 µs.

So T1 = T3 and T3 > T2. Splitting helps until the repeated headers outweigh the extra pipelining, and here the finest split has returned to exactly the cost of sending the file whole.

Example 5 — original worked example: circuit against packet

Original example 640 kbit to send over three links of 64 kbps. Circuit setup is 0.5 s. Packet switching uses 1 kbit packets with no setup. Propagation negligible. Which is faster, and by how much?

Circuit. 0.5 + 640000/64000 = 0.5 + 10 = 10.5 s.

Packet. P = 640 packets, N = 3, so (3 + 640 − 1) × (1000/64000) = 642 × 0.015625 = 10.031 s.

The crossover. Packet switching costs (N − 1)·L/R = 2 × 0.015625 = 0.03125 s more in overhead than a circuit's data phase. So the circuit wins iff S < 0.03125 s. Here S = 0.5 s, far above it, so packets win by about 0.47 s.

This is the point of the inequality: neither design is faster in general. A 5 ms setup on the same path would reverse the answer.

Example 6 — a path of three unequal links

Reported previous-year item A 4-million-byte file crosses links of 2 Mbps, 500 kbps and 1 Mbps. Processing, propagation and headers negligible. Total time?

Step 1, bits. 4 × 106 bytes = 32 × 106 bits.

Step 2, the bottleneck. min(2 Mbps, 500 kbps, 1 Mbps) = 500 kbps. Bits cannot arrive faster than the narrowest link carries them.

Step 3. 32 × 106 / 5 × 105 = 64 s.

This item is reproduced from one question archive that names it as GATE 2026 CS2, Q21, and offers 731, 64, 8 and 16 as the options. The arithmetic above is mine and matches one of those options, but I did not check it against the paper itself, so treat the attribution as a single source rather than a verified fact.

Edge cases, boundary cases and one genuine counterexample

These are the cases where the formula is right but the question is not the one you assumed.

Counterexample: more bandwidth does not mean less delay

Take the GATE 2022 satellite link: 8000 bits, 2100 km, 100 Mbps. Total 7.08 ms. Now raise the rate to 10 Gbps — a hundredfold increase.

Transmission delay falls from 0.08 ms to 0.0008 ms. Propagation delay stays at exactly 7 ms. The total falls from 7.08 ms to 7.0008 ms, a change of about one percent.

So "buy more bandwidth to make it faster" is false as a general claim. It is true only when the transmission term dominates, which happens on slow links or with very large packets, and not on long fast ones.

Counterexample: more packets is not monotonically better

The GATE CSE 2014 Set 2 item is a clean counterexample to "split the file finer and it goes faster". Splitting once (1 packet) costs 3300 µs; ten ways costs 2400 µs; twenty ways costs 3300 µs again.

Two effects pull in opposite directions. More packets means more pipelining, which helps. More packets means more headers, which hurts, and the header cost is linear in the number of packets while the pipelining gain saturates at N − 1 extra packet times.

Once the split is fine enough that (N − 1)·L/R is no longer the limiting term, every extra packet is pure overhead.

Boundary: one link, N = 1

With one link the pipelined formula collapses to (1 + P − 1)·L/R + Tp = P·L/R + Tp, which is exactly right: with no store-and-forward in between, there is nothing to overlap and the transmission times simply add.

This is the check that catches the error of subtracting one from the packet count instead of from the total. On one link, P − 1 would give an answer that is one packet time too small.

Boundary: propagation speed is given, never assumed

Questions supply v, and the supplied value is not always 3 × 108 m/s. Copper and fibre are commonly given as 2 × 108, and one recent item gave 5 nanoseconds per metre, which is 2 × 108 m/s expressed as a rate per unit length.

Assuming the speed of light in vacuum is a silent 33 percent error. Read v off the question every time.

Boundary: "completely receive" and "first bit arrives"

The GATE 2022 item asks when the receiver has completely received the packet, which is transmission plus propagation. A question that asked when the first bit arrives would want only the propagation delay.

On a store-and-forward path the difference compounds: the last bit of the last packet finishes a full transmission time after the first bit of it arrives.

Boundary: a switch that forwards before it finishes receiving

Store-and-forward is an assumption, not a law. A cut-through switch reads only the destination address at the front of the frame and begins forwarding immediately, so it does not pay a full transmission time per hop.

Every GATE item I checked states or implies store-and-forward. When a question is silent, say which you assumed — the two answers differ, and the assumption is worth stating in one line.

Boundary: unequal links break the closed form

(N + P − 1)·L/R assumes every link has the same rate. With unequal links there is no single R, and the answer depends on how the packets queue behind each other at each rate change.

The model on this page therefore simulates each packet on each link rather than using the closed form, and the closed form is checked against that simulation only for equal links, where it is valid.

Boundary: units, which is where most marks go

Rates use powers of ten: 1 Mbps = 106 bits/s. Sizes may use either convention, and the question tells you. 1 KB may be 1000 or 1024 bytes; a rate of 1 kbps is always 1000 bits/s even when sizes in the same question use 1024.

Convert everything to bits and seconds before dividing, then convert back to the unit the question asked for. The 2012 item is in milliseconds; the 2024 item is in seconds; the 2014 item is in microseconds.

Ten things that are commonly believed and are not true

Each entry names the belief, the correction, and the smallest case that shows the difference.

1. "Higher bandwidth means lower latency."

Correction. Bandwidth changes the transmission delay L/R and nothing else. Propagation delay d/v is set by distance and medium.

Smallest case. A 1000-byte packet over a 2100 km satellite link: at 100 Mbps the total is 7.08 ms; at 10 Gbps it is 7.0008 ms.

2. "Propagation delay depends on the packet size."

Correction. Propagation delay is the time for one bit to cross the wire. A bigger packet takes longer to push onto the wire, not longer to travel along it.

Smallest case. Doubling L doubles Tt and leaves Tp unchanged — checked in the model on this page.

3. "A switch waits for the whole file."

Correction. A store-and-forward switch waits for one packet, then forwards it while the next is still arriving. That overlap is the whole of the pipelining arithmetic.

Smallest case. GATE 2024 CS1: 1000 chunks over two links take 8.008 s, not 16 s.

4. "Layer n on the sender talks directly to layer n on the receiver."

Correction. The conversation is logical. It exists only in the header layer n writes; the bits travel down the sender's stack, across the wire, and up the receiver's.

Smallest case. A transport header written once by the sender and read once by the receiver, while passing through every router unread.

5. "The Internet runs OSI."

Correction. OSI is a reference model. The deployed protocols follow the Internet stack, which merges OSI's application, presentation and session into one application layer.

Smallest case. There is no presentation-layer header on an HTTP request. HTTP does its own character encoding and its own TLS handshake sits between application and transport.

6. "A virtual circuit reserves bandwidth like a circuit."

Correction. A virtual circuit sets up state, not capacity. It shares the circuit's setup phase and the datagram network's contention.

Smallest case. An ATM or frame-relay virtual circuit can still queue and still lose cells when the path is congested.

7. "Throughput equals bandwidth."

Correction. Bandwidth is a link's capacity. Throughput is the rate actually delivered, capped by the slowest link on the path and by the sender's window.

Smallest case. Links of 2 Mbps, 500 kbps and 1 Mbps in series deliver 500 kbps, not 1.17 Mbps.

8. "Transmission delay is paid once for the journey."

Correction. Store-and-forward pays it once per link, per packet. With three links and one packet, that is three transmission delays.

Smallest case. One packet over three links: 3·L/R, not L/R.

9. "P packets over N links cost N × P transmission times."

Correction. They cost N + P − 1, because after the first packet the pipeline is full and each later packet finishes one transmission time after the previous one.

Smallest case. GATE CSE 2012: 1002 terms, not 3000. The difference is 2000 ms on a five-mark question.

10. "The link-layer destination is the final destination."

Correction. The link-layer destination names the next hop only, and is rewritten at every router. Only the network-layer address survives end to end.

Smallest case. On the last hop, the link-layer destination is the destination host; on every earlier hop it is a router.

How this topic is actually asked, and what each shape demands

Four question shapes cover every item I checked. The pattern to notice is that the numbers change and the structure does not.

Shape 1 — one packet, given link parameters

The question gives L, R, d, v and the number of links, and asks for the delay to deliver one packet. Sum one transmission and one propagation term per link.

What it tests. Whether you know that transmission is paid per hop and that the two delays have different inputs.

Example seen. GATE CSE 2022 Q59, one link, answer 7.08 ms. The item is easy arithmetic on top of a distinction people get wrong.

Shape 2 — many packets, asked as a total time

A file is split into P packets over N store-and-forward links. Use (N + P − 1)·L/R + N·Tp, and be careful whether headers are included in L.

What it tests. The overlap. The wrong options are almost always N·P·L/R and P·L/R.

Examples seen. GATE CSE 2012 Q44 (1005 ms) and GATE 2024 CS1 Q36 (8.008 s).

Shape 3 — a comparison or an ordering

Compute two or three configurations and put them in order, or decide which of four statements is true. No single number is the answer.

What it tests. Whether you can carry two competing effects at once — pipelining against header overhead.

Example seen. GATE CSE 2014 Set 2, where T1 = T3 and T3 > T2. The equality is the trap: it looks like a mistake in your arithmetic.

Shape 4 — a conceptual MCQ or MSQ with no numbers

Which layer owns a job, which device reads which header, which of these statements about switching is true. These are the layering marks, and they are cheap if the stack is solid.

What it tests. The scope of each layer: end to end against hop by hop.

Example seen. Several items in the archive ask which device may need to broadcast, or which layer a function belongs to; I did not pin those to a year and a paper, so they are not reproduced here as previous-year items.

The three traps that account for most lost marks

Multiplying instead of pipelining. N·P·L/R instead of (N + P − 1)·L/R. On the 2012 item this is the difference between 1005 and 3003 ms.

Forgetting the header in the packet size. On the 2014 item, using 100 bytes instead of 200 for the ten-way split gives 1200 µs and reverses the ordering.

Dropping propagation when it dominates. On the 2022 item, propagation is 87.5 times the transmission delay; omitting it gives 0.08 ms instead of 7.08 ms.

The decision procedure, in one place

  1. Write L, R, d, v, P and N in consistent units — bits, bits/s, metres, m/s.
  2. Ask: one packet, many packets, or a circuit?
  3. Read which delays the question says to ignore, and drop only those.
  4. Compute the dominant term first and estimate the answer's magnitude.
  5. Convert back to the unit asked for, and compare with the options.

Step 4 is the one people skip. Estimating 7 ms before computing 7.08 ms tells you immediately that an answer of 0.08 ms is wrong, and on a multiple-choice paper that is often enough on its own.

Practice set — twelve questions

Five are previous-year items with their year and paper named; seven are original practice written for this lesson and labelled as such. Answers are hidden until you reveal them, and each solution states why the wrong options are wrong.

Original practice Q1 (MCQ)

Which layer is the highest layer that a router must implement?

(A) Transport (B) Network (C) Data link (D) Application

(B). A router reads the destination address in the network header to choose a next hop, so it must implement the network layer. It does not need anything above it.

(A) is the tempting one, because people think of "the Internet layer" as the top of the stack. A transport header is read only in the two end hosts. (C) is a layer the router certainly implements, but not the highest. (D) is implemented only by hosts.

Original practice Q2 (MSQ)

A packet of L bits crosses one link of rate R and length d at propagation speed v. Which statements are true?

(A) Doubling L doubles the transmission delay. (B) Doubling L doubles the propagation delay. (C) Doubling R halves the transmission delay. (D) Doubling d doubles the propagation delay.

(A), (C) and (D). Tt = L/R is linear in L and inversely linear in R. Tp = d/v is linear in d.

(B) is the misconception this whole lesson is aimed at: Tp does not contain L at all, so no change to the packet size can affect it. The model on this page checks all four relations directly.

GATE CSE 2022, Q59 Q3 (NAT, 2 marks)

A 100 Mbps link between an earth station and a satellite at 2100 km. Signal speed 3 × 108 m/s. The time for the receiver to completely receive a 1000-byte packet, in milliseconds (two decimal places), is ______.

7.08. Transmission 8000/108 = 0.08 ms; propagation 2.1 × 106/3 × 108 = 7 ms; total 7.08 ms.

0.08 is the answer if you compute only transmission delay. 7 is the answer if you drop the transmission term as negligible — closer, but not the accepted value. The model on this page recomputes 7.08 independently.

GATE CSE 2012, Q44 Q4 (NAT)

A 106-bit file from S to D over two routers and three 100 km links at 1 Mbps, signal at 108 m/s, split into 1000 packets of 1000 bits. Total transmission plus propagation delay, in ms, is ______.

1005. (3 + 1000 − 1) × 1 ms of transmission, plus 3 × 1 ms of propagation.

3003 is N·P·L/R plus propagation, which forgets the overlap. 1004 subtracts one from the packet count instead of the total, which is right only for N = 2 by accident. 2003 comes from adding only the propagation of one link.

GATE 2024 CS1, Q36 Q5 (MCQ, 2 marks)

P sends 106 bytes to R via router Q, in chunks of 103 bytes sent back to back. Both links 106 bits/s, propagation, processing and queuing negligible. Q forwards each chunk immediately and can receive and transmit at the same time. When does R have the whole file?

(A) 8.000 s   (B) 8.008 s   (C) 15.992 s   (D) 16.000 s

(B). 1000 chunks of 8000 bits at 106 bits/s: 8 ms each. (2 + 1000 − 1) × 8 ms = 8.008 s.

(A) forgets that the second link adds one chunk time. (D) assumes Q buffers the whole file before forwarding, giving 8 + 8 s. (C) subtracts the final chunk time instead of adding it, which is the same error as (A) with the wrong sign.

GATE CSE 2014 Set 2 Q6 (MCQ, 2 marks)

A 103-byte file from A to B over two routers and three links of 106 bytes/s, each packet carrying 100 bytes of header. The file is sent whole, then in 10 parts, then in 20 parts; times are T1, T2, T3. Transmission time only. Which is correct?

(A) T1 < T2 < T3   (B) T1 > T2 > T3   (C) T2 = T3, T3 < T1   (D) T1 = T3, T3 > T2

(D). 3 × 1100 = 3300; 12 × 200 = 2400; 22 × 150 = 3300 microseconds.

(A) and (B) both assume the ordering is monotone in the number of packets. (C) is the right shape with the wrong comparison: T2 and T3 differ by 900 µs. The equality T1 = T3 is exact, not approximate, which is what makes the item disconcerting.

Original practice Q7 (NAT)

A 100 Mbps link has a one-way propagation delay of 5 ms. How many kilobits can be in flight on the link in one direction at one instant when it is completely full?

500. Bandwidth-delay product = 108 × 0.005 = 5 × 105 bits = 500 kbit.

1000 comes from using the round-trip time (10 ms) instead of the one-way delay. 50 comes from treating 5 ms as 0.0005 s. The one-way convention is what "in one direction" fixes.

Original practice Q8 (MCQ)

Which of these is a genuine difference between circuit switching and a virtual circuit?

(A) A circuit sets up state before data flows; a virtual circuit does not. (B) A circuit reserves capacity on every link; a virtual circuit does not. (C) A circuit carries data in packets; a virtual circuit carries bits. (D) A circuit can lose data; a virtual circuit cannot.

(B). The reservation of a fixed slice is what makes a circuit a circuit. A virtual circuit sets up state and a label, but reserves nothing, so it can still queue and still lose packets.

(A) is false: both set up state, which is why the two are so easily confused. (C) reverses the truth — a circuit carries a bit stream, a virtual circuit carries packets. (D) reverses it again: a circuit does not lose data, a virtual circuit can.

Original practice Q9 (MSQ)

A message from host A to host B crosses two routers. Which headers are rewritten on the way?

(A) The transport header (B) The network header (C) The link header (D) None of them

(C) only. The link header is scoped to one hop and is rewritten at every router; the network and transport headers are written once by the sender and read once by the receiver.

(A) is wrong for a reason worth stating: a router never looks inside a transport header, so it could not rewrite one. (B) is the most tempting, because the network header's time-to-live field is decremented at each router — but decrementing a field is not re-encapsulation, and the addresses in it are unchanged.

Original practice Q10 (NAT)

Three links in series run at 2 Mbps, 500 kbps and 1 Mbps. Propagation, processing and headers are negligible. How many seconds does a 4-million-byte file take?

64. 4 × 106 bytes = 32 × 106 bits. The bottleneck is 500 kbps, so 32 × 106 / 5 × 105 = 64 s.

16 comes from dividing by 2 Mbps, the fastest link. 8 comes from dividing 4 million by 500 000 and forgetting the factor of eight between bytes and bits. 731 comes from adding the three links' times as if they did not overlap in the wrong direction — a deliberate distractor in the archive's option list.

Original practice Q11 (MCQ)

A 640 kbit transfer over three links of 64 kbps. Packet switching uses 1 kbit packets with no setup; a circuit needs a 0.5 s setup. Propagation is negligible. Which is faster?

(A) The circuit, by about 0.47 s (B) Packet switching, by about 0.47 s (C) They are equal (D) The circuit, by about 0.03 s

(B). Circuit: 0.5 + 10 = 10.5 s. Packet: (3 + 640 − 1) × 0.015625 = 10.031 s. Packets win by 0.469 s.

(A) has the right magnitude and the wrong sign — a plausible outcome, since the setup is 16 times the overhead. (D) confuses the crossover setup time, 0.03125 s, with the difference in totals. (C) would need the setup to equal 0.03125 s exactly.

Original practice Q12 (MCQ)

A 1-bit message is sent over a 2100 km link at 3 × 108 m/s, first at 100 Mbps and then at 10 Gbps. What happens to the end-to-end delay?

(A) It falls by a factor of about 100 (B) It falls by a factor of about 2 (C) It is essentially unchanged (D) It rises, because the higher rate means shorter bits

(C). Propagation is 7 ms and the transmission delay is 10−8 s at 100 Mbps and 10−10 s at 10 Gbps. Both are invisible next to 7 ms.

(A) is the belief this lesson exists to correct: it is true of the transmission term alone, which is not the total. (B) is right for a large packet on a short fast link, not for this one. (D) invents a mechanism — the physical length of a bit on the wire does change with rate, but that does not change the propagation delay of the signal.

Revision sheet — everything this lesson asks you to carry

Definitions, formulas, the decision procedure, the traps, and the counterexamples. Read this in the last week, not the first.

Formulas

Transmission delay Tt = L / R, bits over bits per second.

Propagation delay Tp = d / v, metres over metres per second.

One packet over N links Σ(L/Ri) + Σ(di/v).

P packets over N equal links (N + P − 1)·L/R + N·d/v.

Circuit S + F/R + Σdi/v.

Crossover circuit beats packet iff S < (N − 1)·L/R.

Throughput min Ri over the path.

Bandwidth-delay product R × Tp, bits in flight one way.

The stack, in one column

Application — message. HTTP, DNS. End to end.

Transport — segment. Ports. End to end, processes.

Network — packet. IP addresses. Host to host; routers stop here.

Link — frame. Hardware addresses. One hop; rewritten at every router.

Physical — bit. Signals. One hop.

The three switching designs side by side

Circuit — setup reserves capacity; data streams through; no store-and-forward; constant rate; wastes idle capacity.

Datagram — no setup; every packet routed independently; may reorder; shares capacity.

Virtual circuit — setup establishes a label and per-flow state; all packets follow one path in order; no capacity reserved; shares capacity.

Traps, in the order they cost marks

1. N·P·L/R instead of (N + P − 1)·L/R.

2. Forgetting the header when the question adds one.

3. Omitting propagation on a long link, or transmission on a slow one.

4. Using RTT where the question said one way, or one way where it said round trip.

5. Assuming the speed of light when v was given.

6. Reporting the answer in the wrong unit — ms, µs and s all appear in the items in this lesson.

Counterexamples worth remembering

Bandwidth is not latency. 100 Mbps to 10 Gbps on a satellite link moves 7.08 ms to 7.0008 ms.

More packets is not better. GATE CSE 2014 Set 2: 3300, 2400, 3300 µs for 1, 10 and 20 packets.

A virtual circuit is not a circuit. It sets up state, not capacity, and it can still lose packets.

Four lines to say out loud before the exam

Transmission is L/R and depends on the packet; propagation is d/v and depends on the wire.

Store-and-forward pays transmission once per link; many packets overlap, so the count is N + P − 1.

A circuit trades a setup for no per-hop packet time; the crossover is S against (N − 1)·L/R.

Throughput is the slowest link; the bandwidth-delay product is what it takes to fill it.

Where this research stopped

Four previous-year items were checked against published reproductions and every answer was recomputed by the model on this page; none was checked against an original paper PDF, and one item rests on a single archive. Items I could not pin to a year and a paper are not reproduced here as previous-year items — that is why the layering questions in the practice set are labelled original even where a similar item certainly exists.
