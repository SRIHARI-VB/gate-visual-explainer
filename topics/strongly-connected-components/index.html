Topic and objective

TOPIC: Strongly connected components — the classes of mutual reachability in a directed graph, the two-pass algorithm that finds them, the one-pass algorithm that finds them faster to write, the condensation DAG that survives the analysis, and the edge count that makes a graph strongly connected.

LEARNING OBJECTIVE: Given a directed graph, find its components by the definition, by Kosaraju’s two passes and by Tarjan’s low-link pass, and say why all three return the same partition. Read the discovery and finish times of one depth-first search and use the finishing order as a topological order of the condensation. Contract the components and check that the result is acyclic. State the Eswaran–Tarjan count of edges needed to make the graph strongly connected, with the isolated-component term that the usual shortcut drops.

GATE RELEVANCE: Class B — Section 5 of the syllabus names “Graph traversals, minimum spanning trees, shortest paths”. The phrase “strongly connected component” is not in the syllabus; it is the standard harder use of a depth-first traversal, which is the named item. The lesson says this on the page rather than implying the words are syllabus wording.

PREREQUISITES: what a directed graph, a path and reachability are; how depth-first search runs and what a search tree is (Graph traversals); the idea of an equivalence relation and its classes (Relations); what a topological order of a DAG is (Counting linear extensions). No probability, no calculus.

Prerequisites, precisely

Must already be comfortable with:

  • A path is a sequence of edges; its length is the number of edges, and a path of length zero is allowed.
  • Depth-first search: it goes as deep as it can, then backs up, and the edges it uses form a forest.
  • An equivalence relation splits a set into disjoint classes. Mutual reachability is one.
  • A topological order is a linear order in which every edge points forward, and only a DAG has one.

Helpful, not required: having seen a graph searched by hand with timestamps, since the whole of pass one is that.

Approximate learning time: 40–55 minutes with the animation, or 10 minutes for the Revision tab alone. The figure is an estimate, not a measurement.

The five ideas

  1. A component is a set, not an edge. Every pair inside it reaches the other, both ways; between components the traffic runs one way.
  2. The components are a partition. They are the classes of mutual reachability, so they are disjoint and cover every vertex — including every isolated vertex.
  3. The finishing order is the condensation, in order. If component X has an edge into Y, X finishes last after Y does, so decreasing finish time is a topological order of the contracted graph.
  4. Both details of pass two are load-bearing. The reversed graph and the decreasing order. Two vertices and one edge refute each of them when it is got wrong.
  5. The condensation is where the questions live. It is always acyclic, and the counts — components, source and sink components, edges to add — are read off it.

Intuition: a city of one-way streets

A directed graph is a city where every street runs one way. Ask whether you can drive from the station to the market: a single trip, and a breadth-first search answers it.

Now ask a harder question. If you drive to the market, can you drive home again? The return trip is not implied by the outbound one, and it is not a property of any single street. It is a property of the pair of places.

Group the places so that within a group every pair can make both trips. Those groups are the strongly connected components. Between two groups, if any street crosses, the traffic runs one way only — otherwise the two groups could reach each other and would have been one group.

Educational interpretation The city is exact about direction and silent about cost. In an exam the streets may be weighted, and weights change nothing here: reachability ignores them, which is why every algorithm in this lesson is linear and none of them is a shortest-path algorithm.

Formal definition

Let $$G = (V, E)$$ be a directed graph. Write $$u \leadsto v$$ when there is a directed path from $$u$$ to $$v$$, counting a path of length zero, so that $$u \leadsto u$$ always. Define

$$u \sim v \iff (u \leadsto v \text{ and } v \leadsto u)$$

Read: $$u$$ is related to $$v$$ exactly when each of them can reach the other. This is a relation on the vertex set $$V$$.

A strongly connected component is a class of this relation: a maximal set $$C \subseteq V$$ such that $$u \sim v$$ for every pair $$u, v \in C$$.

The condensation $$G^{\text{SCC}}$$ is the graph whose vertices are the components of $$G$$, with an edge from component $$X$$ to component $$Y$$ when some edge of $$G$$ runs from a vertex of $$X$$ to a vertex of $$Y$$.

Verified fact The definitions are the standard ones; the textbook reference is the chapter on elementary graph algorithms. Every consequence below is then recomputed in code, so no number depends on a source being read correctly.

Derivation 1 — the relation is an equivalence relation

Reflexive. $$u \leadsto u$$ by the path of length zero, so $$u \sim u$$.

Symmetric. The definition asks for both directions at once, so it cannot hold one way and not the other.

Transitive. If $$u \leadsto v$$ and $$v \leadsto w$$, follow the first path and then the second to get $$u \leadsto w$$; the return paths join in the other order.

An equivalence relation on a finite set always splits the set into disjoint non-empty classes, and the classes are exactly the components. So the components are a partition, and the number of components is a partition count.

Derivation The page checks the consequence rather than the proof: on every directed graph with up to four vertices, the components it computes are pairwise disjoint and cover every vertex, because they are compared with the partition produced by the slow definition.

Derivation 2 — the finishing-order lemma

Run a depth-first search of $$G$$ and give each vertex a discovery time $$d$$ and a finish time $$f$$, both from one counter. Then:

$$\text{if } X \to Y \text{ in the condensation, then } \max_{v \in X} f(v) > \max_{w \in Y} f(w)$$

Read: a component that has an edge into another finishes later, comparing the last vertex of each.

Case one: the search enters $$X$$ first. From $$X$$ it can reach $$Y$$ through the edge, so every vertex of $$Y$$ is discovered inside that search and finishes before the vertex of $$X$$ that started it.

Case two: the search enters $$Y$$ first. Then $$Y$$ is entirely finished before any vertex of $$X$$ is discovered, so its last finish is smaller still.

Derivation Checked as its own property: on all 4,164 enumerated graphs, ordering the components by decreasing largest finish time gives a topological order of the condensation, with zero violations.

Derivation 3 — Kosaraju, and why the second pass is trapped

Pass one produces the vertices in decreasing finish order. Pass two runs the same search on $$G^{T}$$, the graph with every edge reversed, taking vertices in that order, and each search tree is one component.

Suppose the first tree, rooted at $$r$$, left its component $$C$$ through an edge of $$G^{T}$$. Reversing that edge gives an edge of $$G$$ entering $$C$$ from outside. But $$r$$ has the largest finish time, so by the lemma $$C$$ is a source component, and a source has no such edge. So the tree is trapped in $$C$$, and it reaches all of $$C$$ because a search tree from a vertex reaches everything reachable from it.

Remove $$C$$; the remaining vertices, in the same order, satisfy the same hypothesis, so the argument repeats component by component.

Derivation Both passes cost one visit per vertex and one examination per edge, so the algorithm is linear. The stack removes the sort by finish time, which would otherwise add a log factor.

Derivation 4 — Tarjan, in one pass

Give each vertex an index, the order in which the search discovers it, and a low-link value: the smallest index reachable from it by following tree edges down and then at most one edge back into the current search.

$$\text{low}(u) = \min\bigl(\text{index}(u),\; \min_{u \to w} \text{low}(w),\; \min_{u \to w,\ w \text{ on stack}} \text{index}(w)\bigr)$$

Read: the smallest index the vertex can climb back to, using its children and one back edge.

A vertex with $$\text{low}(u) = \text{index}(u)$$ cannot climb back above itself, so it is the root of a component. When it finishes, everything pushed on the stack since it is one component, and it is popped.

Derivation On the drawn graph the values are 0, 0, 0 for the first component, then 3, 3, then 5, 5, then 7, 7 — equal inside a component, rising across components. The page computes them and checks them against the partition.

Derivation 5 — the edges needed to make it strongly connected

Read the condensation, and let $$s$$ be the number of source components (no incoming edge), $$t$$ the number of sink components (no outgoing edge), and $$q$$ the number of isolated components (neither). Then for a condensation with more than one vertex, the minimum number of edges to add is

$$\max(s, t) + q$$

Read: the larger of the two counts, plus one edge for each component that has neither an in-edge nor an out-edge.

Why the bound is needed: every source must receive an edge, every sink must send one, and an isolated component must do both, so one edge of its own.

Why it is enough: a maximal matching between sinks and sources, closed into a cycle, spends exactly that many edges and makes the whole graph one component.

Verified fact This is the Eswaran–Tarjan count, stated with the isolated term. The page checks it against a brute-force search on all 571 acyclic digraphs with up to four vertices: no disagreement.

Example 7 — the two boundaries

One component: a single vertex, or a graph already strongly connected, needs zero edges. The formula agrees, because a single vertex has neither a source nor a sink nor an isolated component to count.

Two isolated components: two vertices and no edges need two, one each way, and the formula gives $$\max(0,0) + 2 = 2$$.

An isolated vertex is a component

A vertex with no edges is related to itself by the empty path and to nothing else, so it forms a component of size one. A graph with no edges at all has one component per vertex.

This is the case that decides the augmentation count, the case that changes when an option deletes isolated vertices, and the case that a shortcut written as $$\max(s, t)$$ silently drops.

Derivation On three vertices with one edge A→B, the count with the isolated term is 2 and the brute force agrees; without it, 1, which is not enough.

Self-loops change nothing

An edge from a vertex to itself adds no reachability that the empty path did not already give. It does change the degree counts, so a count of edges or of a vertex’s out-degree must say whether self-loops are allowed.

Every graph in this lesson is simple: no self-loops, no repeated edges. That is why the number of directed graphs on $$n$$ labelled vertices is $$2^{n(n-1)}$$, which is 4,096 at $$n = 4$$.

Verified fact The page enumerates exactly those $$2^{12} = 4096$$ graphs at four vertices, and $$2^{2} = 4$$, $$2^{6} = 64$$ at two and three.

A strongly connected graph has no source and no sink

If the condensation has one vertex, that vertex has no in-edge and no out-edge in the condensation, so it is counted as isolated, not as a source. That is why the formula needs the condition on the number of vertices rather than a special case for $$q = 1$$.

A condensation with two vertices joined by edges both ways cannot exist: those two would be mutually reachable and therefore one component.

Derivation Checked: on all 4,164 enumerated graphs the condensation is acyclic, so no two-vertex cycle in it ever occurs.

The finishing order is not the graph’s order

A graph with a cycle has no topological order of its vertices at all. The order produced by pass one is a topological order of the components, which always exists because the condensation is always acyclic.

A question that asks for a topological order of a graph with a cycle therefore has no answer, and the right response is to say so and give the order of the components instead.

Educational interpretation This distinction is where a confident wrong answer comes from, because the algorithm and the definition use the same words.

The start vertex and the start order do not matter

Pass one may begin at any vertex and take the vertices in any order; the partition that pass two returns is the same. What changes is the timestamps and the stack.

The drawn graph deliberately starts at E rather than at A, so that the finish order is not alphabetical and the order is visibly a product of the search.

Verified fact The page’s enumeration uses the natural order 0, 1, 2, … throughout, and the drawn graph uses E, A, F; both give the same partition, checked against the definition.

Parallel edges and repeated components

Several edges between the same two components produce one edge in the condensation, because the condensation is defined on sets of components, not on edges. A count of condensation edges is therefore a count of distinct pairs.

On the drawn graph the thirteen original edges give four condensation edges, which is a difference worth noticing: 13 minus the 3 inside S1, the 2 inside S2, the 2 inside S3 and the 2 inside S4 leaves 4, and no pair is repeated.

Derivation 13 = 3 + 2 + 2 + 2 + 4, and the page counts the distinct pairs rather than the original edges.

1. “A component is a cycle”

Wrong. A component is a maximal set of mutually reachable vertices, which may contain many cycles, or none. Counterexample: a single vertex with no edges is a component and contains no cycle at all; and two triangles joined by edges in both directions form one component with two cycles.

Derivation Every cycle lies inside one component, so counting cycles does not count components.

2. “Run the second pass on the graph itself”

Wrong. The second pass must run on the transpose. Counterexample: two vertices and one edge A→B. On the original graph, the second pass starts at A, walks the edge and reports one component; the truth is two.

Verified fact This is the smallest counterexample, found by searching the graphs in order of size rather than chosen; the page reports it as a model check.

3. “Take the vertices in increasing finish time”

Wrong. The order is decreasing, which is the top of the stack. Counterexample: the same two vertices. On the transpose in increasing order the search starts at B, walks the reversed edge to A, and merges two components into one.

Derivation The two errors are dual: one is the wrong graph, the other the wrong comparison. Remembering “reverse something” gives a fifty per cent chance on each.

4. “The number of edges to add is the larger of sources and sinks”

Wrong when there is an isolated component. Counterexample: A→B plus an isolated C. Sources 1, sinks 1, isolated 1, so the answer is 2, and the shortcut says 1.

Verified fact The brute-force search over added edge sets gives 2 as well, on this graph and on all 571 acyclic digraphs with up to four vertices.

5. “Deleting isolated vertices keeps the components”

Wrong. Each isolated vertex is a component of its own, so deleting it changes the partition. Counterexample: the page’s search finds 235 of the 4,096 directed graphs on four vertices where it changes a component.

Derivation This is exactly the 2014 item’s fourth option, and the count is the reason it is not the answer.

6. “The finishing order is a topological order of the graph”

Wrong. It is a topological order of the components. Counterexample: the drawn graph has cycles, so it has no topological order of its vertices at all; the decreasing finish order A B C E F G H I D still orders the components correctly.

Derivation Checked as a property on all 4,164 graphs: the component order is topological for the condensation, zero violations.

How this unit is actually asked

Five shapes. The first step is the same in all of them: decide whether the question is about the graph or about its condensation, and if it is about the condensation, draw the condensation first.

Pattern A — which construction preserves the components

GATE CSE 2014, Set 1. “Let G = (V, E) be a directed graph where V is the set of vertices and E the set of edges. Then which one of the following graphs has the same strongly connected components as G?” The options are the complement, the transpose, the graph of paths of length at most two, and the graph with the isolated vertices deleted.

Step 1. The components are the classes of mutual reachability, so a construction preserves them exactly when it preserves each pair’s mutual reachability. Step 2. Reversing every edge reverses every path, so $$u \leadsto v$$ becomes $$v \leadsto u$$ and the pair survives.

Answer: the transpose. The page checks it on all 4,096 digraphs with four vertices: zero differences. The complement differs on 3,684 of them, and deleting isolated vertices on 235.

Verified fact Wording and key from two independent archives that agree; the official paper was not opened. The length-two option did not differ anywhere in the page’s search, which the lesson reports rather than hides.

Pattern B — how many components does this graph have

A graph is drawn and the answer is a number. The fast route is to look for cycles: every cycle is inside one component, and vertices joined by one-way edges only are separate.

The safe route is to contract: name the components by hand, then check that every edge between two of them runs the same way. If any pair of components has edges both ways, they were one component.

Educational interpretation On the drawn graph the four cycles give four components immediately; the three one-way edges between them confirm that none of them merge.

Pattern C — the traversal and its edge classes

GATE CSE 2021, Set 2 gives a directed graph and four statements: it has no topological order, a depth-first traversal from a named vertex classifies three edges as back edges, it has no strongly connected component, and every pair of vertices is joined by a directed path.

Three of the four are settled by two facts from this lesson: a back edge means a cycle, a cycle means no topological order, and a cycle also means a component of size greater than one. The fourth is settled by finding one pair with no path.

Unverified claim The item exists and the statement set is as described, from two archives; its figure was not reproduced here, so no answer is claimed. The reasoning above is what the page teaches, not a recomputation of that paper’s figure.

Pattern D — the count read off the condensation

Questions that name sources, sinks, or “the minimum number of edges to make it strongly connected” are all condensation questions. Contract first, then count.

The trap is the isolated term: a component with neither an in-edge nor an out-edge costs one edge of its own, so the count is $$\max(s,t) + q$$ and not $$\max(s,t)$$.

Verified fact Checked against brute force on 571 acyclic digraphs; the isolated case is 2, and the shortcut gives 1.

The five-step procedure

  1. Name the question. Components, a count, a topological order, or edges to add? Each one is read off a different object.
  2. Find the components — by eye if the graph is small, by the two passes or by Tarjan if it is not, and say which you used.
  3. Contract to the condensation: one vertex per component, one edge per distinct pair.
  4. Check it is acyclic, then read the source count, the sink count and the isolated count.
  5. Answer from the condensation, not from the original graph, and state the hypothesis you used.

The step candidates skip is the third, and almost every wrong answer is a statement about the original graph that is only true of the condensation.

Q1 — count the components

Vertices 1 to 6, edges 1→2, 2→3, 3→1, 3→4, 5→6, 6→5. The number of strongly connected components is ______.

Answer: 3

{1, 2, 3} is a cycle; {5, 6} is a cycle; vertex 4 has an edge in from 3 and no edge out, so it is a component of its own.

The trap is to answer 2 by counting only the cycles. A vertex with no cycle through it is still a component.

MCQ original

Q2 — which statement is true of every directed graph

(a) every component contains at least one cycle   (b) the condensation is acyclic   (c) the number of components equals the number of cycles   (d) a component can always be enlarged by adding one more vertex

Answer: (b)

A cycle in the condensation would mean those components all reach each other, so they would have been one component.

(a) fails on an isolated vertex, which is a component with no edge at all. (c) fails on a graph with no cycles, which still has one component per vertex. (d) fails on any graph that is already strongly connected, where one component covers everything.

NAT original

Q3 — the edges to add

A directed graph has a condensation with 3 sources, 2 sinks and 1 isolated component. The minimum number of edges to add to make the graph strongly connected is ______.

Answer: 4

$$\max(3, 2) + 1 = 4$$. The isolated component needs one edge that both enters it and leaves it, which the extra term provides.

The trap is answering 3 by dropping the isolated term. The page’s brute-force check on 571 acyclic digraphs never disagrees with the formula that keeps it.

MSQ original

Q4 — which are true

(a) reversing every edge preserves the components   (b) adding a vertex with no edges raises the component count by one   (c) a graph with one component has a topological order   (d) a graph with no edges has no components

Answer: (a), (b), (c)

(a) reversing every path reverses mutual reachability. (b) the new vertex is related only to itself. (c) one component means the graph is strongly connected, and then every edge lies on a cycle, so there is no edge to violate an order — any order works. (d) is false: every vertex is in a component of its own.

(c) is the one that looks wrong: a strongly connected graph has no edge pointing backwards in any order, because every pair of vertices is joined by paths both ways.

MCQ original

Q5 — the wrong variant

A candidate runs pass one on G, then runs pass two on G as well, taking vertices in decreasing finish order. On which graph does this first give a wrong answer?

(a) two vertices with one edge   (b) three vertices in a cycle   (c) a graph with no edges   (d) it is always correct

Answer: (a)

A→B: the second pass starts at A, follows the edge forward, and reports one component where there are two.

(c) is a near miss that survives: with no edges, every search tree is one vertex, so the wrong variant happens to be right. That is why the smallest counterexample is the one with one edge, not the empty graph.

NAT original

Q6 — the condensation edge count

A graph has components S1, S2, S3 with edges: two edges from S1 to S2, one from S2 to S3, one from S1 to S3. The number of edges in the condensation is ______.

Answer: 3

The pairs are S1→S2, S2→S3 and S1→S3. The two edges from S1 to S2 count once, because the condensation is a simple graph on components.

The trap is answering 4 by counting the original edges. Also worth noticing: S2 and S3 have no edge between them in the other direction, which is what keeps them separate components.

MCQ original

Q7 — the low-link value

In Tarjan’s algorithm, a vertex finishes with low-link equal to its own discovery index. What follows?

(a) it has no outgoing edge   (b) it is the root of a component   (c) it is the largest element of its component   (d) it has a self-loop

Answer: (b)

Low equal to index means the vertex cannot climb back to anything discovered before it, so nothing outside the vertices above it on the stack can be mutually reachable with it. Everything above it on the stack is its component.

(a) fails on a cycle’s first vertex, which has an outgoing edge. (d) is irrelevant: a self-loop changes no reachability.

MSQ original

Q8 — the closely confused pair

Which statements distinguish the finishing order of pass one from a topological order of the graph?

(a) the finishing order always exists   (b) a topological order always exists   (c) the finishing order is a topological order of the condensation   (d) they coincide when the graph is a DAG

Answer: (a), (c), (d)

(a) every graph can be searched, so the finishing order always exists. (b) is false: only a DAG has a topological order of its vertices. (c) is the lemma. (d) when the graph is a DAG, every component is a single vertex and the two orders coincide — up to the direction convention, since a topological order is the reverse of the finish order.

(d) is the one to be careful with: the textbook statement is that a topological order is the reverse of the decreasing finish order, so read the option’s wording before agreeing with it.

The definitions in four lines

Mutual
u ~ v when paths run each way; the empty path counts
Component
a maximal class of ~: every pair reaches both ways
Condensation
one vertex per component; one edge per distinct pair
Strongly connected
exactly one component

The components are a partition: disjoint, and covering every vertex, isolated ones included.

The two algorithms

Kosaraju 1
DFS on G; push each vertex as it finishes
Kosaraju 2
DFS on GT in decreasing finish order; each tree is a component
Tarjan
one DFS; pop the stack when low equals index
Cost
both linear: vertices plus edges

Both details of Kosaraju’s second pass are load-bearing: the transpose, and the decreasing order.

Fast tests that are safe

Acyclic check
condensation cyclic ⇒ the algorithm is wrong
Count check
components = distinct classes of mutual reachability
Merge test
edges both ways between two groups ⇒ they are one component
Augment test
one source and one sink ⇒ one edge is enough
Boundary
isolated vertex = a component, and one edge of its own

The unsafe shortcut is answering max(sources, sinks) without the isolated term, and reading the finishing order as a topological order of the graph.

What to say in one sentence

Two vertices are in the same component when each can reach the other; contracting the components always gives an acyclic graph, and the finishing order of one depth-first search is exactly that contracted graph in topological order — which is why searching the reversed graph in that order cuts the graph into its components.

If you remember one thing: the components are the classes of mutual reachability, and everything else is read off the contraction.
