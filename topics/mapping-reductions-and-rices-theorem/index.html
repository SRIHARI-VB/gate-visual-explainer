Topic and objective

TOPIC: Mapping reductions — the computable translation of one decision problem into another — the direction in which decidability travels along that translation, and Rice’s theorem, which is one reduction that settles a whole family of questions at once.

LEARNING OBJECTIVE: State mapping reducibility with both of its obligations and say why each is load-bearing; derive the two propagation laws from a single procedure and say which end of the arrow each law talks about; construct the wrapper machine that carries the acceptance problem to the halting problem and explain why its deliberate infinite loop is the construction and not a defect; run the reduction on real instances and read the answer correspondence off the run; build the reverse reduction and conclude equivalence under the order; and apply Rice’s theorem only after checking its two exclusions, semantic and non-trivial.

I read the request as the reduction method as a skill, not another tour of Turing machines. Turing machines and undecidability owns the machine model, the diagonal argument and the first undecidable language; Post’s correspondence problem owns one reduction chain end to end. This page owns what neither does: the definition’s two obligations, the direction trap run as a computed counterexample, a wrapper machine the page builds and executes, and Rice’s theorem with the two checks that must come before it.

1. Intuition, and 2. the formal definition

Intuition. A translator at a hospital desk does not treat patients. A patient arrives speaking one language, the translator rewrites the complaint into a second language, and the doctor — who reads only that second language — treats it. If the translation is faithful, the doctor’s yes or no is the patient’s yes or no. That is a reduction: not a comparison of two problems, but a faithful rewrite of one instance into the other’s language.

Formal. A function $$f$$ from strings to strings is computable when some Turing machine, started with $$w$$ on its tape, halts with exactly $$f(w)$$ on its tape, for every $$w$$. Then $$A$$ is mapping reducible to $$B$$, written $$A \le_m B$$, when there is a computable $$f$$ with $$w \in A$$ if and only if $$f(w) \in B$$, for every $$w$$. VERIFIED FACT

Read the second half as: $$A$$ is exactly the set of strings that $$f$$ carries into $$B$$. Many strings of $$A$$ may land on one string of $$B$$, which is why the older name is many-one reducibility. (Sipser, Introduction to the Theory of Computation, definition 5.20; Queen’s University CISC 462 notes, read 2026-11-05.)

3. The two obligations, and why each is needed

Totality. The candidate decider for $$A$$ is: compute $$f(w)$$, then run the decider for $$B$$. Two halting computations compose into a halting computation. If $$f$$ may run forever, the composed procedure may run forever, and it is no longer a decider.

Both directions of the iff. A one-way implication lets a yes for $$B$$ arrive from a no instance of $$A$$, and the solver for $$B$$ becomes useless for $$A$$. MATHEMATICAL DERIVATION

4. The two laws, derived once

Assume $$A \le_m B$$ via $$f$$. Build the machine $$D$$: on input $$w$$, compute $$f(w)$$ and run the decider for $$B$$ on it.

Good news backwards. If $$B$$ is decidable then $$D$$ decides $$A$$.

Bad news forwards. If $$A$$ is undecidable then $$B$$ is undecidable — because a decider for $$B$$ would give one for $$A$$, by the line above. MATHEMATICAL DERIVATION

5. Boundaries: what the arrow does and does not say

It says: a solver for $$B$$ gives a solver for $$A$$. So $$A$$ is no harder than $$B$$.

It does not say: that $$A$$ and $$B$$ are similar, that $$A$$ is hard because $$B$$ is hard, or that $$B$$ reduces back to $$A$$.

The order is reflexive and transitive, and it is not total: there are recognisable languages with reductions in neither direction. VERIFIED FACT

6. Edge cases in one line each

$$\varnothing \le_m A_{TM}$$ and $$\varnothing$$ is decidable: a constant function to an instance outside $$A_{TM}$$ is a legal reduction.

$$A \le_m B$$ gives $$\overline{A} \le_m \overline{B}$$ by the same $$f$$, because the biconditional survives negation.

A reduction may be wildly non-injective: mapping everything to one string is allowed and often useful.

Example 1: the acceptance problem reduces to the halting problem

Goal: $$A_{TM} \le_m HALT$$, where $$A_{TM}$$ is the set of pairs (machine, string) whose machine accepts the string, and $$HALT$$ is the set whose machine stops on the string at all.

The function. On input $$\langle M, w\rangle$$, output $$\langle M', w\rangle$$, where $$M'$$ on any input ignores it, runs $$M$$ on $$w$$, accepts if that run accepts, and loops forever if it rejects.

Why the iff holds. $$M'$$ halts on $$w$$ in exactly three cases: the inner run accepts (so $$M'$$ accepts), the inner run never halts (so $$M'$$ never halts), or the inner run rejects (so $$M'$$ loops). The first is $$w \in A_{TM}$$ and the last two are not. This page builds that machine as a real description and runs it — seven instances, seven correct answers. MATHEMATICAL DERIVATION

Example 2: the reverse reduction

On input $$\langle M, w\rangle$$, output $$\langle M'', w\rangle$$, where $$M''$$ runs $$M$$ on $$w$$ and accepts on either outcome, so long as the run finished.

Then $$M''$$ accepts $$w$$ exactly when $$M$$ halts on $$w$$, giving $$HALT \le_m A_{TM}$$. Both arrows hold, so the two problems are equivalent under the order. Computed on the same seven instances: seven of seven. MATHEMATICAL DERIVATION

Example 3: the empty language, done properly

$$f(w) = \langle R, 0\rangle$$ for every $$w$$, where $$R$$ rejects at once. $$R$$ never accepts, so the image is never in $$A_{TM}$$, and no string is in $$\varnothing$$: the biconditional holds.

Computed on all fifteen strings of length at most three: fifteen agreements, zero disagreements. So $$\varnothing \le_m A_{TM}$$, and $$\varnothing$$ is decidable. MATHEMATICAL DERIVATION

Example 4: one language, two descriptions

Machine $$E$$ accepts strings over {0,1} that end in 1. Machine $$P$$ is $$E$$ with three unreachable states added.

On the fifteen strings of length at most three, both accept the same seven: 1, 01, 11, 001, 011, 101, 111.

$$E$$ has 4 states and $$P$$ has 7, so “has at most 5 states” is true of one and false of the other while the language is the same. That split is the engine of Rice’s theorem.

Example 5: chaining by transitivity

Let $$X$$ be the set of strings $$E$$ accepts. Then $$X \le_m A_{TM}$$ via $$w \mapsto \langle E, w\rangle$$, and $$A_{TM} \le_m HALT$$ by Example 1.

Composing gives $$X \le_m HALT$$. Checked on the fifteen sampled strings: fifteen of fifteen. This is how a library of undecidable problems is built — one root reduction, then chains. MATHEMATICAL DERIVATION

Counterexample: a decidable language reducing to an undecidable one

$$\varnothing \le_m A_{TM}$$, and $$\varnothing$$ is decidable. The reduction is the constant function to $$\langle R, 0\rangle$$ with $$R$$ the reject-everything machine.

So “$$L \le_m A_{TM}$$, therefore $$L$$ is undecidable” is false, and this is its smallest counterexample. The arrow carries difficulty to the right only. It is a one-way street, and the sign on it says no harder than, not as hard as.

This is the single most costly error in the topic, because the wrong version of the sentence sounds exactly like the right one.

A cap is not a proof

Running a machine for 400 steps can only ever establish “no acceptance within 400 steps”. For a machine that loops, no finite cap distinguishes not-yet from never.

The page says this on screen. The seven instances are chosen so the capped verdict equals the truth, and one of them is a deliberately non-halting machine, included to make the limit visible rather than hidden.

Reduction is not injective, and need not be

A constant function is computable. So is a function that maps every string of $$A$$ to one string and every string outside $$A$$ to another. The definition asks only that the biconditional hold.

Consequence: “the reduction must be one-to-one” is a false extra condition, and adding it can make a correct argument look wrong.

The complement comes free

If $$A \le_m B$$ via $$f$$, then $$\overline{A} \le_m \overline{B}$$ via the same $$f$$: $$w \notin A$$ iff $$f(w) \notin B$$ is the same biconditional read backwards.

This is why undecidability of a language and of its complement come as a pair, and why non-recognisability needs a separate argument: undecidable plus recognisable means the complement is not recognisable.

Equivalence is not equality

$$A_{TM} \equiv_m HALT$$ does not make the two languages equal. The pair (machine that halts and rejects, its string) is in $$HALT$$ and not in $$A_{TM}$$, and the page computes exactly such a row.

Equivalence under $$\le_m$$ means each is decidable exactly when the other is. Nothing about their contents follows.

Where Rice stops, in one line each

Semantic and non-trivial: undecidable (Rice). Semantic and trivial: decidable, and trivially so.

Syntactic: decidable by reading the encoding, or by a bounded simulation.

Bounded-step properties are the sneaky case: “reaches state $$q$$ in exactly 100 steps” is syntactic and decidable; “reaches $$q$$ ever” is not bounded and is undecidable.

1. “$$A \le_m B$$ and $$B$$ is undecidable, so $$A$$ is undecidable”

Wrong. $$\varnothing \le_m A_{TM}$$ and $$\varnothing$$ is decidable. The arrow carries difficulty rightwards, never leftwards.

Right. Undecidability travels forwards: from $$A$$ undecidable, conclude $$B$$ undecidable. If you want to prove $$B$$ undecidable, the undecidable thing must be on the left.

2. “The symbol $$\le$$ means the left set is smaller”

Wrong. It compares difficulty, not size. $$\varnothing \le_m A_{TM}$$ compares the empty set with a set of encodings; nothing is being counted.

Right. Read it aloud as “$$A$$ is no harder than $$B$$” every single time, until the reading is automatic.

3. “Rice says any property of a Turing machine is undecidable”

Wrong. “Has at least 2016 states” is a property of a Turing machine and is decidable by counting. “Reaches $$q$$ in exactly 100 steps” is decidable by simulating 100 steps.

Right. Rice covers properties of the language $$L(M)$$ only, and only non-trivial ones.

4. “Rice’s theorem shows the set is unrecognisable”

Wrong. It shows undecidable, which is weaker. $$\{M : L(M) \neq \varnothing\}$$ is undecidable and still recognisable, by running $$M$$ on every string in parallel.

Right. Recognisability needs its own argument. Undecidable and unrecognisable are different verdicts, and a question may ask for either.

5. “A reduction only has to preserve yes answers”

Wrong. One direction lets a no instance of $$A$$ land inside $$B$$, and the solver for $$B$$ then answers yes for a no instance.

Right. The biconditional, both directions, for every string in the alphabet. That is the definition, and it is also what the propagation laws use.

6. “The wrapper’s infinite loop is a mistake to be fixed”

Wrong. The loop is the reduction. Acceptance and halting differ on exactly one case, a machine that halts and rejects, and the loop deletes that case from the image.

Right. When a construction needs to destroy information, a deliberate divergence is the standard tool.

The four shapes, and the tool each demands

Shape 1 — a property of a language. “Given $$M$$, decide if $$L(M)$$ is empty / finite / regular / all strings.” Two checks first: is the property about the language, and is it non-trivial. If both, Rice gives undecidable in one line. If the property is about the description, it is usually decidable by reading the encoding.

Shape 2 — a constructed reduction. “Show that $$L$$ is undecidable”, or “the reduction from $$A$$ to $$B$$ is ___.” The reasoning is the wrapper: state the function, state why the iff holds, and name the case the wrapper destroys.

Shape 3 — a wrong-direction trap. “$$L \le_m A_{TM}$$; what follows?” Nothing about $$L$$. The counterexample is $$\varnothing$$, and quoting it takes one sentence.

Shape 4 — sort several languages. Four to six definitions, and a choice among options. Work item by item, writing semantic / syntactic and trivial / non-trivial beside each, then apply Rice only where both conditions hold. COMMUNITY OBSERVATION for the observation that this shape recurs, from the GATE Overflow discussion of the 2022 question.

The bounded-step exception, which looks semantic

$$L = \{\langle M\rangle : M \text{ takes more than } 1073 \text{ steps on every string}\}$$ is decidable.

Why. In 1073 steps the head can have visited at most the first 1073 symbols, so a string longer than that behaves in that budget exactly as its 1073-symbol prefix does. Simulate $$M$$ on every string of length at most 1073 for 1073 steps each — finite, so decidable. The bound is what makes it work, not a theorem about languages. MATHEMATICAL DERIVATION

Wording that flips the answer

“reaches $$q$$ in exactly 100 steps” — decidable.

“reaches $$q$$ ever” — undecidable, and recognisable.

“$$L(M)$$ has at least 21 strings” — undecidable (Rice).

“$$M$$ has at least 21 states” — decidable. One word, one symbol, opposite answers.

How to write the answer in three lines

Line 1. Name the source problem and the target problem, in that order, with the arrow between them.

Line 2. Give the function, and say what it outputs on an arbitrary instance.

Line 3. State the iff and name the case that makes it hold. Three lines, no prose, full marks.

MCQ original practice

If $$A \le_m B$$ and $$B$$ is decidable, which of the following follows?

  1. $$A$$ is decidable
  2. $$A$$ is undecidable
  3. $$B \le_m A$$
  4. Nothing follows about $$A$$

Answer: (1). Good news travels backwards. To decide $$A$$ on input $$w$$, compute $$f(w)$$ — which halts because $$f$$ is total — and run the decider for $$B$$. Both steps halt, so the composite decides $$A$$.

Option 3 is the reflexivity confusion: nothing here gives the reverse reduction. Option 4 is the answer to the other hypothesis, $$B$$ undecidable, which is the trap in question 4.

MSQ PYQ — GATE CSE 2022, Question 36

Which of the following is/are undecidable?

  1. Given two Turing machines $$M_1$$ and $$M_2$$, decide if $$L(M_1) = L(M_2)$$.
  2. Given a Turing machine $$M$$, decide if $$L(M)$$ is regular.
  3. Given a Turing machine $$M$$, decide if $$M$$ accepts all strings.
  4. Given a Turing machine $$M$$, decide if $$M$$ takes more than 1073 steps on every string.

Answer: (1), (2), (3). Each of the first three is a non-trivial property of the language $$L(M)$$, so Rice’s theorem applies directly. Equality of two languages is a non-trivial property of the pair, and the direct reduction from $$A_{TM}$$ also gives it.

Option 4 is decidable, and this is the option the exam is really testing. In 1073 steps the head sees at most the first 1073 symbols, so simulating on every string of length at most 1073 for 1073 steps each settles it. Anyone who applies Rice to option 4 has applied it to a property of the machine’s running time, not of its language.

MCQ PYQ — GATE CSE 2020, Question 26

Which of the following languages are undecidable? Here $$\langle M\rangle$$ is an encoding of the Turing machine $$M$$.

  1. $$L_1 = \{\langle M\rangle : L(M) = \varnothing\}$$
  2. $$L_2 = \{\langle M, w, q\rangle : M \text{ on input } w \text{ reaches state } q \text{ in exactly 100 steps}\}$$
  3. $$L_3 = \{\langle M\rangle : L(M) \text{ is not recursive}\}$$
  4. $$L_4 = \{\langle M\rangle : L(M) \text{ contains at least 21 members}\}$$

Answer: $$L_1, L_3, L_4$$ only. Emptiness, non-recursiveness and having at least 21 members are all non-trivial properties of the language, so all three are undecidable by Rice.

$$L_2$$ is decidable: simulate $$M$$ on $$w$$ for exactly 100 steps and look at the state. The trap is that $$L_2$$ is a property of the machine’s behaviour, not of its language, so Rice does not reach it. Note also that reaching $$q$$ ever, with the 100 removed, is undecidable — the bound is doing all the work.

MCQ original practice

A student writes: “$$L \le_m A_{TM}$$, and $$A_{TM}$$ is undecidable, therefore $$L$$ is undecidable.” What is the defect?

  1. The reduction must go the other way; the argument is otherwise sound.
  2. Nothing follows about $$L$$, because $$\varnothing \le_m A_{TM}$$ and $$\varnothing$$ is decidable.
  3. $$A_{TM}$$ is in fact decidable, so the premise is false.
  4. The argument is valid but only proves $$L$$ is unrecognisable.

Answer: (2). Difficulty travels forwards along the arrow, so the right end being hard constrains nothing on the left. The constant function to $$\langle R, 0\rangle$$, with $$R$$ rejecting at once, is a computable reduction from $$\varnothing$$ into $$A_{TM}$$; the page checks the biconditional on fifteen strings with zero disagreements.

Option 1 is the correct fix stated as though it were the whole defect: the direction is the defect, and reversing it gives $$A_{TM} \le_m L$$, which would prove $$L$$ undecidable. Option 4 confuses undecidability with unrecognisability, and undecidability of $$L$$ would not follow either.

NAT original practice

Machine $$E$$ accepts exactly the strings over {0,1} that end in 1, and has 4 states. Machine $$P$$ is $$E$$ with three unreachable states added. How many strings of length at most 3 are accepted by $$E$$?

Answer: 7. Of the fifteen strings of length at most three, the seven ending in 1 are: 1, 01, 11, 001, 011, 101, 111. The page computes this by running the machine on all fifteen.

The point of the question is the second sentence of the setup: $$P$$ accepts exactly the same seven, while having 7 states to $$E$$’s 4. A property of the language did not move; a property of the description did. That is Rice’s theorem in miniature, and it is why “has at most 5 states” is decidable but cannot be a property of $$L(M)$$.

MSQ original practice

Which of these are decidable?

  1. Given $$M$$, does $$L(M)$$ contain every string?
  2. Given $$M$$, does the encoding of $$M$$ contain at least 21 transitions?
  3. Given $$M$$ and $$w$$, does $$M$$ halt on $$w$$?
  4. Given $$M$$ and $$q$$, does $$M$$ reach state $$q$$ within 100 steps on the empty input?

Answer: (2) and (4). Option 2 counts entries in a finite encoding. Option 4 simulates a fixed 100 steps — a bounded run always finishes.

Option 1 is a non-trivial property of the language, so undecidable by Rice. Option 3 is the halting problem itself, undecidable. The pair 2 and 4 are the syntactic and the bounded-step escapes from Rice, and they are the two that students most often miss.

MCQ original practice

Which statement about the relation $$\le_m$$ is true?

  1. It is a total order: any two languages are comparable.
  2. It is reflexive and transitive, and not total.
  3. It is symmetric, so $$A \le_m B$$ implies $$B \le_m A$$.
  4. It is antisymmetric, so $$A \le_m B$$ and $$B \le_m A$$ imply $$A = B$$.

Answer: (2). Reflexive: the identity function is computable. Transitive: a composition of computable functions is computable, and two always-halting procedures always halt. Not total: there are recognisable languages with no reduction in either direction. Both properties are checked on the page’s fifteen-string sample.

Option 4 fails on equivalence classes: $$A_{TM} \equiv_m HALT$$ while the two languages are different, and the page computes a pair that separates them. Antisymmetry would hold only if you quotiented by equivalence, and even then it is antisymmetry of the quotient, not of the languages.

The six facts to carry

1. $$A \le_m B$$ means: a computable total $$f$$ with $$w \in A$$ iff $$f(w) \in B$$, for every $$w$$. Read it as “$$A$$ is no harder than $$B$$”.

2. Decidability travels backwards, undecidability forwards. Same hypothesis, opposite conclusions, and that asymmetry is the whole topic.

3. To prove $$B$$ undecidable, the undecidable problem must be on the left. A hard right end proves nothing: $$\varnothing \le_m A_{TM}$$.

4. The standard reduction $$A_{TM} \le_m HALT$$ wraps the machine so that rejection becomes divergence. The loop is the construction.

5. Rice: every non-trivial property of $$L(M)$$ is undecidable. Check semantic first, then non-trivial; if either fails, Rice does not apply and the property is usually decidable.

6. Rice gives undecidable, never unrecognisable. $$\{M : L(M) \neq \varnothing\}$$ is undecidable and recognisable; $$\{M : L(M) = \varnothing\}$$ is neither.

The four propagation laws

$$A \le_m B$$, $$B$$ decidable $$\Rightarrow$$ $$A$$ decidable

$$A \le_m B$$, $$A$$ undecidable $$\Rightarrow$$ $$B$$ undecidable

$$A \le_m B$$, $$B$$ recognisable $$\Rightarrow$$ $$A$$ recognisable

$$A \le_m B$$, $$A$$ unrecognisable $$\Rightarrow$$ $$B$$ unrecognisable

The sorting test, in order

1. Is the property about $$L(M)$$ or about the description? Description $$\rightarrow$$ decidable, usually.

2. Is it bounded (a fixed number of steps, states, transitions)? Bounded $$\rightarrow$$ decidable.

3. Is it trivial? Trivial $$\rightarrow$$ decidable.

4. Otherwise: undecidable by Rice. Then ask separately whether it is recognisable.

One line to carry into the exam

Decide the direction before you write the function: the undecidable problem goes on the left, the thing you are proving goes on the right, and if the arrow is the wrong way round no amount of correct detail will save the answer.
