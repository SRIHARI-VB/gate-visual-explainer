Topic and objective

TOPIC: Turing machines and undecidability — the last clause of GATE 2027 Section 6, Theory of Computation, together with the decidability classification that the earlier clauses keep borrowing.

LEARNING OBJECTIVE: Read a Turing machine and trace it, and say whether it halts. Separate the three fates of a run, and separate a decider from a recogniser in one sentence. Prove the halting problem undecidable by the diagonal construction, and use a many-one reduction in the direction that is valid. Apply Rice's theorem to a semantic property and refuse to apply it to a bounded run. Read the five decision problems off the ladder table for regular, context-free, recursive and recursively enumerable languages, and state which of them is not even recognisable.

I read this topic as one question asked about three different objects: does a run end, does a language have a machine that always ends, and can any machine answer that question for all machines. The tape answers the first, the decider answers the second, and the diagonal argument answers the third. Every definition, table and previous-year item below is that sentence at a different object.

Prerequisites

  • Machines with finitely many states, and languages as sets of strings. The whole vocabulary is assumed. Built in Regular Expressions and Finite Automata and Sets and Set Operations.
  • Context-free grammars, and what a stack cannot do. The ladder table's second row is that lesson's classification, and the pumping lemma there is the same diagonal idea in a weaker form. Built in Context-Free Grammars and Pushdown Automata.
  • Sets of strings and their power set. Countability, and the difference between a set and its power set, carry the whole existence argument in scene 3. Built in Sets and Set Operations.
  • Functions that are computable, and functions that are not. A reduction is a computable function, and the word computable is only meaningful after this lesson's machine. Built in Functions and Their Properties.
  • Proof by contradiction and the pigeonhole principle. The halting proof is a contradiction, and the diagonal argument is a pigeonhole argument on an infinite table. Built in Propositional Logic and Counting and Combinatorics.

Nothing about complexity classes, NP-completeness or polynomial-time reductions is assumed or taught here; those belong to a different clause and a different kind of reduction. Nothing about compiler construction is assumed either.

The five ideas to leave with

  1. A run has three fates, not two. Never halting is a legal outcome, and it is the whole source of undecidability.
  2. Deciding is stronger than recognising. A decider must answer no as well as yes, which means it must halt on the strings it rejects.
  3. Strings and machines are countable; languages are not. So most languages have no machine, and the diagonal flip is the proof.
  4. Rice's theorem is about properties of the language. A property with a fixed number of steps in it is a property of the run, and it is decidable.
  5. Hardness flows against the reduction arrow. Every lost mark in this clause is a direction error or a missing halt.

Intuition: the clerk who is asked whether the queue ever ends

Imagine a clerk whose only job is to watch a process and report whether it finishes. He watches, and watches. When it finishes he can say so with confidence, because he saw the end. When it does not finish, he can never say so, because there is always another minute to wait. That is a recogniser, and the asymmetry is the whole topic.

Now ask a second question, which sounds like a small extension: can some other clerk, watching the first clerk, always say in advance whether the process will finish? That clerk would need to answer without waiting, since waiting never settles the negative case. The answer is no, and the proof is not a limitation of clerks but a limitation of any procedure at all.

Educational interpretation The analogy is a teaching device. It fixes the one fact every question in this topic turns on: a finite run certifies itself, and an infinite run never does.

Formal vocabulary, every symbol glossed

Turing machine M = (Q, Γ, b, Σ, δ, q0, F). Q is a finite set of states. Γ is the finite tape alphabet. b ∈ Γ is the blank symbol that fills every cell not yet written. Σ ⊆ Γ − {b} is the input alphabet. δ is the transition function, from a state and a tape symbol to a state, a symbol to write, and a direction in {L, R}. q0 ∈ Q is the start state. F ⊆ Q is the set of accepting states.

Configuration (also called an instantaneous description): the state, the whole current tape, and the head position. Three things, and together they fix every later step.

A move applies δ: read the symbol under the head, write the new symbol there, move the head one cell, enter the new state. In a deterministic machine there is at most one move per configuration, so a run is a single path.

L(M) is the set of input strings on which the run reaches a state in F. M halts on w means the run is finite — it may halt accepting or halting rejecting. M decides L means M halts on every input and L(M) = L. M recognises L means only L(M) = L.

The one sentence the whole topic turns on

A halting run is finite, so a machine that watches it can always report the positive answer. A non-halting run is infinite, and no finite amount of watching rules it out. Every undecidability result below is this asymmetry, applied to a machine that is itself the thing being watched.

finite runs certify themselves; infinite runs never do

That line produces four consequences in order: the halting language is recognisable but not decidable; its complement is not recognisable at all; every non-trivial semantic property inherits the failure; and the only escape is a property with a bound, because a bound makes the question finite.

Three checks that catch most slips

Check 1 — does the question say halts, accepts, or decides? Halts includes halting by rejecting. Accepts is only the accepting case. Decides means halts with the right answer on both sides. Three different questions, three different answers.

Check 2 — is the property about the language or about the run? If the answer would not change when the machine is replaced by another machine for the same language, the property is semantic. Rice applies to semantic properties and to nothing else.

Check 3 — which way does the reduction point? The arrow goes from the problem you want to the problem you have. A decider for the target solves the source, so hardness travels backwards along the arrow and easiness forwards.

Closely confused: "undecidable" against "unrecognisable"

Undecidable means no machine halts with the right answer on every input. The language may still be recognisable: some machine halts and says yes on every member.

Unrecognisable means no machine even does that. Nothing halts and says yes on all members, so the positive answer is also unavailable.

The pair that separates them. The halting language H is recognisable and undecidable. Its complement is not recognisable. Both statements are theorems, and the difference between them is exactly the presence of a machine that halts on the yes side.

Build-up, page 2 of 2: the three arguments, in the order they depend on each other

Counting comes first, because it proves that some language has no machine without naming one. The diagonal comes second, because it turns that existence proof into a contradiction about a specific decider. Reduction comes third, because once one problem is known undecidable, every problem it reduces to inherits that. Rice is the general form of the third step.

Argument 1: count the machines, then count the languages

Step 1. List every string over {0,1} in shortlex order: ε, 0, 1, 00, 01, 10, 11, … Every string is finite, so every string has a finite index. The set is countably infinite.

Step 2. A machine can be written down as a finite string — its table. So descriptions are strings, and the machines can be listed in the same order. Countably many machines.

Step 3. A language is a set of strings, so it is a subset of that list. The number of subsets of a countable set is uncountable. Over just the 31 strings of length at most 4 there are 231 = 2,147,483,648 languages, and only 31 descriptions of length at most 4.

Mathematical derivation So there are more languages than machines, and at least one language has no machine. The argument is Cantor's, and it names nothing. Verified fact GATE CSE 2014 Set 3 Q16 asks which of Σ* and 2Σ* is countable: Σ* is, and its power set is not.

Argument 2: the diagonal, in table form

Step 1. Put the machines down the side, in the order they were listed: M0, M1, M2, … Put the strings across the top, in shortlex order: s0, s1, s2, …

Step 2. Fill cell (i, j) with yes if Mi accepts sj. Row i is the language of Mi. (For a machine that never halts on sj, the cell is no: it does not accept.)

Step 3. Define D(si) = yes exactly when cell (i, i) is no. Then D differs from row i at column i, for every i, so D is no row of the table.

Mathematical derivation This page computes a six-by-six version of that table and checks that the flipped diagonal differs from every one of the six rows. The infinite version is the same argument, and it does not need the list to be finite.

Argument 3: reduction, and the direction

Definition. A ≤m B means there is a computable f with w ∈ A exactly when f(w) ∈ B. The f is the reduction: it rewrites an instance of A into an instance of B, keeping the answer.

Valid directions. If B is decidable then A is decidable (run f, then the decider for B). If A is undecidable then B is undecidable (contrapositive of the previous line). If B is recognisable then A is recognisable (the same construction, with a recogniser).

Invalid directions. A decidable does not make B decidable, and B undecidable does not make A undecidable. Both fail because f only reads A and writes B; nothing travels the other way.

Verified fact GATE CSE 2014 Set 2 Q16 asks which implication about many-one reducibility is false, and the false option is always one of these two reversed directions.

The wrapper, which is the only gadget you need to remember

To show that a property P of machine languages is undecidable, do not attack P directly. Build a machine whose language is everything or nothing depending on a halting question, and observe that P must separate those two languages.

W(M, w): ignore the input, run M on w, accept when M halts

Then L(W) = Σ* if M halts on w, and L(W) = ∅ if it does not. Any property that treats ∅ and Σ* differently — emptiness, universality, finiteness, regularity, containing a 0, having at least 21 members — becomes a decider for halting. The page builds this wrapper for six machine and input pairs and checks both lines on each.

Worked examples, page 1 of 2

Every figure below is recomputed by this page's own model, and the Animation tab lists the checks. Nothing is copied from a key without being re-derived, and where a claim is a theorem rather than a computation the card says so.

A run, traced move by move on 0011

Step 1 — the idea. Mark the first unmarked 0 as X, walk right to the first unmarked 1, mark it Y, then walk left back to the X. Repeat. Accept when every 0 and 1 is marked and the tape is blank.

Step 2 — the run. On 0011 the machine takes thirteen moves and passes through fourteen configurations: q0 0011, q1 X011, q2 X0Y1, q0 X0Y1, q1 XXY1, q2 XXYY, q0 XXYY, q3 XXYY, then it accepts on the blank.

Step 3 — the claim. This machine halts on every input, so it is a decider. On 010 it halts rejecting: it marks the second 0 and then finds the tape blank where a matching 1 should have been.

Mathematical derivation The page compares it with the definition of 0n1n on all 63 strings of length at most 5 and finds no disagreement. The same test is run on five other machines, including one that accepts everything and one that never halts.

Why a machine that never halts is still a legal machine

Step 1. The definition of a machine says nothing about halting. It fixes the states, the alphabet and the table, and a table with no accepting transition is a table like any other.

Step 2. The machine that walks right for ever is the smallest example: every transition is (q0, anything) → (q0, same, R). No state in F is ever reached, and no run ends.

Step 3 — the consequence. Its language is empty, exactly as the language of the machine that rejects everything is empty. Two machines, same language, one halts and one does not. That is why the language cannot tell you whether the machine halts, and why the halting question is about the machine rather than about its language.

The diagonal table, computed on six machines

The rows. In order: accepts everything, accepts nothing, accepts exactly {0}, accepts strings containing a 0, accepts strings with an even number of 1s, accepts 0n1n. The columns are ε, 0, 1, 00, 01, 10.

The diagonal. Read cell (0,0): the machine that accepts everything accepts ε, so D(ε) = no. Cell (1,1): the machine that accepts nothing does not accept 0, so D(0) = yes. The diagonal reads no, yes, yes, no, yes, yes.

Why it matters. The language D = {0, 1, 01, 10} differs from every one of the six rows somewhere, and the page checks all six disagreements. That is the whole argument; the infinite version just refuses to stop at six.

Worked examples, page 2 of 2: the three undecidability arguments, worked on numbers

These three are the ones that get marked. Each is written as the proof you would put on paper, with the page's computation underneath it.

Halting is undecidable: the two cases, both refuted

Step 1 — assume. Suppose D is a machine that always halts and, on input ⟨M⟩#w, prints halt or loop correctly.

Step 2 — build. N takes a description ⟨M⟩, asks D about ⟨M⟩#⟨M⟩, and loops if the answer is halt, halts if the answer is loop. N only runs D, so N is a legal machine with a description of its own.

Step 3 — refute. If D says N halts on ⟨N⟩, then N loops, so D was wrong. If D says N loops on ⟨N⟩, then N halts, so D was wrong. There is no third answer.

Mathematical derivation The page builds N and evaluates both cases. It also checks that the same D is correct on all seven ordinary machines over all 15 inputs of length at most 2 — the failure is not general incompetence, it is exactly the machine built to defeat it.

Emptiness is undecidable: the wrapper, on six pairs

Step 1. Suppose E decides whether the language of a machine is empty.

Step 2. Given M and w, build W: ignore the input, run M on w, accept when the run halts. Then L(W) = Σ* if M halts on w, and L(W) = ∅ if it does not.

Step 3. So E(⟨W⟩) = empty exactly when M does not halt on w. That decides halting, which is impossible. Hence E does not exist.

Mathematical derivation The page builds W for six pairs and checks both lines. Note the pair (0n1n, 010): the machine rejects 010, but it halts, so W still accepts everything. The wrapper reads halting, not acceptance.

Rice, with the witnesses written out

The theorem. Let P be a property of recursively enumerable languages. If some language has P and some language does not, then no machine decides, for an arbitrary machine, whether L(M) has P.

The witnesses. Machine A rejects everything, so L(A) = ∅: empty, finite, regular, and it contains no 0. Machine B accepts everything, so L(B) = Σ*: not empty, not finite, regular, contains a 0, and has more than 21 members.

Applying it. Every property in that list separates A from B, so every one is non-trivial, so every one is undecidable. The page runs both machines and checks that the list splits them. Verified fact GATE CSE 2020 Q26, 2022 Q46 and 2016 Set 2 Q44 are all instances of this card.

Boundaries, and what breaks when a condition fails

Every card here is a case where a rule that is right in the ordinary case gives the wrong answer at the edge. Each one names the condition it violates.

The empty language and the language containing the empty string

L = ∅ has no strings at all. L = {ε} has exactly one, the empty string. They are different languages, and a machine for one is not a machine for the other.

This matters because "M accepts ε" is the standard undecidable property, while "L(M) = ∅" is a different undecidable property, and a question may offer both as options.

The condition that fails. Treating "accepts nothing" and "accepts the empty string" as the same case, because both feel empty. They differ by one string, and that string is a member.

A missing transition is a rejection, not a loop

In a deterministic machine given as a partial table, a configuration with no entry halts and rejects. That is the convention every textbook uses, and this page's interpreter follows it.

A run that loops is different: it keeps finding entries and keeps moving. The machine that walks right for ever has an entry for every symbol, which is exactly why it never stops.

The condition that fails. Reading "no move available" as "runs for ever". It is the opposite: no move available is the definition of halting here.

Halts on every input, halts on some input, halts on this input

Three different questions. "M halts on w" is about one input and is semidecidable. "M halts on every input" is a different, also undecidable question. "M halts on some input" is a third.

Adding a step bound changes all three into decidable questions, and that is what GATE 2016 Set 2 Q44 and 2021 Set 1 Q39 test.

The condition that fails. Carrying an answer from one quantifier to another. "Some input" and "every input" are not interchangeable, and neither is "this input".

A decidable language with a machine that does not halt

Take any decidable language and a decider for it. Now add a state that loops on a symbol the decider never reads. The language is unchanged and the new machine does not halt on some inputs.

So "the language is recursive" and "this machine halts on everything" are properties of different objects. The class belongs to the language; halting belongs to the machine.

The condition that fails. Assuming that because some machine decides L, every machine for L does. Only the existence of one decider is claimed.

Recognisable but not co-recognisable

H is recognisable and undecidable. If H were also co-recognisable — that is, if its complement were recognisable — then by Post's theorem H would be decidable. Since it is not, the complement is not recognisable.

This is the one place in the subject where a language and its complement sit on opposite sides of a boundary.

The condition that fails. Assuming that a language and its complement always have the same status. For regular and recursive languages they do; for recognisable languages they need not.

The encoding is an assumption you inherit

Every result here uses "the i-th machine" and "the description ⟨M⟩". Both need one fixed, decodable encoding, and every proof assumes the same one.

The choice never changes an answer, because any two reasonable encodings can be translated into each other by a computable function — which is itself a reduction.

What to do in an exam. Say "fix any standard encoding" once, then use it. Do not try to write the encoding out; no question has ever needed it.

Misconceptions, page 1 of 2

Each card gives the wrong belief, why it is tempting, the smallest counterexample, and the rule that replaces it. These are the six that account for most lost marks in this clause.

"Undecidable means no machine can even try"

Why it tempts. The word sounds absolute, and the halting proof feels like a wall.

Minimal counterexample. The halting language H is undecidable, and the machine that simulates and says yes on halting is a recogniser for it. So a machine does try, and is always right when it answers.

The rule. Undecidable means no machine halts with the right answer on every input. It does not mean no machine does anything useful. Recognisable and undecidable is the normal state of affairs.

"Rice's theorem applies to any property of a machine"

Why it tempts. The theorem is stated as "any non-trivial property", and students drop the word semantic.

Minimal counterexample. "M takes more than 1073 steps on every input" is non-trivial and decidable, because it is a property of the run. Simulate 1074 steps on every input of length at most 1073.

The rule. Rice needs both conditions: the property must be about the language, and it must be non-trivial. A property that a machine with the same language could fail is not a property of the language.

"A reduction from A to B means B is at least as easy as A"

Why it tempts. The arrow looks like a difficulty arrow, and in some subjects it is read that way.

Minimal counterexample. Every decidable language reduces to the halting language: ignore the input, and output a fixed halting instance. So A ≤m H for easy A, and H is as hard as it gets.

The rule. A ≤m B means B is at least as hard as A. Easiness flows along the arrow, hardness against it. A solver for B gives you a solver for A, never the other way round.

"If a language is undecidable, its complement must be too"

Why it tempts. For regular and recursive languages it is true, so it feels like a general law.

Minimal counterexample. H is undecidable and recognisable; its complement is undecidable and not recognisable. Both undecidable, but for different reasons, and the second is strictly worse.

The rule. Undecidability is inherited by the complement — that direction is true. What is not inherited is recognisability. Track both properties separately, not one.

Misconceptions, page 2 of 2

Two more, then the pair that is most often confused in a multiple-select question.

"Emptiness is undecidable, so it must be undecidable for grammars too"

Why it tempts. The word emptiness is the same, and the wrapper argument is fresh in mind.

Minimal counterexample. For a context-free grammar, emptiness is decided by marking the nonterminals that can reach a terminal string, and iterating. The page runs that algorithm on two grammars.

The rule. The wrapper needs a machine whose run can be infinite. A grammar is not a machine with a run, so the argument does not transfer. Emptiness is decidable for regular and context-free languages, and undecidable only from the machine level up.

"Countably many machines over an alphabet means countably many languages"

Why it tempts. Both are built from strings over the same finite alphabet, so they feel like the same size.

Minimal counterexample. Over the 31 strings of length at most 4 there are 231 languages and 31 descriptions. The number of subsets outruns the number of elements at every length.

The rule. A set of strings is countable; its power set is not. Languages are subsets, so there are uncountably many, and most of them have no machine.

Closely confused pair: "decides" against "recognises"

Decides. Halts on every input, accepting the members and rejecting the non-members. The machine answers no, and answers it in finite time.

Recognises. Halts and accepts every member. On a non-member it may loop, so no answer is ever given.

The witness. The simulating machine for H recognises H and does not decide it. If it decided H, halting would be decidable, which the diagonal argument forbids. Verified fact GATE CSE 2026 Set 2 Q13 asks for the equivalent of "M decides L", and the key is the explicit rejection of every string outside L.

The sentence to say to yourself before answering

"Which object is this about — the run, the language, or the whole class of machines?"

A run is simulated and is decidable when bounded. A language is a candidate for Rice, and undecidable when the property is non-trivial and semantic. The whole class is the ladder table, and it is a theorem.

Nearly every wrong answer in this clause comes from answering about one object when the question asked about another.

Six question shapes, and the reasoning each demands

These are the shapes this clause is asked in. Each card gives the shape, the reasoning it demands, and the wrong approach that is most often taken. No marks distribution is claimed here: the shapes are read off the papers cited on the Sources tab, not off a weightage chart.

Shape 1 — "which of these languages is undecidable?"

The reasoning. For each option, decide whether it is a property of the language or of the run. Semantic and non-trivial means undecidable. A fixed step bound, a fixed state and a fixed number of steps mean decidable by simulation.

The wrong approach. Marking the option that looks most complicated as the undecidable one. In 2020 Q26 the complicated-looking option is the only decidable one.

Seen in. GATE CSE 2020 Q26, 2022 Q46, 2013 Q41, 2016 Set 1 Q17.

Shape 2 — "which of these statements is true?" over closure

The reasoning. Two properties are being mixed: closure under an operation, and the decidability class. Read the closure table for the operation, then the ladder for the class, and keep them apart.

The wrong approach. Using De Morgan across the complement gap: RE is closed under intersection and not under complement, and the two facts are consistent only because De Morgan cannot be applied inside the class.

Seen in. GATE CSE 2013 Q17, 2018 Q7, 2022 Q13, 2015 Set 2 Q21.

Shape 3 — the step-bound trap

The reasoning. In k steps the head reads at most k cells, so only inputs of length at most k matter. Finitely many such inputs means a finite table, which means a decider. This works for "on all inputs" and for "on some input" alike.

The wrong approach. Applying Rice because the option mentions a machine. The option mentions a run, and Rice is not about runs.

Seen in. GATE CSE 2021 Set 1 Q39, 2016 Set 2 Q44, 2022 Q46, 2020 Q26.

Shape 4 — many-one reduction, direction

The reasoning. Write the implication with the arrow and check it against the three valid rows. A decider for the target gives a decider for the source; hardness travels the other way.

The wrong approach. Assuming A ≤m B transfers decidability in both directions. It transfers easiness from B to A only.

Seen in. GATE CSE 2014 Set 2 Q16, 2016 Set 1 Q44, 2015 Set 3 Q53.

Shape 5 — countability and the existence of non-recognisable languages

The reasoning. Σ* is countable. The set of machines is countable. 2Σ* is uncountable, so some language has no machine. The set of recursively enumerable languages is countable and is a proper subset of all languages.

The wrong approach. Arguing that 2Σ* is countable because each of its members is built from finitely many strings. A language may be infinite, and the collection of subsets is what is being counted.

Seen in. GATE CSE 2014 Set 3 Q16, 2018 Q27, 2018 Q7.

Shape 6 — definitions of decide, recognise and halt

The reasoning. Quote the definition and match it word by word. Decides: halts on all inputs, accepts members, rejects non-members. Recognises: accepts members, may loop elsewhere.

The wrong approach. Accepting "M accepts all strings of L" as equivalent to deciding L. A recogniser satisfies that sentence too.

Seen in. GATE CSE 2026 Set 2 Q13, 2014 Set 2 Q35, 2012 Q24.

GATE CSE 2020 Q26 Q1 (MCQ, 2 marks)

Which of the following languages are undecidable? ⟨M⟩ is an encoding of the Turing machine M.

L1 = {⟨M⟩ | L(M) = ∅}   L2 = {⟨M, w, q⟩ | M on input w reaches state q in exactly 100 steps}   L3 = {⟨M⟩ | L(M) is not recursive}   L4 = {⟨M⟩ | L(M) contains at least 21 members}

(A) L1, L3 and L4 only   (B) L1 and L3 only   (C) L2 and L3 only   (D) L2, L3 and L4 only

(A). L1, L3 and L4 are properties of L(M), and each is non-trivial: the machine that rejects everything has L(M) = ∅, and the machine that accepts everything does not. Rice makes all three undecidable. L2 is a property of a bounded run, so it is decided by simulating a hundred steps and reading the state.

(B) and (C) each drop one semantic property; (D) wrongly includes the bounded run. The page runs both witness machines and confirms that emptiness, "not recursive" and "at least 21 members" separate them, while the 100-step property is decided by the trace itself.

GATE CSE 2022 Q46 Q2 (MSQ, 2 marks)

Which of the following is/are undecidable?

(A) Given two Turing machines M1 and M2, decide if L(M1) = L(M2).   (B) Given a Turing machine M, decide if L(M) is regular.   (C) Given a Turing machine M, decide if M accepts all strings.   (D) Given a Turing machine M, decide if M takes more than 1073 steps on every string.

(A), (B) and (C). Equality of two machine languages, regularity of a machine language, and universality are all semantic and non-trivial, so Rice applies to each. (D) is decidable: in 1073 steps the head can read at most the first 1073 symbols, so it is enough to simulate 1074 steps on every input of length at most 1073.

The trap is (D): "every string" is an infinite set, and it feels as though an infinite set cannot be checked. It can here, because the step bound makes longer strings behave exactly like their prefixes. The page's k-step procedure is checked against a search over longer inputs for k = 6 and agrees on every machine it runs.

GATE CSE 2021 Set 1 Q39 Q3 (MCQ, 2 marks)

L1 = {⟨M⟩ | M takes more than 2021 steps on all inputs} and L2 = {⟨M⟩ | M takes more than 2021 steps on some input}. Which one of the following is correct?

(A) Both L1 and L2 are decidable.   (B) L1 is decidable and L2 is undecidable.   (C) L1 is undecidable and L2 is decidable.   (D) Both L1 and L2 are undecidable.

(A). Run M for 2022 steps on every input of length at most 2021. That is finitely many runs, and each finishes. If every one of them is still running at step 2021, then no input anywhere finishes sooner, because a longer input cannot be read that far in that many steps. So L1 is decided. For L2 the same finite search either finds a witness or shows there is none.

The tempting answer is (D), by analogy with the halting problem. The difference is the number: a bound converts "for ever" into "2021 steps", and 2021 steps is a finite table. The page checks the same argument with k = 6 and finds the short-input search and a longer-input search agree.

GATE CSE 2016 Set 2 Q44 Q4 (MCQ, 2 marks)

L1 = {⟨M⟩ | M takes at least 2016 steps on some input}, L2 = {⟨M⟩ | M takes at least 2016 steps on all inputs}, L3 = {⟨M⟩ | M accepts ε}. Which one of the following is true?

(A) L1 is recursive and L2, L3 are not   (B) L2 is recursive and L1, L3 are not   (C) L1, L2 are recursive and L3 is not   (D) L1, L2, L3 are all recursive

(C). L1 and L2 are properties of a bounded run and are decided by searching inputs of length at most 2016 for 2017 steps. L3 asks about L(M), which is semantic and non-trivial, so it is undecidable.

Accepting ε looks like the mildest question of the three, and it is the only undecidable one. The page's own pair of witnesses makes the point: the machine that rejects everything does not accept ε, and the machine that accepts everything does.

GATE CSE 2014 Set 2 Q35 Q5 (MCQ, 2 marks)

Let ⟨M⟩ be the encoding of a Turing machine as a string over Σ = {0,1}, and let L = {⟨M⟩ | M is a Turing machine that accepts a string of length 2014}. Then L is

(A) decidable and recursively enumerable   (B) undecidable but recursively enumerable   (C) undecidable and not recursively enumerable   (D) decidable but not recursively enumerable

(B). There are finitely many strings of length 2014, so a machine can dovetail: run M on each of them for one step, then two steps, then three, and say yes as soon as any run accepts. That makes L recognisable. It is not decidable, because "L(M) contains a string of length 2014" is a non-trivial semantic property and Rice applies.

The finite supply of strings of a fixed length gives recognisability, not decidability: if no run accepts, the search never ends. (A) is the trap for anyone who reasons that a finite set of strings must make the question decidable; (C) over-corrects; (D) is impossible, since every decidable language is recognisable.

GATE CSE 2013 Q17 Q6 (MSQ, 1 mark)

Which of the following statements is/are FALSE?

1. For every nondeterministic Turing machine there is an equivalent deterministic one.   2. Turing-recognisable languages are closed under union and complementation.   3. Turing-decidable languages are closed under intersection and complementation.   4. Turing-recognisable languages are closed under union and intersection.

2 only. Recognisable languages are closed under union and intersection but not under complement. The other three statements are true: nondeterminism adds no power to a Turing machine, and decidable languages are closed under intersection and complement.

Statement 2 is the only one that fails, and it fails on the complement half alone. If a language and its complement are both recognisable, Post's theorem makes the language decidable — which would collapse the two classes, and the halting language shows they do not collapse. The page dovetails two recognisers to demonstrate exactly the step that this argument forbids you to take for free.

Original practice Q7 (NAT)

Over the alphabet {0,1}, how many languages are there whose strings all have length at most 2? (That is, how many subsets of {ε, 0, 1, 00, 01, 10, 11} are there?)

128. There are 7 strings of length at most 2, so there are 27 = 128 subsets, and each subset is a language whose strings are all short.

The slip is to answer 7, counting the strings instead of the subsets. The page's count is the same computation at length 4: 31 strings give 231 languages, and it prints that number beside the diagonal table. This is the count that makes "more languages than machines" true at every length.

Original practice Q8 (MSQ)

Let H = {⟨M⟩#w | M halts on input w}. Which of the following are true?

(A) H is recursively enumerable.   (B) H is recursive.   (C) The complement of H is recursively enumerable.   (D) H is undecidable.

(A) and (D). H is recognised by simulating: a halting run is finite, so the yes answer always arrives. It is not decided, by the diagonal argument, so (B) is false. If the complement were also recognisable, Post's theorem would make H decidable, so (C) is false too.

(B) and (C) fail together, and that is the point: the three statements "H is recursive", "the complement of H is recognisable", and "H is decidable" are the same statement. Choosing (A) and (C) is the common error, and it would make the halting problem decidable.

Original practice Q9 (MCQ)

A machine M is given, and you are asked whether M ever writes the symbol X on its tape. Which statement is correct?

(A) Decidable, by simulating M until it writes X.   (B) Decidable, by simulating M for a bounded number of steps.   (C) Undecidable in general, but recognisable.   (D) Neither decidable nor recognisable.

(C). If M writes X, a finite simulation finds it, so the question is recognisable. If M never writes X the simulation runs for ever, so it is not decidable: "never writes X" is a statement about an infinite run, and the standard reduction from halting applies.

(B) is the trap. A bound makes the question decidable, but only for the bounded question — "writes X within k steps" — which is not what was asked. The bound has to come from the question, not from the answerer's patience.

Original practice Q10 (MCQ)

Suppose A ≤m B. Which of the following is not a valid conclusion?

(A) If B is decidable then A is decidable.   (B) If A is undecidable then B is undecidable.   (C) If A is decidable then B is decidable.   (D) If B is recognisable then A is recognisable.

(C). The reduction only rewrites instances of A into instances of B. A decider for B, composed with the reduction, decides A; nothing in that composition decides B. So (A), (B) and (D) hold and (C) does not.

A concrete instance of the failure: every decidable language reduces to the halting language, by ignoring the input and emitting a fixed halting instance. So A is decidable, B is undecidable, and (C) is false in the most familiar case there is.

The one-screen revision sheet

Definitions, the three arguments, the two tables and the traps. Nothing here is new; it is the lesson compressed to what you would want in the last ten minutes before a paper.

Definitions in one line each

TM (Q, Γ, b, Σ, δ, q0, F); a move reads, writes, moves, changes state.

Configuration state + tape + head position.

Halts on w the run is finite, accepting or rejecting.

Decides L halts on every input, L(M) = L.

Recognises L L(M) = L, halting not promised.

REC the decidable languages. RE the recognisable ones.

A ≤m B computable f with w ∈ A ⇔ f(w) ∈ B.

The three arguments

Counting. Strings countable, machines countable, languages not. So some language has no machine.

Diagonal. Assume a decider D for halting, build N that does the opposite of D's answer about N itself, and both cases fail.

Reduction. Wrap a halting question into a language question. L(W) = Σ* if M halts on w, ∅ otherwise. Any property separating ∅ from Σ* is therefore undecidable.

The ladder

Regular: all five decidable.

Context-free: membership, emptiness, finiteness decidable; universality, equivalence not.

Recursive: all five decidable.

RE: all five undecidable.

Beyond RE: not even recognisable, so no cell has a procedure.

Closure

REC: closed under union, intersection, complement, concatenation, star.

RE: closed under union, intersection, concatenation, star.

RE, complement: not closed.

Post: L ∈ RE and its complement ∈ RE ⇒ L ∈ REC, by dovetailing.

The four slips

1. Rice applied to a step-bounded property.

2. The reduction arrow reversed.

3. Recognition confused with decision.

4. Undecidable read as unrecognisable.

The decision procedure, in five steps

1. Run or language?

2. Is there a fixed bound? Then decidable.

3. Semantic and non-trivial? Then Rice.

4. Which direction is the reduction?

5. Which class? Read the ladder.

Quick revision questions

Is the halting language recognisable? Yes, and not decidable.

Is its complement recognisable? No, or halting would be decidable.

Is "takes more than 2016 steps on all inputs" decidable? Yes: finitely many inputs matter.

Is "accepts ε" decidable? No: semantic and non-trivial.

Is emptiness of a CFG decidable? Yes, by marking nonterminals.
