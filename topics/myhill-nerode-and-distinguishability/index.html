Topic and objective

TOPIC: The Myhill–Nerode theorem: two strings are equivalent when no ending tells them apart, the classes of that relation are the states of the smallest machine, and a finite number of classes is the same statement as regularity.

LEARNING OBJECTIVE: Given a language described in words, compute its index by naming the invariant a class records; justify that a machine with that many states is the smallest possible; prove a language is not regular by exhibiting infinitely many pairwise distinguishable strings; and say why a language can satisfy the pumping lemma and still be irregular.

I read the request as the theorem behind every “minimum number of states” question. The automata lesson in this repository builds subset construction, table-filling minimisation and state counting with distinguishing suffixes; it names this theorem in one sentence and does not build it. This page owns the theorem, its two directions, and the non-regularity proof that follows from it.

Two previous-year items are reproduced on this page because their year and question number were confirmed against a public record; no frequency is inferred from them.

Educational interpretation The theorem is examinable because the printed clause asks for finite automata and regular languages, and the two questions that clause generates — “how many states at least” and “is this language regular” — are both answered exactly by the index and by nothing else.

Prerequisites

  • Finite automata and minimisation — a DFA as five pieces, a run of a machine on a string, and table filling on a pair of states.
  • Sets and relations — an equivalence relation, a partition, and what it means for a relation to be right-invariant.
  • The pumping lemma — its statement, and that it is used to refute regularity.
  • Reading Σ* as the set of all strings over the alphabet, and ε as the empty string.

No counting beyond multiplication, no calculus, no probability. Every class, index and machine on this page is computed in the browser when the page loads.

The five ideas, in one line each

  • Equivalence is about futures — x ≈ y when every ending z gives xz and yz the same verdict.
  • The signature is the object — the set of endings that complete x. Equal signatures, same class.
  • The classes are the states — the index is the state count of the smallest machine, so the answer is exact.
  • Infinite index means not regular — a positive proof: exhibit the classes, and no finite machine can exist.
  • The pumping lemma is one-way — a language can satisfy it and still be irregular; the index cannot.

Intuition first: the machine cannot remember the journey, only the position

Two travellers arrive at the same junction from different roads. Everything they can still do is decided by the junction, not by the road. Educational interpretation

A deterministic machine is in exactly that position. After reading a and after reading aa it may or may not be in the same place; the only test available is to keep reading and see whether the two runs end in the same verdict. If no continuation ever separates them, then for the machine's purposes the two strings are the same place, and the machine may as well merge them.

The theorem is that sentence made exact: “the same place” is defined by the language alone, with no machine mentioned, and the number of places is the smallest number of states any machine could have.

Definition 1 — the relation

Fix a language L over an alphabet Σ. For two strings x and y over Σ, write

x ≈L y   iff   for every z ∈ Σ*,   xz ∈ L ⇔ yz ∈ L

Read it in words: no ending treats x and y differently. The symbol z ranges over every string over the alphabet, including the empty string.

Verified fact This is the relation of Hopcroft, Motwani and Ullman, Introduction to Automata Theory, Languages, and Computation, §4.1.3, where it is written x ≡L y.

Definition 2 — the signature

The signature of x is the set of endings that carry it into L:

sig(x) = { z ∈ Σ* : xz ∈ L }

Then x ≈ y exactly when sig(x) = sig(y). The signature is the same definition written as an object instead of as a universal statement, which is what makes it computable for a bounded ending length.

Mathematical derivation Two sets are equal exactly when they have the same members, and “xz ∈ L for every z” is a statement about which z are members. The two spellings say the same thing.

Definition 3 — the index

The index of L, written index(L), is the number of classes of ≈L. It may be finite or infinite.

The relation is an equivalence relation, so its classes partition Σ*: every string is in exactly one class, and the classes are disjoint. That is what lets them be counted and used as states.

Mathematical derivation Reflexivity, symmetry and transitivity all follow from “for every z, the two verdicts are equal”, because equality of truth values has those three properties. The partition then follows from the general fact that the classes of an equivalence relation partition the set.

Definition 4 — right-invariance

If x ≈ y then xa ≈ ya for every letter a.

This is the property that is not automatic. It says the class of a string determines the class of that string with one more letter, which is exactly what a transition function needs.

Mathematical derivation Take any ending z. Then xa z = x(az) and ya z = y(az), and az is itself an ending, so the two verdicts agree by the hypothesis on x and y.

Definition 5 — the quotient machine

When the index is finite, the classes are the states of a machine:

  • States — the classes of ≈L, written [x] for the class of x.
  • Start — the class of the empty string, [ε].
  • Transition — δ([x], a) = [xa], well defined by Definition 4.
  • Accepting — the classes whose members are in L.

Mathematical derivation A class is wholly inside or wholly outside L, because the empty string is one of the endings. So “its members are in L” is a property of the class, and the accepting set is well defined too.

Definition 6 — the theorem

L is regular  ⇔  index(L) is finite.    When it is finite, index(L) is the number of states of the smallest DFA for L, and that DFA is the quotient machine, unique up to renaming states.

Three statements, in the order they are proved. (a) Finite index gives a machine, because the quotient of Definition 5 has one state per class. (b) A machine gives a finite index, because two strings that reach one state are equivalent, so each class is a union of “reach this state” sets and there are at most n of them. (c) The two bounds meet: no machine has fewer than index(L) states, and the quotient has exactly that many.

Verified fact The statement and both directions are the Myhill–Nerode theorem as presented in Sipser, Introduction to the Theory of Computation, §1.4, and in Hopcroft, Motwani and Ullman, §4.1.3. The theorem is named for Myhill (1957) and Nerode (1958); the name is not printed in the GATE syllabus.

The same idea, said three ways

Three sentences that a GATE question can be written in, all of them the theorem:

  • “What is the minimum number of states in a DFA that accepts L?” — count the classes.
  • “Is L regular?” — is the number of classes finite?
  • “Show that L is not regular.” — exhibit infinitely many pairwise distinguishable strings, which is the same as infinitely many classes.

How to compute an index by hand

  1. Name the invariant. Write down a summary of a string that decides its future: the pair of parities, the value mod 3, the last two symbols, the length mod n.
  2. Show the invariant is enough. Two strings with the same summary must have the same signature, so the invariant does not split a class.
  3. Show the invariant is necessary. Two strings with different summaries must be separable by some ending, so the invariant does not merge two classes.
  4. Count the values. The number of reachable summaries is the index.

Educational interpretation Steps 2 and 3 are the two halves a minimum needs: step 2 gives a machine with that many states, step 3 rules out a smaller one.

How the bound on endings works

To compute signatures on a computer you must bound the ending length. The bound is justified, not guessed:

if two states of an n-state DFA disagree, they disagree on some ending of length < n

Take a shortest disagreeing ending z. If |z| ≥ n, the run of the machine on z repeats a state, and cutting out the loop gives a shorter disagreeing ending. So endings shorter than n suffice.

Mathematical derivation This is the pigeonhole principle applied to the n+1 states visited while reading z. It is the reason a finite table of signatures is a proof rather than a sample.

What has to be true before you use it

  • The alphabet must be fixed. A language over a different alphabet is a different language.
  • The relation is defined over all of Σ*, including strings longer than any you will enumerate.
  • The claim “index = n” needs both halves: a machine with n states, and a proof that no machine has fewer.
  • “Minimum” means minimum over deterministic machines unless the question says otherwise.

Four worked examples, each computed by the model on this page

Every number below was produced by the code that draws the animation, not copied from a solution key. The last card in the set is the one that answers a state-count question end to end.

Example 1 — even a’s and even b’s

The invariant is the pair (#a mod 2, #b mod 3) — here (#a mod 2, #b mod 2). Two strings with the same pair have the same signature, because the two parities decide whether any ending can complete the string; and two strings with different pairs are separated, because appending the letters that fix the difference gives a string with even counts for one and odd for the other.

The pairs are (0,0), (1,0), (0,1), (1,1) and each is reachable, so the index is 4.

Mathematical derivation The classes are [ε] = {ε, aa, bb, …}, [a], [b] and [ab]. The model lists them and checks that each is wholly inside or wholly outside L.

Example 2 — binary value divisible by three

Reading a bit b updates the remainder r to (2r + b) mod 3, so the invariant is the remainder, and it takes three values. All three are reachable: ε gives 0, 1 gives 1, 10 gives 2.

Index 3. The three-state machine a reader draws is the quotient, and the model checks it on every string up to length seven.

Mathematical derivation Two strings with the same remainder are equivalent because the update rule depends only on the remainder; two with different remainders are separated by the ending that makes the remainder zero, which is a fixed string of bits for each residue.

Example 3 — strings that end in 01

The invariant is the longest suffix that is a prefix of 01: nothing, 0, or 01. Three values, all reachable.

Index 3. Notice that the accepting class is the one whose members end in 01, and the other two classes are not accepting.

Mathematical derivation The three classes are separated by the endings ε, 1 and 01: appending 01 completes only the class that is “one symbol away”, and appending nothing accepts only the finished class.

Example 4 — anbn has no finite index

The strings ai for i = 0, 1, 2, … are pairwise distinguishable: the ending bi turns ai into a member and turns aj (for j > i) into a non-member, because it leaves more a’s than b’s.

Infinitely many pairwise distinguishable strings means infinitely many classes, which means no finite machine. The model checks the witness for every pair with i < j ≤ 5 and reports the class count rising as the ending bound grows.

Mathematical derivation A machine with n states has at most n classes, so an infinite index rules out every n at once. This is a positive proof, not a failed search.

Example 5 — a state-count question, answered end to end

How many states does a DFA need, at least, to accept the strings over {a,b} in which the number of a’s is divisible by 2 and the number of b’s is divisible by 3?

Step 1, the invariant. (#a mod 2, #b mod 3). Step 2, enough. Two strings with the same pair differ by a multiple of 2 a’s and a multiple of 3 b’s, so any ending adds the same residues to both and the verdicts agree. Step 3, necessary. Two strings with different pairs are separated: appending the letters that complete the first pair without completing the second gives a member and a non-member. Step 4, count. 2 × 3 = 6 pairs, all reachable, so the index is 6.

The model computes 6 independently, by comparing signatures over all strings up to length four. Mathematical derivation The multiplication is valid because the two conditions are independent; two conditions that interact would not multiply.

The empty language and Σ*

Both have index 1. For L = ∅ no string has any ending in L, so every signature is empty and all of Σ* is one class; the machine is a single non-accepting state. For L = Σ* every signature is all of Σ*, one class, one accepting state.

Mathematical derivation A one-class partition is the smallest an equivalence relation can have, and index 1 is the smallest a machine can be. Index 0 is impossible.

A one-letter alphabet

Over Σ = {a} every string is an, so a language is a set of lengths. The classes are decided by the length, and the index is the number of distinct signatures among lengths — which is why the GATE CSE 2011 item on ank is a counting question, not a drawing question.

Mathematical derivation Two lengths are equivalent exactly when every added length that completes one also completes the other, which is a statement about the set of accepted lengths.

The empty ending is always one of the tests

Because z = ε is allowed, two equivalent strings must already agree on membership. So a class can never contain one string in L and one outside L, and “accepting class” is well defined.

Mathematical derivation Substituting z = ε into the definition gives x ∈ L ⇔ y ∈ L. This is the first test, not an afterthought.

A language that pumps and is still not regular

L = { aibjck : i = 1 ⇒ j = k } satisfies the pumping lemma with pumping length 2: the model finds no failure among every string of L up to length 9. It is still not regular, because L ∩ ab*c* = { abjcj }, which has infinite index.

Mathematical derivation Regular languages are closed under intersection with a regular language, so if L were regular the intersection would be regular. It is not, by the distinguishability witness abi against the ending ci.

DFA against NFA at the minimum

The theorem's uniqueness and its lower bound are about deterministic machines. A non-deterministic machine for the same language can be smaller, and there is no unique smallest one.

Educational interpretation If a question says “NFA”, the index is an upper bound on the DFA you would get by subset construction, not a statement about the NFA's size.

Index 8 from a four-letter pattern

For “the third symbol from the end is a” over {a,b}, the invariant is the last three symbols read, which takes 8 values. All are reachable, so the index is 8, computed on this page.

Mathematical derivation Looking one symbol further back doubles the count, because each remembered symbol splits every class in two. That is why a short description can force a large machine.

1. “Two states are equivalent when they have the same outgoing letters”

Why it tempts. The transition table is the first thing you write, and comparing rows feels like comparing states.

Counterexample. p accepting with a→p, b→p; q not accepting with a→q, b→q. Identical labels, different futures; the empty ending separates them.

The rule. Equivalence compares the set of endings accepted, not the arrows leaving the state. Mathematical derivation The empty ending is a test, and the two states fail it.

2. “If the pumping lemma holds, the language is regular”

Why it tempts. The lemma is usually met as a tool for proving non-regularity, so “it worked” feels like a positive result.

Counterexample. { aibjck : i = 1 ⇒ j = k } satisfies the lemma with p = 2, verified on every string up to length 9 on this page, and is not regular.

The rule. The pumping lemma is necessary and not sufficient. The index is both. Mathematical derivation A regular language has a finite index; the example's index is infinite.

3. “Index = the number of strings up to some length”

Why it tempts. Enumeration is how you actually compute the classes, so the bound feels like part of the definition.

Counterexample. Comparing signatures over endings of length at most one splits the parity language into fewer classes than it has; the count only settles once the bound reaches the state count.

The rule. The index counts classes of the whole of Σ*. A finite computation is justified only by the bound “endings shorter than n suffice”.

4. “Two strings that are both in L are equivalent”

Why it tempts. Membership is the first test, so passing it feels like passing all of them.

Counterexample. In the parity language, ε and aa are both in L and are equivalent — but a and aaa are both outside L and are also equivalent, while ε and a differ. Membership is one test out of infinitely many.

The rule. Grouping by “both in L” gives a partition that is not right-invariant, so it is not a set of states. Mathematical derivation Right-invariance fails: two equivalent-by-membership strings can take one letter to strings with different membership.

5. “The minimum is whatever machine I drew”

Why it tempts. A correct machine is a complete answer to “give a DFA”, and the same drawing is then offered for “give the minimum DFA”.

Counterexample. Subset construction routinely produces unreachable states; deleting them changes nothing about the language and changes the count.

The rule. A minimum needs the lower bound. Either name the invariant and prove no two of its values merge, or run table filling on a machine you already know is reachable. Mathematical derivation Without the lower bound, nothing rules out a smaller machine.

6. “The theorem applies to any language”

Why it tempts. The definition of ≈L is written for an arbitrary language, so it looks universal.

Counterexample. The definition applies to anbn perfectly well; what fails is the finiteness. The quotient construction then has infinitely many states and is not a DFA.

The rule. The relation is defined for every language; the machine exists only when the index is finite. For non-regular languages the theorem is a refutation, not a construction.

Three question shapes, and the reasoning each demands

No claim is made here about how often each shape appears. The shapes are the ones the printed clause “regular expressions and finite automata … regular languages” generates, and each is answered by a different half of the theorem.

Shape 1 — “minimum number of states”

What it demands. An exact integer and a reason. Name the invariant, count its reachable values, and say that two strings with different values are separable.

The common wrong approach. Draw a machine, count its states, stop. That answers “how many states did you use”.

The trap inside the trap. Conditions that look additive often are not, and a condition like “k > 0” or “non-empty” costs one extra class because the empty string is separated from everything else. Mathematical derivation Indexes computed on this page: parity 4, divisible by 3 in binary 3, ends in 01 3, third from the end 8, no 111 4.

Shape 2 — “is this language regular?”

What it demands. A decision and a proof. For a “no”, the cleanest proof is infinitely many pairwise distinguishable strings: one ending per pair, chosen after seeing the pair.

The common wrong approach. A pumping-lemma attempt that picks the wrong pumping length or the wrong string, which proves nothing either way.

What to write. “The strings ai are pairwise distinguishable, since bi separates ai from every aj with j > i; so the index is infinite; so no DFA exists.” Three clauses, one proof.

Shape 3 — “which pair of states is equivalent”

What it demands. Table filling on the given machine: mark pairs that differ in acceptance, then propagate through letters until nothing changes.

The common wrong approach. Comparing outgoing labels, or comparing the states' names, or assuming that unreachable states matter.

What to check afterwards. Delete unreachable states first, then merge, then count. The count you get is the index of the language the machine accepts — and that is why the two procedures agree. Mathematical derivation On the four-state parity machine, table filling marks all 6 pairs, so the count is 4 and nothing merges.

Two sentences that cost marks

“It is regular because the pumping lemma holds.” — the lemma is necessary, not sufficient. The counterexample is on this page.

“The minimum is n because my machine has n states.” — a machine shows an upper bound. The lower bound is the classes.

The decision procedure, in four lines

Write the invariant → prove same invariant means same signature → prove different invariant means separable → count. If step 3 cannot be done for some pair, those two values are one class and the count drops. If step 3 can be done for infinitely many pairs, the language is not regular.

NATGATE CSE 1997 · Q20

What is the minimum number of states in a deterministic finite automaton that accepts all strings over {a, b} in which the number of a’s is divisible by two and the number of b’s is divisible by three?

Answer: 6

Each class records the pair (#a mod 2, #b mod 3). Two strings with the same pair behave identically under every ending, and two with different pairs are separated by the ending that completes one pair and not the other. There are 2 × 3 = 6 pairs and all are reachable, so the index is 6. The model computes 6 independently by comparing signatures.

Why 5 is wrong. Five states cannot separate six classes; two of the six pairs would have to share a state and then no ending could distinguish them.

Trap. Adding 2 + 3 = 5 instead of multiplying. That is right only when the conditions are exclusive, which they are not.

MCQGATE CSE 2011 · Q42

The language L over the alphabet {a} is L = { ank : k > 0, n a positive integer constant }. What is the minimum number of states needed in a DFA to recognise L?

  1. k + 1
  2. n + 1
  3. 2n+1
  4. 2k+1

Answer: B

The invariant is the length modulo n, which takes n values, and the empty string needs a class of its own because k > 0 excludes it while length 0 and length n are not equivalent. That gives n + 1. The model reports 4 classes for n = 3, and 3 when the condition is relaxed to k ≥ 0.

Why A is wrong. k is the multiplier in the language, not a parameter of the machine; the machine does not count multiples.

Why C and D are wrong. Nothing here remembers symbols independently; the alphabet has one letter and the state records only a length.

Trap. Answering n by forgetting that ε is excluded. The difference between k > 0 and k ≥ 0 is exactly one state.

NATOriginal practice

Over the alphabet {a, b}, how many states does the smallest DFA need for the language of strings whose third symbol from the end is a?

Answer: 8

The invariant is the last three symbols read, which takes 23 = 8 values, and every value is reachable. The model computes 8 by comparing signatures over strings up to length five.

Why 4 is wrong. Four states remember two symbols, which answers “the second symbol from the end”. Looking one symbol further back doubles the count.

Trap. Drawing a machine that shifts symbols and counting its boxes without checking that no two of them are equivalent.

MSQOriginal practice

Which of the following statements are true?

  1. A language is regular exactly when its index is finite.
  2. If two strings are equivalent, then appending the same letter to both keeps them equivalent.
  3. Every language has a finite index.
  4. The smallest DFA for a regular language is unique up to renaming its states.

Answer: A, B and D

A is one direction of the theorem and B is right-invariance, both verified in the model over all strings up to length three. D follows because every minimal machine has one state per class.

Why C is wrong. anbn has infinitely many classes: the strings ai are pairwise distinguishable.

Trap. Reading D as “the drawing is unique”. The states can be placed anywhere and named anything.

MCQOriginal practice

Which statement about the pumping lemma is correct?

  1. It characterises the regular languages exactly.
  2. It is necessary for regularity but not sufficient.
  3. It is sufficient for regularity but not necessary.
  4. It is neither necessary nor sufficient.

Answer: B

Every regular language satisfies the lemma, so it is necessary. The language { aibjck : i = 1 ⇒ j = k } satisfies it with p = 2 — no failure among every string of L up to length 9 on this page — and is not regular.

Why A is wrong. That is the Myhill–Nerode characterisation, not the pumping lemma.

Trap. Answering A because the lemma “feels” like the definition of regularity. It is a necessary condition with a visible gap.

NATOriginal practice

Over {a, b}, how many equivalence classes does the language of strings with no two consecutive a’s have?

Answer: 3

The invariant is “how the string ends”: nothing read yet or ending in b, ending in a, and dead. The model computes 3.

Why 2 is wrong. “Ends in a” and “ends in b” are separated by the ending a: one gives aa, the other gives ba.

Trap. Forgetting the dead class, which is needed because a string containing aa can never be repaired by any ending.

MCQOriginal practice

Two states p and q of a DFA have the same outgoing labels on every letter, and p is accepting while q is not. Which is true?

  1. p and q are equivalent, because their transitions agree.
  2. p and q are distinguishable, by the empty string.
  3. p and q are distinguishable only if some longer ending separates them.
  4. Equivalence cannot be decided without minimising the machine first.

Answer: B

The empty ending is one of the endings, and it separates an accepting state from a non-accepting one immediately. Table filling marks such a pair in round zero.

Why A is wrong. Matching labels is not equivalence; the futures differ.

Why D is wrong. Table filling decides it directly, and it is the minimisation procedure.

NATOriginal practice

Over {a, b}, what is the index of the language of strings in which the number of a’s is odd and the number of b’s is even?

Answer: 4

The invariant is again the pair of parities, four values, all reachable. Changing which pair is accepting changes the machine, not its size. The model computes 4.

Why 3 is wrong. Three values cannot encode two independent parities.

Trap. Assuming an odd/even condition needs one state fewer than an even/even one. The count is the number of classes, not the number of accepting ones.

Definitions, in the order to recall them

  • ≈L — x ≈ y iff for every z, xz ∈ L ⇔ yz ∈ L.
  • signature — sig(x) = { z : xz ∈ L }.
  • index — the number of classes of ≈L.
  • right-invariance — x ≈ y ⇒ xa ≈ ya.
  • quotient — states = classes, start = [ε], δ([x], a) = [xa], accepting = classes inside L.
  • theorem — L regular ⇔ index finite; then index = states of the smallest DFA, which is the quotient.

Indexes computed on this page

  • even a’s and even b’s — 4
  • odd a’s and even b’s — 4
  • binary value divisible by 3 — 3
  • strings ending in 01 — 3
  • no two consecutive a’s — 3
  • no three consecutive 1s — 4
  • #a divisible by 2 and #b by 3 — 6
  • a3k with k > 0 — 4; with k ≥ 0 — 3
  • third symbol from the end is a — 8
  • anbn — infinite

Decision procedure for a state count

Name the invariant → same invariant means same signature → different invariant means some ending separates → count the reachable values. Two of the four steps are the upper bound and two are the lower bound; skipping either half turns an exact answer into a guess.

Five traps

  • Matching outgoing labels is not equivalence.
  • The pumping lemma is necessary, not sufficient.
  • “Both in L” is not an equivalence class.
  • “k > 0” or “non-empty” costs one extra state.
  • Uniqueness is for deterministic machines only.

The two witnesses worth memorising

Non-regularity. anbn: the strings ai are pairwise distinguishable, since bi separates ai from every aj with j > i. Infinitely many classes, no machine.

The pumping lemma is not enough. { aibjck : i = 1 ⇒ j = k } pumps with p = 2 and is still not regular, because its intersection with ab*c* is { abjcj }.
