Topic and objective

TOPIC: The Chomsky hierarchy treated as one object — the four grammar types, the five language classes they produce, and the language that separates each neighbouring pair.

LEARNING OBJECTIVE: Given any language, name the smallest class in the chain that contains it by naming the machine that recognises it, and then justify the answer: with a pumping search, with a grammar whose rules you can check for shrinking, with a space argument, or with a complement argument. Read the closure table as two facts rather than three failures, and read the decidability table without assuming that a bigger class decides fewer questions.

I read this topic as the containment lattice plus its witnesses, not as four separate topics. Every claim in the lesson is either a rule shape you can inspect, a search this page runs, or a theorem named with its assumption. Where a class boundary needs a deep theorem rather than an example, the lesson says so instead of inventing a slogan.

The five ideas to leave with

  1. The four types are four rule shapes. Nothing else defines them.
  2. The chain has five classes, not four: REC sits between Type 1 and Type 0.
  3. Every link is strict, and each strictness needs its own witness language.
  4. CFL fails two operations that are really one: no complement means no intersection.
  5. Decidability is not monotone along the chain. REC decides more than CSL does.

Intuition: three desks in a post office

A clerk at the first desk may look at the letter in front of him and at nothing else. He can stamp it, pass it on, or refuse it, but he cannot remember how many letters came before it. That is a finite automaton, and the class it recognises is the regular languages.

A clerk at the second desk may keep one pile of notes beside him, and must take notes off the top. That is a stack. It is enough to check that the number of stamps equals the number of seals, because he can push one note per stamp and pop one per seal. It is not enough to check two independent equalities at once, because he cannot reach the note underneath without losing the one above it.

A clerk at the third desk may write anywhere on the letter itself, but he may not attach more paper. That is a linear bounded automaton, and the ceiling is what makes his work finite: there are only finitely many ways to write on a fixed-length letter, so he either finishes or repeats himself.

A clerk at the fourth desk may fetch more paper without limit. He can now compute anything computable, and he can also fail to finish, which is the halting problem. That is the top of the ladder, and the four desks are the four Chomsky types.

Formal definition: the four rule shapes

A grammar is four things: a set of terminals, a set of nonterminals, a start symbol, and a set of rules. Only the shape of the rules changes between the types. In the shapes below, capital letters are single nonterminals, lowercase letters are terminals, and Greek letters are strings of symbols, possibly empty.

Type 3, regular. Every rule is A → aB or A → a, with an optional A → ε. One nonterminal, always on the right end, and at most one terminal before it.

Type 2, context-free. Every rule is A → γ, where the right side is any string of terminals and nonterminals. One nonterminal on the left, no context around it.

Type 1, context-sensitive. Every rule is αAβ → αγβ with γ non-empty. Equivalently, the right side is never shorter than the left side, and one exception is allowed: S → ε if the start symbol never appears on a right side.

Type 0, unrestricted. Every rule is α → β with at least one nonterminal in α. No restriction on length or order.

Why the restriction is the definition

Mathematical derivation The Type 1 condition "never shrinks" is not decoration. If rules could shrink, a derivation could delete symbols and then rewrite the shorter string, and the set of reachable strings would no longer be bounded by the input length. The bounded-search argument that makes context-sensitive languages decidable depends entirely on non-shrinking.

The same idea explains why CB → BC is legal in a Type 1 grammar but illegal in a Type 2 one. It preserves length, so it satisfies the Type 1 condition; it has two symbols on the left, so it violates the Type 2 condition.

Five classes, and the witness that separates each pair

Four types give four classes, and a fifth class is inserted between the two at the bottom of the list. The chain is REG ⊂ CFL ⊂ CSL ⊂ REC ⊂ RE, and every link is strict: a proper subset, not an equality. A strict link is a claim that some language sits on the upper rung and not the lower one, and each claim needs its own witness.

  • REG ⊂ CFL. Witness { aⁿbⁿ }. Regular by no means: the pumping search in scene 3 has zero survivors at every length from 1 to 8. Context-free: three rules, S → aSb, S → ε.
  • CFL ⊂ CSL. Witness { aⁿbⁿcⁿ }. Not context-free: one stack cannot hold two independent counts. Context-sensitive: the seven-rule monotonic grammar in scene 4.
  • CSL ⊂ REC. Witness: any language in SPACE(n³) that is not in SPACE(n²). Decidable, because a polynomial space bound always halts. Not context-sensitive, because NSPACE(n) ⊆ SPACE(n²).
  • REC ⊂ RE. Witness: the complement of the halting set. It is not even recognisable, so it is outside RE entirely.

Verified fact The REC row is not one of Chomsky's four types. It is the class of languages decided by a machine that always halts, and it is standard to insert it between the context-sensitive and the recursively enumerable classes because CSL ⊆ REC ⊆ RE with both inclusions strict.

Why CSL is decidable: the finite-configuration argument

Mathematical derivation On an input of length n, a linear bounded automaton has a tape of n cells, a finite state set of size s and a head position in one of n places. So it has at most s × n × |Γ|ⁿ distinct configurations, where Γ is the tape alphabet. That number is finite.

Run the machine. If it has not halted after that many steps, it has repeated a configuration, so it will repeat forever. Either way you learn the answer in finite time. This is why every context-sensitive language is recursive — and the inclusion is strict, by the space hierarchy argument.

How to read the two tables without memorising 35 cells

The closure table and the decidability table look like memory work and are mostly not. Three regularities generate almost every cell.

One: union, concatenation, star, reversal and intersection with a regular set never fail. All five classes are closed under all five of those operations. If a statement question offers "not closed under union" for any class on this chain, it is false.

Two: complement is the operation that does the separating work. CFL does not have it and RE does not have it; REG, CSL and REC all do. From complement plus union you get intersection by De Morgan, so a class without complement may still have intersection — CSL proves that, since it has both.

Three: decidability is about halting, not about size. Membership, emptiness and finiteness are decidable from REG through REC and only semi-decidable at RE. Universality and equivalence survive only where you can compare two machines outright: REG by product construction, REC by running both. Everything in between loses them.

The counterexample that does the most work

Take L₁ = { aᵗbᵈcᵏ : i = j } and L₂ = { aᵗbᵈcᵏ : j = k }. Each is generated by a three-rule context-free grammar, so each is context-free.

Their intersection requires i = j and j = k, which forces all three counts equal. So L₁ ∩ L₂ = { aⁿbⁿcⁿ }, which is not context-free.

Verified fact This page enumerates both languages over the universe i, j, k ∈ {0,1,2,3,4} at load: 125 strings, 25 in L₁, 25 in L₂, 5 in both, 45 in the union, and the union size is checked against 25 + 25 − 5.

The one distinction that decides most questions

Recognise versus decide. A recogniser for L halts and accepts on members and may run forever on non-members. A decider always halts. RE is the recognisable class; REC is the decidable one.

Every "is this language recursive" question is really asking whether you have a machine that stops. Every "is this language r.e." question is asking whether you have a machine that says yes. They are different promises, and the halting set is the standard witness that the first is strictly stronger.

Worked example 1: place aⁿbⁿcⁿdⁿ on the ladder, honestly

Ask the four questions in order.

Is there a DFA? No. Four counts that must agree cannot be tracked with finitely many states. The regular pumping search, run on aᵙbᵙcᵙdᵙ, has zero survivors, exactly as it does for two letters.

Is there a CFG? No. One stack cannot hold two independent counts, and four counts need three. The context-free pumping lemma gives zero survivors here too.

Is there a monotonic grammar? This is the question where care is needed. The usual answer given in tutorials is "yes, Type 1", and the usual justification is "it is a natural extension of the aⁿbⁿcⁿ grammar". Unverified claim I could not verify a monotonic grammar for four or more letters during this run, and the claim that aⁿbⁿcⁿdⁿ is context-sensitive is not one I am willing to assert without a construction I can check.

What is safe to say. The language is decidable, by a machine that counts each block with a counter and compares them; a Turing machine can obviously do it. So the honest placement is: in REC, not in CFL, and not claimed to be in CSL. That is a better answer than a confident wrong rung, and it is the answer this lesson's procedure produces when a construction is missing.

Worked example 2: the pumping search, step by step

Take pumping length p = 3 and the string z = aaabbb, which has length 6 and so is at least p.

The lemma promises a split z = xyz with |xy| ≤ 3 and |y| ≥ 1. The allowed pairs are (|x|, |y|) equal to (0,1), (0,2), (0,3), (1,1), (1,2), (2,1): six splits, which is p(p+1)/2 = 6.

Each split is tested by pumping y zero, one, two and three times. Take (0,1): y = a, so pumping gives aabbb, aaabbb, aaaabbb, aaaaabbb. Three of the four are unbalanced, so the split fails.

Take (2,1): x = aa, y = a. Pumping gives the same family, and the same failures. Every one of the six splits fails, and the same happens at p = 1 through 8 with 1, 3, 6, 10, 15, 21, 28 and 36 splits. Zero survivors at every length.

Worked example 3: why the counts matter

The search is exhaustive over the splits the lemma allows, which is what makes it a proof for each fixed p. It is not exhaustive over p, which is why the proof needs the general argument: because |xy| ≤ p, the block y lies entirely inside the run of a's, so pumping it changes the a-count and not the b-count.

The numbers 1, 3, 6, 10, 15, 21, 28, 36 are the check that the search really is testing what it says it tests. If the split count were wrong, "zero survivors" would be a claim about the wrong set of splits.

Worked example 4: the monotonic grammar, checked rather than asserted

The seven rules are S → aSBC, S → aBC, CB → BC, aB → ab, bB → bb, bC → bc, cC → cc.

Check each for shrinking: 1→4, 1→3, 2→2, 2→2, 2→2, 2→2, 2→2. No rule shrinks, so the grammar is Type 1 by inspection rather than by hope.

Now a derivation for n = 2: S → aSBC → aaBCBC → aaBBCC → aabBCC → aabbCC → aabbcC → aabbcc. The swap rule moved the C past the B, which is what keeps the three blocks in order.

The bounded search at load applied rules 65 times and reached 41 distinct sentential forms. The only terminal strings of length at most 11 are abc, aabbcc and aaabbbccc. That is evidence for short n, not a proof for all n; the proof is the induction that the rule pattern makes available, which is a separate step and is not replaced by the search.

Worked example 5: the counting argument, in numbers

Over the one-letter alphabet {a}, a language is any set of strings. Fix a length bound n and the strings are n+1 in number, so there are 2ⁿ⁺¹ − 1 languages: for n = 9 that is 1023, for n = 10 it is 2047.

Machines are finite strings over a finite alphabet. Descriptions of length at most 50 bits number 2⁵¹ − 2, which is 2251799813685246.

Languages on strings of length at most 51 number 2⁵² − 1, which is 4503599627370495 — about twice as many, and that is with a description budget of only 50 bits.

Mathematical derivation Machines are countable: a countable union of finite sets. Languages over a non-empty alphabet are uncountable: as many as subsets of a countable set. So almost every language has no machine at all, which is the strongest statement in the lesson and needs no diagonal argument to see.

Worked example 6: which complement claim is true?

Four statements, one true.

(a) CFL is closed under complement. False: if it were, De Morgan would make it closed under intersection, and L₁ ∩ L₂ above is a counterexample.

(b) CSL is closed under complement. True — the Immerman-Szelepcsényi theorem, 1988. It does not follow from the definition and is not a small result.

(c) Every subclass of a class that is not closed under complement is also not closed. False, and (b) refutes it: CSL is a subclass of REC and CSL has complement. DCFL is another: closed under complement, not closed under union.

(d) RE is closed under complement. False: Post's theorem would then make every r.e. set recursive.

The boundaries where the definitions bite

Every one of these is a place where a confident statement becomes false if the boundary is ignored. They are the cases a well-written question is built on.

The empty string and the empty language

ε is a string of length zero. ∅ is a language with no strings at all. {ε} is a language with exactly one string, and it is regular, context-free, context-sensitive, recursive and r.e.

The empty language is also in all five classes. What is not true is that ε is a member of the empty language: it is a member of {ε} only. Three objects, two of them languages, one of them a string.

The Type 1 exception for the empty string

A strict reading of "no rule shrinks" forbids S → ε, which would make {ε} not context-sensitive. The standard definition therefore allows exactly that one rule, provided the start symbol never appears on a right side.

The condition is not decoration: without it you could derive S → ε and then rewrite the empty string, which breaks the bounded-search argument. With it, the empty string can only ever be produced at the very top of a derivation.

CSL and the complement, and why it is a theorem

The Immerman-Szelepcsényi theorem says nondeterministic space classes are closed under complement. Since CSL is NSPACE(n), CSL is closed under complement.

This is the exception that breaks the pattern "nondeterministic classes lose complement". It is also the reason CSL has intersection: with complement and union, De Morgan supplies it.

Decidability is not monotone

The number of the five questions each class can decide runs 5, 3, 3, 5, 0 along REG, CFL, CSL, REC, RE.

The jump back to 5 at REC is not a mistake. A decider can be run on two machines and their answers compared, which is why equivalence survives at REC and dies at CSL. Recognition power grows along the chain; decision power does not follow it.

Intersection with a regular set is not intersection

CFL is closed under L ∩ R when R is regular, and not closed under L₁ ∩ L₂ when both are context-free. Both statements are true and they are not in tension.

The closure holds because a finite automaton can be run alongside the push-down machine without a second stack. The non-closure holds because two stacks are needed once both sides are unbounded. The regularity of the second operand is the whole content of the first statement.

A bounded count is regular

{ aⁿbⁿ : n ≤ 100 } is finite, so it is regular. It looks exactly like the non-regular { aⁿbⁿ : n ≥ 0 }, and the difference is one word in the definition.

Any question that hides a bound inside a counting language is testing whether you read the quantifier. "At most n" with a fixed n is regular; "for all n" is not.

Six beliefs that cost marks, each with the smallest thing that refutes it

Each entry is the wrong belief, then the correction, then the smallest counterexample or argument that settles it. The counterexamples are the ones this page computes.

1. "Not regular, therefore context-free"

Wrong. The chain is strict at every link, so failing the bottom rung says nothing about the next one. aⁿbⁿcⁿ is not regular and also not context-free.

Fix. Ask each question separately. The four-question procedure in scene 10 exists because the questions are nested, not exclusive.

2. "Surviving the pumping lemma means the language is regular"

Wrong. The lemma is necessary, not sufficient. There are non-regular languages that satisfy it, so passing it proves nothing at all.

Fix. The lemma has one direction of use: to prove a language is not regular. Proving regularity needs a DFA, a regular expression or a closure construction.

3. "Context-sensitive means sensitive to context"

Wrong. The name comes from the rule shape αAβ → αγβ: the nonterminal A may be rewritten only in the context of the surrounding α and β.

Fix. The operational content of Type 1 is "no rule shrinks". That is the condition you check, and it is the condition the decidability argument uses.

4. "Two context-free languages intersect in a context-free language"

Wrong. { aᵗbᵈcᵏ : i = j } and { aᵗbᵈcᵏ : j = k } are both context-free and their intersection is aⁿbⁿcⁿ.

Fix. Union, concatenation and star compose context-free grammars; intersection does not, because there is no way to make two derivations agree on the same string.

5. "A bigger class decides fewer questions"

Wrong. REC decides all five of the questions in scene 9, while CSL — a strictly smaller class — decides only three.

Fix. Recognition power grows monotonically; decision power does not. A decider is a promise about halting, and halting is not implied by having a bigger tape.

6. "If a class is not closed under complement, no subclass is"

Wrong. CFL is not closed under complement, and DCFL — a proper subclass — is. CSL is closed under complement while its subclass CFL is not.

Fix. Closure properties are not inherited downwards, and they are not lost downwards either. Each class needs its own argument, which is exactly why the table has 35 cells rather than 7.

How this material is asked, and the reasoning each shape demands

Educational interpretation The four question shapes below are the ones the syllabus clauses make natural: closure statements, class placement, pumping-lemma use, and decidability classification. No frequency claim is made and no previous-year question is quoted.

Shape 1: statement questions (MSQ)

"Which of the following statements are true?" with options drawn from the closure and decidability tables.

What it demands. One cell of the table per option, plus the discipline not to reason by analogy between classes. The three regularities in the Build-up tab generate most cells; the exceptions — CFL complement, CFL intersection, RE complement, CSL complement — are the ones actually tested.

Procedure. For each option, name the class and the operation, then recall or derive the cell. Derive rather than recall whenever complement and intersection are both involved, because one implies the other.

Shape 2: place the language

"The language L = { ... } is (A) regular (B) context-free but not regular (C) context-sensitive but not context-free (D) recursive but not context-sensitive."

What it demands. A machine, not a guess. Count the independent comparisons the language needs: none means regular, one means one stack, two or more means beyond context-free.

Trap. The options are nested, so the smallest correct class is the answer. A language that is regular is also context-free, but option B says "but not regular", which is why the wording matters.

Shape 3: pumping lemma as a tool

"Use the pumping lemma to show L is not regular / not context-free", or "which string is a valid choice of z".

What it demands. A string that is in the language, long enough, and adversarial for every allowed split. The pumping length p is chosen by the opponent; you answer with a string in terms of p.

Trap. A valid z must be in L. A string that is already outside L makes the proof vacuous, and that is the commonest lost-mark answer.

Shape 4: decidable, undecidable, semi-decidable

"Which of these problems is decidable?" with one problem per class.

What it demands. The row of the decidability table, and the distinction between recognising and deciding.

Trap. Ambiguity of a context-free grammar is undecidable while equivalence of regular expressions is decidable — two questions that sound equally algorithmic and are not.

Practice set — answers withheld until you reveal them

Q1 MCQ Original

Which class is closed under complement while the class immediately below it in the chain is not?

(A) CFL, below REG
(B) CSL, below CFL
(C) REC, below CSL
(D) RE, below REC

Answer: B. CSL is closed under complement by the Immerman-Szelepcsényi theorem, and CFL — the class immediately below it — is not.

A inverts the chain: REG is below nothing here, and it has complement anyway. C is wrong in both halves: REC has complement, and so does CSL, so there is no contrast at that link. D is wrong because RE is the one class on the chain that lacks complement.

The table on this page computes this: the CFL row has "no" in the complement column and the CSL row has "yes".

Q2 MSQ Original

Let L₁ = { aᵗbᵈcᵏ : i = j } and L₂ = { aᵗbᵈcᵏ : j = k }. Which statements are true?

(A) Both are context-free.
(B) Their union is context-free.
(C) Their intersection is context-free.
(D) Their intersection is context-sensitive.

Answer: A, B and D.

A: each needs one comparison, so each has a three-rule grammar. B: CFL is closed under union, and the union here has 45 strings on the 5×5×5 universe. D: the intersection is aⁿbⁿcⁿ, which has the seven-rule monotonic grammar from scene 4.

C is false and it is the whole point: i = j together with j = k forces three equal counts, which needs two stacks. Note that A, B and D are all true while C is false — the pair "union is context-free, intersection is not" is exactly the distinction being tested.

Q3 NAT Original

A grammar has the rules S → AB, AB → BA, A → a, B → b. What is the smallest Chomsky type number that contains it? Answer as 0, 1, 2 or 3.

Answer: 1. The rule AB → BA has two nonterminals on the left, so it is not context-free, which rules out types 2 and 3. It preserves length (2 to 2) and no rule shrinks, so it satisfies the Type 1 condition.

The tempting answer is 0, on the reasoning that any unrestricted grammar is Type 0. That is true but not the question: the smallest type is asked, and every Type 1 grammar is also a Type 0 grammar. Type numbers describe the weakest restriction that holds, which is why "1" and not "0".

Q4 MCQ Original

Which of these problems is decidable for a context-free grammar G?

(A) Is L(G) equal to Σ*?
(B) Is L(G) empty?
(C) Is G ambiguous?
(D) Is L(G) equal to L(G′) for another context-free grammar G′?

Answer: B. Emptiness is decidable: mark the productive nonterminals and check whether the start symbol is marked.

A is universality, undecidable for context-free grammars. C is ambiguity, undecidable for context-free grammars — decidable for regular grammars. D is equivalence, undecidable in general, though decidable for deterministic push-down automata.

Note the shape of the trap: three of the four are decidable for regular languages, and the question is about context-free ones. The row of the table matters more than the operation.

Q5 MSQ Original

Which statements about the chain REG ⊂ CFL ⊂ CSL ⊂ REC ⊂ RE are true?

(A) Every link is a proper inclusion.
(B) Every class in the chain is countable.
(C) The set of all languages over {a} is countable.
(D) Some language is in none of the five classes.

Answer: A, B and D.

A: each strictness has a witness, listed in the Build-up tab. B: each class is defined by a finite description — a grammar or a machine — and finite descriptions are countable. D: since the classes are countable and the languages are not, some language is outside all five.

C is false. Languages over {a} correspond to subsets of a countable set, so there are uncountably many: on strings of length at most 51 alone there are 4503599627370495 of them. This is the counting argument in numbers, and it is what makes D true.

Q6 MCQ Original

A language L is r.e. and its complement is also r.e. What follows?

(A) L is regular
(B) L is context-free
(C) L is recursive
(D) L is context-sensitive

Answer: C. Post's theorem: run the two recognisers in parallel, one must halt, and its answer decides membership. So L is decidable.

A, B and D each claim more than the hypothesis gives. A decidable language can be arbitrarily hard inside REC; nothing in the hypothesis constrains the memory needed.

The hypothesis is not hypothetical: every regular, context-free and context-sensitive language satisfies it, since all of those classes sit inside REC. So the conclusion is the strongest statement available, and the other three are merely sometimes true.

Q7 NAT Original

For the regular pumping lemma applied to z = aⁿbⁿ with pumping length p = 4, how many splits satisfy |xy| ≤ p and |y| ≥ 1?

Answer: 10. The count is p(p+1)/2 = 4 × 5 / 2 = 10, matching the row this page computes for p = 4.

The trap is counting |xy| < p instead of ≤ p, which gives 6, or forgetting that y must be non-empty, which gives 15. The page's check asserts the p = 8 value of 36 against the same formula, so the formula is tested at both ends of the table.

Q8 MSQ Original

Which of the following are context-sensitive but not context-free?

(A) { aⁿbⁿcⁿ : n ≥ 0 }
(B) { aⁿbⁿ : n ≥ 0 }
(C) { ww : w ∈ {a,b}* }
(D) { aⁿbⁿcⁿdⁿ : n ≥ 0 }

Answer: A and C.

A: the seven-rule monotonic grammar on this page derives exactly it, and no context-free grammar can. C: ww needs the input copied, which a stack cannot do because it returns symbols in reverse; a monotonic grammar can, by marking pairs.

B is context-free, not merely context-sensitive. D is the careful case: it is certainly not context-free, but Unverified claim I could not verify a monotonic grammar for four letters during this run, so I do not assert that it is context-sensitive. Its status is decidable and non-context-free; anything finer needs a construction.

This is the distinction the lesson wants you to keep: "not context-free" is a proved negative, while "context-sensitive" is a proved positive, and they are different obligations.

Revision sheet

The chain and the witnesses

REG ⊂ CFL ⊂ CSL ⊂ REC ⊂ RE

  • REG → CFL: aⁿbⁿ
  • CFL → CSL: aⁿbⁿcⁿ
  • CSL → REC: a language in SPACE(n³) outside SPACE(n²)
  • REC → RE: the complement of the halting set

Machines

REG finite automaton · CFL push-down automaton · CSL linear bounded automaton · REC always-halting Turing machine · RE Turing machine. The memory is the difference: none, one stack, tape of length n, unbounded, unbounded.

Closure, in one line each

Closed under union, concatenation, star, reversal and intersection with a regular set: all five classes.

Complement: REG yes, CFL no, CSL yes, REC yes, RE no.

Intersection: REG yes, CFL no, CSL yes, REC yes, RE yes. The CFL failures are one fact twice, by De Morgan.

Decidability, in one line each

Membership: decidable for REG, CFL, CSL, REC; semi-decidable for RE.

Emptiness and finiteness: decidable for REG, CFL, CSL, REC; undecidable for RE.

Universality and equivalence: decidable for REG and REC; undecidable for CFL, CSL and RE.

Decision procedure for an unfamiliar language

  1. Count the independent comparisons the language needs. None: regular. One: context-free. Two or more: above context-free.
  2. Ask whether a monotonic grammar exists, and check every rule for shrinking. If yes: CSL.
  3. Ask whether a machine that always halts exists. If yes: REC.
  4. Ask whether the complement is describable. If not: RE and nothing lower.
  5. Never answer a rung you cannot construct. "Decidable and not context-free" is a complete answer; "context-sensitive" without a grammar is a guess.

Four traps, one line each

1. Not regular does not mean context-free.

2. Surviving a pumping lemma proves nothing; failing it proves non-membership of the class.

3. A bounded count is regular; an unbounded one is not.

4. Decidability does not fall as the class grows: REC decides more than CSL.
