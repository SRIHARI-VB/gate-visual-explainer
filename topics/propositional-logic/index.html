Topic and objective

TOPIC: Propositional logic — propositions, the five connectives, truth tables, logical equivalence, tautology and contradiction, and the validity of argument forms, at the depth GATE CSE asks them.

LEARNING OBJECTIVE: Given a formula over at most three propositional variables, decide whether it is a tautology, a contradiction or a contingency; decide whether two formulas are logically equivalent; and decide whether a proposed argument form is valid — each time by building the whole truth table and reading it correctly, including the vacuous rows of an implication.

I read "propositional logic" as the truth-functional part of the syllabus item "Propositional and first order logic": no quantifiers, no predicates, no proof systems. First-order logic is the next lesson and is linked from the Revision tab.

Prerequisites

  • None from logic. This lesson starts from the word "statement".
  • Comfort with enumeration: writing every case of a small finite set and checking each one.
  • Reading a table by columns as well as by rows.
  • Nothing about sets, relations or quantifiers is assumed.

The five ideas

  1. A proposition has exactly one truth value; a command or an open sentence has none.
  2. Each connective is defined by its whole column, not by the word it borrows from English.
  3. An implication is false in exactly one of its four rows — the two rows with a false hypothesis are true.
  4. Two formulas are equivalent only if their columns agree in every row.
  5. An argument form is invalid the moment one row makes all premises true and the conclusion false.

Conventions used throughout

Verified fact Notation: ¬ (not), ∧ (and), ∨ (or), ⊕ (exclusive or), → (implies), ↔ (if and only if). Truth values are written T and F, and 1 and 0 in code. Rows of a two-variable table run TT, TF, FT, FF; the first variable alternates slowest. Row order is a convention, not part of the meaning — any order is correct provided every combination appears exactly once.

Intuition first: a promise, not a cause

Someone tells you: "If you score above ninety, I will gift you a cycle." Later you want to know whether they lied. There are four worlds to check. You scored above ninety and got the cycle — no lie. You scored above ninety and got nothing — that is the lie. You scored below ninety and got a cycle anyway — generous, still no lie. You scored below ninety and got nothing — also no lie, because nothing was ever promised to you.

Educational interpretation The promise is the implication, the score is the hypothesis and the cycle is the conclusion. The analogy earns its keep in the two awkward rows: an implication is not a claim that the conclusion happens, it is a claim that a particular combination never happens — hypothesis true together with conclusion false.

Definition 1 — proposition

A proposition is a declarative sentence that is either true or false, but not both. Its truth value is which of the two it is.

"7 is prime" is a proposition with value T. "2 + 2 = 5" is a proposition with value F. "Close the door" is a command, so it has no truth value. "x + 1 = 3" is an open sentence: it becomes a proposition only after x is given a value.

Definition 2 — the connectives

A compound proposition is built from propositions by connectives. Each connective is defined by a truth table — that table is the definition, and the English word is only a hint.

PQ¬PP∧QP∨QP⊕QP→QP↔Q

Derivation Every entry follows from the reading in words: ¬ flips; ∧ needs both; ∨ needs at least one; ⊕ needs exactly one; → forbids true-then-false; ↔ asks for agreement.

Definition 3 — implication, and the four English phrasings

In P → Q, P is the antecedent (hypothesis) and Q the consequent (conclusion). It is false only when P is true and Q is false. All four of these mean the same arrow:

  • P only if Q
  • Q if P
  • P is sufficient for Q
  • Q is necessary for P

Exam trap "P if Q" is the converse Q → P. Moving the word "only" moves the arrow.

Definition 4 — equivalence

Two formulas are logically equivalent, written F ≡ G, when they have the same truth value in every row of every valuation. Equivalent formulas may be substituted for one another anywhere.

Derivation P → Q ≡ ¬P ∨ Q, because the two columns agree in all four rows. This one identity removes every arrow and is the workhorse of the whole subject.

Definition 5 — the three classes

Read the final column of a formula's truth table:

  • all T → tautology (valid)
  • all F → contradiction (unsatisfiable)
  • mixed → contingency (satisfiable, not valid)

Definition 6 — a valid argument

An argument is a list of premises and a conclusion. It is valid when no row makes every premise true and the conclusion false.

Derivation Validity is a tautology test: form the single formula (P₁ ∧ P₂ ∧ … ) → C. The argument is valid exactly when that formula is a tautology. Validity is about form; sound additionally requires the premises to be true in the world, which no truth table can decide.

Precedence, in one line

¬ binds tightest, then ∧, then ∨, then →, then ↔. Implication is right associative: P → Q → R means P → (Q → R). Brackets always win, and writing them is never wrong.

Worked example 1 — a three-variable formula, built one column at a time

Show that (P → Q) ∧ (Q → R) → (P → R) is a tautology. Eight rows, because three variables give 2³ = 8.

Step 1 — write the two implications

Column A is P → Q: false only in the row P true, Q false. Column B is Q → R: false only where Q true, R false.

PQRA=P→QB=Q→R
TTTTT
TTFTF
TFTFT
TFFFT
FTTTT
FTFTF
FFTTT
FFFTT

Step 2 — conjunct, then imply

Column C = A ∧ B is true only where both are true: rows 1, 5, 7, 8. The conclusion P → R is false only in rows 3 and 4. Now check the whole formula C → (P → R): the only rows where C is true are 1, 5, 7, 8, and in every one of them P → R is also true. So the formula is true in all eight rows.

Derivation C is true in exactly rows 1, 5, 7, 8. P → R is true in 1, 2, 5, 6, 7, 8. Since {1,5,7,8} ⊆ {1,2,5,6,7,8}, no row has C true and P → R false, so C → (P → R) is a tautology and the argument form (hypothetical syllogism) is valid.

Why this method is safe

You never reason about meaning, only about columns. The cost is 2ⁿ rows; for three variables that is eight lines of arithmetic. This is the procedure to use when a formula is short but looks unfriendly.

Worked example 2 — from English to a formula, and back

"You will pass only if you practise, and you will practise unless you are ill."

Translation, step by step

  1. Name the atoms. P = you pass, Q = you practise, R = you are ill.
  2. "P only if Q" puts the arrow P → Q. Not Q → P: passing requires practice, practice does not require passing.
  3. "Q unless R" means Q if not R, that is ¬R → Q. "Unless" introduces the exception, so it negates the condition.
  4. Join with ∧. The whole sentence is (P → Q) ∧ (¬R → Q).

The two translation traps

"Only if" and "if" put the arrow at opposite ends. "Unless" is ¬R → Q, and is equivalent to R ∨ Q — which is often the quicker form to reason with.

Derivation ¬R → Q ≡ ¬(¬R) ∨ Q ≡ R ∨ Q. So "Q unless R" is the same claim as "R or Q", and a question that offers R ∨ Q is offering the same formula in disguise.

Reading a formula back into English

Take ¬(P ∧ ¬Q). Push the negation inside with De Morgan: ¬P ∨ ¬¬Q, then ¬P ∨ Q, which is P → Q.

Derivation ¬(P ∧ ¬Q) ≡ ¬P ∨ ¬(¬Q) ≡ ¬P ∨ Q ≡ P → Q. Three identities, each one a substitution you could check row by row.

Worked example 3 — testing an argument form for validity

Premises: "If the file is corrupt then the checksum fails." "The checksum did not fail." Conclusion: "The file is not corrupt." Is the form valid?

The test

Let P = file corrupt, Q = checksum fails. The form is (P → Q) ∧ ¬Q, therefore ¬P. The single test formula is ((P → Q) ∧ ¬Q) → ¬P. Its column over the four rows:

PQ(P→Q)∧¬Q→ ¬P
TTFT
TFTT
FTFT
FFFT

All four rows are true, so the form is valid. This is modus tollens.

Compare: the form that fails

Now swap the premise to Q: (P → Q) ∧ Q, therefore P. Row P false, Q true makes both premises true and the conclusion false, so this form is invalid — affirming the consequent. One row is a complete disproof.

Derivation In the row P = F, Q = T: P → Q is T, Q is T, so the premise conjunction is T, while P is F. True premises with a false conclusion: invalid.

Habit worth forming

Never judge a form by how plausible the English sounds. Translate, write the test formula, and check every row — the row you skip is where the counterexample lives.

Edge case 1 — the vacuous rows

"If 2 + 2 = 5, then I am the king of India" is a true implication. The hypothesis is false, so the implication was never tested, and logic counts an untested conditional as true. Every theorem of the form "if P then Q" with an empty P is true for the same reason.

Derivation P → Q ≡ ¬P ∨ Q. With P false, ¬P is true, so the disjunction is true whatever Q is.

Edge case 2 — "unless"

"I will go unless it rains" is ¬R → G, which is R ∨ G. The exception negates the condition, and it does not mean R → ¬G.

Both "I go" and "it rains" can be true at once under the intended claim.

Edge case 3 — necessary versus sufficient

"Q is necessary for P" is P → Q. "Q is sufficient for P" is Q → P. Necessary points at the conclusion; sufficient points at the hypothesis. Swap the words and the arrow reverses.

Neither phrasing asserts the other direction, and neither asserts that P actually happens.

Edge case 4 — sentences that are not propositions

"This sentence is false" has no consistent truth value, so it is not a proposition of the logic studied here. Questions, commands and exclamations are excluded for the simpler reason that they are not declarative.

An open sentence such as x + 1 = 3 is excluded until x is bound — that binding is what quantifiers do in first-order logic.

Edge case 5 — the row count is not optional

A formula over three distinct variables has eight rows. Six rows cannot cover every combination, and the two missing rows are exactly where a counterexample can hide.

Derivation Each variable doubles the row count: 2, then 4, then 8. Distinctness matters — P ∨ P has one variable, not two, so it needs two rows.

Edge case 6 — zero and one variable

A formula with no variables, such as 1 → 0, has a one-row table and is simply a constant: false. A formula with one variable has two rows. The rule 2ⁿ covers both cases without special treatment.

This is why "T" and "F" can be treated as formulas in their own right.

Misconception 1 — "P → Q is the same as Q → P"

Why it feels right: the two sentences share all their words, and English often implies the reverse informally.

Counterexample: "If it is a square then it is a rectangle" is true; "if it is a rectangle then it is a square" is false. The row P false, Q true separates the two columns.

Correct belief: only the contrapositive ¬Q → ¬P is equivalent to P → Q.

Misconception 2 — "a false hypothesis makes the implication false"

Why it feels right: a false premise sounds like a broken statement.

Counterexample: "If 1 = 0 then 2 = 2" is true. The implication is broken only by a true hypothesis with a false conclusion.

Correct belief: exactly one row is false, and it is the one with P true and Q false.

Misconception 3 — "¬(P ∧ Q) is ¬P ∧ ¬Q"

Why it feels right: the negation looks like it should attach to each part and leave the connective alone.

Counterexample: P false, Q true. Then P ∧ Q is false so ¬(P ∧ Q) is true, while ¬P ∧ ¬Q is false. They disagree in two of the four rows.

Correct belief: ¬(P ∧ Q) ≡ ¬P ∨ ¬Q. The connective flips.

Misconception 4 — "valid means true"

Why it feels right: both words sound like approval.

Counterexample: "All fish fly; a salmon is a fish; therefore a salmon flies" is a valid form with a false premise, so its conclusion is not true.

Correct belief: valid is about the form; sound means valid plus true premises. Only soundness delivers a true conclusion.

Misconception 5 — "or is exclusive"

Why it feels right: in everyday choices, "tea or coffee" usually excludes both.

Counterexample: "Students who have taken C or mathematics may enrol" does not expel a student who took both. That is ∨, not ⊕.

Correct belief: ∨ includes the both-true row. If a question wants exclusion it writes ⊕ or says "but not both".

Misconception 6 — "every row I checked was true, so it is a tautology"

Why it feels right: three true rows out of four looks like overwhelming evidence.

Counterexample: P → Q is true in three of its four rows and is not a tautology; the fourth row is false.

Correct belief: a tautology needs every row true, and with n variables that means all 2ⁿ of them.

How this topic is asked

Propositional logic appears in the Discrete Mathematics part of Engineering Mathematics. The question types below are the forms the topic takes; no specific previous-year question is reproduced or claimed here, because none was verified against an actual paper for this lesson.

Pattern 1 — classify a formula

"Which of the following is a tautology / contradiction / contingency?" Options are four short formulas.

Procedure: eliminate by finding one false row for each candidate. You need a full column only for the one that survives. Fastest eliminations: a formula with an arrow is usually a contingency; a formula of the form X ∨ ¬X is a tautology.

Pattern 2 — which formula is equivalent

"Which of the following is logically equivalent to ¬(P → Q)?" Rewrite first: ¬(¬P ∨ Q) ≡ P ∧ ¬Q.

Procedure: remove arrows, push negations inward with De Morgan, then compare shapes. If two shapes still differ, test a single row designed to separate them.

Pattern 3 — counting

"How many rows does the truth table of a formula in n variables have?" is 2ⁿ. "How many distinct Boolean functions of n variables exist?" is 2^(2ⁿ).

Procedure: count the distinct variables first — repeated variables do not add rows. For n = 2 the answers are 4 and 16; for n = 3, 8 and 256.

Pattern 4 — is the argument valid

Premises in English or in symbols, four conclusions offered.

Procedure: translate, form (premises) → conclusion, and look for the one row with all premises true and the conclusion false. If you find one, the form is invalid; if the set of rows with all premises true is empty, the form is vacuously valid.

Pattern 5 — translate English

"Only if", "unless", "necessary", "sufficient", "but not both".

Procedure: fix the atoms first, then place the arrow from the condition to the consequence. Write the four phrasings from the Build-up tab on your rough sheet before the exam and check each translation against them.

The four traps that cost marks

  • Reading P → Q as the converse, or "proving" a claim by proving its converse.
  • Calling a formula a tautology after checking three rows of four.
  • Negating a conjunction or disjunction without flipping the connective.
  • Treating "valid" as "true", so a valid argument with a false premise is marked wrong.

MCQBasicOriginal GATE-style

Which of the following is a tautology?

  1. (P → Q) ∧ (Q → P)
  2. (P → Q) ∨ (Q → P)
  3. (P → Q) ∧ (P ∧ ¬Q)
  4. (P ∨ Q) → (P ∧ Q)

Answer: B — (P → Q) ∨ (Q → P)

In every row at least one of the two implications is true: when P and Q agree, both are true; when they differ, exactly one is false and the other true. So the disjunction is true in all four rows.

Why the others fail: A is false when P is true and Q is false. C is false whenever P is true, because it conjoins P → Q with P ∧ ¬Q. D is false when exactly one of P, Q holds.

Concept tested: a disjunction of two implications is easier to be a tautology than a conjunction of them.

NATBasicOriginal GATE-style

A formula is built from the four distinct variables P, Q, R, S using any connectives. How many rows does its truth table have? Answer as an integer.

Answer: 16

Rows = 2ⁿ with n = 4 distinct variables, so 2⁴ = 16.

Trap: the connectives and the length of the formula do not change the count. Only the number of distinct variables does.

MCQBasicOriginal GATE-style

What is the contrapositive of "If it rains, the ground is wet"?

  1. If the ground is wet, it rains.
  2. If it does not rain, the ground is not wet.
  3. If the ground is not wet, it did not rain.
  4. If the ground is wet, it did not rain.

Answer: C

The original is R → W. The contrapositive swaps the ends and negates both: ¬W → ¬R.

Why the others fail: A is the converse W → R. B is the inverse ¬R → ¬W. D negates only one side, which is neither.

Concept tested: only the contrapositive is equivalent to the original.

MSQApplicationOriginal GATE-style

Which of the following are logically equivalent to P → Q? (One or more may be correct.)

  1. ¬P ∨ Q
  2. ¬Q → ¬P
  3. Q → P
  4. ¬(P ∧ ¬Q)

Answer: A, B and D

A is the defining identity. B is the contrapositive. D is A in disguise: ¬(P ∧ ¬Q) ≡ ¬P ∨ ¬¬Q ≡ ¬P ∨ Q.

Why C fails: Q → P is the converse, false in the row P false, Q true, where P → Q is true.

Trap: MSQ awards nothing for a partial answer, so check every option rather than stopping at the first two correct ones.

MCQApplicationOriginal GATE-style

The premises are P → Q and ¬Q. Which conclusion follows by a valid form?

  1. P
  2. ¬P
  3. Q
  4. Nothing follows.

Answer: B — ¬P

Both premises are true only in the row P false, Q false. In that row ¬P is true, so ¬P is entailed. This is modus tollens.

Why the others fail: A would be affirming the consequent with the roles rearranged, and is not entailed. C contradicts the second premise. D is wrong because a conclusion does follow.

Shortcut and its assumption: you may reason via the contrapositive ¬Q → ¬P only because contraposition is an equivalence — state that when you use it.

NATApplicationOriginal GATE-style

How many distinct Boolean functions of three variables exist? Answer as an integer.

Answer: 256

A function of three variables is a column of 2³ = 8 truth values, and each of the 8 entries can be chosen freely, giving 2⁸ = 256 distinct columns.

Trap: 2^(2ⁿ) with n = 3 is 256, not 64. The exponent is 2ⁿ = 8, not 2n = 6.

MCQConceptualOriginal GATE-style

What is the truth value of the statement "If 2 + 2 = 5, then 1 = 1"?

  1. True
  2. False
  3. Undefined, because the hypothesis is false
  4. It depends on the meaning of "="

Answer: A — True

The hypothesis is false, so the implication is vacuously true, and here the conclusion is also true, which makes it true for two independent reasons.

Why C is the popular wrong answer: an implication is never undefined; every row of its table has a value. Confusing "not tested" with "no truth value" is the error.

Concept tested: vacuous truth, which appears in GATE options designed to feel absurd.

MSQConceptualOriginal GATE-style

Which of these argument forms are valid? (One or more may be correct.)

  1. P → Q, P, therefore Q
  2. P → Q, ¬Q, therefore ¬P
  3. P → Q, Q, therefore P
  4. P → Q, ¬P, therefore ¬Q

Answer: A and B

A is modus ponens and B is modus tollens; both test formulas are tautologies. C and D both fail at the single row P false, Q true.

Why C and D look right: each is a mirror image of a valid form. Mirroring is exactly the move the arrow forbids.

Concept tested: the same one row kills both invalid forms, which is why one counterexample settles a form completely.

MCQAnalysisOriginal GATE-style

Under the usual precedence, which formula is equivalent to P → Q → R?

  1. (P → Q) → R
  2. ¬P ∨ ¬Q ∨ R
  3. P ∧ Q ∧ ¬R
  4. P → (R → Q)

Answer: B

The arrow is right associative, so P → Q → R is P → (Q → R). Removing both arrows: ¬P ∨ (¬Q ∨ R), which is ¬P ∨ ¬Q ∨ R.

Why A fails: left bracketing is a different formula. It disagrees with the right-bracketed one in the rows where P is false and R is false.

Why C fails: it is the negation of B, so it is true in exactly the rows where B is false.

Assumption stated: this uses the standard convention that → associates to the right. A question that brackets explicitly overrides the convention.

Truth tables worth memorising

PQ¬P∧∨⊕→↔
TTFTTFTT
TFFFTTFF
FTTFTTTF
FFTFFFTT

Identities to carry

  • P → Q ≡ ¬P ∨ Q ≡ ¬Q → ¬P
  • P ↔ Q ≡ (P → Q) ∧ (Q → P) ≡ ¬(P ⊕ Q)
  • P ⊕ Q ≡ (P ∨ Q) ∧ ¬(P ∧ Q)
  • ¬(P ∧ Q) ≡ ¬P ∨ ¬Q
  • ¬(P ∨ Q) ≡ ¬P ∧ ¬Q
  • P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R)
  • ¬¬P ≡ P

Decision procedures

  1. Tautology? Build all 2ⁿ rows; check the last column is all T.
  2. Equivalent? Compare columns row by row; one disagreement settles it.
  3. Valid form? Form (premises) → conclusion; look for true premises with a false conclusion.
  4. Satisfiable? Find one row where the formula is true.

Traps in one glance

  • Converse and inverse are not equivalent to the original; the contrapositive is.
  • Vacuous truth: false hypothesis makes the implication true.
  • "P if Q" is Q → P; "P only if Q" is P → Q.
  • Negation flips the connective.
  • Valid ≠ true; sound = valid + true premises.
  • 3 variables → 8 rows; 2 variables → 16 functions.

Five quick checks

  1. Is ¬(P → Q) ≡ P ∧ ¬Q? (Yes — remove the arrow, then De Morgan.)
  2. Is P → (Q ∧ R) ≡ (P → Q) ∧ (P → R)? (Yes.)
  3. Is (P → Q) → R ≡ P → (Q → R)? (No — one row separates them.)
  4. How many rows does (P ∨ ¬P) ∧ Q have? (Two — one distinct variable Q, since P ∨ ¬P is constant.)
  5. Does P → Q entail Q → P? (No — invalid form.)
