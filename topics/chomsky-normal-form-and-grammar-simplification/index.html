Topic and objective

TOPIC: Simplifying a context-free grammar and converting it to Chomsky normal form — the four passes (useless symbols, the empty production, unit productions, the two-shape restriction), the order the passes must run in, and the arithmetic the resulting shape makes possible.

LEARNING OBJECTIVE: Given any context-free grammar, compute its productive and reachable sets, its nullable set, its unit pairs and its terminal helpers; produce an equivalent grammar in Chomsky normal form; and use the shape to state the derivation length of a string of length n, the node counts of its parse tree, and the length bound a grammar with k nonterminals imposes.

I read the request as the conversion and its arithmetic, not another tour of context-free grammars: CFGs and push-down automata introduces the four-tuple, derivations, parse trees and ambiguity, and quotes normal forms once. This page owns what that lesson only names: the four passes as algorithms, the order that makes them correct, the helper count, and every count that follows from the binary shape. Every grammar on this page is stored in the page’s own model, every pass is executed on it in the browser, and 41 checks re-verify the numbers the captions quote.

Prerequisites

  • A context-free grammar as a four-tuple, a derivation, a parse tree, leftmost and rightmost derivation — CFGs and push-down automata.
  • The empty string, written ε, and the empty right-hand side, written as a rule that ends at the arrow.
  • Fixpoint computation: start with nothing known, repeat until nothing changes. Used four times on this page.
  • Sets, subsets and intersections; a full binary tree with n leaves has n − 1 internal nodes.
  • Powers of two: 2k−1 is the largest length a grammar with k nonterminals is forced to produce somewhere.

Five ideas this page establishes

  1. Useless means unproductive or unreachable; the useful set is the intersection, and the teaching grammar fails each test once.
  2. The four passes must run as empty → unit → useless → shape, because each earlier pass can create work for a later one.
  3. Terminal isolation costs one helper per terminal; splitting a right-hand side of k symbols costs k − 2 helpers.
  4. In normal form every derivation of a string of n letters has exactly 2n − 1 steps and the tree has 3n − 1 nodes.
  5. Membership becomes a triangle of n(n+1)/2 cells at a cost of order n cubed — and with k nonterminals some string has length at most 2k−1.

The one sentence worth remembering

A normal form changes nothing about the language and everything about the shape, and the shape is what turns a derivation into arithmetic.

Intuition first

You are packing a suitcase and the airline will only accept two brick shapes: a long brick made of two small bricks joined, and a single small brick. Your job is to rebuild every object you own out of those two shapes without changing what the objects are. You can glue bricks together, you can throw away pieces that never end up in the finished object, and you can drop the “empty” brick that some objects have inside them.

That is grammar simplification. The rules of a grammar are the objects; Chomsky normal form is the two allowed bricks; the four passes are the rebuilding steps. What you gain is a uniform shape, and a uniform shape is what lets you count: if every object is built from two-brick joins and single bricks, then an object with n small bricks must have been built in exactly 2n − 1 moves, always, whatever order you glue them in.

Formal definition: the grammar, and the two normal forms

A context-free grammar is a four-tuple (V, Σ, S, P). V is the set of nonterminals — symbols you are allowed to rewrite. Σ is the set of terminals — the letters of the finished string. S is the start symbol, one member of V. P is a set of rules, each of the form A → α, where A is one nonterminal and α is any string of symbols, possibly empty.

A grammar is in Chomsky normal form when every rule is A → B C, with A, B, C nonterminals, or A → a, with a a single terminal. One exception is allowed and only when needed: S → ε, the start symbol producing the empty string.

A grammar is in Greibach normal form when every rule is A → a α, where a is a terminal and α is a possibly empty string of nonterminals. The empty string is written ε; the symbol → is read “may be rewritten as”.

Pass 1: useless symbols

A nonterminal is productive if some derivation from it ends in a string of terminals. A nonterminal is reachable if it appears in some derivation that starts at S. A nonterminal is useful if it is both. Delete every rule that mentions a non-useful symbol, then delete the symbol.

Productive is computed bottom-up to a fixpoint; reachable is computed top-down from S. The two are independent: a symbol can be reachable and barren (it never produces terminals) or productive and unreachable (nothing ever mentions it).

Pass 2: the empty production

A nonterminal is nullable if it derives ε. Compute the nullable set to a fixpoint. Then for every rule, add one copy for each subset of its nullable positions that you delete, skipping the copy that deletes everything. Finally delete every rule of the form A → ε.

If S itself is nullable then ε is in the language, and the standard repair is a new start symbol S0 with S0 → S and S0 → ε. One empty rule survives, by necessity.

Pass 3: unit productions

A unit production is a rule A → B whose right-hand side is a single nonterminal. A unit pair is a pair (A, B) with A ⇒ B using only unit productions; every symbol is paired with itself. Compute the pairs by closure, then give A a copy of every non-unit rule of every B it is paired with, and delete all unit rules.

A unit step produces no terminal and no pair of nonterminals, so it is exactly the step the count of 2n − 1 cannot accommodate.

Pass 4: the shape

Two rule shapes are still illegal: a terminal standing beside another symbol, and a right-hand side of three or more symbols. First give every terminal that shares a right-hand side its own nonterminal — one per terminal, shared by every rule that uses it. Then split each remaining right-hand side of k > 2 symbols into a chain, which needs k − 2 new nonterminals.

The order of those two sub-steps is fixed: isolate terminals first, split second. Splitting first moves terminals into helper rules and the helper count no longer matches the rule.

Worked example 1 — the grammar used throughout

V = { S, A, B, X, Y }, Σ = { a, b }, start S

S → A B | a b | X A → a A | ε B → b B | b X → X c Y → a

  1. Productive. A is productive because A → ε has nothing to derive; B and S follow; Y is productive because Y → a. X is not productive: its only rule is X → X c, which never reaches a terminal. — set { S, A, B, Y }.
  2. Reachable. From S the rules mention A, B and X. Nothing mentions Y. — set { S, A, B, X }.
  3. Useful. The intersection is { S, A, B }. X fails productivity, Y fails reachability, so both go, and S → X and X → X c and Y → a go with them.
  4. Result. Three nonterminals, six rules, and the language is unchanged.

Worked example 2 — the empty production

nullable set: { A }

  1. A is nullable because A → ε. B is not, S is not. — the empty string is not in the language, so no new start symbol is needed.
  2. S → A B has one nullable position, so it yields S → A B and S → B.
  3. A → a A has one nullable position, so it yields A → a A and A → a.
  4. B → b B and B → b are untouched. A → ε is deleted.
  5. Result. S → A B | B | a b; A → a A | a; B → b B | b. Seven rules, and a unit rule S → B that did not exist before.

Worked example 3 — the unit production

unit pairs: (S,S) (A,A) (B,B) (S,B)

  1. Only S → B is a real unit rule; the other three pairs are the trivial symbol-with-itself pairs.
  2. S receives every non-unit rule of B: S → b B and S → b.
  3. The unit rule S → B is deleted. No other unit rule exists.
  4. Result. S → A B | a b | b B | b; A → a A | a; B → b B | b. Eight rules, three nonterminals, no unit rule.

Worked example 4 — the shape

  1. Terminals beside other symbols. S → a b needs helpers for both a and b. Introduce X1 → a and X2 → b, once each, and rewrite every offending rule: S → a b becomes S → X1 X2; S → b B becomes S → X2 B; A → a A becomes A → X1 A; B → b B becomes B → X2 B.
  2. Splitting. After isolation the longest right-hand side is two, so no binarisation helper is needed. That is why this grammar needs exactly two helpers.
  3. Result. S → A B | X1 X2 | X2 B | b; A → X1 A | a; B → X2 B | b; X1 → a; X2 → b. Ten rules, five nonterminals, every rule of an allowed shape.
  4. Check. The model tests all 126 strings of length 1 to 6 over {a,b} against both grammars: each accepts 21, and they are the same 21.

Worked example 5 — GATE CSE 2024 Set 1, Question 49 (verified PYQ)

Let G be a context-free grammar in Chomsky normal form with Σ = {a, b, c} and V containing 10 variable symbols including the start symbol. The string w = a30b30c30 is derivable from S. Find the number of steps (applications of rules) in the derivation.

  1. Length of the string: 30 + 30 + 30 = 90.
  2. Every derivation in normal form has exactly 2n − 1 steps, whatever the order: 2(90) − 1 = 179.
  3. The ten variables are decoration. They bound the length of some string in the language at 29 = 512, which 90 does not exceed, so the question is consistent — but they never enter the count.
  4. Answer: 179, which matches the published key.

Worked example 6 — the textbook grammar, as a second check

S → A S A | a B A → B | S B → b | ε

  1. Nullable: B, then A, but not S, so ε is not in the language.
  2. After the empty pass: S → A S A | S A | A S | S | a B | a; A → B | S; B → b.
  3. After the unit pass: S and A both receive A’s and S’s non-unit rules, including the single rule S → S, which is dropped as trivial.
  4. After the shape: five nonterminals and fifteen rules, including X1 → a and X2 → A S.
  5. Check. Both grammars accept the same 120 strings of length 1 to 6 over {a,b}, and neither generates ε.

Edge case 1 — the empty string is in the language

Take S → a S | ε. S is nullable, so ε is in the language and no pass may remove its last empty rule. The repair adds S0 → S and S0 → ε and makes S0 the start symbol.

Computed: the converted grammar is S0 → ε | X1 S | a and S → X1 S | a, with X1 → a. It is in normal form, it keeps ε, and it accepts the same strings of length up to five.

Edge case 2 — the start symbol appears on a right-hand side

If S appears on the right of some rule, the empty-string repair cannot simply reuse S as the new start symbol, because the new S0 → ε rule would also make every recursive use of S vanish. A fresh symbol is required.

This is the reason the standard statement is “a fresh start symbol”, not “the start symbol”. On this page the fresh name is generated and checked for collision.

Edge case 3 — a grammar with no terminals at all

Let S → A, A → B, B → A. Nothing is productive, so the useful set is empty. The language is empty.

A conversion routine must decide what to do here: the correct answer is the empty language, which is represented by a grammar with one nonterminal and no rules. Reporting “conversion failed” is wrong; reporting the empty language is right.

Edge case 4 — one rule, one letter

S → a is already in normal form: it is the second allowed shape. S → ε is the only other acceptable single rule, and only at the start symbol.

A one-letter language therefore needs no work at all, and a question that asks “is this grammar in normal form?” is often answered by that single line.

Edge case 5 — ambiguity survives the conversion

Normal form constrains the shape of every rule, not the number of derivations. An ambiguous grammar converts into an ambiguous grammar in normal form: the same string keeps two distinct parse trees, each with exactly 2n − 1 internal nodes.

So the counts are statements about each tree, not about the string. That is exactly why they are usable in a pumping argument: you may pick any tree and still know its size.

Edge case 6 — the order of the four passes

On S → A B, A → a, B → C, C → D, D → ε every symbol is useful at the start. Delete the empty rule and D, C and B become unproductive.

Computed: after that pass the productive set is exactly {S, A}, so a second useless pass is needed. Run that second pass and you are left with S → A and A → a: the language is right, but S → A is a unit production the unit pass has already gone past, so the grammar is not in normal form. The standard order gives S → a and A → a with no unit rule.

“A normal form removes ambiguity”

Why it tempts: normal forms are used when a deterministic parse is wanted, and the two ideas appear in the same chapter.

Minimal counterexample: S → A A, A → A A | a is in normal form, and the string aaa has two distinct parse trees in it.

Correct rule: normal form constrains rule shapes only. Determinism needs an LR or LL condition on the grammar, which is a different property.

“All empty productions can always be removed”

Why it tempts: the algorithm for removing them is standard and usually works.

Minimal counterexample: S → a S | ε generates a*. Removing the empty rule gives a+, a different language.

Correct rule: exactly one empty rule may survive, at a fresh start symbol, and only when ε is in the language. GATE CSE 2008 Q50 statement II is false for this reason.

“The number of variables affects the number of steps”

Why it tempts: the 2024 question prints “10 variable symbols” in the same sentence as the string.

Minimal counterexample: S → A A, A → a uses two variables and takes 3 steps for a string of length 2; the 2024 grammar uses ten and takes 179 for 90. Both are 2n − 1.

Correct rule: the step count depends on the length of the string alone. The variable count only bounds how long a shortest string can be.

“Unreachable and unproductive are the same failure”

Why it tempts: both are described as “useless” in the same paragraph.

Minimal counterexample: in the teaching grammar, X is reachable but barren and Y is fertile but unreachable. Deleting by one test alone leaves the other symbol in place.

Correct rule: useful = productive ∩ reachable. Both tests, and the order of computation matters: productivity first, then reachability, because reachability alone can walk into a barren symbol.

“A unit production is harmless, so leave it”

Why it tempts: the language is unchanged, so the grammar is still correct.

Minimal counterexample: add S → A to a normal-form grammar and the step count of every derivation changes while the string does not, so 2n − 1 no longer describes that grammar.

Correct rule: a unit step is a step, and the counting theorem assumes every step is one of the two shapes. The language being right is not the property being claimed.

“Converting to normal form makes the language regular, or finite”

Why it tempts: after conversion every rule looks small and machine-like, and the table of scene ten looks like a finite automaton.

Minimal counterexample: the converted teaching grammar generates akbm for every k and m, an infinite non-regular language, and its rules are two symbols wide.

Correct rule: normal form preserves the language class. A context-free language stays context-free, an infinite one stays infinite, and the stack is still needed.

Pattern 1 — the step count

The question gives a grammar in normal form and a string, and asks for the number of steps, or the number of internal nodes, or the total nodes. Reasoning: steps = 2n − 1, internal nodes = 2n − 1, total nodes = 3n − 1, where n is the length of the string. GATE CSE 1994 Q20 asks it in general form; GATE CSE 2024 Set 1 Q49 asks it with n = 90.

The common wrong approach: dividing by something, or letting the variable count in. If a printed number of variables or alphabet size appears, it is decoration unless the question is about the length bound.

Pattern 2 — is this grammar in normal form?

Four grammars, one of which has every rule of an allowed shape. Reasoning: check each rule against two shapes only. A terminal beside a nonterminal disqualifies; three symbols disqualify; a lone nonterminal disqualifies.

The distractors are usually a rule with a terminal beside a nonterminal, and a rule with three symbols — the two shapes pass 4 removes.

Pattern 3 — the conversion itself

Convert a given grammar, or count the new nonterminals the conversion needs. Reasoning: one helper per distinct terminal that shares a right-hand side, plus k − 2 per right-hand side of k > 2 symbols, after isolation.

The trap is counting a helper per rule instead of per terminal, and forgetting that isolation runs before splitting.

Pattern 4 — a consequence of the shape

Statements about what a normal form does or does not allow: can every empty rule be removed, are derivation trees binary, does the form remove ambiguity, is the length of some string bounded. Reasoning: each statement is answered by one property of the shape.

GATE CSE 2008 Q50 is the model: four statements, answer I, III and IV only, because statement II fails when ε is in the language.

The procedure, in four lines

1. Write the shape of every rule in the question. 2. Decide which of the two allowed shapes it is, or which one it violates. 3. Apply the count for that shape — 2n − 1 steps, 3n − 1 nodes, n(n+1)/2 cells. 4. Only then look at the options and name the substitution behind each wrong one.

NAT GATE CSE 2024 Set 1, Q49

Let G be a context-free grammar in Chomsky normal form with Σ = {a, b, c} and V containing 10 variable symbols including the start symbol S. The string w = a30b30c30 is derivable from S. Find the number of steps (applications of rules) in the derivation S ⇒* w.

Answer: 179. |w| = 90, and every derivation in normal form has exactly 2n − 1 = 179 steps.

The ten variables bound the length of a shortest string at 29 = 512, which is consistent with 90 but irrelevant to the count. A common wrong answer is 89 (counting only the binary steps) or 90 (counting the Greibach figure).

MCQ GATE CSE 1994, Q20

A grammar G is in Chomsky normal form if all its productions are of the form A → BC or A → a. Suppose G is a CFG in CNF and w is a string in L(G) of length n. How long is a derivation of w in G?

  1. n
  2. 2n
  3. 2n − 1
  4. n2

Answer: (C) 2n − 1. n − 1 steps create the nonterminal spine and n steps turn each nonterminal into a terminal.

(A) is the Greibach figure, which counts one terminal per step. (B) counts the terminal steps twice over. (D) is a table size, not a derivation length.

MSQ GATE CSE 2008, Q50

Which of the following statements are true?

I. Every left-recursive grammar can be converted to a right-recursive grammar and vice-versa.
II. All ε-productions can be removed from any context-free grammar by suitable transformations.
III. The language generated by a CFG all of whose productions are of the form X → w or X → wY, where w is a string of terminals and Y is a nonterminal, is always regular.
IV. The derivation trees of strings generated by a CFG in CNF are always binary trees.

  1. I, II, III and IV
  2. II, III and IV only
  3. I, III and IV only
  4. I, II and IV only

Answer: (C) I, III and IV only. Statement II fails: if ε is in the language, the empty rule at the start symbol cannot be removed without changing the language.

I is true by the standard conversion. III is true because those rules are right-linear, which is exactly a regular grammar. IV is true because in normal form a node has either two nonterminal children or one terminal child, so deleting the terminal leaves leaves a full binary tree.

MCQ Original practice

Which one of these grammars is in Chomsky normal form?

  1. S → A B | a
  2. S → A B C | a
  3. S → a B
  4. S → A a

Answer: (A). A B is two nonterminals and a is one terminal.

(B) has a right-hand side of three symbols, which must be split. (C) and (D) each put a terminal beside a nonterminal, which must be isolated into a helper. These are exactly the two shapes pass 4 removes.

NAT Original practice

A string of length 12 belongs to the language of a grammar in Chomsky normal form. How many steps does every derivation of it have?

Answer: 23. 2(12) − 1 = 23.

The same tree has 23 internal nodes and 35 nodes in total, since 3(12) − 1 = 35. In Greibach normal form the same string would take 12 steps.

NAT Original practice

A grammar in Chomsky normal form has 6 nonterminals and generates a nonempty language. What is the largest possible length of a shortest string in its language?

Answer: 32. A shortest string has length at most 2k−1 = 25 = 32, and the chain grammar S → N1N1, N1 → N2N2, …, N5 → a reaches it exactly.

The model checks this bound for k = 2, 3, 4 and 5 by generating each chain grammar and taking its longest derivable string: the values are 2, 4, 8 and 16.

NAT Original practice

The single rule S → a B c D is to be brought into Chomsky normal form. Counting terminal helpers and splitting helpers together, how many new nonterminals are needed?

Answer: 4. Two terminal helpers (one for a, one for c) give S → X1 B X2 D, a right-hand side of 4 symbols, which needs 4 − 2 = 2 splitting helpers. Two plus two is four.

Counting three would be the answer if the splitting were done first and one helper were reused; the order is fixed, isolation first, so the count is 4.

MCQ Original practice

Which pass can create a unit production that was not in the grammar before?

  1. Removing useless symbols.
  2. Removing ε-productions.
  3. Isolating terminals into helpers.
  4. None: unit productions can only be removed, never created.

Answer: (B). S → A B with A nullable produces the copy S → B, which is a unit production.

(A) only deletes. (C) turns S → a b into S → X1 X2, which is not a unit rule. (D) is false, and it is the reason the unit pass runs after the empty pass.

MSQ Original practice

Which of these statements about Chomsky normal form are true?

I. Every derivation of a string of length n has exactly 2n − 1 steps.
II. A parse tree of a string of length n has 3n − 1 nodes in total.
III. Removing ε-productions can introduce new useless symbols.
IV. A grammar in Chomsky normal form cannot be ambiguous.

Answer: I, II and III only. IV is false: S → A A with A → A A | a is in normal form, and aaa has two parse trees in it.

I and II are the two counts, and they hold for every parse tree separately. III is what the order counterexample shows: deleting D → ε makes D, then C, then B unproductive.

NAT Original practice

Using the membership table on a grammar in Chomsky normal form, how many cells does a string of length 7 require?

Answer: 28. 7 × 8 / 2 = 28.

The table costs order n cubed overall: for length 7 the number of split checks is 7 × 6 × 8 / 6 = 56, each check looking at two cells.

MCQ Original practice

Which property is preserved by every one of the four passes?

  1. The number of nonterminals.
  2. The language, possibly minus the empty string.
  3. Whether the grammar is ambiguous.
  4. Whether the grammar is left-recursive.

Answer: (B). Language preservation is the invariant each pass is proved against; the empty string may be lost only if the repair is skipped.

(A) changes on the first pass: five nonterminals become three. (C) can change: an ambiguous grammar can convert to an unambiguous-looking one if the ambiguity came from a unit or empty rule, and the reverse is also possible. (D) changes as soon as terminals are isolated.

The four passes, in the only order that works

1 empty productions → nullable set, then copies, then delete
2 unit productions → unit pairs by closure, copy, then delete
3 useless symbols → productive ∩ reachable
4 the shape → isolate terminals, then split long sides

Each pass preserves the language, except that pass 1 may drop the empty string, which is put back by the fresh start symbol when the language contains it. Every pass can create work for a later one, which is why the order is fixed.

Helper counts in pass 4

Terminal helpers: one per distinct terminal that shares a right-hand side, however many rules use it. On the teaching grammar that is two, for a and b.

Splitting helpers: k − 2 for a right-hand side of k > 2 symbols, counted after isolation. S → a B c D needs 2 terminal helpers and then 2 splitting helpers, four in all.

Definitions to have cold

Productive: some derivation ends in terminals. Reachable: appears in a derivation from S. Nullable: derives ε. Unit pair: A ⇒ B using only single-nonterminal rules. Chomsky normal form: A → BC or A → a, plus S → ε only when needed. Greibach normal form: A → aα with α a string of nonterminals.

Five traps

The variable count never enters the step count. A normal form does not remove ambiguity. One empty rule may have to stay. A leftover unit rule invalidates 2n − 1 for that grammar. Unreachable and unproductive are different failures, and both must be tested.

One line to carry into the exam

Read the shape of each rule, then apply the count for that shape: 2n − 1 steps, 3n − 1 nodes, n(n+1)/2 cells, 2k−1 bound.
