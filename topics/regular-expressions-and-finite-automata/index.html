Topic and objective

TOPIC: Regular expressions and finite automata — the first clause of GATE 2027 Section 6, Theory of Computation.

LEARNING OBJECTIVE: Given a language described in words, decide how many states a minimal deterministic machine needs and justify that number by naming a distinguishing suffix for every pair of states you keep. Convert an NFA to a DFA by subset construction and say why the reachable count is usually far below the 2n bound. Minimise a given machine by table filling. Convert a regular expression to a machine by Thompson's construction and back by state elimination. Decide membership of a union, intersection or complement. And refute a non-regular language with the pumping lemma.

I read this topic as one question asked four ways: how much of the input must the machine remember? Constructing a machine answers it, counting minimal states prices it, minimising a machine removes what was remembered unnecessarily, and the pumping lemma proves when no finite amount of remembering can work. Every definition, count and previous-year question in this area is that sentence at a different scale.

Prerequisites

  • Sets, subsets and cardinality. A language is a set of strings and an NFA state is a set of states, so the whole lesson is set notation. Built in Sets and Set Operations.
  • Functions and what single-valued means. A transition function returns exactly one value, which is the whole meaning of deterministic. Built in Functions and Their Properties.
  • Equivalence relations and partitions. Minimality is a partition of the strings into indistinguishable classes. Built in Relations and Their Properties.
  • Counting and the pigeonhole principle. The pumping lemma is a pigeonhole argument, and every string-counting question is counting. Built in Counting and Combinatorics.
  • Graphs and reachability. A machine is a directed labelled graph and "reachable subset" is graph reachability. Built in Graphs: Connectivity and Structure.

Nothing about grammars, pushdown machines or Turing machines is assumed; those are the next two lessons in this subject.

The five ideas to leave with

  1. The state is the machine's entire memory. Every count in this topic is a count of distinctions that must be remembered.
  2. Two strings need different states exactly when some suffix separates them. That is a proof of minimality, not a feeling.
  3. Nondeterminism changes the description, never the power. An n-state NFA becomes a DFA of at most 2n states, and usually far fewer.
  4. Independent counters multiply, and the size of the product is the product of the sizes; the minimal size divides it.
  5. Finitely many states cannot count without bound, which is why anbn has no machine and the pumping lemma can prove it.

Intuition: the doorman with a fixed number of moods

A nightclub doorman has to decide, for each person arriving, whether to let them in. He has no notebook and no calculator. He has a fixed set of moods — say four of them — and a rule that says which mood he moves to for each kind of visitor. When the last visitor has passed, the mood he is in decides the answer. That is the entire machine.

Because there are only four moods, he can only ever remember four things about the queue behind him. If a decision needed five facts at once, no doorman could make it, however patient. That is the shape of every result in this topic: a language is a set of strings, a machine is a doorman, and the interesting question is always how many moods the job actually needs.

Educational interpretation The analogy is a teaching device. It fixes the two facts that matter: the machine's memory is its state, and the number of states is the whole cost.

Formal vocabulary, every symbol glossed

Alphabet (Σ). A finite set of symbols. Here it is usually the two symbols 0 and 1, or a and b.

String. A finite sequence of symbols. ε is the empty string, of length zero.

Σ* is the set of every string over Σ, including ε. Language. Any subset of Σ*.

DFA. A five-tuple (Q, Σ, δ, q0, F): states, alphabet, transition function, start state, accepting states. δ(q, a) is the one state reached from q on symbol a.

NFA. The same five parts except that δ(q, a) is a set of states, possibly empty. ε-closure(S) is S plus every state reachable from S along ε-arrows only.

The one sentence the whole topic turns on

After reading a prefix, the machine's only knowledge is which state it stands in. So for a language L, two prefixes u and v must lead to different states exactly when some suffix w puts one of uw, vw in L and the other out.

states of the minimal DFA = number of classes of this relation

This is the Myhill–Nerode statement. It is the only honest justification for a state count, and it is why the answer to "how many states" is never a matter of taste.

Three checks that catch most slips

Check one. Count addresses, not arrows. A machine's size is |Q|, and a missing arrow means an incomplete machine, not a smaller one.

Check two. Reachability first. States that cannot be reached from the start state are not part of the machine and must be deleted before any count.

Check three. Every merge you claim needs a witness. To keep two states apart, name the suffix that separates them; to merge them, show that no suffix can.

Nondeterminism, and the one construction that removes it

Nondeterminism is not a new kind of power; it is a shorter way to write the same thing. The subset construction turns any NFA into a DFA, and its cost is the only thing that changes.

Subset construction, in four lines

1. Start from ε-closure({q0}). That set is the DFA start state.

2. For a DFA state S and a symbol a, collect every target of every a-arrow leaving any state in S, then close under ε.

3. If the result is new, add it as a new DFA state. Repeat until nothing new appears.

4. Mark S accepting if S contains any NFA accepting state.

What it costs, and what it does not

There are at most 2|Q| subsets, so the DFA has at most 2n states before minimisation. That is an upper bound and it is tight for some languages, which is why nondeterminism can be exponentially more compact.

It is not a floor. A four-state NFA whose only reachable subset is one state has a one-state minimal DFA. Both halves of GATE 2018's question come from exactly this distinction.

ε-arrows are free, and that is the trap

An ε-arrow consumes no input. It can be followed any number of times, including zero, and immediately after another ε-arrow. So every step of a run — the first one included — must be closed under ε.

The commonest error is to close the target set but not the start set. A machine whose start state has an ε-arrow begins in the closure of the start state.

The two directions between expressions and machines

Expression to machine: Thompson's construction. A symbol costs two states and one arrow. Union and star each add two states and up to four ε-arrows; concatenation adds nothing, because the fragments are joined at a shared state. The output is correct but never minimal.

Machine to expression: state elimination. Label each arc with an expression. To delete a state k, replace the arc i to j by the union of what it was with the path i to k, then the loop on k any number of times, then k to j. Delete until one arc remains from start to accept.

Both directions are mechanical, which is why they are safe. Neither is the efficient way to answer a question by hand — for that, use the structure of the language and count.

Minimising, counting, and the three language operations

Minimisation and counting are the same theorem from two ends: one takes a machine and finds its classes, the other takes a language and counts them.

Table filling, in four lines

1. Delete unreachable states.

2. Mark every pair where exactly one state is accepting.

3. Repeat: mark any unmarked pair whose two states go to an already-marked pair on some symbol.

4. When a pass marks nothing, the unmarked cells are the merge classes.

Counting a machine that tracks a pattern

For "ends with a fixed word", one state per length of the pattern that the string's suffix currently matches, so the pattern of length m costs m+1 states. For "does not contain a fixed word", the same chain plus one dead state.

For "contains a fixed word", the accepting state becomes a sink that loops to itself, because the pattern can never be undone.

Counting a machine that counts

A condition on the count of one symbol modulo m costs m states. Two independent conditions cost the pairs, so m times n before minimisation.

size of the product machine = |Q1| × |Q2|

The minimal size divides that product, and it equals it when the two conditions do not interact — which is the usual case on a paper, and never an assumption you may skip silently.

The three operations on languages

Union. Run both machines on the same string in lock-step, accept if either accepts. State pairs, at most |Q1|·|Q2|.

Intersection. The same product, accept if both accept.

Complement. Flip the accepting marks of a complete deterministic machine. The count does not grow.

Concatenation and star need an ε-NFA, then subset construction and minimisation, and their cost is not bounded by anything as tidy as a product.

Where the pumping lemma sits

Finitely many states means finitely many prefixes can be told apart, so any sufficiently long string must revisit a state, and the loop between the two visits can be repeated. That is the whole proof, and it only ever runs one way.

The lemma is necessary for regularity, not sufficient: some non-regular languages satisfy it. So it can refute a language and can never certify one. A question that asks you to prove a language is regular wants a machine or a regular expression, not the lemma.

(0+1)*(0+1)(0+1)*, and why it is two states

The number of states in the minimum sized DFA that accepts the language of (0+1)*(0+1)(0+1)* is ___.

Step 1 — simplify the expression. The middle group consumes exactly one symbol, and the two stars absorb everything else, so the expression is (0+1)(0+1)*, which is "length at least one".

Step 2 — name the distinctions. Two classes only: ε, and every non-empty string. From ε the empty suffix is not accepted; from any non-empty string it is.

Step 3 — the count. 2 states: a non-accepting start and an accepting sink. Mathematical derivation Verified here against all 511 strings of length at most eight.

(a+b)*b(a+b): seven states, then four

The smallest number of states needed in a DFA accepting (a+b)*b(a+b) is ___.

Step 1 — read the expression. It is w1 · b · c: at least two symbols, and the second-to-last is b.

Step 2 — the obvious machine. Remember the last two symbols. That is 1 + 2 + 4 = 7 states: ε, a, b, aa, ab, ba, bb.

Step 3 — minimise. Table filling merges {ε, a, aa} and {b, ab}, leaving 4 classes: one for "ends in a or empty", one for "ends in b with no b before it", and two accepting ones.

The quotient machine was compared with the seven-state original on every string up to length nine and agreed on all 1023.

Closely confused: "ends with 011" against "contains 011"

Ends with 011. States track the longest matched prefix: ε, 0, 01, 011. On reading 011 the machine is accepting, but a following 0 drops it back to "0". Four states.

Contains 011. The same four states, except that the accepting one is a sink: once the pattern has appeared, every extension is accepted. Four states.

The witness. The string 0110 separates them: it contains 011, and it does not end with 011. Both machines are minimal at four states, which is exactly why the two questions are easy to confuse and worth a mark.

Worked examples, page 2 of 2

Four counts that look unrelated and are the same three moves: identify the residue or the class, count it, then check that nothing can be merged.

Divisible by 2 but not by 3, and the residue that must not be marked

L = { x in {a,b}* : the number of a's in x is divisible by 2 but not by 3 }. The minimum number of states is ___.

Step 1 — one counter. Both conditions are conditions on the count of a, so a single counter modulo 6 suffices: 6 states.

Step 2 — which residues accept. A count is divisible by 2 and not by 3 exactly when its residue modulo 6 is 2 or 4. Residue 0 is divisible by both, so it is excluded.

Step 3 — the count. 6, and the model confirms that all six residues stay pairwise distinguishable, so nothing merges. The published key is 6.

A product modulo 7 over four symbols

Σ = {1,2,3,4}; prod(x) is the product of the symbols of x modulo 7, with prod(ε) = 1. For L = { x : prod(x) = 2 }, the minimum number of states is ___.

Step 1 — the reachable residues. Starting from 1, multiplying by 3 cycles through all of 1,3,2,6,4,5. Every nonzero residue is reachable, and 0 never is.

Step 2 — distinguishability. For two distinct residues r and s, the string consisting of one 3 repeated is enough to separate them, because multiplying by a power of 3 is a bijection on the group.

Step 3 — the count. 6. The model checks all 340 strings of length at most four against the definition of the product, then confirms that all six residues stay distinguishable.

Two more counts, and the trap they share

"Ends with 10" (GATE 2015 Set 2). Three classes: last symbol is not 1, ends in a single 1, ends in 10. So 3 states. A fourth state for ε is wrong, because ε behaves exactly like "last symbol is not 1".

"Does not contain 111" (GATE 2023). Run length 0, 1, 2 are all accepting; run length 3 is a dead state. So 4 states. Answering 3 forgets the dead state.

Both traps are the same trap: a state that "adds nothing" to the picture is still a state, and the only test for whether it is needed is whether some suffix distinguishes it from the others.

Where each rule stops holding

Every rule in this topic has a condition attached. These are the conditions, and what happens on the other side of each.

Zero is divisible by everything

A count of zero is divisible by 2 and divisible by 3. So in "divisible by 2 but not by 3", the residue 0 is excluded, and marking it accepting turns the right answer into a wrong one.

The same edge decides whether ε is in the language, because ε has a count of zero. A question that says "at least one" instead of "divisible" is asking you to move the start state's mark, not to add a state.

A machine without a dead state is not a smaller machine

A deterministic machine must have exactly one arrow for every state and symbol. If an arrow is missing, the run dies, which is a third outcome that the five-tuple does not describe.

The standard repair is one dead state that loops to itself on every symbol. It is never mergeable with anything, because it rejects ε while a live state may not. That is exactly the fourth state in "does not contain 111".

2n is a ceiling, not the answer

The subset construction creates one DFA state per reachable subset. On the running four-state NFA only four of the sixteen subsets are reachable, so the DFA has four states before minimisation.

And the ceiling is not a floor either: a four-state NFA can have a one-state minimal DFA. Both facts come from the same question, GATE 2018, and they are the two halves of its option set.

Complement needs a complete deterministic machine

Flipping the accepting marks is correct only when every string has exactly one run and every run finishes somewhere. On an NFA, flipping the marks gives a different language altogether.

The check is mechanical: convert to a DFA, add the dead state if any arrow is missing, then flip. A k-state minimal DFA then yields a complement of at most k states.

The pumping lemma cannot certify regularity

The lemma is necessary for regularity, not sufficient. There exist non-regular languages that satisfy it — for instance any language containing a symbol that never appears in the rest of the alphabet behaves as if pumpable.

So a proof that every legal split pumps proves nothing about regularity. Only a failure proves non-regularity, and only a machine or an expression proves regularity.

Unreachable states are not states

A five-tuple may name a state that no string can reach from the start state. It changes nothing about the language, and it inflates any count.

Delete unreachable states before filling the table. Doing it afterwards gives the same answer here but wastes work, and on a hand-drawn paper diagram it is the commonest source of an answer one too high.

The count is a count of distinctions, not of conditions

Two conditions in an English sentence may imply one another, in which case the pair machine collapses and the answer is smaller than the product. "Divisible by 6" and "divisible by 2 and by 3" are the same language, and each needs six states, but "divisible by 2 or by 3" also needs six while accepting four of them.

The safe procedure is always the same: build the machine that is obviously correct, then minimise it, then read the count off the minimised machine. Guessing the count from the sentence is the step that loses marks.

Six beliefs that cost marks

Each is stated as a learner would state it, then broken with the smallest counterexample available.

1. "An NFA is more powerful than a DFA"

Why it is wrong. Every NFA has an equivalent DFA, built by subset construction. The two accept exactly the same class of languages. Nondeterminism buys shorter descriptions, not new languages.

Where it is tested. Any question that asks which pair of models has different expressive power. DFA and NFA are the pair that does not, and DPDA against NPDA is the pair that does.

2. "The first machine that works is the minimal machine"

Why it is wrong. The obvious machine for "second-to-last symbol is b" remembers the last two symbols and needs seven states. Table filling reduces it to four, and four is what the paper asks for.

Where it is tested. GATE CSE 2017 Set 1, whose answer is 4. The same trap sits inside every "minimum number of states" item.

3. "2n is how many states the DFA has"

Why it is wrong. 2n counts the subsets that exist. The construction builds only the subsets that are reachable, and on the running example that is four out of sixteen.

Where it is tested. GATE CSE 2018 asks which relation is necessarily true; the answer is k ≤ 2n, an upper bound. A question asking for the actual number wants the reachable count.

4. "Contains 011 and ends with 011 are the same question"

Why it is wrong. Both cost four states, which is what makes the confusion so tempting. But 0110 contains 011 and does not end with 011, so the languages differ.

The difference in one arrow. For "ends with", the accepting state falls back to "0" on a further 0. For "contains", it becomes a sink. One arrow, two languages, same state count.

5. "The plus in a regular expression means the character is optional"

Why it is wrong. The plus is union of two whole expressions, and it binds loosest. So a + bc is a or bc, never (a+b)c. Optionality is written with a star or a question mark, never with a plus.

What it costs. A question that asks which expression represents a given machine. Reading the plus as optional produces an expression that accepts strings the machine rejects, which is usually option (A).

6. "To complement a language, flip the accepting states of its NFA"

Why it is wrong. Complementing requires that every string have exactly one run with a defined end. An NFA has many runs and may have none, so flipping its marks produces a language that is neither the complement nor anything else predictable.

The safe route. Convert to a DFA, complete it with a dead state if needed, then flip. Only then is the state count meaningful, and only then is it at most the original count.

Two confusions that are not quite misconceptions

"The pumping lemma proves a language is regular." It cannot. It is a necessary condition, so it refutes and never certifies. A language that satisfies it may still be non-regular, and a proof that only exhibits one pumpable split proves nothing at all.

"The state count equals the number of conditions in the sentence." Conditions can imply one another, and then the pair machine collapses. The reliable procedure is to build the obviously-correct machine, minimise, and read the count off the result.

The test to apply before answering

Ask what the machine must remember about the prefix, and then ask whether two different things it might remember could ever be told apart by a suffix. If they can, they are two states; if they cannot, they are one. Every count, merge, bound and refutation in this lesson is that pair of questions, and both are answerable before any arrow is drawn.

What this clause actually asks

The items quoted across this lesson run from 2011 to 2026. Five patterns account for almost all of them: counting minimal states under a suffix or modulo condition, the NFA-to-DFA bound, expression against machine equivalence, counting strings inside a language, and the statement cluster on closure. The patterns below describe those questions; they are not a forecast.

Pattern 1 — minimal state counting

Give a language in words or as an expression and ask for the smallest DFA. The condition is a suffix, a prefix, a forbidden substring, or a modulo count.

Seen in 2015 Set 2 (3), 2016 Set 2 (2), 2017 Set 1 (4), 2020 (6), 2023 (4), 2025 Set 2 (6). Procedure: name the distinctions, build the obvious machine, minimise, then check the count by exhibiting a distinguishing suffix for every pair you kept.

Pattern 2 — the bound question

Give an NFA with n states and ask what must be true of the minimal DFA's k states. The answer is always one of the two halves of "k ≤ 2n, and no lower bound".

Seen in 2018 Q6, and again in 2025 Set 1 and 2026 Set 1 as multiple-select. Procedure: the upper bound is 2n; the floor is 1; anything in between is possible for some NFA.

Pattern 3 — expression against machine

Show a machine and four expressions, or an expression and four machines. One option is equivalent; the rest differ on a short string.

Seen in 2014 Set 1, 2022, 2023 Q14, 2024 Set 2. Procedure: do not derive the expression. Test the shortest strings — ε, then length 1, then length 2 — against the machine and eliminate. A single witness kills an option.

Pattern 4 — counting strings inside a language

Give two expressions or a length bound and ask how many strings of length at most k are in one, the other, or neither.

Seen in 2024 Set 1 (44) and 2024 Set 2 (15). Procedure: count by length, subtract the union, and remember that ε is a string of length zero that the stars usually contain.

Pattern 5 — the statement cluster

Four one-line claims about closure, nondeterminism or acceptance, and a request for the true ones.

Seen in 2016 Set 2, 2020, 2021 Set 2, 2024 Set 1, 2025 Set 1. Procedure: for each claim, try to build the smallest counterexample. A claim about closure fails fastest when one language is empty or Σ*.

The two wrong approaches that feel right

Drawing until it looks minimal. A picture cannot prove minimality, and the seven-state machine for a four-state language looks perfectly tidy.

Reading the count off the English. "Divisible by 2 but not by 3" mentions two numbers and needs six states, because the conditions share one counter. The sentence and the machine are not the same object.

NATEasyPYQ — GATE CSE 2016 Set 2

The number of states in the minimum sized DFA that accepts the language defined by the regular expression (0+1)*(0+1)(0+1)* is ______.

Answer: 2

The middle group is exactly one symbol and the two stars absorb the rest, so the language is (0+1)(0+1)*, which is "length at least one". Two classes: ε and everything else.

The tempting wrong answer is 3, from building a three-state machine for "contains one symbol" and forgetting that the stars let it loop. Verified here on all 511 strings of length at most eight.

NATMediumPYQ — GATE CSE 2017 Set 1, Q22

Consider the language L given by the regular expression (a+b)*b(a+b) over the alphabet {a,b}. The smallest number of states needed in a deterministic finite-state automaton accepting L is ______.

Answer: 4

The final group (a+b) is one symbol, so L is "length at least 2 and the second-to-last symbol is b". The obvious machine remembers the last two symbols and has 7 states; table filling merges {ε, a, aa} and {b, ab}, leaving 4.

The quotient was checked against the seven-state machine on all 1023 strings of length at most nine. The two archives consulted give 4 as the key.

NATEasyPYQ — GATE CSE 2015 Set 2, Q53

The number of states in the minimal deterministic finite automaton corresponding to the regular expression (0+1)*(10) is ______.

Answer: 3

The language is "ends with 10". Three classes: last symbol is not 1, ends in a single 1, ends in 10. Only the third accepts.

The fourth state people add is for ε, and it is wrong: ε behaves exactly like "last symbol is not 1", so it joins that class rather than forming its own.

NATMediumPYQ — GATE CSE 2023, Q63

Consider the language L over the alphabet {0,1}: L = { w in {0,1}* : w does not contain three or more consecutive 1s }. The minimum number of states in a DFA for L is ______.

Answer: 4

Track the current run of 1s, capped at three. Runs of 0, 1 and 2 are all accepting; a run of 3 is a dead state that loops to itself and never accepts.

Three is the answer only if the machine is left incomplete. Completing it adds the dead state, and the dead state cannot merge with anything because it rejects ε while the other three accept it. One archive prints this item with options; the paper's answer is 4 either way.

NATMediumPYQ — GATE CSE 2020

Consider the language L = { x in {a,b}* : the number of a's in x is divisible by 2 but not divisible by 3 }. The minimum number of states in a DFA that accepts L is ______.

Answer: 6

One counter modulo 6 suffices, because both conditions are conditions on the count of a. The accepting residues are 2 and 4: a count of 0 is divisible by both 2 and 3, so residue 0 is excluded.

All six residues stay pairwise distinguishable, so nothing merges. Marking residue 0 accepting is the error that produces 3 accepting states and a wrong machine.

MCQEasyPYQ — GATE CSE 2018, Q6

Let N be an NFA with n states. Let k be the number of states of a minimal DFA which is equivalent to N. Which one of the following is necessarily true?

(A) k ≥ 2n   (B) k ≥ n   (C) k ≤ n2   (D) k ≤ 2n

Answer: (D) k ≤ 2n

Each DFA state is a set of NFA states, and there are 2n such sets, so no equivalent DFA can need more than that. It is an upper bound on the blow-up, which is why nondeterminism can be exponentially more compact.

(B) is the tempting one and it is false: a four-state NFA whose only reachable subset is a single looping accepting state has a one-state minimal DFA. This page builds that NFA and confirms the count.

NATMediumPYQ — GATE CSE 2024 Set 1

Consider two regular expressions over {0,1}: r = 0* + 1* and s = 01* + 10*. The total number of strings of length less than or equal to 5 which are neither in r nor in s is ______.

Answer: 44

There are 20+21+…+25 = 63 strings of length at most 5. L(r) contributes ε and the two all-equal strings at each length, 11 in total. L(s) adds 01* and 10*, which are new at every length from 2 upwards, 8 more. The union has 19, so 63 − 19 = 44.

By length the excluded strings are 1, 2, 4, 4, 4, 4, so the answer splits as 0, 0, 0, 4, 12, 28. Three archives give 44 and this page recomputes it.

NATHardPYQ — GATE CSE 2025 Set 2

Let Σ = {1,2,3,4}. For x in Σ*, let prod(x) be the product of the symbols in x modulo 7, with prod(ε) = 1. Define L = { x in Σ* : prod(x) = 2 }. The number of states in a minimum state DFA for L is ______.

Answer: 6

Start at residue 1 and multiply. The symbol 3 cycles through 1, 3, 2, 6, 4, 5, so every nonzero residue is reachable and 0 never is. Six states, with residue 2 accepting.

Nothing merges: for distinct residues r and s, a string of repeated 3's separates them, because multiplication by a power of 3 is a bijection on the six nonzero residues. This page checks all 340 strings of length at most four against the definition of prod, then confirms minimality.

MCQHardOriginal practice — counterexample

Which statement about the two languages A = { w in {0,1}* : w contains 011 } and B = { w in {0,1}* : w ends with 011 } is TRUE?

(A) A and B need different minimal state counts, because B must remember a suffix and A need not.
(B) A and B both need exactly 4 states, and 0110 is in A but not in B.
(C) A ⊂ B, because every string that contains 011 also ends with it.
(D) B ⊂ A, so the two minimal machines differ only in which state is accepting.

Answer: (B)

Both machines have four states. For B the accepting state falls back to "0" when it reads a 0; for A the accepting state is a sink. The witness 0110 is in A and not in B, so the languages differ.

(A) is wrong because the counts are equal — which is exactly what makes this pair worth a question. (D) has a true premise and a false conclusion: B really is a subset of A, because every string ending in 011 contains it — the page checks all 255 strings up to length seven. But the machines are not the same machine with a different accepting state: one has a sink, the other has a fallback arrow, and that arrow is what the languages turn on. (C) reverses the containment.

Revision sheet

Definitions, procedures and traps, in the order a question uses them.

Definitions, one line each

  • Language — any subset of Σ*, the set of all strings over the alphabet.
  • DFA — (Q, Σ, δ, q0, F) with δ single-valued and total.
  • NFA — the same, but δ(q, a) is a set, possibly empty.
  • ε-closure(S) — S plus everything reachable from S by ε-arrows alone.
  • Reachable subset — a set of NFA states some string can actually produce.
  • Distinguishable — some suffix w puts exactly one of uw, vw in L.
  • Minimal DFA — one state per class of indistinguishable strings.
  • Regular expression — a finite expression over symbols, ε, ∅, union, concatenation, star.
  • Pumping length — a bound p such that every longer string splits as xyz with y non-empty and xykz in L.

Procedures, four steps each

Minimise. Delete unreachable states → mark pairs differing on acceptance → propagate through transitions → read the unmarked classes.

NFA to DFA. Close the start set → for each state and symbol take the union of targets and close → add if new → mark accepting if it meets F.

Expression to machine. Two states per symbol → union and star add two states and ε-arrows → concatenation fuses at a shared state → then minimise.

Refute regularity. Assume p → choose a string longer than p → show every split fails for some k → conclude.

Counts worth memorising, with their reasons

  • Ends with a word of length m → m+1 states.
  • Does not contain a word of length m → m+1, the last one a dead state.
  • Contains a word of length m → m+1, the last one a sink.
  • Count of one symbol modulo m → m states.
  • Two independent moduli → at most m·n states, minimal size divides it.
  • Complement of a k-state minimal DFA → at most k states.
  • n-state NFA → at most 2n DFA states, and at least 1.

Traps, one line each

  • Contains is not ends with, even at equal cost.
  • A missing arrow is a dead branch, not a rejection rule.
  • Residue 0 is divisible by every modulus.
  • Unreachable states must be deleted before counting.
  • 2n is a ceiling, never a floor.
  • Complement only works on a complete deterministic machine.
  • The pumping lemma refutes and never certifies.
  • ε is a string, of length zero, and the stars usually contain it.
  • The obvious machine is almost never the minimal one.
  • In an expression, plus binds loosest.

The one sentence

How much of the input must the machine remember, and how few states can hold those distinctions? Construction answers it, counting prices it, minimisation removes the excess, and the pumping lemma proves when no finite number of states will do.
