Topic and objective

TOPIC: Instruction set and addressing modes — the first clause of GATE 2027 Section 3: "Instruction set and addressing modes."

LEARNING OBJECTIVE: Given a word length, a number of instructions, a number of registers and a list of fields, derive every field width and check that they spend the word exactly. Given an instruction set with two or three formats, count how many opcodes each format buys and say why the counts do not simply add. Given a machine state — registers, memory, program counter — compute the effective address of eight common modes and the number of memory reads each costs. Given a branch target and an instruction length, produce the signed PC-relative offset. Given a high-level statement and a load-store machine, write the instruction sequence.

I read this topic as two questions with one habit. The habit is: never read a field, always decode it. The two questions are "how many bits does each field get?" and "what address does this field finally produce?". Every previous-year item on this clause is one of those two, asked in a different costume. The register, ALU and flag machinery used in the last scenes is built in ALU and Control Unit Design, and the byte-level representation used for scaling and byte order is built in Number Representation and Arithmetic.

Prerequisites

This lesson needs four small pieces of machinery, all of which have their own lessons:

  • Powers of two, and the ceiling of a base-two logarithm. Every field width here is "the smallest b with 2b ≥ n". Nothing harder is used.
  • Two's complement. A branch offset is signed, and its range is asymmetric. Built in Number Representation and Arithmetic.
  • What a register and an ALU are. The effective-address arithmetic is done by the ALU; the register file is what makes register-indirect addressing possible. Built in ALU and Control Unit Design.
  • Byte addressing and byte order. Element scaling and the little-endian questions both assume a byte-addressable machine. Also in Number Representation and Arithmetic.

Nothing is assumed about caches, pipelines or control-unit design. Where a question needs a memory access time or a cycle count, the paper gives it.

The five ideas to leave with

  1. The instruction set is the contract a compiler may rely on. Cache size and clock speed are not in it.
  2. Field widths are forced: each names one of n things, so it costs the ceiling of log base two of n, and the widths must sum to the word length.
  3. Two formats with different opcode widths are two separate encoding spaces. Their opcode counts do not compete.
  4. An addressing mode is a recipe for one address. Count memory reads for the operand, then decide separately whether the fetch is included.
  5. A branch stores a signed distance from the next instruction, not an address.

Intuition: the order form and the shelf number

A warehouse clerk receives a form for every job. The form has boxes: what to do (fetch, add, store), which trolley (a register), and where on the shelf (an address, or a hint at one). The clerk never decides anything the form does not say. That is the instruction set: the complete list of forms the clerk is trained to accept, and what each box means.

Three facts about this arrangement are the three facts about an instruction set, and each is easy to get wrong. First, the boxes are a fixed width — the form is a fixed number of boxes, so making the "what to do" box wider means taking width from somewhere else. Second, "where on the shelf" is not always a shelf number: sometimes it is "the shelf number written on the trolley", or "this many shelves past the trolley", and the clerk must know which, because the answer changes. Third, the form says nothing about how fast the clerk walks. Speed is not on the form, and a form that mentioned it would have to be reprinted whenever the clerk changed shoes.

Educational interpretation The analogy is a teaching device, not a model of a processor. It is chosen because it keeps three separate questions separate: how the bits are divided, what address the bits finally name, and which facts a program is allowed to depend on.

The instruction set architecture

The instruction set architecture, or ISA, is the programmer-visible interface of a processor: the set of instructions, their encodings, the registers a program may name, the addressing modes, the data types and their sizes, and the memory model — address width, byte addressability and byte order.

The microarchitecture is how one chip implements that interface: cache sizes and levels, clock frequency, pipeline depth, the number of physical registers behind the architectural ones. Two chips with the same ISA run the same binary at different speeds.

The test for "is it in the ISA?"

Ask: could a compiler emit an instruction that depends on this fact? If the answer is no, the fact is implementation.

A compiler can emit ADD R1, R2, R3 only because it knows there are at least four registers, and the encoding fixes how many exist. It cannot emit anything that depends on the L2 cache being 512 KB, because nothing in the instruction stream can observe that.

The instruction word, and the three quantities it fixes

An instruction format is a fixed partition of the instruction word into fields. Three kinds of field recur: the opcode, which names the operation; one or more register fields, each naming one of the machine's registers; and a constant field — an immediate value, a displacement, or a jump offset — whose meaning depends on the mode.

The widths are not a design choice in the questions. A field that must name one of n things needs the smallest b with 2b ≥ n bits, which is written ⌈log2 n⌉. So the whole format is one equation: the sum of the field widths equals the word length.

Addressing mode and effective address

An addressing mode is the rule that turns the fields of an instruction, together with the machine state, into the location of an operand. The address it produces is the effective address.

The machine state the rule may consult is exactly: the program counter, the registers named by the instruction, and — in the indirect modes — the contents of memory.

A mode is not a property of the instruction word alone. The same bit pattern in the address field means a different address under direct and under indirect, which is why a question must tell you the mode.

Load-store, and register-memory

A load-store architecture allows only load and store to name memory. Every arithmetic instruction has all its operands in registers.

A register-memory architecture allows an arithmetic instruction to take one operand from memory directly. Both are legitimate designs; the difference decides whether a sequence of instructions is legal, which is what GATE 2026 Set 1 asked.

Two rows that look identical and are not

Displacement and indexed both compute register plus something. The difference is which part varies at run time. In displacement the constant is in the instruction and the register is fixed for the whole loop; the constant selects a field. In indexed the register varies and the constant is the element size; the register selects the element. If the thing that changes from one access to the next is a field name, it is displacement. If it is an element number, it is indexed — and then the index is scaled.

Worked example 1 — three real bit budgets

In each case the method is the same three lines: list the fields, take the ceiling of log base two of each count, and set the sum equal to the word length. The unknown is whatever is left.

PYQ GATE 2014 Set 1, Q9

A 32-bit architecture with one-word instructions has 64 registers, each 32 bits long. It must support 45 instructions, each with an immediate operand in addition to two register operands. The immediate is unsigned. What is its maximum value?

1Opcode: 45 instructions need ⌈log2 45⌉ = 6 bits, because 25 = 32 is not enough and 26 = 64 is.
2Register fields: ⌈log2 64⌉ = 6 bits each, so 12 for two operands.
3Immediate: 32 − 6 − 12 = 14 bits.
4Largest unsigned 14-bit value: 214 − 1 = 16383.

Answer 16383. The register width of 32 bits is a distractor: a register field names a register, so it costs six bits regardless of how wide the register is.

PYQ GATE 2025 Set 1, Q37

A processor has 64 general-purpose registers and 50 distinct instruction types. An instruction is encoded in 32 bits, and the instruction shown is ADD R1, #25. What is the maximum number of bits for the immediate operand?

1Opcode: ⌈log2 50⌉ = 6 bits.
2Registers: ⌈log2 64⌉ = 6 bits — and only one register is encoded, because the # marks the other operand as an immediate.
3Immediate: 32 − 6 − 6 = 20 bits.

Answer 20. The whole question turns on reading ADD R1, #25 as one register and one constant. If you assume two register operands you get 14, which is the trap.

PYQ GATE 2024 Set 2, Q57

A processor with 16 general-purpose registers uses a 32-bit instruction format consisting of an opcode field, an addressing-mode field, two register operand fields and a 16-bit scalar field. If 8 addressing modes are supported, what is the maximum number of unique opcodes?

1Registers: 2 × ⌈log2 16⌉ = 8 bits.
2Addressing modes: ⌈log2 8⌉ = 3 bits.
3Scalar: 16 bits, given.
4Opcode: 32 − 8 − 3 − 16 = 5 bits, so 25 = 32 opcodes.

Answer 32. The question asks for opcodes, not for the opcode width; five bits buys thirty-two distinct codes.

Worked example 2 — a 16-bit instruction with three formats

Design: 16 registers, so a register field is 4 bits. Three formats are wanted: three registers, two registers, and one register. With one fixed opcode field the answer would be "whatever the widest format leaves", which wastes the narrow ones. The escape trick instead chains them.

The three formats

FormatOpcode bitsOperand bitsCodes
A: three registers41215
B: two registers8815
C: one register12415

Format A uses codes 0000 to 1110. Code 1111 means "the opcode continues", so the next four bits are a second opcode field. In format B, codes 0000 to 1110 are two-register instructions and 1111 continues again. In format C, 0000 to 1110 are one-register instructions and 1111 1111 1111 is unused.

Why the counts are 15 and not 16, and why the sum is not 45

Each format gives up exactly one code to the escape, so it keeps 16 − 1 = 15. The three counts cannot be added as "45 opcodes", because a code of one length is not a code of another length: format A's 15 codes each stand for 212 distinct instruction words, format B's for 28, and format C's for 24.

Check (Kraft): 15/16 + 15/256 + 15/4096 = 0.99976 ≤ 1, so the design fits in the 16-bit space with one 12-bit prefix unused. If the sum had exceeded 1, some encodings would be reachable two ways and the scheme would be broken.

The prefix test, done mechanically

A set of opcodes is decodable exactly when no code is a prefix of another. Here no shorter code begins with 1111, and every longer code begins with it, so the test passes by construction. The lesson's model builds all 45 codes and checks every ordered pair for the prefix relation, and it checks the Kraft sum; both appear in the Model checks panel. This is the step most hand solutions skip, and it is what makes the escape trick legal rather than merely convenient.

PYQ GATE 2020, Q44

A processor has 64 registers and a 16-bit instruction format with two types. Each I-type instruction has an opcode, one register name and a 4-bit immediate. Each R-type has an opcode and two register names. If there are 8 distinct I-type opcodes, what is the maximum number of R-type opcodes?

Register field = 6 bits. I-type: 16 − 6 − 4 = 6 opcode bits. R-type: 16 − 6 − 6 = 4 opcode bits, so 24 = 16.

The eight used I-type codes live in a six-bit space; the R-type codes live in a four-bit space. They are disjoint, so nothing is subtracted.

Worked example 3 — eight effective addresses from one state

State: byte-addressable memory, four-byte words. R1 = 2000, R2 = 3, R3 = 4096, PC = 400. Memory: 2000 → 7, 2004 → 8, 2008 → 9, 2012 → 11, 4096 → 5, 4104 → 9, 5000 → 2000, 496 → 42. Work each row before reading the answer column.

The four that need no address arithmetic

1Immediate, field 25. The operand is 25. No address, no read.
2Register, field R2. The operand is R2, which is 3. No read.
3Direct, field 2012. Effective address 2012, operand mem[2012] = 11. One read.
4Register indirect, field R1. Effective address R1 = 2000, operand 7. One read.

Direct and register indirect cost the same one read. What differs is where the address came from — the instruction word or a register — and therefore whether it can change at run time.

The four that do

5Memory indirect, field 5000. Read mem[5000] = 2000, then read mem[2000] = 7. Two reads.
6Displacement, field 8, base R3. 4096 + 8 = 4104, operand 9. One read.
7Indexed, field R2, base R1. 2000 + 3 × 4 = 2012, operand 11. One read.
8PC-relative, field 96. 400 + 96 = 496, operand 42. One read.

Row 7 is the one that catches people: 2000 + 3 = 2003 is not an element boundary on a four-byte machine. The index is a count of elements, so it is multiplied by the element size before it is added.

Worked example 4 — a branch offset, and a load-store sequence

Two previous-year questions that are pure procedure once the convention is stated.

PYQ GATE 2017 Set 1, Q49

A RISC machine has four-byte instructions. Branch instructions use PC-relative addressing with the offset in bytes, measured from the address of the next instruction. The branch is the fourth instruction in the sequence and its target is the first. Give the offset.

1Let the first instruction be at address i. Four instructions of four bytes occupy i to i + 15.
2The branch is the fourth, at i + 12. The next instruction is at i + 16.
3Offset = target − next = i − (i + 16) = −16.
4Check forward: next + offset = (i + 16) + (−16) = i, the target.

Answer −16. Measuring from the branch itself would give −12, which is the standard wrong answer.

PYQ GATE 2026 Set 1, Q15

Processor P has a load-store architecture. The first operand of every instruction is the destination. Which sequence implements Z = X + Y, where X, Y and Z are memory operands and R0, R1, R2 are registers?

1LOAD R0, X — memory to register, allowed.
2LOAD R1, Y — memory to register, allowed.
3ADD R2, R0, R1 — all three operands in registers, allowed.
4STORE Z, R2 — register to memory, allowed.

Answer: that four-instruction sequence. The distractors were ADD Z, X, Y; LOAD R0, X then ADD Z, R0, Y; and ADD R0, X, Y then STORE Z, R0. Each puts at least one memory operand inside the add.

Boundaries where the usual sentence stops being true

Each card names the condition the case breaks. If you can name the condition, you can usually see which of two answers the question wants.

A field of b bits does not hold 2b

It holds 2b patterns, numbered 0 to 2b − 1. An unsigned 14-bit immediate therefore reaches 16383, and a signed 14-bit one reaches −8192 to +8191.

Broken condition: "largest value equals number of patterns". True only for one bit.

An operand value of 0 and an address of 0 are different facts

Under immediate mode the field 0 means the operand is zero. Under direct mode the field 0 means the operand lives at address 0. Under indirect mode the field 0 means "read address 0, and the operand is at whatever address is stored there".

Broken condition: "the address field is the operand". That is only the direct mode.

A branch offset of zero is legal

Offset 0 means "the target is the next instruction", which is a fall-through that happens to be encoded as a branch. It is not an error and it is not an infinite loop; a backward loop needs a negative offset.

Broken condition: "a branch must change the control flow". The encoding does not promise that.

A two-word instruction is two fetches, not one

On a machine whose instruction is two words, the second word holds the address field and is fetched separately. A question that says "in the execution cycle" excludes both fetches; one that says "to fetch and execute" includes both.

Broken condition: "the instruction costs one memory access". True only for a one-word instruction.

Autoincrement by one is wrong for anything wider than a byte

The register advances by the size of the item accessed, because advancing by one would land inside the next element. This is exactly what GATE 2008 Q33 tested: of the three statements about autoincrement, only "the amount depends on the size of the data item" is true.

Broken condition: "increment means add one".

Scaling applies to an element number, not to a byte offset

In A[i] the index i is a count of elements, so the machine multiplies it by the element size. In S.grade the offset is already a byte count computed by the compiler, so it is added unchanged.

Broken condition: "indexed mode always scales". It scales when the field is an element number.

Zero-address does not mean zero work

A zero-address instruction names no operand, but it still pops its operands from a stack that lives in memory or in registers, and the stack pointer still moves. The instruction is short; the work is not absent.

Broken condition: "no address field means no addressing".

Two formats with different opcode widths do not compete

In GATE 2020 Q44 the I-type opcode field is six bits and the R-type field is four. Eight used I-type codes leave the entire four-bit R-type space free, so the answer is 16, not 8.

Broken condition: "all opcodes share one space". They share a space only when the field is the same width.

Six wrong beliefs, each with the smallest counterexample

Each card gives the belief, why it is tempting, and the one case that settles it. The counterexample is deliberately the smallest one that can exist.

"Cache size is part of the architecture"

Why it tempts: datasheets list cache size next to the instruction set, and the word "architecture" is used loosely in marketing.

Minimal counterexample: two x86 chips with 256 KB and 1 MB of L2 run the same compiled binary unchanged. If cache size were in the ISA, the binary would have to differ.

Correct rule: the ISA is what a compiler may depend on. GATE 2025 Set 2 Q28 accepts only "the total number of registers" out of cache size, clock frequency, number of cache levels and register count.

"Memory indirect is one memory access"

Why it tempts: the mode is named after one idea — follow a pointer — so it feels like one step.

Minimal counterexample: with the pointer at 5000 holding 2000, reaching the operand needs a read of 5000 and a read of 2000. Stop after one read and you have the pointer, not the operand.

Correct rule: indirect is two reads. Register indirect is one, because the pointer is already in a register.

"An n-bit immediate reaches 2n"

Why it tempts: the number of patterns really is 2n, and the difference of one looks like rounding.

Minimal counterexample: a one-bit unsigned field holds 0 and 1, so its maximum is 1, not 2. The pattern count and the maximum differ by exactly one at every width.

Correct rule: maximum unsigned = 2n − 1. Maximum signed = 2n−1 − 1, with minimum −2n−1.

"The branch offset is measured from the branch"

Why it tempts: the branch is the instruction you are looking at, so it feels like the origin.

Minimal counterexample: GATE 2017 Set 1 Q49. Measured from the branch the answer is −12; from the next instruction it is −16, which is the official answer.

Correct rule: offset = target − address of the next instruction. Always check by adding it back.

"Base with index and base with displacement are the same mode"

Why it tempts: both compute base plus something, and many textbooks use "indexed" for both.

Minimal counterexample: GATE 2026 Set 1 Q14 offers both and asks which maps to an array element and which to a record field. Only base-with-index matches the array, because only there does the varying part need scaling.

Correct rule: the varying part decides the name. Element number → base with index. Fixed field offset → base with displacement.

"A bigger opcode field always means fewer instructions"

Why it tempts: within one format, more opcode bits do buy more opcodes, and that sentence is true there.

Minimal counterexample: in a two-format design, shrinking the opcode field from six bits to four reduces that format's opcodes from 64 to 16 — but if the six-bit codes were only eight used, nothing is lost and the four bits buy a separate 16.

Correct rule: compare within a format. Across formats of different opcode widths, the encoding spaces are disjoint.

The one habit that answers most of these

Before computing anything, write down what the field names: an operation, a register, a value, an address, or a distance. Almost every error on this clause is a field read as the wrong one of those five.

Twelve questions

Three single-correct, three multiple-select and six numerical. Answers are hidden until you reveal them, one at a time, or all at once with the mock-test switch. Every previous-year question carries its year and paper; everything else is labelled as original practice written for this lesson.

MCQoriginal practiceeasy

A processor has a 24-bit instruction word, 32 registers and 60 distinct instructions. Each instruction has an opcode and two register operands. How many bits are left for an immediate operand?

  1. 6
  2. 8
  3. 10
  4. 12

Answer: B, 8 bits. Opcode: ⌈log2 60⌉ = 6. Two register fields: 2 × ⌈log2 32⌉ = 10. Immediate: 24 − 6 − 10 = 8.

Why the others are wrong. 6 comes from forgetting one register field (24 − 6 − 5 = 13, so no) or from using ⌈log2 60⌉ twice. 10 is the register-field total, not the remainder. 12 comes from using a five-bit opcode, which is the rounding-down error: 25 = 32 < 60.

Shortcut and its assumption. "Sum the ceilings and subtract" works only when every field width is independent, which it is here. It fails the moment one format has a variable-length opcode.

MCQPYQGATE 2011 Q21

A processor has an instruction LW R1, 20(R2), which reads a 32-bit word from memory into R1. The effective address is the sum of the constant 20 and the contents of R2. Which addressing mode does this use for the memory operand?

  1. Immediate addressing
  2. Register addressing
  3. Register indirect scaled addressing
  4. Base indexed addressing

Answer: D. A register supplies the base and a constant supplies the offset, which is the base-plus-displacement (base-indexed) form.

Why the others are wrong. Immediate would mean the operand is 20 itself. Register addressing would mean the operand is inside R2, with no memory read at all. "Register indirect scaled" would mean an index register multiplied by a scale factor, and here nothing is scaled — the 20 is a byte displacement, not an element number.

Edge case. The same syntax with a scale, as in LW R1, (R2)[R3], would be indexed mode. The presence of a constant does not by itself make a mode indexed.

MCQoriginal practiceeasy

Which addressing mode allows a program to be loaded at any address and run without changing a single bit of its code, and without reloading any register?

  1. Direct addressing
  2. Base register addressing
  3. PC-relative addressing
  4. Memory indirect addressing

Answer: C. Both the offset and the program counter move together, so the computed address is unchanged and nothing at all has to be adjusted.

Why the others are wrong. Direct addressing stores absolute addresses, which are wrong as soon as the program moves. Base register addressing keeps the code unchanged but the base register must be reloaded — which is why GATE 1998, whose wording is "without any change whatsoever in the code", takes PC-relative while GATE 2004, whose wording is "suitable for relocation at run time", takes both base and relative.

Distinction to keep. "No change to the code" and "no change at all" are different requirements, and two papers chose the two different answers on purpose.

MSQPYQGATE 2025 Set 2 Q28

Which of the following is/are part of the Instruction Set Architecture of a processor?

  1. The size of the cache memory
  2. The clock frequency of the processor
  3. The number of cache memory levels
  4. The total number of registers

Answer: D only. The number of architectural registers is fixed by the ISA, because instructions must name registers with a field of a defined width.

Why the others are wrong. Cache size, cache levels and clock frequency are all microarchitecture. Two chips implementing the same ISA may differ in all three, and the same binary runs on both.

The test that generalises. Could a compiler emit an instruction that depends on this fact? It can depend on how many registers exist. It cannot depend on how big the cache is.

MSQoriginal practicemedium

A byte-addressable machine has four-byte words. Which statements about memory indirect addressing are true?

  1. It requires two operand memory reads.
  2. It is the natural encoding of a pointer variable.
  3. It costs the same number of operand reads as register indirect addressing.
  4. Its effective address is the contents of the memory location named in the instruction.

Answer: A, B and D.

Why C is wrong. Register indirect costs one read, because the pointer is already in a register. Memory indirect costs two, because the pointer itself must be fetched.

Why D is worth stating carefully. The effective address is what the pointer holds, not the pointer's own location. With the pointer at 5000 holding 2000, the effective address is 2000 and the operand is at 2000.

Edge case. If the pointer is held in a register instead, the mode is register indirect and the cost drops to one read — the arithmetic is the same, the storage of the pointer is not.

MSQPYQGATE 2008 Q33

Which of the following is/are true of the auto-increment addressing mode?

  1. It is useful in creating self-relocating code.
  2. If it is included in an ISA, an additional ALU is required for effective address calculation.
  3. The amount of increment depends on the size of the data item accessed.

Answer: III only.

Why I is wrong. Autoincrement works from an absolute register value, so moving the program invalidates it. Self-relocating code needs PC-relative or base addressing, where the operand is an offset rather than an address.

Why II is wrong. The increment can be done by a small adder in the address-generation path, exactly as the program counter is incremented. No extra ALU is required.

Why III is right. Advancing by one would land inside the next element on any machine whose items are wider than a byte. The step is the item size.

NATPYQGATE 2014 Set 1 Q9

A machine has a 32-bit architecture with one-word instructions and 64 registers, each 32 bits long. It supports 45 instructions, each with an unsigned immediate operand in addition to two register operands. What is the maximum value of the immediate operand?

Answer: 16383.

Work. Opcode 6 bits, two register fields 6 bits each, immediate 32 − 6 − 12 = 14 bits. Largest unsigned 14-bit value = 214 − 1 = 16383.

Traps. 16384 is the pattern count, not the maximum. Using a five-bit opcode gives 15 immediate bits and 32767, which is the answer to a different question. The 32-bit register width is irrelevant: a field names a register rather than holding one.

NATPYQGATE 2025 Set 1 Q37

A processor has 64 general-purpose registers and 50 distinct instruction types. An instruction is encoded in 32 bits, and the instruction is ADD R1, #25. What is the maximum number of bits that can be used for the immediate operand?

Answer: 20.

Work. Opcode ⌈log2 50⌉ = 6 bits. One register field ⌈log2 64⌉ = 6 bits. Immediate = 32 − 6 − 6 = 20.

The trap. Assuming two register operands, which gives 14. The # in the operand list is the signal that the second operand is a constant carried in the instruction, not a register name.

NATPYQGATE 2024 Set 2 Q57

A processor with 16 general-purpose registers uses a 32-bit instruction format: an opcode field, an addressing-mode field, two register operand fields and a 16-bit scalar field. If 8 addressing modes are supported, what is the maximum number of unique opcodes?

Answer: 32.

Work. Registers 2 × 4 = 8 bits; addressing modes 3 bits; scalar 16 bits. Opcode = 32 − 8 − 3 − 16 = 5 bits, so 25 = 32 opcodes.

Traps. Answering 5 (the width, not the count). Forgetting the addressing-mode field, which gives 40. Using 8 registers per field instead of 16.

NATPYQGATE 2020 Q44

A processor has 64 registers and a 16-bit instruction format with two instruction types. Each I-type instruction contains an opcode, a register name and a 4-bit immediate. Each R-type instruction contains an opcode and two register names. If there are 8 distinct I-type opcodes, what is the maximum number of R-type opcodes?

Answer: 16.

Work. Register field 6 bits. I-type opcode = 16 − 6 − 4 = 6 bits. R-type opcode = 16 − 6 − 6 = 4 bits, so 24 = 16.

The trap. Subtracting 8 from 64 and treating the remainder as available R-type opcodes. The two opcode fields have different widths, so they are different encoding spaces and do not compete.

NATPYQGATE 2017 Set 1 Q49

A RISC machine has four-byte instructions. Branches use PC-relative addressing with the offset in bytes, measured from the address of the next instruction. The branch is the fourth instruction of a sequence and its target is the first instruction, at address i. Give the decimal value of the offset.

Answer: −16.

Work. Branch at i + 12, next instruction at i + 16, target i. Offset = i − (i + 16) = −16.

Traps. −12 (measuring from the branch), +16 (wrong direction), and 16 (dropping the sign). Check by adding: (i + 16) + (−16) = i.

NAToriginal practicemedium

Memory is byte addressable and an integer is four bytes. Register R1 holds 5000, the base address of an array of integers, and R2 holds 7, an element number. Using indexed addressing with R1 as base and R2 as index, what effective address is produced?

Answer: 5028.

Work. Element 7 of a four-byte array begins 7 × 4 = 28 bytes past the base: 5000 + 28 = 5028.

The trap. 5007, which forgets the scaling. On a byte-addressable machine the index is a count of elements, so it is multiplied by the element size before being added.

Distinction. If the field had been a byte offset, as it is for a record field, no scaling would apply and 5007 would be correct. The mode name does not decide this; what the field means does.

The revision sheet

One screen. If a line here is not obvious, the tab that explains it is named beside it.

Widths

A field naming one of n things: ⌈log2 n⌉ bits.
Unsigned maximum: 2b − 1.
Signed range: −2b−1 to 2b−1 − 1.
Format: sum of field widths = word length.

Two formats with different opcode widths have disjoint opcode spaces.

Addresses

Immediate: value in the instruction, 0 reads.
Register: value in a register, 0 reads.
Direct: address in the instruction, 1 read.
Register indirect: address is R, 1 read.
Memory indirect: address is mem[field], 2 reads.
Displacement: Rbase + constant, 1 read.
Indexed: Rbase + Rindex × element size, 1 read.
PC-relative: PC + signed offset, 1 read.
Autoincrement: address is R, then R += element size.

Add one read per instruction word if the question includes the fetch.

Constructs

Constant → immediate.
Pointer → indirect (memory or register).
Array element → base with index (scaled).
Record field → base with displacement (unscaled).
Loop or branch → PC-relative.
Array walk → autoincrement / autodecrement.

Branch offsets

offset = target − address of the next instruction.
Check: next + offset = target.
Backward branch ⇒ negative offset.
Offset 0 means fall through to the next instruction.

Architectures

Load-store: only load and store name memory.
Register-memory: arithmetic may take one memory operand.
RISC: register-to-register, fixed length, hardwired control.
CISC: variable length, memory operands, often microprogrammed.

The five traps

1. Forgetting the instruction fetch (or including it when the question says execution cycle).   2. Forgetting to scale an index.   3. Charging memory indirect as one read.   4. Writing a branch offset unsigned, or measuring from the branch.   5. Calling cache size or clock frequency part of the architecture.
